Continuous scene contract:

One model state owns parameters, semantic_state, transition_progress and playing. semantic_state counts completed real steps; transition_progress in [0,1) is visual progress toward the next step. An endpoint becomes the next semantic step at progress zero. Keep the mathematical update computed at a step's start distinct from the visually interpolated point; label them separately when both appear. Parameter changes pause and recompute from the initial condition, resetting step/progress.

Define renderAt(parameters, semantic_state, transition_progress) so forward, backward and repeated positioning rebuild identical geometry and only the trajectory up to that point. Expose window.presentationScene.seek({semantic_state,transition_progress}) and snapshot() returning those fields plus playing. The public seek takes ONE OBJECT: wrap an internal two-argument function. seek stops playback, renders the target and resolves with playing=false. snapshot reports the actual playing state while the timer advances; only seek forces it false. A sequence of static reveals cannot substitute for requested continuous motion.

Provide keyboard-accessible play/pause, backward and local position controls when time is part of the explanation. The preview seek API is not a reader control. A position slider can map q to floor(q) and q-floor(q) through the same seek used by preview and restoration. Keep controls near the change they operate. Save both semantic_state and transition_progress under page values and restore them through the same paused positioning path; saving only a completed step loses the paused frame.

Preview a supported nonzero fractional position, move backward, then repeat it; inspect both screenshot and returned scene and repair scene_position_mismatch or scene_changed_during_capture. Exercise relevant stationary and boundary parameters from the actual model. Zero-magnitude updates must hide the entire arrow including the arrowhead, preserving the stationary object. Apply the model's boundary meanings consistently to legends, labels and prose. Check actual geometry as well as reported values.
