# 用新对象重做装配或剖切

两件作品共享指针／键盘绕物观察、自适应取景与按需重绘；主题几何、色彩、读数和布局分别实现。完整 index.html 已内联 stage.js，正式 write 需声明 libraries:["three"]，使用宿主冻结的本地库。不要加载 CDN。没有 WebGL 时仍保留对应的平面图和读数。

装配时先选定观察面和各件的安装方向，把零件写成独立组。每件的位置等于安装位置加上拆解比例乘以展示位移。环、孔或腔体要在几何上贯通。让轮廓、材料和随物体移动的标签共同标出相邻部件。换题时依新物件重做形体、连接和装配顺序；实际工作状态和拆开展示状态应有各自的说明。

剖切：先规定数学轴与渲染轴，切口上的点应同时属于物体表面与切平面。改变相机只改变观察；改变剖面才改变读数。需要真实形态的器官、遗物等应有领域几何或插画依据，不能把占位球当作成品。

按新模型改写 DOM 读数、初始状态和恢复定义。分别检查装配、中段、完全展开和第二视角，看实体及其连接处；将结果与一次独立计算或结构参照比对。
