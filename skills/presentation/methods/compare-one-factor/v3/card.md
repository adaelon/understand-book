# 固定条件，只改变一个因素

method_id: `compare-one-factor` · revision: `3` · 状态：同页演示与接手

沿用 @2 的同起点、共同时间、共用尺度跑道与距离曲线。新增待应用输入、教师动作、分步揭示与可恢复的帮助现场。

先读共同时间和已经显示的速度，再只改变 B 的输入。应用后对照 A、B 的距离，揭示距离与速度的关系；每一步依据真实回执继续。教师结束后，学习者可以直接改参、拖动时间或提问。无需强制回答才能继续演示。
