已有缓存改变了“这一次还要算哪些对象”。省去了旧位置的新投影和旧 query 行；新 query 仍要访问已有的全部 key，并包括自己的 key。

这个教学模型的条件与边界
  • 单序列、因果注意力；每个 query 可以看到当前位置及之前的位置。计数包含自身。
  • “缓存后补一个”从已经存在的 N 个位置的 KV 缓存出发，再处理第 N+1 个位置；它的可见 key 数为 N+1。
  • 只数本次新投影的位置行数、有效 query–key 配对数和词表投影行数。Q、K、V 等具体矩阵的乘法次数、模型宽度、层数都未计入。
  • 本例仅对最后位置做词表投影。训练或需要所有位置分数的实现，输出行数会不同。
  • 有效因果配对数不等于 kernel 一定执行了同样数量的乘加，也不直接等于延迟。完整资源核算仍需具体实现、矩阵形状与硬件条件。

独立构造的教学示范 · 从对象计数进入公式；精确核对与完整条件保留在展开区。
