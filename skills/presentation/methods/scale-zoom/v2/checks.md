# 保留定位的尺度缩放：具体预期

1. q=0/1/2/3：视野1 m/10 cm/1 cm/1 mm，目标宽度占窗口0.1%/1%/10%/100%。
2. 目标 SVG 宽度=0.6×10^q；全景窗口宽度=580/10^q；标尺始终占局部窗口的1/5。
3. focus=0.0005,q=3：窗口是0至1 mm，固定目标 −0.5至0.5 mm 只有一半可见，真实长度仍为1 mm。

在 320×420、640×240、960×720 中操作主图与细节图，检查没有横向溢出、可触控控件不小于44px；先定位0.35、回到0、再定位0.35，实际 SVG 和读数应相同。保存参数与小数位置后由正式 Reader 重开，应恢复同一图形并暂停。静态导出应保留两幅 SVG 和当前结论。
