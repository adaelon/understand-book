齿轮的约定

两只齿轮并没有约定谁应该快、谁应该慢。齿的接触，替它们约定了一切。转动视角，再改变齿数，看同一件事怎样出现在三维结构、平面图和数字里。

● 金色：输入轮● 青色：输出轮

为什么变慢，却变得更有力？

接触的齿不能互相穿过。两个节圆相切处的线速度相同，而更大的圆每转一圈，要走更长的距离。所以大轮转得更慢。同一个力作用在更长的力臂上，又会产生更大的扭矩。

ω₂ / ω₁ = − z₁ / z₂　　τ₂ / τ₁ = z₂ / z₁

改变输出齿数，只改变速度与扭矩的交换比例。理想条件下，输入与输出功率相等。把输入转速或扭矩设为零，观察哪些关系仍然成立。

模型：20° 标准渐开线直齿轮，模数 2 mm，输入 20 齿；忽略摩擦、弹性与惯性，所示扭矩为理想传递值。根部过渡作几何简化。拆解不代表可运行装配。
