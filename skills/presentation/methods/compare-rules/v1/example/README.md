# 改写一个规则比较场景

从卡片选中的入口开始。它和同目录的 author.json 配套；HTML 可直接交给 Author，不依赖网络或额外库。三种构图彼此独立。本文中的坐标、步数和数学结论只属于这三件作品。

1. 用新材料定义对象、可选规则、结果与单位。先独立算出一对能分出差别的输入；把原始事实与教学设定分清。
2. 固定观察的基准：边界图用同一坐标映射点和边界；路线按同一消耗量分别求两个位置；印痕共用起点、最大值和方向。颜色之外还须能凭标记、名称或形状认出原对象。
3. 以选中作品的图层、局部样式和控件为起点，按新语义重做对象与讲解。蓝图保留制图纸与精细刻网，路线保留街区、人物和移动轨迹，套印保留双色印痕与共用横尺。正文可在场景外单独排版。对齐附加条形的轨道与刻度的两端。改写初值、state_contract 和状态读写，保存重开应回到暂停的同一步。

若两组结果原本同时可见，无需再造实验历史表。把范例结果当作新题的事实、把已展示的答案当作独立预测，都会误导读者。
