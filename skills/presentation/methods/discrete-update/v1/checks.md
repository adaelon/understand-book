# discrete-update v1 检查合同（se1.v1）

1. 独立使用 `xₖ=2+2(1−2η)ᵏ`，对照页面当前/梯度/更新/下一/插值/损失读数，以及实际 SVG 点、箭头和轨迹。η 覆盖 0、0.25、0.49、0.5、0.51、0.75、0.99、1、1.01、1.2；k 覆盖 0..8，小数位置覆盖 .35、.999。错误时修正计算或表示。
2. 从空页面运行，实际操作前后步、播放/暂停、重置与参数改变；回退后不得残留未来轨迹，重复 seek 几何相同。错误时修正单一状态到渲染的路径。
3. Author 在 320×420 touch、640×240 touch、960×720 mouse 真实预览，保存 screenshot、DOM、scene 和末态 reading；每批至多四动作，参数每批重新建立。观察中文、图例、箭头及短屏滚动。错误时调整版式或控件。
4. Reader 在相同三环境使用鼠标/触摸及键盘操作，保存 2+.35、7+.999、8+0 后重启存储宿主并重开，检查精确位置、参数、图形与暂停状态。错误时修正恢复路径，不能把进度吸附到整步。
5. 只在测试副本中将运动点冻结在 x₀，保持读数和 scene 正确；独立图形检查必须拒绝坏例，并接受好例。坏例漏检时修正检查，不把正确读数视为图形证据。

测试入口、命令与实际结果见 [SE1 实验记录](https://github.com/adaelon/understand-book/blob/625b4405af3b011e87d4eb256f819c8075f88613/docs/performance/explanation-evolution/se1/README.md)。这些检查证明该作品的工程与数学性质，迁移和采用证据另行形成。
