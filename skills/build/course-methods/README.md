用于 ADR-0182 的短课制作。当前已有资源下界方法、三课编排与可运行首课；Rust／TypeScript 合同、共享发布和私人学习闭环已接通。真实 DeepSeek API 已按该合同产出候选并完成修正及浏览器验收，自动构建已接入原执行器，目标用户试学待续。通用课件支持阅读取证、推理论证、动手练习和资源实验；新方法的学习效果仍须实际试学。

## 每次制作的输入

代表课的制作者根据书籍结构提出暂定起点和主问题，用所选段落制作一节可体验的课。整课制作读取委托人选定的路线、目标与范围，以及可读取的原文和结构引用。作者读取本次适用的方法及样课，再补齐当前材料所需的来源；当前材料中的参数、结论和题解重新建立。

每课默认按 20–30 分钟的完整探究过程制作。主问题下安排多轮递进的预测、观察和解释，最后用新情境综合应用；每轮可暂停、可回看。蓝本估算必要阅读、思考、操作、作答与反馈的用时，并由真实试学校准；额外追问、深入探索与离开暂停分别记录。较大的目标按可收束的中间问题分课，必要知识与关键推理保留在必经路径。

## 三项具体工作

### 1. 写出可制作的单课蓝本

根据来源和主问题，写出本课结束时读者要独立完成的任务，并先求解。倒推所需知识与活动，逐项说明学生做什么、依据什么判断、会看到什么、何时揭示结果。蓝本交付目标与起点、来源、题面与解法、活动顺序、演示制作说明、预期观察及反馈依据。

在制作页面前判断最终任务是否成立、支持是否充分、活动是否推进目标。有具体缺项时先补源、改题或调整本课范围。

### 2. 按蓝本制作实际课件

原 Author 读取蓝本指定的解释方法、完整示范和适配说明，制作页面及预置文字。题目、实验模型、图形、读数和解释使用对应条件。预测与观察分别安排展示内容；提示、自由探索及返回任务沿既有教学合同处理。

解释环节同时保留本轮实验图、模型和读数，学习者能够对照观察作答；切换原文或再次调整实验时保留解释草稿和观察状态。提交解释所绑定的实验条件应与当前图形一致。书内播放器的实现与宽窄屏验证见解释与实验同屏记录。

原文回读须写出具体任务：实验前在对应小节寻找什么概念或条件，实验后用哪些观察核对原文。当前合同用 `reading.before_experiment` 和 `reading.after_experiment` 保存这两项引导，来源沿 `summary.source` 绑定。书内播放器在课程／原文／实验之间保留状态，右侧 Agent 接住临时问题；回读与核心作答一起纳入时长估算。

交付可运行页面、学生可见内容、私有参考解答与判断依据，以及所用的确切素材版本。作者工作稿中的解答不能直接作为学生首屏内容发布。

### 3. 依据实际产物作出接纳判断

审题先提供题面、允许前提及必要来源，独立求解后再比较作者解答；来源核对回读关键结论及其条件。页面按蓝本中的具体场景实际操作，计算采用独立依据。意见写明问题所在、依据及影响；修正受影响产物后复验，正确内容可以接纳。

内容与工程接纳记录留在原构建任务中，真实试学另外记录适用人群、帮助和新任务表现。制作中产生的具体失败回写方法的改写说明；新增方法先完成样课，并用未参与方法修订的新材料试制，再扩大采用范围。

## 接入顺序

首课使用 [InquiryCourse 合同](../../../crates/memory/src/course.rs)与[可运行样例](../../../docs/examples/inquiry-course/ai-infra-resource-bounds.course.json)。样例来源身份为导入占位符，发布前绑定真实来源版本；目录与公共导出只提供概要，题目、提示和解答由宿主按阶段提供。IC4／IC5 已将范围选择、制作、独立解题、来源核验和定点修复接入原构建执行器；共享播放器的宽窄屏交互证据见自动课程记录。IC6 继续完成目标用户试学与学习效果验证。进度以[切片方案](../../../docs/切片方案-BookStructure驱动的探究课程.md)为准，实际调用与修正见验收记录。


多轮课程沿 `CourseLesson` 的首轮字段及 `follow_up_rounds` 制作；每轮提供标题、预测、实验、解释、反思任务、参数和原文阅读指引。原文小节在开头标明，原书算例与新构造练习分别说明。总时长包括各轮思考、操作、回读、解释和综合题；后续轮只在到达时揭示，历史轮的原话和参数保留。当前完整样课见[27 分钟资源决策课](../../../docs/examples/inquiry-course/ai-infra-resource-bounds.course.json)，上一版短课仅作历史回归样本。
