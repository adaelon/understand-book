# 用资源下界筛选方案

版本：4。状态：资源升级与批内复用两课已实现，加入共享参数的三维知识对象；验收范围见各次记录，目标用户试学与新材料适用性验证待完成。首次 API 试制采用版本 1，原输入保留在验收记录中。

## 适用条件

原文给出可计算的工作量、相应资源能力、执行关系和期限，课程要帮助读者排除无法满足期限的方案、比较优化方向，并区分下界与实际耗时。容量或其他运行前提由题目说明或先行检查。

## 本课必须建立的关系

工作量除以对应资源能力得到该项时间下界；整体下界按当前模型的依赖与重叠关系组织。已高于期限的下界可排除方案，低于期限的下界需要进一步测量和补齐模型。若讨论批处理，整批时间、每输出分摊时间和吞吐分别解释。

## 编排方法

以下活动按本课目标选用，每课默认 20–30 分钟，以多轮预测、实验和解释推进同一主问题。资源比较、批内复用和实测判断各自需要独立理解时，拆成连续短课，保留共同的原节问题。各课都有自己的结尾任务，估算时包含学生思考、操作和作答。

1. 给出工作量、资源能力和期限，先请读者选择可能有用的优化方向，说明依据。
2. 在原文支持的条件下算出各项下界，提供必要的单位换算与合成规则。
3. 固定工作量，只改变一种资源条件；先预测，再显示时间项如何变化，解释为什么另一项可能限制收益。
4. 若目标涉及共享或批处理，在单独活动中说明共享量、随请求数增加的工作量，以及每个请求何时完成。
5. 用未展示过解法的新数据筛选方案，要求区分“可以排除”与“尚不能保证”。
6. 根据任务目标连接后续测量：明确当前模型遗漏了什么，需要哪项实际观察继续判断。

## 演示选择与改写

时间下界的并列比较可使用 [chart-reveal@2](../../presentation/methods/chart-reveal/v2/card.md)，沿同单位、零基线和原数表呈现。改写时明确各参数的单位、状态以及变化后需重新计算的量；不同口径分别呈现。预测阶段展示输入与问题，观察阶段再显示本题结果。学生切换方案时保留当前条件，回到原任务时恢复对应场景。

共同页面可复用数值呈现和交互结构；新的资源关系、模型条件、默认值、题解与说明按原文重新建立。读取与计算是否能重叠决定怎样合成；页上须说明本题采用的条件。

### 把公式落实为可观察的对象

蓝本明确每个对象表示什么、与什么量关联、可以怎样操作、操作后应观察什么，以及哪些结构是示意。本资源课使用权重数据（读取量 R）、读取通路（带宽 W）、计算阵列（计算量 F 与算力 C）、请求与输出（批大小 B）。对象选择接到相应公式、当前值和 Agent 提问；教学关注点应能指向这些对象，例如“同一份权重有没有复制八份”“每个输出何时完成”。

引入阶段展示对象及关系，保留待预测的数值结果；实验阶段让三维对象、数值和二维图读取同一参数。旋转与拆层用于辨认组成，播放与暂停用于比较完成进度；这些视觉操作不改变计算结果，不证明学生已理解。解释与追问时保持相关模型可见，窄屏保留对象选择和提问入口，将详细说明与播放控件折叠展开。

本课使用充分重叠的理想资源预算，场景不模拟真实 GPU 调度和物理尺寸。计算、读取和输出完成的动画必须与这个声明一致。读取量不能冒充显存容量；教学用 batch 转折算例明确假设容量满足。

批处理实验以 `work_gflops` 保存整批计算量，`batch_size` 保存输出数。切换 1、4、8 条请求时，按每请求工作量改变总计算量，共享读取量保持不变。分别呈现整批下界、分摊量和吞吐上界；判断延迟时回到整批完成事件。学习模型取得同样的字段含义，不能再次把整批计算量乘以 B。

## 制作时应发现的具体失败

- 把增加算力自动解释为整体等比例加速：对照未改变的读取项，修正结论或实验模型。
- 把两项下界一律相加或一律取最大值：回读当前执行关系，修正合成规则及其适用说明。
- 把整批时间除以输出数当作单请求等待：回到每个请求的完成事件，分别说明分摊量和延迟。
- 把低于期限的下界直接判成达标：补上模型范围与实测任务，修正判题依据。
- 通过展示四舍五入后的数字改变期限判断：计算保留原值，显示按需舍入，比较使用原值。
- 使用资源交点宣称容量可行：补读容量依据，或将当前结论明确限定为时间模型。
- 正确答案成立但错项内部的计算不对应其声称的误解：逐项按选项陈述的运算复算。首次模型稿将相加错项写成 15 ms 与 12 ms，计算翻倍后的相加应为 5 + 4 = 9 ms；修为 9 ms 与 12 ms 后才接纳。
- 主问题标题提前说出最终情境的瓶颈：用待解决的问题作标题，把哪个时间项较大留给当前任务判断。标题还需覆盖实际首个实验的条件。
- 一次选择题反馈声称已经稳定迁移：将反馈限定为本题实际选择、保存的理由和所用支持，后续新任务与真人试学分别取证。

复算每个实际题面、所有选项和观察预设，并核对页面采用的参数及结果。首次试制中来源审阅未发现上述错项问题；模型通过只保留为一份证据，候选接纳仍依据具体内容核对和实际页面。方法在新材料上的采用范围由后续试制和真实试学记录更新。


第三版围绕资源升级主问题安排三轮：原书极端算例比较资源与工作量 → 近均衡情境求出 F/C = R/W 转折 → 工作量变化后同时求解两条门槛。每轮需要不同判断，不能仅替换数值机械重复。综合题另用 1200 GFLOPs、40 GB、100 TFLOP/s、5 TB/s 的未演示情境；服务端保存每轮解释后才进入下一段。样课预计 27 分钟，真实学习用时待试学校准。本轮内容由 Codex 基于原文编排与复算，未调用 DeepSeek。
