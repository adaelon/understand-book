# 云端学习与考试冲刺运行说明

对应 [产品方案](产品方案-云端学习与考试冲刺.md)、[实施计划 C1–C11](实施计划-云端学习与考试冲刺.md) 和 [ADR-0173](adr/0173-cloud-learning-subscriptions-and-exam-sprints.md)。

## 服务与数据

本轮服务元数据版本为 **19**。既有账号、人工收款、额度、课程发布、学习目标与私人记录沿用原存储；新表增加套餐权益、空间占用、非模型处理用量、课程分档权限、考试设置及桌面一次性授权。模型与处理费用从统一只读视图汇总，账户没有第二份余额。

服务启动沿 `ControlStore::open` 完成既有版本升级。正式切换沿项目现有备份、恢复与单写者维护流程执行；先在旧数据副本验证，再切换服务器、Reader、Admin 和 Windows。升级后的数据库包含新增事实，回退不能只把旧程序指向新库，也不能用旧备份覆盖上线后新产生的学习记录。

旧账号的私人原件按原归属建立占用记录。超额时可查看、导出、整理；新增原始材料上传需要有效套餐和剩余空间。演示页等学习成果及旧版记录的成果占用不计入上传配额，实际成果文件继续按学习记录保留。旧费用不因占用承接而补扣。服务既有维护循环处理遗弃上传和已完成的准备缓存，不依赖用户再次打开空间页面。

## 套餐配置与人工核款

运营后台的“额度与套餐”页分别提供“开通 / 续费套餐”“本期 AI 使用预算”和折叠的全局商品配置。商品有 `basic`、`plus`、`pro` 三档，以及 `day1`、`day3`、`day7`、`month` 四种期限。每个商品保存独立版本，购买确认绑定具体版本。

正式开放前填写：

- 售价与每期 AI 使用预算（元）。售价是实际收款，预算是允许消耗的 AI 服务成本；内部换算标识由系统生成。
- 账号空间、单文件上限、到期保留时间。
- 开通说明与运营联系方式。

字段不完整、停用或标为测试的商品不进入读者可售目录。初始数据库不生成正式商品或价格。管理员可以保存未完整配置的草稿。

读者在“使用额度 → 套餐与权益”选择期限与档位，查看开通说明。选择本身不扣款。运营者核对到账后提交实际收款信息；收款事实、额度期、授额与套餐快照在同一管理事务中完成。响应丢失时沿原操作编号核对或重试。

首次开通以核款完成时间开始。日包提供连续 24、72、168 小时；月付按 UTC+8 的开通日期续期，月底不足对应日期时落到当月末，并保留原日期锚点。已有有效期或预购期时，新一期接在最后一期之后。下一期换档不改本期权益，不结转旧额度。

本期额外用量使用“收款并补充本期”，分别填写实收金额与增加的 AI 预算；免费赠送或扣回使用“赠送 / 扣回预算”。补充不延长期限，也不增加空间。没有有效额度时，可用“单独赠送 AI 额度”一次设置预算、原因和起止时间。已售套餐期限只沿套餐续期，直接编辑期限仅用于独立额度。

读者余额以本期累计净授予预算为100%，已用、在途和待核算占用从剩余额度中扣除。补充后剩余比例重算；例如总额10、已用5时为50%，再补10后为75%。历史明细保留原标准比例。套餐目录以相同时长的基础版用量为参照展示倍数；加购说明显示相对于当前总额的增加量。

商品和加购配置影响所有账号；保存配置不授额。内测不限额度账号先结束内测有效期再开通收费套餐，避免将收费权益排到无限期之后。提交被拒绝时弹窗保留输入并显示原因；结果不确定时可关闭弹窗核对原操作。

## 空间与个人材料

账户空间同时统计已保存与上传中预留。上传开始时按完整长度准入，跨工作区共享同一上限；重复块、恢复上传和重复创建同一准备任务不重复占用。

读者可从个人资料区查看占用、下载原件、取消未完成上传、删除可整理材料。材料仍被工作区引用或任务正在执行时，页面要求先移除引用或暂停任务。公共课程材料的个人引用不占私人空间，也不重复产生公共准备费用。

演示版本、交互状态、笔记等学习成果不经过上传套餐与空间准入；无存储套餐、套餐到期或原件空间已满时仍可保存。演示保留现有独立的系统文件限制与学习记录生命周期。临时制作候选、预览和内部索引沿现有生命周期清理。模型及处理服务的额度规则、公共课程的内容访问权限独立生效。

PDF、课件转换及原页定位见 [考试资料准备运行说明](运行说明-考试资料准备.md)。服务端与准备宿主的格式配置应一致；没有转换能力时，界面会在上传前明确限制对应格式。

## 统一服务处理计量

个人视频准备和学习中的原声复核均在实际转写启动前准入，用真实音频毫秒数计量。模型与处理共享账号余额；个人资料准备还受用户确认的父任务累计上限约束。

`service-rates.json` 位于服务数据根目录，与原模型费率配置同级。正式费率尚未配置时，不启动个人付费转写。配置合同、费率快照、待确认回执、跨期结算及运营核对见 [服务处理计量说明](服务处理计量-20261020.md)。

服务额度扣减与平台已确认成本、估计成本分别展示。测试准入费率不代表真实供应商报价，不用于推导售价。

## 课程与考试冲刺

运营沿原公共资料准备流程生成确切发布编号，再发布课程版本。`allowed_tiers` 决定套餐范围；原有明确白名单与独立资料授权保留其既有语义。套餐授权按当前有效期计算，不复制为永久资料授权。

[课程运营样例](examples/cloud-course/README.md)提供原创短文本、人工字幕、可运行视频夹具、准备记录及发布请求模板。正式课程的适用范围、教材版本和使用授权在实际选定后填写。

已准备教材和视频使用真实发布编号，可提供原文、字幕或帧能力。`external_resources` 用于外部课程链接导览，只打开所填 HTTP/HTTPS 页面；外链不冒充已解析教材、字幕或可检索视频。

学生使用课程后得到自己的工作区、目标和学习记录，公共材料仍共享。填写考试日期、范围、每天可用时间后，可选择短诊断或直接提问。页面和每次模型运行都按当前日期计算剩余天数；修改日期或范围会更新目标版本。既有作答、理解证据及旧来源保留。

已确认考试目标下的直接讲题复用现有教学审阅，审阅通过后显示完整答案；发现具体问题时，原任务依据意见修订。审阅和修订仍消耗该次任务的服务额度。额度不足或审阅未完成时保留已有来源与未完成提示，不把草稿标成已交付。教师的修订意见存入自己的工作记录，不能当作学生答错或已掌握的证据。

课程新版由学生预览后明确采用，私人补充材料和学习记录继续保留。套餐到期后仍保留私人实例与目标，受限教材和视频是否可读继续按独立内容权限判断。

## Windows 本机书库、云端学习与维护工具

Windows 本地导入不要求云端存储套餐，不调用云端上传或预留接口。**0.3.1 已发布**，增加随安装包提供的本机书库，资料位于应用本地数据目录的 `local-materials`；本机原文可离线打开。工作区中的“同步到云端”才检查云端套餐和空间；云端 AI 与深度资料准备仍使用服务额度。只在原件被明确同步后产生云端副本。当前原文件后续编辑不自动同步，PPT/PPTX 在系统演示应用中打开，导出 PDF 后可在内置阅读器中查看。[发布记录与已知限制](https://github.com/adaelon/understand-book/blob/625b4405af3b011e87d4eb256f819c8075f88613/docs/performance/windows-local-materials-20261021/README.md)。本机资料的临时云端 AI 处理尚未接通，现有 AI 准备仍依赖云端副本。

Windows 云端 Reader **0.3.0** 已于 2026-10-21 与配套网站服务一同发布，安装包见[正式下载](https://understandbook.top/downloads/UnderstandBookSetup.exe)。正式打包显式设置 `UNDERSTAND_BOOK_CLOUD_ORIGIN` 为托管 Reader 的 HTTPS 站点，再执行桌面项目现有打包入口。网站的 Reader 与服务 API 必须先提供本轮对应接口。

系统浏览器完成账号登录与确认，通过一次性授权码和 PKCE 建立独立桌面会话。桌面在 WebView2 中使用同源会话访问 Reader、资料、流式回答与私人演示；网站和桌面共享学习记录，各自退出只结束对应会话。会话写入独立云端浏览器配置目录，重开应用可恢复。

正式安装包不携带本地 Server、Runtime、构建、发布或音视频处理程序，不默认安装本地构建插件。历史本地书库、配置和用户自行安装的插件保留。

运营维护工具见 [桌面运行说明](../apps/desktop/README.md)；原意图规划控制器移入独立 `maintenance-host`。维护插件使用显式配置的 `UNDERSTAND_BOOK_BUILD_EXE` 和 `UNDERSTAND_BOOK_DESKTOP_EXE`，不能从云端 Reader 安装目录推导本地执行程序。远程 Book MCP 的独立资格与计次合同保持。

## 配置与发布边界

正式售价、额度、空间、保留期限、处理费率、真实课程与授权资料仍按产品决策待定。测试商品、原创样例和隔离验收账号只用于验证工程行为。

工程验收与实际成本证据完成后，正式开售仍需要把上述配置和材料落实到服务；未配置状态会由目录、上传和处理准入实际约束。每次发布记录应写明实际构建、升级副本、浏览器和 Windows 验收结果，不能仅依据本说明宣布通过。

生产 release `cloud-20261021` 已升级至 schema 19，旧数据保留。正式商品、费率与课程仍未配置，私人上传尚未开放；常驻资料准备宿主需在开售前按既有运营流程接入本轮 Engine／DSH。实际结果及恢复位置见[2026-10-21 发布记录](https://github.com/adaelon/understand-book/blob/625b4405af3b011e87d4eb256f819c8075f88613/docs/performance/cloud-learning-20261020/release-20261021/README.md)。
