当前只有实验专用的固定库装配与 API 说明；正式 Author 的装配调用受 cfg(test) 限制，生产 presentation-method 仍为 ed3.v1。已证明 Agent 能制作、预览、修订并交付 Konva 页面，尚未实现正式的通用 Konva 供给与制作指导。

- [ ] 将固定库供给接入正式制作链路，保持库源码不进入模型调用历史。
- [ ] 沉淀适用于不同主题的 Konva 制作指导：布局、动画与时间定位、拖动命中区域、零位移图形、commitState 与恢复。
