## 执行边界

A/C/D经过本机真实Provider HTTP、普通工具循环与持久库，只有模型响应和用量受控。B使用实际FFmpeg解码及实际私人理解入口，来源按已捕获媒体引用提供；公共构建成本回执是固定输入。C外部重试、取消与迟到回执由测试输入控制，准入、账本和恢复沿实际服务执行。

后台书籍执行使用既有编译Engine与原生DSH，语义模型由本机受控供应商提供。视频导入、转写、媒体读取与浏览器为真实执行。浏览器中间准备状态由受控宿主提交；实际语义执行与暂停恢复在HTTP场景单独验证。本轮未付费调用真实供应商，测试费率不代表供应商实扣。

本轮修复了纯画面/原声私人理解被文字行号约束阻止的问题，并改进上传入口。完整原声复核的真实Whisper历史证据保留在[B2/V1结果](../b2-v1-20261018/real-cross-audio.json)，本轮新增媒体目标存储回归，不重复将历史验收计入28项。
