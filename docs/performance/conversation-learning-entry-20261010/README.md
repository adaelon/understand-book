# 对话中的学习入口

2026-10-10 已随展示首页和分享图修改发布，见 [发布记录](../learning-home-release-20261010/README.md)。

## 设计

**决策**：开始、继续和回顾学习直接在聊天区完成。

**否决**：
- 全局工具栏先进入会话管理：入口与阅读问题脱节。
- 普通提问自动恢复或替换已有学习：改变用户明确保留的学习状态。

**命门**：全局连续教学开关、当前教学会话和普通对话保持既有含义；本书目标只显示匹配材料的会话。

## 验证结果

- 136 项单元测试通过：`ConversationLearningGoal`、`TutorControl`、`TutorPanel`、`useTutorControl`、`RightRail`、`TopBar`、`App.startup`。
- 15 项浏览器用例通过：正式 App 学习入口 5 项、学习详情弹窗 4 项、理解空间 4 项、原有移动端菜单与视口缩小 2 项。
- 新入口覆盖：开关不自动发问、示例只填草稿、首问建立目标、显式恢复、关闭状态下开启并恢复、其他书籍目标隔离、保存失败保留状态与草稿、重试同一操作、直接进入理解、关闭后恢复焦点。
- 布局覆盖：桌面、390px／320px 手机、问答全屏、短视口输入和发送按钮可见；原移动端用例继续覆盖 visualViewport 缩小。
- `pnpm --filter @understand-book/web build` 通过，包含 Web 类型检查；日志见 [build.log](build.log)。
