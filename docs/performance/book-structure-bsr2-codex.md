## 原文内容审阅

验收映射在生成完成后读取 BSR0 `acceptance.json`。程序只负责把已选引用映射到预定位置；以下内容判断另行对照原文及实际候选理由完成。

| 机制 | 实际保留的内容与原文位置 | 判断 |
| --- | --- | --- |
| 显存需求与准入 | 权重、KV、缓冲区容量约束与生成预留；10.8.3.14、10.8.3.28 | 保留 |
| 合批的读取收益 | 权重读取可按批分摊，各请求 KV 读取仍相加；10.9.2.25 | 保留 |
| 连续批处理与分块 prefill | 迭代边界接纳；总时间约 870→766 ms 但最大输出间隔约 26→376 ms；decode 优先分块后约 844/133 ms；10.9.3.2、10.9.3.8、10.9.3.13 | 三个机制点分别保留，取舍方向正确 |
| 分页、共享与写时复制 | 块表映射、引用计数安全回收、共享尾块修改前私有化；10.10.2.4、10.10.3.2、10.10.3.5 | 保留，没有把分页等同于共享 |
| 前缀复用与恢复位置 | 模型、位置、adapter、格式及连续前缀一致；首个不同 token 截止；快照密度在重算与存储间取舍；10.10.4.2、10.10.4.3、10.10.4.10 | 条件与快照机制保留 |
| 缓存收益 | 命中概率下重算与取回成本，再扣维护成本；10.10.5.13 | 保留 |
| 压缩与卸载 | 压缩减去转换时间、约 7000 token 交点；卸载每轮搬移、PCIe 示例无法满足 7 秒；10.11.3.23、10.11.3.31、10.11.4.2、10.11.4.11 | 净收益、适用条件与反例保留 |
| 推测解码 | 摘要区分草稿与目标验证，重点指向 min(1,p(x)/q(x)) 接受规则；10.12.2.2、10.12.2.16 | 保留，未把草稿速度当作正确产出 |
| 有效产出 | 正确且按时、吞吐饱和后的准入、每合格结果成本；10.13.3.11、10.13.3.19–20、10.13.4.45 | 保留，未退回纯 tokens/s 指标 |

其余实际保留的独立含义也有原文支持：快速独立 ROM 改变合批收益（10.9.2.61、63），取消须等待已提交操作结束再释放（10.10.3.25），抢占换来恢复重算（10.10.3.28），共享与压缩的空间机制不同（10.11.3.15），预取依赖及双缓冲（10.11.4.6），更快链路每轮约 6 ms 复制可被计算覆盖（10.11.4.12）。

未选的 4 项为共享物理块数算例（10.10.3.11）、整批 KV 容量算例（10.10.3.17）、共享前缀并发容量（10.10.3.24）、压缩传输的解压吞吐阈值 `R_dec > B_link/(1-r)`（10.11.4.29）。前两项的重复数值性质在生成者工作笔记中有说明。独立审阅认为：前三项已有保留机制支撑；最后一项是有价值的更细条件，本次选择省略了它，但压缩净收益及卸载链路条件仍在，满足此片固定验收范围。四项都保留在候选目录，并未被程序丢弃。
