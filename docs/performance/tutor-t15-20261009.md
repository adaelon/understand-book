## 实现与边界

独立入口为 `tutor_api::tutor_source_readiness`。来源接纳及 `pass1 → profile_sidecar → book_structure` 的当前 close/publication 回执决定可用性；既有回执的源版本及产物摘要用于确认当前正式产物，未引入新的摘要文件。技术书由 Pass1 发布的 source.txt 锚定规范来源；论文保留可信来源，使用来源清单、当前输入和 Pass1 的 profile_metadata 发布依据。Pass2 可缺失；构建任务的未完成或损坏记录不参与判断。

`teaching_assets` 单独投影地图、正式对象与认知素材。候选或过时资料不提供可用引用。`PublicationManifest.tutor_readiness` 在导入时保存必要接纳投影及可选资料状态，发布与重新发布无需复制私有构建目录。

`TeachingTarget` 保存学习焦点、期望表现、能力、非空确切来源范围及可选正式对象修订。TeachingMove 可携带目标，TeachingBinding 地图引用可以真正缺省。Memory 校验目标与绑定身份后追加保存；历史 JSON 保持原字节和原地图/对象引用。范围是否由本轮原文读取支持在 T16 接入时核对。
