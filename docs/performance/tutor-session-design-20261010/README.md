# 学习会话界面验收

2026-10-10 已随对话学习入口发布，见 [发布记录](../learning-home-release-20261010/README.md)。

### §1 当前学习与记录的呈现

**决策**：当前目标优先，理解与历史按页签呈现。

**否决**：
- 新建表单始终置顶：已有会话的继续入口被挤到下方。
- 所有记录连续堆叠：当前操作与理解详情争用同一个长页面。

**命门**：页签只改变显示；会话、教法和纠正仍由现有接口确认。

## 实现

- 暖纸底色、陶土橙主操作、统一图标与间距；弹窗标题和底部操作固定，长内容在正文区滚动。
- 当前目标完整显示用户原文；教法使用按需调整、直接讲解、引导思考三项选择。
- 新建目标独立展开；新建草稿、理解详情与纠正草稿在切换页签时保留。
- 历史包含非当前会话和暂停／结束的当前会话；查看记录不会恢复教学，恢复必须显式操作。
- 理解详情保留原话、系统解释、帮助条件、未知状态、详细依据、纠正与历史；没有新增掌握度推断。
- 教法选中态和会话状态使用已确认结果；失败重试沿用现有 mutation 身份。
- 键盘可切换页签，焦点保持在弹窗内，Escape 关闭后返回入口。

## 验证
