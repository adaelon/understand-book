`let bar = &foo;` 之后还能打印两个变量，是因为 `foo` 仍拥有那个值，`bar` 只是借用它来读取。借用不会取得值的所有权。[[source:source_ref_b7cdf804a5f27a0d]]

先把原文里的名字拆开：`Foo` 是一种自定义类型，这里装着一个整数；`Foo(0)` 就是装着 `0` 的一个值。`foo` 是变量名。原文还给 `Foo` 加了 `Debug`，供这里的 `{:?}` 显示使用。[[source:source_ref_4c3de5a75d5bc2f7]]

下面补充一个原文默认你已知道的概念：**所有权**。在这个例子里，可以先把“拥有一个值”理解为负责保存和管理它；有所有权的变量能继续使用它。借用则让另一个变量临时访问这个值，同时保留原来的拥有关系。

跟着这两行看：

```rust
let foo = Foo(0);
let bar = &foo;
```

第一行让 `foo` 拥有 `Foo(0)`。第二行先计算右边的 `&foo`：它创建一个指向这个值的共享引用；然后把这个引用赋给 `bar`。所以赋值确实发生了，但赋给 `bar` 的是引用，并没有把 `foo` 拥有的 `Foo` 值交走。[[source:source_ref_b7cdf804a5f27a0d]]

`&Foo` 是类型的写法，读作“对 `Foo` 值的共享引用”。它告诉我们：`bar` 可以借着这个引用读取那个值，不能通过它修改值。`foo` 和 `bar` 不是各自拥有一个 `Foo(0)`。[[source:source_ref_9af277d1d3d785d4]]

补充这里的打印规则：这两行用 `{:?}` 显示值时，会借用要显示的内容，不会把它的所有权拿走。因此，第一行打印时 `foo` 仍可读取；第二行又能通过 `bar` 读取同一个值。原文中的这两行可以编译：[[source:source_ref_e2f1f69dfb7b32e3]]

```rust
println!("Foo is {:?}", foo);
println!("Bar is {:?}", bar);
```

现在准备你要做的判断。还需要补充一条赋值规则：**一个没有 `Copy` 能力的值，直接赋给另一个变量时会转移所有权；原变量此后不能再用来读取这个值，新变量可以使用它。**整数通常有 `Copy` 能力，所以你熟悉的整数赋值可以复制值，赋值后两个变量都还能用；这不能直接套到所有类型上。原文的 `Foo` 只声明了 `Debug`，没有 `Copy` 能力。[[source:source_ref_4c3de5a75d5bc2f7]]

例如，另一个没有 `Copy` 能力的类型 `Parcel`，若 `a` 拥有它的一个值，执行 `let b = a;` 后，拥有关系交给 `b`，就不能再通过 `a` 读取这个值。这是“交出值”；而 `let b = &a;` 是“借来读取”，`a` 仍拥有值。

轮到你把这条规则用到原文：只把第二行改成 `let bar = foo;`，后面两个 `println!` 保持原样。**整个程序还能编译吗？请说明这时谁拥有 `Foo(0)`，以及第一条打印中的 `foo` 是否还可以使用。**
