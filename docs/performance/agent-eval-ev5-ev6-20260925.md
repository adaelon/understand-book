# EV5–EV6：充分原文与共同回答器诊断

状态：2026-09-25 完成首个 `target-l2` 真实模型探针、确定性回归和原始评委输出复核。诊断产物留在 Git 忽略的 `evals/semantic/quality-results/`；首轮产品运行及正式评分未改。

## 预先选择的案例与假设

首轮正式报告中，`target-l2` Resident 的内容、准确、完整、解释均为 `met`，来源要求为 `unmet`：答案一处引号中的表述不在其所引原文摘录内。Chunk 的同题产品结果为 `pass`。

EV5 假设：给 Resident 在本轮开头合法读到目标熵、互信息和比值变化的完整必要原文后，它仍可能在后续引用组织或终答交付处丢失支持。判据是 `book.text` 回执真实接纳、模型请求确实包含原文、终答来源可打开且获语义支持。此干预改变了前两个模型采样的工具决策和上下文，不是自然运行的重复。

EV6 假设：Resident 自然运行已取得的原文足够回答该题；把两系统各自实际进入模型输入的 canonical 原文交给同一回答器，可以区分证据集合效用与后续交付损失。两组均按原书顺序去重，正文上限 6000 UTF-16 字符，不用金标准补片段。

## EV5 实测

脚本化前两次模型工具选择先用真实 `book.search_text` 搜索两个固定原文短语，再从搜索结果复制 LID 调用真实 `book.text`。第三次模型请求含 `1.4.14–1.4.25` 的 660 UTF-16 字符原文，回执为 `ok` 且有 accepted evidence；后续三个请求由原模型完成，产品交付了答案及一个经 `source.resolve` 验证可打开的引用。对同一保存回合只读复核：真实引用 `can_open_in_reader=true`，伪造的 `source_ref_not_in_this_turn` 返回 HTTP 404 `SOURCE_REF_NOT_FOUND`。原始评委将来源、准确、完整和解释均判为 `met`。

该评委把事实槽 `ratio` 写成中文释义，而冻结合同的 `acceptable` 是 `denominator_falls_more`。程序的字面比较因此给 `ratio` 一个 `unmet`，与评委其余维度及理由冲突。复核报告把本次完整任务结果记为 **未决（评分无效）**，保留原始评委输出；不能称为诊断通过或产品失败。它说明预供必要原文后来源支持这一原失败项没有重现，但一次样本不证明自然取证是唯一原因。

首次试跑的脚本化工具调用缺服务商要求的 `reasoning_content` 回传，导致下一次请求 HTTP 400；已在夹具中修正，原失败尝试保留。有效探针的三个真实 Provider 请求均缺 usage，产品 Token 成本未知。有效探针的一次 Judge 请求使用 3599 tokens。脚本化的两个工具决策记录为诊断干预，零 Provider 调用，不计入真实模型费用。

## EV6 实测

从保存的自然运行请求及真实工具回执抽取实际进入模型的 canonical 原文；Chunk 从其真实回答请求抽取。按原书顺序合并重叠范围并截取同一正文预算，未把参考答案、公共核验材料、工具指令、locator preview 或未被接纳的范围补入。

| 来源集合 | 可用/送入正文 UTF-16 | 超预算遗漏 | 共同回答器结果 | 实际 Provider 用量 |
| --- | ---: | ---: | --- | ---: |
| Chunk | 5550 / 5550 | 0 | 未决：事实槽与维度冲突 | 4293 tokens |
| Resident | 1362 / 1362 | 0 | `pass` | 2148 tokens |

两组使用同一模型、温度、回答 prompt、来源编号规则与 6000 字符正文预算；改变的是来源集合内容和由此产生的实际输入长度。双顺序偏好评委均给 `tie`，不支持断言某组证据更好。Chunk 诊断答案也把正确内容写成非冻结枚举值，同时准确、完整、来源维度为 `met`；复核标记为未决。EV6 四次 Judge 请求共用 23314 tokens，独立于产品与 EV5。

Resident 的实际取证集经共同回答器可生成合格答案，支持下一步优先检查自然产品的引用绑定和终答组织；这不是原 Resident 终答上下文的重放，也不能归因于某条图边。两组原文都含本题必要片段，且均未触及 6000 字符上限。

## 已知问题

- `task-v1` 的事实槽允许评委写入自由文本，随后以冻结枚举值做精确比较；在本次两份答案及首轮部分样本上，它会把有支持的正确内容记为 `unmet`。本切片保留旧正式报告，在诊断复核中标记冲突为未决。要恢复这些范围的自动内容判定，应修订评委协议、重新校准，并统一复评受影响系统；不能重试原作业刷结果。
- EV5 是一次脚本化工具决策的诊断，不是自然运行；它只针对 `target-l2`，没有全题集外推。有效运行的 Resident Provider usage 缺失，完整成本未知。
- EV6 反映共同预算下的证据集合效用，不代表自然 Agent 的最后一次模型上下文、真实 UI 体验或图关系因果效果。
