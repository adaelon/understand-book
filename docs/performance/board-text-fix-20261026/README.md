# 新画板讲解正文不一致：修复与验收

用户在新建画板提问后收到 `BOARD_TEACHING_TEXT_MISMATCH`。对应线上回合 `turn_01a178d0-a782-7c43-b25a-73afa60fd528`，运行版本为 `board-refresh-20261026`。该回合已经两次准备并实际预览原生画板，尚无正式保存。

## 已定位的原因

画板候选正文来自 `prepare.blocks[].markdown` 按顺序以两个换行连接；教学选择另外要求提供完整 `move.delivery_text`。预览与教学检查之间缺少直接引用这一正文的输入方式。此次先发生一次缺少正文的参数错误，之后提交的正文与预览版本不一致。持久化的公开工具记录会隐藏候选教学正文，因此不能从该记录断言具体差了哪些句子。

错误要求重新准备和预览候选，但无进展恢复只放行了 `tutor.step`，没有允许跨工具回到 `board.author`。实际下一次 `prepare` 被 `AGENT_NO_PROGRESS` 拦截，运行终止并向用户显示上一条正文不一致错误。

## 修改

- `tutor.step select` 的 `move.board_candidate_revision` 可以引用本轮已预览并已观察的原生候选；运行时从该候选取完整正文，再执行原有来源核对和教学检查。引用仅用于工具输入，不新增数据库字段或改写历史记录。
- 预览后的下一步指引明确要求先选择该候选，再保存。提供显式正文时仍检查一致性；过期版本、未观察截图、已提交候选和冲突正文均不接受。
- 原生画板校验错误复用现有的一次有限恢复机会，同时允许教学选择与画板准备、预览。有效修改与预览继续记作进展，重复失败不无限续期。
- 原生画板通过整轮教学检查后，将该候选的图形与正文一起暂存；`finish=true` 或最终答复完成时才正式保存。暂存失败会使该轮保持未完成，不能降级为只保存文字。局部 `board_part` 仍需显式提交。
