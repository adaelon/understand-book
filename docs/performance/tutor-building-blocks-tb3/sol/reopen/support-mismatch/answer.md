接着上次，我们沿用你说能跟上的逐行代码和类型对照，先把判断依据放在旁边。

```rust
let foo = Foo(0);
let bar = &foo;
```

第一行创建 `Foo(0)`，绑定给 `foo`；第二行的右侧 `&foo` 创建不可变引用，再把引用绑定给 `bar`。正文明确说 `bar` 的类型是 `&Foo`，不能通过它修改原值。[[source:source_ref_9af277d1d3d785d4]]

| 变量 | 类型 | 这一行执行后保存的内容 |
|---|---|---|
| `foo` | `Foo` | 原来的 `Foo(0)` 值 |
| `bar` | `&Foo` | 对原值的不可变引用 |

借用允许临时访问原值，却不取得原值的所有权。[[source:source_ref_b7cdf804a5f27a0d]]

再沿用上次补充的打印规则：这里 `println!("… {:?}", ...)` 为格式化而借用参数读取，不拿走参数的所有权；已有共享借用时，仍允许这样的共享只读访问。这是解释打印语句所需的补充规则。

现在只处理原例中的两个打印：[[source:source_ref_e2f1f69dfb7b32e3]]

```rust
println!("Foo is {:?}", foo);
println!("Bar is {:?}", bar);
```

请按这两行的顺序，用自己的话解释：**每行使用的变量是什么类型、通过它读取什么；结合“借用不取得所有权”和“打印只读借用”，为什么两行都能使用？** 可以直接写两句话，用变量名和类型串起理由。
