你选“第一条 `println!` 不能编译”，这个结论是对的。你说这是猜的，所以我们先接上理由，再由你自己说明。

只补一条判断方法：**新绑定接收右侧表达式的结果；类型看这个结果，所有权看这里是在借用还是移动。** 原文中 `&foo` 创建的是 `&Foo` 引用，借用不取得那个 `Foo` 值的所有权。[[source:source_ref_b7cdf804a5f27a0d]] [[source:source_ref_9af277d1d3d785d4]]

下面是补充的小示例，沿用原文没有实现 `Copy` 的 `Foo`：

```rust
let a = Foo(0);
let b = a;
```

第二行右侧是 `a`，这里交给 `b` 的是 `Foo` 值，没有用 `&` 创建引用。因此 `b` 的类型仍是 `Foo`。这个值不是 `Copy`，所以此次赋值会移动它：所有权从 `a` 转到 `b`，之后可以通过 `b` 使用这个值，不能再通过 `a` 使用已移走的值。**移动改变了谁拥有值，没有把值的类型变成引用类型。** 原文的 `Foo` 只派生了 `Debug`，没有实现 `Copy`。[[source:source_ref_4c3de5a75d5bc2f7]]

现在把这个连接用回你刚才判断的这一行：

```rust
let bar = foo;
println!("Foo is {:?}", foo);
println!("Bar is {:?}", bar);
```

请用你自己的话补完一条因果链：**右侧交给 `bar` 的是什么、所以 `bar` 是什么类型 → 赋值后谁拥有这个值 → 第一条打印为什么不能再用 `foo`。** 不用再猜选项，只说明这三个连接。
