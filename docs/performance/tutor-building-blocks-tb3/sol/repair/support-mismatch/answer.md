好，按你说的，换成逐行代码和类型对照。你已经明确纠正了“两份 Foo”的说法，我们从这里继续。

先读这两行：

```rust
let foo = Foo(0);
let bar = &foo;
```

第一行：右侧创建 `Foo(0)`，绑定给 `foo`。
第二行：先看右侧 `&foo`，它产生对原值的不可变引用；再看左侧，把这个引用绑定给 `bar`。正文明确说 `bar` 的类型是 `&Foo`。[[source:source_ref_e2f1f69dfb7b32e3]] [[source:source_ref_9af277d1d3d785d4]]

| 变量 | 类型 | 绑定的内容 |
|---|---|---|
| `foo` | `Foo` | 原来的 `Foo(0)` 值 |
| `bar` | `&Foo` | 对原值的不可变引用 |

读这张对照时，注意 `&Foo` 中的 `&`：它标明引用类型。借用没有取得原值的所有权；不可变引用允许读取，但不能通过它修改原值。[[source:source_ref_b7cdf804a5f27a0d]] [[source:source_ref_9af277d1d3d785d4]]

再补充一条用于读打印语句的规则：这里的 `println!("… {:?}", ...)` 为了格式化而借用参数来读取，不会把参数的所有权拿走。共享借用期间可以继续做这样的只读访问。

现在由你解释原例的这两行：

```rust
println!("Foo is {:?}", foo);
println!("Bar is {:?}", bar);
```

请按代码顺序说：**第一行用的变量是什么类型、第二行又是什么类型；结合上面的借用和打印规则，为什么两行都能使用？** 你可以直接用变量名和类型来说明。
