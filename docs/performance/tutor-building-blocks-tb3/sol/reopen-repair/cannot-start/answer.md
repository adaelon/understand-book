接着上次留下的那一步：**先看赋值后谁拥有值，再看打印要读取哪个变量。**

上次的 `Parcel` 示例里，`let b = a;` 把没有 `Copy` 能力的值交给 `b`，于是 `a` 不能再读取它，打印 `a` 就不能通过编译。这是我们已经示范过的连接，你现在可以照着用。

这里沿用两条补充规则：没有 `Copy` 能力的值直接赋给另一个变量，会转移所有权；`println!` 用 `{:?}` 显示时虽然只是借用，也必须能够合法读取要显示的变量。原文的 `Foo` 只派生了 `Debug`；按这份定义，它没有 `Copy` 能力。[[source:source_ref_4c3de5a75d5bc2f7]]

原文第二行是 `let bar = &foo;`，创建的是共享引用，借用不会拿走值的所有权。[[source:source_ref_b7cdf804a5f27a0d]] 现在只把这一行的 `&` 去掉，其他代码沿用原文：[[source:source_ref_e2f1f69dfb7b32e3]]

```rust
let foo = Foo(0);
let bar = foo;
println!("Foo is {:?}", foo); // 这次只判断这一行
```
