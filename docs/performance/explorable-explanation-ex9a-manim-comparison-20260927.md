**采用建议：保留浏览器主路径，Manim 暂作离线讲解样片。** 本片确实增加跨点自动停顿、真实更新箭头与公式同步强调，能把方向变化与乘数联系在同一时刻。EX1 仍承担改参数、逐步回退、预测揭示及 Reader 现场恢复。新增表达来自本次编排，浏览器也能实现这些动作；没有同编排的浏览器对照，不能把收益归因于 Manim 引擎。若用户需要可复用的固定讲解视频，再单独定义接入切片；若核心需求仍为自主探索，继续浏览器方案。

## 冻结范围与身份

本轮由 Codex 按明确工程合同编写、渲染、检查和修订一个 Manim 样片，属于模型辅助的定向样片。不是 Resident 的自然请求实验，不计入 EX2/EX7，也不是读者学习效果证据。题目、初值、η=0.2/0.8/1.1 与 EX0、EX1 相同。

## 验证意图

独立闭式解检查真实 w/e/L、位移符号、步长及距离比；从实际 Manim 对象提取箭头端点、距离线长度和跨点位置，发现图文比例或时刻错配则修订场景。视频逐帧解码与浏览器实际播放检查文件损坏、无法播放或中途停止；关键帧用于检查文字重叠和标尺。EX1 通过同题实际播放对照对象运动、解释节奏与可探索能力。

## 验收结果

- `python -m unittest test_scene -v`：3/3。对 η=0.2/0.8/1.1、k=0…5，用 Fraction 独立闭式计算 w/e/L、Δw、步长、误差倍率；实际箭头起终点、移动点跨点坐标和到达后距离线均与独立结果一致。场景证据有 15 个过渡关键点、5 个真实端点时刻，三条轨迹均核对。
- 真实数值例：第一步 w 为 0.8 / 3.2 / 4.4，Δw 为 +0.8 / +3.2 / +4.4；第五步 w 为 1.84448 / 2.15552 / 6.97664。前两条距离均每步乘 0.6，第三条乘 1.2。没有限幅或线宽下限。
- `verify_media.py learning-rate-final.mp4`：全片 1,838 帧按递增时间戳解码，无缺帧报错；文件时长与场景时长相符。保留[解码记录](ex9a-manim/learning-rate-final-media-check.json)及[七个关键画面](ex9a-manim/frames/learning-rate-final/contact-sheet.jpg)。
- 正式关键画面覆盖开场、运动中、红色跨点、橙色跨点、第一步真实结果、第五步真实结果和归纳。首步红色在约 12.03 秒、橙色在约 15.13 秒到达 w=2 并停顿，圈选位置与负乘数框同步出现。运动中读数明确为起点→目标，到达后才显示新的真实 w/e/L。未发现裁切、文字碰撞或数值错位。
- Codex 内置浏览器加载正式 MP4，readyState=4、1920×1080、duration=61.265365；实际从起点持续播放至 `ended=true`、currentTime=61.265365。另验证橙色章节跳至 15.394 秒、暂停于 23.535 秒、回退红色章节并暂停于 12.312 秒，实际画面对应红色跨点。EX1 同题页面实际播放从 0 到 5 步，滑块归于 500，最终三种 η 数值与样片一致。
