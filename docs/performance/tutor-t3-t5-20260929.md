# Tutor T3–T5 实现与验证 — 2026-09-29

T3 正式对象、T4 重点认知素材及 T5 构建发布链已实现。`formal_objects → cognitive_materials → teaching_publish` 复用既有 BuildPlan、generation work unit、执行器输入/写入、恢复与原子发布。Reader 单独读取正式教学就绪，不用全局开关或普通阅读状态代替就绪。

## 实现

- `teaching-map.ts`：Agent 提出语义对象，系统分配来源内身份；身份与内容 revision 分开。关系拥有参与者、角色、条件和原文依据；图边仅引用关系。能力轴属于 prerequisite，实质拆并保存对应与旧对象。
- `cognitive-materials.ts`：围绕 key_stops 分步检索、预览、读取和完成；检索扫描所有来源及 discourse，不依赖图边。每步保存已读内容、用量和结果。来源缺口需要完成检索及实际读取依据；预算耗尽保持 incomplete。
- `teaching-build.ts`：冻结任务、接纳 generation 产物、关闭阶段、独立来源抽样任务及不可变版本发布。抽样覆盖每单元代表对象、所有关系/复合对象、各素材形态及所有含缺口素材；输入包含所引原文及同单元上下文。失败不发布，修正轮继承对象身份。
- `build-orchestrator.ts`：从已接纳的 Pass1/sidecar/BookStructure 构造输入；沿 LID span 读取完整原文。BookStructure 的截短 excerpt 仅为预览，不能充当完整来源。
- Pass2 可选；若本计划会更新 Pass2，BookStructure 及三项教学资产均重建。正式版本保存在 `teaching/versions/<revision>/map.json`，与 `teaching_readiness.json` 通过既有发布事务提交。
- Server `/tutor/readiness` 验证来源、覆盖、来源审阅和版本文件；工作台登记三个阶段并投影状态。Web 显示准备/就绪/失效及来源限制，刷新失败清除旧的就绪提示，保留私人学习意图。

## 来源判读

完整小材料位于 `packages/core/test/fixtures/teaching-source.ts`，包含五段实际文本、两个单元和三个重点。它是本次编写的确定性来源夹具。

| 原文位置 | 判读与对应产物 |
| --- | --- |
| 1.1 | “平均速率/平均速度大小”归并；口语共同简称“速度”的路程量与位移量分开。名字相同不等于含义相同。 |
| 1.2、2.1 | 等距离的调和平均和等时间的算术平均保留为不同条件关系；往返与去/回程同时存在。 |
| 1.1 → 2.1 | 没有候选图边的定义仍能被检索和读取；认知步骤以平均速率定义为起点，代入总路程与总时间，保留正数和等距离条件。 |
| 2.2 | 记录、求和、相除是测量方法，不构造论证连接。 |
| 2.3 | 原文缺少各段测量记录，不能由平均值增加断言每段增加；素材保留这个缺口，受限版本可发布。 |

对象及素材的上述意义由本次实现者对照原文判读。独立来源审阅作为单独构建任务接线；测试输入固定审阅候选，分别覆盖通过、失败、修正后的通过。

## 恢复入口

正常中断沿既有构建续跑，已接纳 generation 输出不重写。来源审阅拒绝后使用 `skills/build/automatic-build.ts teaching-repair <target> [--root <root>]` 开启修正轮，带入旧身份与审阅反馈。

认知动作/读取预算中断可用 `teaching-resume-budget <target> --target-id <key_stop_id> --budget-json <file> [--root <root>]`。预算文件包含正整数 `searches`、`preview_chars`、`read_chars`、`context_chars`，不得小于原额度；续跑保留已读原文与累计用量。BuildPlan 总预算及现有确认门禁继续生效。

## 已知限制

- 正式对象首版以整份材料作为一个语义输入；单任务正文上限为 6,000 估算 token。大材料、过大的认知工作上下文或审阅单元会保持未完成并要求缩小构造单元，目前没有大材料对象分块/归并实现。增加读取额度不能绕过输入上限。
- 本次没有调用真实模型完成整份来源抽取与教学生成，也没有执行打包二进制验收。确定性小材料证明接纳、恢复、发布及 Reader 状态路径；真实书籍/论文和安装包端到端体验仍属于 T13。
- T6–T13 尚未实施。已就绪表示教学材料可供后续消费；保存开始请求仍不执行 TutorLoop、Trace、评分或学习 Evidence。
