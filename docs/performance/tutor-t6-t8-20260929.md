# Tutor T6–T8 实现与验证

日期：2026-09-29。实现基于 `5e10516` 及工作区已有 T0–T5；本轮保持未提交。T6 实际交付 Trace、T7 首个 Resident 教学循环、T8 宿主显式行为已实现。评分、学习证据和完整体验的后续边界见文末。

## 实际行为与所有权

LearningMemory 在同一 learning.db 增加追加式 `teaching_trace`。每条事实带 TutorSession/control revision、来源/TeachingMap revision、聊天与回合、因果引用和原 payload。`TurnBound / MoveSelected / MessageDelivered / Displayed / LearnerAction / HelpDelivered / HelpDisplayed` 分别保存冻结现场、选择、正文完成、实际可见、显式回答与帮助阶段。重试同一身份返回原事件，冲突拒绝；事务失败不产生半条事实，重建控制投影不删除 Trace。

Server 在原正文完成落盘后记录交付；未使用页面候选、失败回合与未显示内容不记展示。原历史已保存而 Trace 写入失败，可由 activities 读取补记；之后关闭 Tutor 仍保留实际交付事实。教学交付保存确切正文、来源绑定和原 Presentation 内容，显式行为保存原版本的不可变现场。跨聊天 teaching_ref 读取原归属，不放宽普通 presentation_follow_up 的活动聊天要求；缺失原 TeachingMap 或来源变化直接返回不可用，不替换成最新版本。

TutorLoop 复用 Resident。每轮冻结用户意图、会话默认、确认过的讲解偏好、正式对象索引和近期事实；能力保持 unknown。tutor.step 先读取正式素材，再依据本轮真实 book.text 证据选择动作。当前直接讲解优先于默认引导，范围外请求显式退出教学。开启/开始/继续是运行入口；导航和 readiness 查询不启动教学。关闭停止自动动作；带旧活动引用的普通请求仍可只读原 Trace。索引、近期摘要和每次 8,000 字符的详情读取限制上下文；页面脚本和媒体保留在存储，不整体注入模型。

宿主 TutorActivities 为每个活动提供 submit、revise、request_hint、reveal、skip、self_report。页面桥只能请求聚焦宿主输入，不能自行正式提交。回答冻结当时现场，页内“正确”提示只作为观察；回答统一保存 unassessed。提示和讲解只在明确请求后从服务端交付，帮助元素实际可见后才记 HelpDisplayed。网络失败沿用同一操作身份和原现场重试；同页多活动独立，关闭、重开和换聊天均不清除帮助记录。

## 验证及失败后的处理

每项检查针对实际改动边界：存储检查发现半写/重复则修事务和身份；Server 检查发现归属/原版本错误则修绑定或完成路径；工具集检查发现普通模式多出工具则修 exposure；浏览器检查发现现场/展示不一致则修宿主捕获和确认。未运行全仓重复审计。

浏览器测试先启动 `cargo test -p server tutor_browser_host --lib -- --ignored --nocapture`，出现 TUTOR_BROWSER_READY 后执行 Playwright。测试宿主在 4175 提供真实 API，4174 为已有 Vite 视觉测试入口；结束 POST `/stop`，并等待在途请求完成。首次提示故障由测试路由注入 503，其余请求走真实 Server。浏览器夹具使用已有 Presentation 保存合同，未调用真实模型生成页面。

这轮验证修正了三个实际集成问题：普通模式不应默认暴露 tutor.step；富回答引用多出的 kind 字段不应影响正式 PresentationRef 比较；状态 reader 应返回 values 包装。浏览器现按独立活动与帮助元素的可见性确认，测试退出等待在途请求结束。

## 真实模型观察

来源为平均速度小材料，正式对象是 speed。首轮请求一次简短观察；实际工具链包含 tutor.step、book.search_text、book.text、source.present 和动作选择，随后交付解释。第二轮用户明确表示混淆路程与时间并要求直接讲解，模型重新读取原文后采用 explain 动作，保持同一学习会话。固定脚本另验证会话 guided_inquiry 默认不会覆盖本轮直接讲解。

## 已知限制

- 真实模型把“时间÷距离”描述为无意义量；它可以表示配速，这是实际内容错误。源读取与动作接线通过，讲解质量未据此宣称完整通过。该用例的固定断言验证接线，语义判断保留为失败观察，后续 T13 应加入等价量与单位的自然交互验收。
- 真实模型样本沿用 sample_base 的 LID span，实际读到首段约 100 字节；它验证最小回合，不是完整书籍/论文构建或全来源语义验收。
- T9–T12 的冻结评分合同、封闭/开放判题、LearningEvidence、掌握状态与理解空间尚未实现；当前只记录事实和未评分回答。T13 的 Windows/Tauri、Linux 完整教学体验尚待实施。
- T3–T5 的整份正式对象输入仍受 6,000 估算 token 限制，大材料分块/归并未实现，见 [原记录](tutor-t3-t5-20260929.md)。
- 本轮未提交、部署或更新桌面安装包。原工作区其他工作线与临时产物保持原状。
