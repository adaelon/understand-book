## 发布内容

- 书库优先显示材料标题，保留材料身份和多版本区分。

- 分享面板打开后自动生成，编辑后自动更新，生成期间保留旧图并暂停下载。
- 画像使用“助手记住了什么”“这本书 / 所有书籍”和明确的纠正、忘记操作。
- 额度突出可用、已用和到期时间，计算说明按需展开。
- 阅读准备先说明结果、范围和预计时间。
- 移除回答下方的工具调用展开项、桌面轨迹页和手机更多菜单的轨迹入口；保留活动进度、引用、停止与错误提示。
