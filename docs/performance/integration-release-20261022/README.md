# 2026-10-22 主实现集成收口

本次整合自 `33c19c7` 以来已进入正式实现的功能，发布目标为网站、管理后台与 Windows 0.3.6。主实现与实验候选、实验报告分别提交。候选已完成本机回归与 Linux 隔离启动验证；线上切换结果以本目录后续补入的 deployment.json、public-browser.json 和 published-browser.json 为准。

## 主实现范围

- 云端学习：套餐与存储限制、共享课程与个人工作区、考试目标与日程、费用与使用额度查询。
- Windows：本机书库与云端入口分离，TXT／Markdown／EPUB／PDF 导入、复制留存、离线阅读、同步与恢复。
- PDF：原页直接阅读、本机 OCR、文字选择、划线笔记、缩放和阅读位置持久化。
- 书库：元数据标题、分页与加载反馈、跨聊天与资料恢复、账号级最近阅读位置。
- 视频：分段播放、首帧与字幕加载分离、跳转、播放速度与位置恢复；收口修复无声音轨视频的播放准备。
- 教学：OM0–OM6 交互现场与学习接续、学习目的、Coach、原文与演示绑定、教学设计及交付审阅。
- 音乐：乐谱／音频／事件来源、播放器、来源展示、音乐工具和教学目标接入。
- 检索：站内相关段落排序、工作区混合检索、外部网页搜索与抓取、来源与计费记录。
- 数学：公式语义、数学结构及来源关系。
- 自动构建：章节结构准备、分片对齐与并行恢复、调度与重填、输入缓存、取消与恢复、维护插件职责分离。
- 交互反馈：提问提交状态、执行进度、取消与停止反馈。

正式解释方法目录保留已采用的 compare-one-factor v3（目录 revision 5）。chart-reveal v3 与 Coach-first 冻结补丁仍属实验，不进入本次服务程序。

- Runtime：807 项通过，11 项因需要外部模型或专门环境而跳过。

## 未完成与上线限制

- 音乐 M0–M8 的完整成品验收未通过：全曲逐音听核、对齐精度、贝九共享许可、完整四轮教学质量／响应速度和真人学习效果仍未完成。贝九本机材料不作为公开课程发布。
- Coach 失败任务的完整重试界面尚未完成；不得把已有后台任务恢复能力写成完整用户流程。
- 实验候选没有证明稳定的教学质量或速度收益。四份解释能力实验报告保留失败、成本和适用范围，冻结补丁未应用到正式代码。
- 云端价格、正式配额、真实售卖课程和运营准备宿主仍待配置；本次不虚构商业配置或开放个人上传。
- 不保留云端文件的本机资料临时 AI 处理尚未接通。
- 工作区语义向量检索需要部署本机嵌入模型与运行环境；未配置时明确退回词法检索，不能声称语义检索已启用。
- 本次收口不重复运行付费模型质量实验；真人学习收益仍需真实使用证据。
