# Tutor 三类关系判断任务

2026-10-14。本地实现、最终请求装配测试与三组固定内容样本验证完成。 2026-10-15 已随 `current-20261015` 发布，见 [上线记录](../current-release-20261015/README.md)。

## 行为与实现

指导版本 `tb4.v5`。`crates/runtime/src/tutor.rs:COMMON` 在问题符合当前请求时，按尚待判断的关系和可用支撑选择条件变化与预测、错误定位与修正、反例与适用边界。学习者可要求换一种形式，每次选一个可完成的任务。

- 条件变化与预测：改变决定性条件，明确保持项，要求判断后果及其联系。
- 错误定位与修正：提供可信的错误连接，交给学习者定位并修复；自拟论证保持假设身份。
- 反例与适用边界：构造满足主张前提却使结论失败的例子，或解释貌似反例为什么超出适用条件；受支持的有效主张不能强求反例。

若原文或已交付解释已完成该预测、修正或边界判断，换成尚未被代答的具体应用，再用回答判断理解。需要判断理由时请求简短解释，正确选项本身仍不能确认原因。公开目标与私有解答继续遵守 `tb4.v4` 的字段边界。

这是既有 TeachingMove 与 GuidedInquiryPolicy 内的出题选择；沿用文字对话、question 动作、ChoiceSet／Open 评分和现有帮助机制。新增实现仅涉及共同指导与现有请求装配测试。工具参数、发布示例、评分模型、界面和存储保持原合同，工具参考无需重新生成。

设计依据见 [ADR-0164 §10](../../adr/0164-tutor-mission-and-cognitive-building-blocks.md#10-认知题型选择) 与 [三类关系判断任务](../../切片方案-Tutor使命与认知积木.md#三类关系判断任务)。

## 三份实际生成内容

三组复用 [TB1 Rust 借用原文](../tutor-building-blocks-tb1/source.txt)，完整范围绑定为 `1.1`。共同背景是编写的用户自述：已知非 Copy 值按值赋值会移动、旧绑定不能继续使用，能够区分变量与值；随后分别明确请求三类题中的一种。没有真人作答或历史能力证据。

每组用一个不携带父会话历史的 Codex 子代理生成一次，共 3 次生成，继承当前模型与推理设置；工具未提供精确模型版本、token 用量或费用。输入保存完整指导、未变的工具合同、来源和请求，输出保存实际 `select` 与中文教学文本。没有补跑或丢弃样本。

| 样本 | 生成任务与内容判断 | 编译器核对 |
|---|---|---|
| [条件变化与预测](prediction/output.json)，[输入](prediction/input.json) | 把直接借用改为借用按值函数的返回值，保持原来的打印，要求预测能否编译并解释求值过程。参数、返回和临时值存活规则明确作为补充支撑；题面没有给出原变量能否继续使用的结论，公开目标只描述判断。 | [原题](code/prediction-original.rs) 的原变量后续使用报 E0382；[仅删除该使用的对照](code/prediction-returned-borrow.rs) 正常运行，输出 `Bar is Foo(0)`，支持返回值借用本身有效的说明。 |
| [错误定位与修正](repair/output.json)，[输入](repair/input.json) | 假设论证先承认所有权已经移走，再错误地推断借用旧绑定不受影响；要求定位第一个错误连接，并在保留所有者及两次打印的条件下修复。明确是假设推理，没有将它归为用户误解；新借用表达式留给用户。 | [原题](code/repair-original.rs) 报 E0382；按私有解析[改为借用当前所有者](code/repair-solution.rs) 后编译通过，分别输出 `owner: Foo(7)` 与 `view: Foo(7)`。 |
| [反例与适用边界](boundary/output.json)，[输入](boundary/input.json) | 检验“经历过共享借用且未修改字段，就始终能读取旧绑定”的过强主张；要求补一条满足限制的语句，并解释为什么构成反例及缺失条件。共享借用已结束和打印不移动作为已给条件，具体反例留给用户。 | [原模板](code/boundary-original.rs) 能编译，输出两行 `Foo(0)`；加入私有解析给出的[后续移动语句](code/boundary-counterexample.rs) 后，最后读取旧绑定报 E0382，且未修改字段或重新声明旧绑定。 |

三道题均要求把原文关系与具体操作结合。复制“借用不取得所有权”或“借用不绕过所有权规则”不能单独完成对应的求值判断、限定修复或反例构造。解析保存在既有私有 `explanation`，实际公开文本和 `target` 未写出具体解答。编译用的对照／修复均在验证记录中说明唯一改动，生成输出原样保存。

## 已知限制

- 本轮证明三种明确请求下能生成相应任务，并核对这些固定样本的事实正确性；没有验证跨学科稳定性、自主选型频率或学习收益。真人学习者为 0。
- 本轮内容生成使用独立子代理，未执行生产 Provider 的自主工具循环。正式交付与帮助记录沿已有实现；其验证见 [上一片的工程记录](../tutor-question-rationale-20261014/README.md#工程验证)，本轮没有重复运行未改动的交付路径。
- 语义区分力与答案边界依靠指导和内容判断，没有程序化保证每次生成都满足。`tb4.v4` 和本片 `tb4.v5` 已随 2026-10-15 版本发布；此前发布记录见 [tb4.v3](../tutor-question-discrimination-20261014/README.md)。
