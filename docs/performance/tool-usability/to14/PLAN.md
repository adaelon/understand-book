## 模型、预算与停止

- 所有模型决策使用用户已指定的 `gpt-6.1-sol` 隔离 Codex 子进程，reasoning effort 固定 medium；温度由 Codex 服务决定，客户端不暴露此参数。记录实际 CLI 版本、指定模型及运行记录；不调用 DeepSeek。
- MCP9 复用真实临时 HTTP／SQLite／发布材料。Resident 复用原 `/agent/chat`、状态、校验和分派，用测试 ModelAdapter 将每次真实 AgentRequestPlan 交给新的 Codex 子进程，返回 AssistantTurn。两组使用同一转换，不模拟工具成功结果；这不是原生 DeepSeek Provider 验收。
- 每个 Resident 任务最多 8 次模型决策，每次 180 秒；MCP 每个任务最多 300 秒。每次完成后累计实际 usage，达到每任务 120,000 token 或全批 1,500,000 token 后不再发新请求。正在运行的请求可能超过阈值；没有声称硬累计 token 封顶。
- 不调用计费 API，不更改订阅／购买设置。货币费用只有宿主返回才记录；缺失为 null，不以 token 换算或写零。累计 usage、缓存输入、活动请求估算和定义字节分别报告。
- 固定次数结束即停止；产品拒绝、超时、未完整交付照常占分母。不补抽到成功。执行器接线故障单列并保留；修复后若改变实验输入，使用新批次并说明。

## 判定与失败处置

先用 Node 测试检测未决／失败被算成功、未读来源被引用、usage 缺失被计零、活动上下文被当累计费用；失败修评测脚本。编译和一个无模型夹具回放检测测试适配器不能驱动实际宿主；失败只修接线。已有 TO1–TO13 不变路径沿用原验证。

确定性判定以实际工具返回、来源区间、重开存储和交付事件为依据。数学条件另用两段正时间恒等式 `(v1-v2)*(t1-t2)=0` 与 10/10、1/2；10/20、1/1；60/30、1/2 的算例核对；原回答和原话位置保留。无法由程序充分判断的语义要求记 needs_review，不假装机器完成了语义校准。

若新版本没有测出收益，明确报告。对能直接归因且明显增加输入成本的无收益示例投影进行窄范围回收；整组对照无法单独归因的项目保留证据不足，不借一次样本撤销其他已验证修正。
