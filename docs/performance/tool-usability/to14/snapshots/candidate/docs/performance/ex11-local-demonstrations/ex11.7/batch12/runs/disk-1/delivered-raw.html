为什么半径大的走得更远

弧度的定义就是“拿半径去量弧”：半径 r 的圆上，长度等于 r 的那段弧，对应的圆心角正好是 1 弧度。把 θ 个这样的弧接起来，长度就是 s = rθ。

换句话说，每转过 1 弧度，边缘前进的长度正好等于半径。盘 2 的半径是盘 1 的 r₂ 倍，同一角度下它走过的弧也就是 r₂ 倍——这正是图里两条展开条长度之比。

相同的是角度，不同的是路程

两盘共用同一个 θ：扇形张角相同、参考射线转过的角度相同；但弧长 s₁ = 1·θ 与 s₂ = r₂·θ 不同。路程比 s₂/s₁ = r₂/r₁ 与 θ 无关；路程差 Δs = s₂ − s₁ = (r₂ − r₁)·θ，当 r₂ = 1 或 θ = 0 时正好是 0。

怎么用这张图

  • 拖动转角 θ 滑块，或直接拖动圆盘上的圆形手柄：两盘的扇形与圆弧同步扫过同一个角度。
  • 拖动半径 r₂ 滑块，或拖动盘 2 半径虚线末端的方块手柄：只有盘 2 的半径、弧长和橙色展开条变化，盘 1 不变。
  • “播放”按 π/4 弧度一步连续推进（8 步转满一圈），再点一次暂停；“上一步”按同样步长回退；改变 θ 或 r₂ 会先暂停。
  • 操作结束后位置会自动保存，重新打开这一版页面会回到同样的 θ、r₂ 和步进位置。

假设

理想圆周运动：θ 以弧度计，s = rθ；盘 1 半径固定为 1 个长度单位，盘 2 半径在 1–3 之间可调，θ 在 0–2π 之间。这里不考虑速度、时间、摩擦等因素——路程只由 r 和 θ 决定。
