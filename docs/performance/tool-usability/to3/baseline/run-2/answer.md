上一段说的是「天平按时间倾斜」。这一步把它变成一个能用的式子，你就能分清什么时候可以「直接平均」、什么时候一定不能。

原文只有三句：**Average speed is total distance divided by total time. Equal distances need not take equal times. The total time must be positive.** 

## 1. 把定义写成加权平均

把整趟行程切成若干小段，每段里速度恒定；第 i 段的速度记为 v_i，花的时间记为 t_i。定义里的两个总量分别是：

- 总路程 = 各段路程之和 = Σ v_i·t_i（每段路程就是「速度 × 该段时间」）
- 总时间 = 各段时间之和 = Σ t_i

代进定义：

**平均速度 = Σ(v_i·t_i) / Σ t_i**

右边正好是**加权平均**的形式：被平均的对象是各个速度 v_i，而每一段速度的权重是它花掉的时间 t_i。所以平均速度不是「速度们的平均值」，而是「你真正保持过的那些速度，按保持时长加权后的结果」。

## 2. 从式子直接读出两个结论

**结论一：只有各段时间相等时，直接取算术平均才对。** 若 t₁ = t₂ = … ，权重全部相同，式子退化成 (v₁ + v₂ + …) / n。时间一不等，权重就不等，直接平均就失真。

**结论二：平均速度一定夹在最慢段和最快段之间。** 权重都是正的，加权平均跑不出被平均对象的最小值与最大值之外。它不可能比全程最快的那一段还快。

## 3. 回到 60 / 30 那个例子（我按定义算的例，不是原文的例子）

两段各 60 km，速度 60 km/h 和 30 km/h，用时 1 小时和 2 小时。用加权式子：

- 平均速度 = (60×1 + 30×2) / (1 + 2) = (60 + 60) / 3 = **40 km/h**

权重是 1 和 2：慢的那段权重是快的两倍，所以结果被拉到 30 那一侧，比 (60+30)/2 = 45 小。那个 45 之所以错，就是因为它默认了两段权重相同——那是「相等时间」的权重，不是「相等路程」的权重。

顺带把等路程这条说完整：两段路程相等时，直接平均的结果**一定不小于**真实的平均速度，而且只有两段速度恰好相等时两者才相等。所以拿等路程问题去平均速度数值，你只会把结果算高，不会算低。

## 一句话抓手

把定义写成 a̅ = Σ(v·t) / Σt：速度是被**时间**加权的，时间才是分母上的「记分员」。想省事直接取算术平均，前提是各段时间相等；等路程的情形不满足这个前提，所以它总是个高估。
