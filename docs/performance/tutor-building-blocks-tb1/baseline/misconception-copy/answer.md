你的思路里大部分是对的，只有一步需要改。

- 对的部分：「变量可以赋值」——这没问题，赋值本身确实存在。
- 要改的部分：把 `&foo` 读成「把 Foo 复制了一份给 bar」。问题的关键在于 Rust 中 `&` 的语义。

借用让代码在不取得所有权的情况下临时访问值。它不是绕过或放宽所有权规则，而是所有权模型本身的一部分。

套到书里那段代码上看：

```
let bar = &foo;
```

注意变量 foo 前面的 &。我们借用了 foo，并把借用赋给 bar。bar 的类型是 &Foo，也就是引用类型。由于这是不可变引用，我们不能通过 bar 修改 Foo 中的值。

也就是说，`&foo` 并没有造出一个新的 Foo 拷贝；它创建的是对 foo 的引用（借用），而 `bar` 的类型是 `&Foo`，指向的仍是 foo 所持有的那个值。

所以两个 `println!` 都能运行的原因，不是「存在两份副本」，而是借用本身：foo 依然拥有它的值，bar 只是临时引用它——这正是「不取得所有权而临时访问」。

需要改的就这一步：把「& 复制原值」替换成「& 创建引用（借用）」。
