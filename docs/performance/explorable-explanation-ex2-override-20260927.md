# EX2 续批：取消用量上限后的对照

后续修复进展见 [v4](explorable-explanation-ex2-v4-20260927.md)、[v5](explorable-explanation-ex2-v5-20260927.md) 和 [v6 总账](explorable-explanation-ex2-v6-20260927.md)。本记录的历史结果保留；当前仍未通过 EX2，生产 ed3.v1 未改。

日期：2026-09-27。用户明确表示超过上限可以接受。EX0 中的 300,000 tokens、300 秒及其他题的倍数限制是本次实验预设的成本门槛；原始记录不改，本续批将用量和时长记为观察值，不以超限判失败。Provider 错误、未交付、内容或数值错误仍记失败。

## 续批条件（运行前记录）

- 候选选 `ex2.v1`。首批 v1、v2 都交付；v2 没减少重写或模型回合，亦未显示出 v1 缺失的具体表示收益。因此先用较短的 v1 做同底座 B/C。两版首批记录只用于选候选，不混入续批稳定性分母。
- B 为生产 `ed3.v1`；C 仅在 Runtime 已加载 presentation method 时，把该 asset 的正文和 revision 换为冻结的 `ex2.v1`。两组使用相同的当前代码、工具、模型、温度、三视口要求和独立会话。续批代码改动仅为实验适配器的 v2→v1 文件指向；生产仍为 `ed3.v1`，待对照结论决定是否启用。
- 学习率题各三次，保留全部失败，先交错 B1/C1，再继续 B2/C2、B3/C3。其余三题各一轮 B/C。输入与独立答案沿用 EX0，不把答案或控件要求放入自然请求。
- 学习率质量沿用 EX0：一维范围、`η=0.2/0.8/1.1` 的方向和距离变化、数值与文字正确，且 C 要有相对 ED3/B 的具体表示收益。其他题直接看是否按题作答，以及不必要页面、虚构因果或动画。模型回合、tokens、墙钟照实记录，不作为本续批拒绝条件。
- 若同底座样本已经足以证明候选没有新增表示收益，则停止剩余重复运行并记录依据；若发现候选有收益，按预定重复运行判断稳定性。每次运行仍保留原始请求、响应、交付和 Provider 用量。

## v1 续批结果与 v3 修订（v3 运行前记录）

同底座 B1、B3 交付；B2 返回 200 但 `incomplete=true` 且没有 `view.json`，按未交付失败。C1、C2、C3 均交付。C1 直接并排显示 η=0.25/0.75 的相同距离缩小速度与不同方向，C2 用步长/距离同标尺解释 η=0.5 与 1，C3 也显示 η=0.3/0.7 的等幅不同向。然而 C3 的 readable description 把 η=0.9 的 `w_3` 写成约 2.75，独立答案和迭代式给出 3.024；随后几步也不符。页面 `index.html` 没有硬编码这些错误数，说明错误位于交付的可读文字。EX0 明确要求 readable content 数值正确，因此 v1 不满足三次全对，不能据此启用。

候选 [v3](explorable-explanation-ex2-skill-v3.md)只针对已发生的两类问题修订：把等幅不同向的成对比较写入可选表示方法，并要求页面、可读描述、最终文字中的数值从同一计算核对。生产与 B 条件不变。B1–B3 原始记录可继续作为同底座对照：适配器文件指向只在 C 已加载说明时生效。v3 运行三次 C 学习率；若仍有内容或数值错误则停，不启用。若三次均正确，再跑其他三题的 B/C 退化对照。成本继续只记录，不设拒绝上限。

所有续批请求、响应、交付页与 Provider 用量保存在 `ex2-windows/override-*/`；`outcome.json` 的 `incomplete` 和 `view.json` 是否存在共同决定交付，单看 HTTP 200 不够。v1 的三次 C 都能在页面上区分过冲与幅度，且 C1/C3 的等幅不同向对比是具体表示收益；但 C3 的可读内容错误，三次全对条件未成立。v3 首次交付又有同类最终文字错误，按运行前条件停止，未运行 v3 C2/C3，也未运行另外三题的 B/C。交付页面存在不抵消交付文字中的错误。

## 最终决定

EX2 目前未通过**数值正确性**门槛。取消用量上限后，tokens 与时长只作为成本实录；它们不再是拒绝原因。v1/v3 均不接入生产，`skills/presentation/SKILL.md` 及 Runtime revision 保持 `ed3.v1`。EX0/EX1 与 EX5a 的独立工程结果不受影响。

## 已知限制

- v3 在第一轮已触发预定停止条件，普通短答、证据边界、静态换视角的新版退化尚无结果；不能断言这些题不会退化。
- 当前证据说明候选有局部表示收益，同时存在真实数值错误；没有完成合格候选的三次稳定样本，也没有真实读者学习前后测量。
