## 两类证据

`evals/semantic/mind-map-acceptance.mjs` 不调用模型。它通过真实 HTTP 接口读取原 Rust 材料并创建导图，验证版本冲突、复制与删除整支、撤销重做、重新读取和来源定位；具有学习空间的宿主还可验证共享笔记正文不随画板撤销回退。浏览器部分打开实际 Reader，操作桌面与 390 × 844 手机视口，验证中文输入、快捷键、拖动、多选、折叠与搜索、大纲、导入导出、手机移动与双指缩放。

`evals/semantic/mind-map-replay.mjs` 使用既有真实模型配置和原游客的材料、前三次请求。第一轮选中原文解释，第二轮要求导图，第三轮对人工补充的精确可变切片主题说“没懂”。它要求第二轮产生正式的 Topic 树，并记录第三轮是否只提供局部解释。随后三轮覆盖补例子期间编辑另一支、同一字段发生冲突和按当前内容重新生成。

`evals/semantic/mind-map-performance.mjs` 把与布局测量相同的 500 主题样例真正保存到服务，并打开实际 Reader。标签来自本机 Rust 书源，结构是固定五叉树，不将它称为模型生成的章节提纲。测量首次显示、五次本地输入反馈与改名显示、服务器保存耗时、指针平移后的下一帧响应和关闭页面后的重开；模型等待不计入编辑性能。

并发编辑发生在模型已产生真实候选以后。脚本记录候选版本、基线修订、预览状态和冲突信息，检查承接其他分支变化后是否出现新的实际预览。生成内容、候选、失败与耗时全部保留；不以预先写好的回答替代模型。

## 运行

在项目根目录执行，显式指定本次构建的服务和 Web 目录：

```text
node evals/semantic/mind-map-acceptance.mjs --server <server.exe> --web-dist <dist> --out tmp/editable-mind-map-20261028/acceptance-01
node evals/semantic/mind-map-replay.mjs --server <server.exe> --web-dist <dist> --out tmp/editable-mind-map-20261028/replay-01
node evals/semantic/mind-map-performance.mjs --server <server.exe> --web-dist <dist> --out tmp/editable-mind-map-20261028/performance-01
```

默认原材料、历史事件和私有模型配置从相邻的原工作树读取。可用 `--book`、`--history`、`--env` 改为明确位置；配置文件与私有历史不会复制到提交资料中。Windows 使用已经安装的 Edge，可用 `--browser` 覆盖。临时浏览器数据写入输出目录，避免占用系统盘。

无模型服务验收可用 `--api-only`，浏览器验收可用 `--ui-only`，避免无关重跑；实模回放可用 `--stop-after 2` 分段查看生成树，再用同一目录的 `--resume` 继续。新尝试使用新目录，失败结果保留。每个输出目录的 `run.json` 记录真实状态，截图与导出文件用于直接视觉检查。

每个新目录都会复制当次服务二进制和 Web 构建，运行中不会换成后续构建。`--resume` 保留该目录原有构建。修复后可用 `--continue-ui <旧UI目录>` 在新目录复制隔离数据、从折叠定位继续；`--ui-stage export` 则只运行导出及后续手机组。`--continue-replay <旧回放目录>` 支持已完成前三轮、第四或第五轮失败的已观察场景：保留历史中的失败请求，使用失败请求的聊天头，只重试失败轮及后续轮，并在新候选出现后做不同于当前标题的人工修改。已成功轮次标注为继承证据，不重复请求模型，也不改写旧证据。

第六轮已提交但验证发现人工标题被改时，续跑先通过正式撤销恢复人工树；若后续请求未产生候选或提交，则继续保留恢复后的修订，严格检查内容与撤销历史，不再次撤销。实际交付后的断言或截图问题可用 `mind-map-regeneration-verify.mjs --resume --before-replay <前一目录>` 只续验已有结果；这个脚本不创建模型请求。

## 证据范围

自动检查只能说明保存、编辑和生成链路在这次输入下的行为。讲解内容还需直接阅读、Rust 代码需实际编译，截图需直接查看。一次回放不能证明原游客已经理解，也不能代替 500 主题的性能测量；性能记录由独立规模场景提供。

手机验证使用 Edge 的 390 × 844 触屏视口与真实浏览器触点事件，并非实体手机。中文输入覆盖编辑器实际接收的组合开始／确认／结束事件和文本保存，没有控制 Windows 输入法候选窗。共享空间笔记由学习空间服务集成测试覆盖，未在单书 Reader 脚本中伪造学习空间宿主。旧图转换使用独立真实模型与 Reader 确认、撤销流程，见 [旧图转换验证](conversion/RESULTS.md)。

## 内容局限

`replay-02` 第三轮已经从整图复述转到具体索引与写入因果，但措辞仍不完美。“s 自己一个整数都没存”更准确应为“不存放这些元素的副本”，因为切片引用本身包含整数形式的长度；末尾把“地址、元素个数、允许写入”连写，可能让初学者误以为写权限是胖指针的第三个运行时字段。图的几何与编辑功能通过不能推出教学文字完美，更不能推出原游客已经理解。
