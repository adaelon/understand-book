# Tutor T9–T12 判定、学习证据与理解视图

日期：2026-09-29。基于 `5e10516` 和工作区已有 T0–T8，实现 T9–T12。代码和文档保持未提交。

## 实际行为

T9 在 `tutor.step select` 接纳前冻结题面、正式对象修订、能力、评分规则、来源正文、反馈策略及解释器版本。合同随私有 MoveSelected 保存；同一动作不能改标准。交付、对话历史和公开工具 Trace 不包含私有键、rubric 或未请求的帮助参数。集合选择题支持单元素或 JSON 数组，忽略 token 大小写及两端空白；正好匹配为 correct，正确集合的非空子集为 partial，包含错误选项为 incorrect，未知 token 或来源不足为 uncertain，格式/技术失败保持 unassessed。

T10 通过原 Resident 的 `tutor.step assess(action_ref)` 调用一次隔离评估，使用冻结 rubric、确切回答和原来源正文。输出逐项回答片段、来源引用、判定与说明；服务端检查项目完整性、唯一性、原文/回答子串及引用范围。缺项、错引或不完整模型输出不能写入 Assessment。每个回答每次运行最多一次评估，调用占用原运行次数，usage 计入原总量，沿用取消及模型上下文检查，输出上限为 3,000 tokens。普通教学回合只获得接纳后的状态和有条件的学习摘要。

正式提交先保存 Trace，封闭题再判定；评估失败不会丢失回答。每次改答保留自己的尝试序号和此前实际展示的帮助。帮助、解释与 rubric 详细反馈在宿主实际可见后追加 HelpDisplayed；读取或生成反馈本身不证明展示。按 on_reveal 冻结的详细反馈在明确揭示前不进入普通页面或理解视图。

T11 将可用 Assessment 确定性解释为条件化 LearningEvidence，记录原对象/来源/素材版本、能力、回答、帮助、尝试和精确行为引用；无评分来源辨析可由 Resident 提议带回答片段与原文引用的解释，仍保持可纠正观察身份。自评只保存主观身份，纯浏览和未评分提交不会生成客观能力结论。投影区分独立、帮助后和改答后的符合标准次数，以及部分符合、不符合和不确定表现，不生成统一掌握布尔值。

学习证据与替代解释保留在 learning.db。知识和路径投影保存解释器版本、证据水位和 TeachingMap 版本集合；清空后可确定性重建。事务中断保留旧投影，下一轮或显式重建可补全 Assessment 后中断的证据。纠正旧回答不会把路径退回旧活动；旧对象修订的表现不自动用于新修订。

T12 在“学习会话 → 我的理解”展示对象、能力表现、帮助条件、原话和系统解释，并提供依据、完整解释历史及纠正入口。保存失败沿原操作重试；纠正形成替代解释，保留原事实和用户原话。每轮根据当前焦点或所引用活动冻结相关学习上下文：至多六项表现、条目正文合计至多 6,000 字符，另含至多六项路径摘要。详细解释按每次 8,000 字符读取；理解对象和历史分页。未知不会补为低能力，陈旧视图明确提示，直接讲解继续优先于适配策略。公共 TeachingMap 不接收私人纠正写入。

## 真实模型样本

固定原文：`Average speed is total distance divided by total time. Total time must be positive.`。两个预先冻结标准分别要求总路程作分子、总时间作分母，允许等价表达；本组不把正时间条件额外加入已冻结 rubric。期望结果在调用模型前从原文确定，生成者不负责设定期望答案。

| 原回答 | 预期/实际 | 模型引用与说明 | usage |
| --- | --- | --- | --- |
| all distance over all elapsed time | correct / correct | 将 all distance、all elapsed time 分别与原文 total distance、total time 对应 | 888 |
| It uses total distance; I do not know what to divide by | partial / partial | 路程项 supported，明确缺分母的时间项 unsupported | 919 |
| It is the colour of the road | incorrect / incorrect | 两项均 unsupported，引用原定义说明缺失标准 | 1,034 |

总用量 2,841 tokens，三组耗时合计 9.58 秒。返回的回答片段与来源引文均通过确定性检查；对照原文，三个语义判定均成立。

## 已知限制

- 封闭题首版支持集合选择；未实现排序、匹配和确定计算等其他题型。未评分来源辨析生成可纠正的观察解释，不能直接升级为客观正确或掌握。
