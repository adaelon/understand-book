上一轮划出的界线是：训练误差低不等于验证误差低。材料接着写的 L2 正则化，动的位置在训练目标本身——在原来的训练损失上加一项惩罚，再照这个新目标求解。下面按目标、梯度、为何不构成保证三步走。

**一、λ=0.01 的训练目标**

材料给的常见目标，预测记作 f_w(x)：

J(w) = (1/n)∑[f_w(x_i) − y_i]^2 + λ∑w_j^2，其中 λ ≥ 0 调节惩罚强度。

把 λ=0.01 代进去：

J(w) = (1/n)∑[f_w(x_i) − y_i]^2 + 0.01∑w_j^2。

两项各管一件事。第一项是经验训练损失：n 个训练样本上预测误差平方的平均，单看它就是训练误差。第二项是惩罚项：把所有参数的平方加起来，再乘 0.01；参数整体越大，它越大，参数全为 0 时它取最小值 0。材料特意点明 0.01 的读法：它是参数平方和的权重，并不对应“从训练误差里减掉 0.01”。另有一条约定得先定下：材料说是否惩罚偏置须按模型约定——若约定不惩罚，∑ 只走权重、不含偏置；若约定惩罚，偏置也在求和里。


**二、惩罚项与它的梯度**

对单个参数 w_j 求偏导。惩罚项 λ∑w_j^2 对 w_j 的偏导是 2λw_j，λ=0.01 时就是 0.02w_j。

第一项也贡献梯度。把 f_w(x_i) 对 w_j 的偏导记作 ∂f_w(x_i)/∂w_j，两项合起来：

∂J/∂w_j = (1/n)∑ 2[f_w(x_i) − y_i]·∂f_w(x_i)/∂w_j + 0.02w_j。

后一半就是材料给出的 2λw_j；前一半由经验损失按平方项求导直接得到，思路与最小二乘一致。

取学习率 η，梯度下降一步是 w_j ← w_j − η·∂J/∂w_j，把 0.02w_j 那一项拆出来：

w_j ← w_j − η·0.02·w_j − η·(前一半) = (1 − 0.02η)·w_j − η·(前一半)。

从这个式子能读出惩罚项的作用方式：每一步更新先把 w_j 乘上一个略小于 1 的系数（在 0.02η 远小于 1 的通常情形下），再按数据项走一步。|w_j| 越大，这一步缩掉的绝对量越大；w_j=0 时缩掉的量为 0。所以它施加的是朝向零、强度与 |w_j| 成正比的回拉，而不是每一步减去一个固定量。这就是 L2 被叫做权重衰减的由来。材料把这种局面表述为：优化时，模型在拟合训练样本与保持较小权重之间取舍。第一项要把权重调到能压小训练误差的位置，第二项要把权重压小，λ=0.01 就是给第二项定的分量。


**三、这为什么能缓解过拟合**

接上一轮的机制：过拟合是模型去贴合训练数据里的偶然细节。要贴合只在少数训练样本上出现的细节，模型通常得把相应方向的权重调大，让那些特征在输出里占更大份额；权重越大，输出对这些输入细节越敏感，换到新样本时这份敏感就变成误差。

惩罚项的回拉强度与 |w_j| 成正比、方向朝向零，于是“靠放大权重记住偶然细节”这条路变贵了，最优解偏向权重较小、把拟合任务分散到更多参数上的配置。第一项仍然在位，训练集里普遍成立的规律照旧值得拟合，只是它不再能靠任意大的权重来换。材料说这一步可能降低方差、改善泛化；这里的方差可以理解为模型对训练数据具体取值的敏感程度。


**四、为什么不能保证验证误差一定下降**

第一，动的是目标，量的却是另一份数据。惩罚项只改变训练目标和它的最优解，而验证误差在未参与拟合的数据上计算。训练目标变小不等于那份数据上的误差变小。材料的原话是：正则化可能降低方差、改善泛化，但不会保证每份验证集上的误差都下降。

第二，λ 太大会走向另一头。惩罚项压过数据项时，权重被压得太小，模型连训练集里稳定成立的规律也拟合不足，即欠拟合，验证误差反而可能上升；λ 太小则正则化作用很弱，过拟合的风险仍在。λ=0.01 具体落在哪一头，取决于数据规模、损失量级和模型，材料没有给出通用答案。

第三，验证误差本身只是估计。同一组权重、同一个 λ，换一份验证数据，数值会变——上一轮“数据划分与度量相同”的前提在这里同样适用，所以“这份验证集上更好”不等于“任何验证集上都更好”。

第四，所以材料给的做法是用验证数据选 λ：取几个不同的 λ 各训练一次，比较各自的验证误差，选实测更好的那个。这一步靠的是比较，而不是从理论上推出某个 λ 必然更好。

三句话收束：λ=0.01 的 L2 目标就是“训练均方误差 + 0.01×参数平方和”；它的梯度给每个权重加一条强度为 0.02|w_j|、方向朝向零的回拉，使权重不容易被放大、模型不易靠放大权重去贴合偶然细节；这使“可能改善泛化”成立，但验证误差是否下降仍要靠在具体验证集上比较，因此不构成保证。
