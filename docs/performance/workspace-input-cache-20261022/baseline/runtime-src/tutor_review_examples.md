以下是历史页面及构造对照的教师示范，用于校准怎样依据理解目的判断表达。它们不是当前待审页面、当前来源或学习者表达；其中的文字、数字和判断不能充当当前 answer_quotes、来源引用或学习者依据。当前请求决定用途与范围，当前实际交付决定是否存在问题；示范不覆盖当前请求，也不规定每页需要提出几条意见。

## 历史案例：通过调整时间理解局部与整体加速

本例要帮助读者理解“模型推理快 3 倍，整个任务能快多少”，并通过调节模型时间、其他时间与加速倍数观察关系。用途是建立并探索这层关系，后续可以继续推导和讨论条件；不是固定的短视频模板。

作者自述称页面有三条滑块、五项结果、同比例尺的前后时间条、公式和来源。这些说明作者想做什么，不能证明读者已经能从画面看清关系。

实际页面文字和历史截图提供了另一层证据：首屏是首轮调用案例、资源核算解释、引用和公式；继续向下经过三条滑块、五张数字卡片及代入公式，才到前后时间条。默认模型时间 76.294 秒、其他时间 0.216 秒、加速 3 倍，显示原总时长 76.51 秒、新时长 25.65 秒、整体 2.98 倍、模型占比 99.7%。开头讲的是只把首轮 36.375 秒减半，随后默认交互加速全部模型调用。加速后时间条的浅色轨道仍延伸到原总时长；极细的其他阶段确实存在，图下注明“模型 25.43 秒＋其它 0.22 秒＝25.65 秒”。下列意见依靠这些实际证据成立。

reading_path 可据此还原为“先读案例与公式，再记住滑块和结果卡，最后看同比例尺时间条”；理解负担是读者要跨屏把先前数字接回图形关系。整体调整是先让核心时间条与主要操作形成一次完整解释，再展开真实配比、推导和条件。它说明为什么调整有用；是否必须拒绝交付，还要区分下面各项的性质。

**表达改进：把需要一起观察的关系放在一起。** 核心时间条出现在多段说明与控件之后，读者要先记住多个数字和符号，再跨屏寻找它们的关系。对于本例的交互理解用途，先让人看见哪一段缩短、哪一段不变、任务何时结束，更直接。可将前后时间条和主要结果移到开场的可见区域，让主要操作靠近变化；公式、来源和适用条件保留，详细部分可展开查阅，影响解释成立的条件仍在相关位置说明。写入 improvements，说明实际顺序、跨屏记忆负担和具体调整；不能仅凭图在后面就判定当前问题未回答，更不要求所有证明或长课程首屏放图。

**表达改进：用能显现差别的起始例子。** 默认 99.7% 的模型占比使局部 3 倍几乎等于整体 2.98 倍，计算正确，却不容易先看出局部与整体的区别。可先用明确标为教学数字的“模型 45 秒＋其他 15 秒”：模型加速 3 倍后是 15＋15＝30 秒，总时长从 60 秒变 30 秒，整体 2 倍。再切回实测时间配比，解释模型占比接近全部时为何接近 3 倍。写入 improvements，增加有解释作用的对照并保留真实配比；不能把正确但对比不明显的例子判为数学错误。

**必须修正：切换例子时保持对象明确。** 开场只加速首轮，默认却加速全部模型调用；“只加速首轮”预设又把 36.375 秒放进模型段，把 40.135 秒放进标为“工具与等待”的其他段。后者实际包含后续三轮模型的 39.919 秒，标签确实改变了对象。读者容易把两次优化当成同一范围。应在每个预设及时间条旁明确“本次被加速段”，将其余部分准确标为“其他不变阶段”，同步占比与说明；首轮预设明确后续模型也保持不变。将真实误标写进 findings；无需重算已经正确的两组结果，也不能以其他表达建议替代这一修正。

**表达改进：区分实际耗时与空出来的轨道。** 加速后的浅底仍占满原长度，结束位置不明确，可能被看成剩余工具耗时。这里的障碍是视觉含义有歧义，不是作者把整个浅底定义成工具，也不是 0.22 秒的其他段没有画。可让实际时间条在新结束位置终止或加明确结束线，保持其他段真实长度并随前段缩短而左移；省下的时间单独标在执行条之外。图下注释已经给出正确耗时，可在 improvements 中提出直接区分“仍要执行”与“已经省下”的画法，不把可能误读改写成实际计算错误。若另一页明确把省下的时间标为执行时间，那才是应进入 findings 的真实错误。

如果审核只说“公式正确、引用齐全、有控件，所以接受”，就漏看了这些表达是否帮助完成当前用途。已有公式可以回答数量关系，同时仍有具体改进空间。本例由于对象误标而 revise；修正误标后，其他有依据的建议仍可随 accept 交给作者。判断不必在“什么也不提”和“所有意见都拒绝交付”之间选择。这四条来自这一页的证据，不是后续页面的审查配额。

## 同一案例里不成立或过度的意见

“做得更美、增加动画”没有说明什么关系没讲清，也没有证明新增形式有用。“所有内容都放第一屏、每页缩成短视频”会破坏需要逐步建立的解释；本例只需调整关键关系的位置。

按钮写“书里实测配比”不等于宣称书中测得了 3 倍优化或 2.98 倍整体收益。可以把实测时间配比、题设加速倍数及计算结果说明白，不能据此指控实测造假或禁止准确名称。其他阶段已有细线及秒数，不能说完全没画；3 倍得到 2.98 倍符合该配比，不能说公式算错。修订应保留正确来源、公式、假设及有效说明。

## 构造正例：完整的长推导应当接受

用户要求从平方误差完整推导含截距的一元线性回归，先解释均值与中心化，再展开误差、求最优斜率、说明最小性，给数字核对并处理所有 x 相等的情况。此处用途是深入推导，篇幅随这些连接展开。

实际完整页面先定义 L(a,b)=Σ(yᵢ−a−bxᵢ)²，并用均值偏差和为零解释交叉项为何消失。固定 b 后令 rᵢ=yᵢ−bxᵢ、m=ȳ−bx̄，展开得到 Σ(rᵢ−a)²=Σ(rᵢ−m)²+n(m−a)²，因此最佳截距是 m。随后定义 uᵢ=xᵢ−x̄、vᵢ=yᵢ−ȳ，逐项展开 Q(b)=Σ(vᵢ−buᵢ)²；令 A=Σuᵢ²、B=Σuᵢvᵢ、C=Σvᵢ²，说明至少两个 x 不同时 A>0，再展示补项与减回的配方过程，得到 Q(b)=A(b−B/A)²+C−B²/A。正文解释非负平方为何在 b=B/A 时最小，以及截距和斜率的两个非负增量能够同时为零，所以这是唯一的全局最小值。

页面还用 (1,2)、(2,2)、(3,4) 算出斜率 1、截距 2/3，并以残差平方和与 C−B²/A 两条路径核对 2/3。所有 x=c 时，说明 A=B=0，问题变成选择共同高度 h=a+bc；最优 h=ȳ，斜率与截距不唯一。

教师判断：这些实际连接共同回答了所问推导，后段使用前段已说明的性质，数字与退化情况也各有作用，应 accept，findings 与 improvements 均可为 []。reading_path 简述“前提与中心化性质→逐项展开及配方→全局最小性→数字核对与退化条件”，理解缺口和调整均为 null。不能仅因长、公式多或没有交互而删减、重排或追加操作。若同页把逐项展开及配方删成“整理可得 b*=B/A”，则用户明确要求的连接缺失，应 unresolved 并要求补回；后面的最小性断言和单个数字验证不能替代一般推导，更不能将缺失的一般推导仅放进 improvements 后接受。
