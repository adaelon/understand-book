接着上一轮讲的两种误差，下面把 L2 正则化写成一个可求导的目标函数，看它在优化里具体做了什么。

**一、λ=0.01 的训练目标**

材料给的常见目标是

J(w) = (1/n)Σ_i [f_w(x_i) − y_i]^2 + λΣ_j w_j^2，λ ≥ 0

把 λ=0.01 代进去：

J(w) = (1/n)Σ_i [f_w(x_i) − y_i]^2 + 0.01·Σ_j w_j^2

第一项是经验训练损失：n 个训练样本的预测值与真实值之差的平方取平均，也就是上一轮说的训练误差（均方误差）。第二项是惩罚项：把每个权重 w_j 各自平方后求和，再乘 0.01。


0.01 的位置是权重，它乘在“参数平方和”这个整体上，表示这一项在目标函数里的相对分量；式子里没有 −0.01 这样的减项，训练误差也不会被扣掉 0.01。材料特意点出这点，是因为上一轮 A 的训练误差恰好也是 0.01；两个 0.01 只是数值上的巧合，一个是被比较的误差值，一个是惩罚项的系数，作用对象不同。

两个条件也在材料里：λ ≥ 0 用来调节惩罚强度；偏置项是否惩罚要按模型约定。所以 Σ_j w_j^2 到底包含哪些参数，取决于这个约定，不能默认一定含偏置。

**二、惩罚项及其梯度**

对单个参数 w_j 求偏导，惩罚项贡献的梯度是

∂(λΣ_k w_k^2)/∂w_j = 2λ w_j

λ=0.01 时即为 0.02·w_j。


从这一个式子可以直接读出三件事。

1. 方向：2λw_j 与 w_j 同号。沿梯度下降走一步 w_j ← w_j − η·∂J/∂w_j 时，这一步把 w_j 往零的方向推。
2. 大小与 w_j 成正比：w_j = 1 时惩罚梯度是 0.02；w_j = 10 时是 0.2；w_j = 0 时惩罚梯度为零，此时惩罚项不再拉它。也就是说，权重越大，被拉回零的力越大。
3. 它与数据项相减，而不单方面决定参数。完整的梯度是

∂J/∂w_j = ∂L_data/∂w_j + 2λ w_j

其中 L_data 表示第一项训练损失，这个分解是常规求导写法，材料只给出惩罚项那一项 2λw_j。参数最后停在哪里，取决于两项何时抵消：数据项还想把 w_j 推离零，惩罚项以 2λw_j 把它拉回，w_j 越大拉力越强，于是在某一点达到平衡。

**三、这个拉力怎样缓解过拟合**

材料的概括是：优化时模型在拟合训练样本与保持较小权重之间取舍。把它和上一轮的过拟合机制接上（下面这一步是我的展开，材料只给出“取舍”这一句）：

- 要把训练残差压到极小，模型往往需要把某些权重堆得很大，让输出对输入的细微差别做出很陡的反应；训练集里的偶然波动也就跟着被拟合进去。
- 加入 0.01·Σw_j^2 之后，大权重自身要付出代价：这一项随权重的平方增长，权重翻倍，它就变成四倍。
- 所以被选中的参数是“残差小”与“权重不那么大”的折中解：输出随输入变化得更平缓，对只在训练集里出现的偶然波动反应更弱。这对应材料说的“降低方差”，即模型对具体训练样本的依赖变小，换一批同类样本时波动更小。

这里有一个容易被 λ=0.01 误导的地方：0.01 只是权重，惩罚的实际大小还取决于权重量级。同一个 λ=0.01，若权重普遍在 10 附近，0.01·Σw_j^2 会明显大于权重都在 1 附近时，因此不能从 λ 的小数位直接推断影响很小。

**四、为什么不能保证验证误差一定下降**

材料的结论是：正则化可能降低方差、改善泛化，但不会保证每份验证集上的误差都下降。原因可以分几层看（除最后一层外为我的补充说明）：

1. λ 不知道哪些方向是噪声。它按权重大小一视同仁地收缩；若某个大权重承载的恰好是真实规律，收缩会把这个真实信号也压小，偏差随之上升。降低方差与增加偏差同时发生，净效果取决于两者相抵后剩下多少。
2. 净效果是“平均而言”的性质。期望泛化误差可以下降，而验证误差是在一份有限的验证集上算出来的估计，本身有抽样波动；平均上变好的模型，落在某份具体验证集上完全可能误差更高。
3. 这是一个选择问题。材料说通常用验证数据选择 λ：选出来的 λ 只是在手上这份验证集上表现好的那个，换一份验证集，最优的 λ 可能移动。
4. λ 太大会走过头：材料说 λ 太大可能造成欠拟合，即权重被压得太小、连真实规律也拟合不动。

因此 L2 提供的是一个可调的折中，它改变的是解的性质（方差与偏差的配比），并不针对某一份验证集作出承诺；验证误差只能实测。若实测发现误差上升，按材料给出的做法是调整 λ（用验证数据重新选择），而不是因为出现这种情况就判定正则化公式失效。
