接上前面那条界线：正则化改的是训练目标本身，“验证误差要另外算”这一点不动。下面分四步：写出 λ=0.01 的目标，看梯度怎样进入每一步更新，看收缩为什么能缓解过拟合，最后看它为什么不能保证验证误差下降。

一、λ=0.01 的训练目标

设模型对第 i 个样本的预测是 f_w(x_i)，参数向量为 w，训练集有 n 个样本。材料用的经验训练损失是均方误差：

L_train(w) = (1/n) Σ[f_w(x_i) − y_i]²

L2 正则化在这个损失上加一项参数平方和，取 λ = 0.01 后，训练目标是：

J(w) = L_train(w) + 0.01 · Σ_j w_j²

它就是把材料的一般形式 J(w) = (1/n)Σ[f_w(x_i) − y_i]² + λΣw_j² 里的 λ 取成 0.01。

这一项在优化里是给参数大小标的价：某个 w_j 只要偏离 0，这一项就是正的；|w_j| 越大，加价越多，并且按平方增长（翻一倍就变成四倍）。λ = 0.01 定的是这个价格的高低。材料在这里划了一条界线：λ=0.01 是这项惩罚的权重，训练误差并没有因此被减掉 0.01。

还有一个要按模型定的约定：偏置 b 算不算进这个平方和。材料写明“是否惩罚偏置须按模型约定”；不惩罚偏置时，求和只走 w_1, …, w_m，不含 b。

二、惩罚项及其梯度

先看一组假设数字，它是我设的，用来展示比较方式，不是材料数据。固定同一训练集、同一模型结构和 λ = 0.01。假设第一组参数在该训练集上 L_train = 0.05，参数平方和 Σw_j² = 2，惩罚就是 0.01 × 2 = 0.02，目标值 J = 0.05 + 0.02 = 0.07。假设第二组参数 L_train = 0.06，但 Σw_j² = 0.5，惩罚是 0.005，J = 0.065。第一组的训练误差更低，目标值反而更高，所以在这个目标下优化器偏向第二组。这就是材料说的“在拟合训练样本与保持较小权重之间取舍”。

梯度只对参数求，对单个 w_j：平方项求导得 2w_j，再乘 λ，

∂/∂w_j (0.01 Σ_k w_k²) = 0.02 w_j

总梯度是数据项梯度加惩罚项梯度：

∂J/∂w_j = ∂L_train/∂w_j + 0.02 w_j

用学习率 η、按这个梯度走一步：

w_j ← w_j − η ∂J/∂w_j = (1 − 0.02η) w_j − η ∂L_train/∂w_j

式子里有两件事同时发生。第一件，旧权重先被乘上 (1 − 0.02η)：只要学习率取到足够小、使 0.02η < 1，这个因子就小于 1，每一步都先把权重按固定比例缩一点，缩多少由 λ 和 η 共同决定。第二件，−η ∂L_train/∂w_j 才是朝降低训练误差方向走的那一步。惩罚项并不针对某个训练样本做加减，它抬高的是大权重本身的代价。

收缩对大权重更狠：0.02w_j 与 w_j 同号。w_j > 0 时它把梯度抬正，使 w_j 减小；w_j < 0 时它把梯度拉负，使 w_j 增大；两种符号都被推向 0，|w_j| 越大推得越明显。

优化的停点是两项抵消处：∂L_train/∂w_j = −0.02 w_j。在这一点上，数据项还想让 w_j 变大，惩罚项让它变小，权重停在这个中间位置；λ 越大，平衡点越靠近 0。

一段补充推导（我按上面的目标、对线性模型 f_w(x) = wᵗx 用最小二乘算出，并且按偏置也纳入惩罚来写）：正规方程从 XᵗX w = Xᵗy 变成

(XᵗX + 0.01n I) w = Xᵗy，即 w = (XᵗX + 0.01n I)⁻¹ Xᵗy

0.01n 加在对角线上，把解整体往 0 压，λ 越大压得越强。若按前文的约定不惩罚偏置，只是不给偏置对应的对角项加 0.01n；若损失约定不带 1/n，这个系数会跟着变，压缩的方向不变。

三、这个过程怎样缓解过拟合

回到前面的定义：过拟合是模型过度适应训练数据的偶然细节。权重被持续往 0 压，模型就越来越难靠很大的系数去贴合训练集里只属于这批样本的波动，它对偶然细节的依赖因此变弱。这种对训练集具体样本不那么敏感的性质就是方差下降，而方差下降是验证误差有机会变小的一条通道。材料把它概括为一句话：正则化可能降低方差、改善泛化。

四、为什么不能保证验证误差一定下降

第一，J(w) 与验证误差是两个量。J 只在训练样本上计算，惩罚项也只加在训练目标里；优化器降的是一个合成量，即训练误差加权重代价。验证误差在未参与拟合的数据上计算，根本不出现在 J 里。J 变小推不出验证误差变小，这和前面“训练误差低并不保证验证误差低”是同一条界线。

第二，收缩权重是在偏差与方差之间重新分配，而验证误差里还有一项不受 λ 影响的成分。这里用平方损失下常见的偏差—方差分解来看（这个框架是我补的，材料只说到“降低方差”）：把一个在训练集上拟合好的模型放到同类新样本上，其期望误差可以写成偏差² + 方差 + 噪声三部分。偏差是模型的平均预测与真实关系的差距，以平方计入；方差描述换一份训练集时预测的波动；噪声描述数据本身无法消除的随机部分。固定训练集、模型结构与样本量，把 λ 从 0 往上增大：方差趋于下降，偏差² 趋于上升，噪声不动。净效果取决于前两项谁变得更多，而这又取决于模型、样本量和噪声水平，于是没有单调保证。这个等式说的是“期望误差”，某一份验证集上的具体数字只是它的一次抽样结果。

第三，两端都是坏值。λ = 0 等于没有惩罚，过拟合原样保留；λ 大到权重接近 0，模型几乎不拟合真实结构，材料说“λ 太大可能造成欠拟合”，这时的验证误差往往比适度正则化时更差。λ 从 0 增大时，验证误差先有下降的理由、后来又有上升的理由，它在整段上就没有“一定下降”的保证。

第四，结论落在“这份验证集”上。材料原话是：正则化“不会保证每份验证集上的误差都下降”。同一个 λ 换一份划分、换一个样本量的验证集，数字可以不同，验证集本身只是有限样本上的估计。材料因此说 λ 通常用验证数据选择：λ 是在一份具体验证集上试出来的经验选择，它给出的是“在这份数据上更合适”，不是普遍保证。

第五，λ=0.01 这个数值本身也不构成保证。过拟合很重时，0.01 可能收缩不足，几乎等于不正则化；模型本来就很受限时，0.01 又可能偏大。哪种情况成立，仍要看验证误差。

回到前面 A、B 的例子：正则化正是用来压小 A 那种训练—验证大差距的手段，但用完仍要拿验证误差验收。加了正则化不等于验证误差会降，能不能降要在这份验证集上算出来看。
