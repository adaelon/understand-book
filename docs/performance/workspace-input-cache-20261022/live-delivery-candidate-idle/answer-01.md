先把两个误差各自站在哪些数据上说清楚，后面 A 与 B 的比较才有依据。

训练误差在参与拟合的数据上计算：这批样本被用来调整模型参数，误差就是在这批样本上算出的偏差。验证误差在未用于拟合参数的数据上计算，材料把它用来看模型对同类新样本的泛化能力。两者的区别来自数据有没有参与拟合，计算方式本身可以一样，比如材料里的两个数字都是均方误差。

过拟合是指模型过度适应训练数据里的偶然细节。这个过程可以拆成两步看：模型在拟合训练样本时，把只属于这一批数据的偶然波动也一起当成规律拟合进去，于是它在这一批样本上的误差被压得很低；换到没参与拟合的新样本上，那些偶然细节不再出现，误差就明显上升。材料由此给出一条界限：训练误差低并不保证验证误差低。

所以低训练误差只能回答一个问题：模型对已经见过的这批数据拟合得紧不紧。它回答不了另一个问题：换成同类新样本会怎样。挑模型要回答的是后一个问题，于是判断落在验证误差上。

把 A 与 B 的数字放进来，材料先限定了一个前提：数据划分和度量相同。在这个前提下，A 的训练均方误差是 0.01、验证均方误差是 0.30；B 的训练均方误差是 0.08、验证均方误差是 0.12。这两组数一起看，能读出两件事。

第一件，看没参与拟合的数据。B 的验证误差 0.12 小于 A 的 0.30，所以 B 在这份验证集上的泛化更好。

第二件，看训练到验证的变化。A 从 0.01 升到 0.30，升幅是 0.30 减 0.01，约 0.29；B 从 0.08 升到 0.12，升幅是 0.04。这个减法是直接用材料给的两个数字算出的。A 的升幅大得多，材料据此说 A 表现出更明显的训练与验证差距；按上面的定义，这个差距正是过拟合在数字上的样子：训练样本上的偶然细节被拟合进去了，新样本上就露出来。

结论因此是选 B。选 B 的依据是它在未参与拟合的数据上误差更低、训练与验证的表现更接近；它的训练误差比 A 高这一点，在“换新样本会怎样”这个问题上不构成反对理由。要是把“0.01 比 0.08 小”当作选 A 的依据，等于用参与拟合的那批数据的表现替代了未见数据的表现，材料划出的那条界限就被跨过去了。

材料还把 B 的优势限定在“这份验证集上”，并且要求数据划分与度量相同。验证误差估计的是对同类新样本的泛化，一份验证集给出的仍然是估计：换一份划分不同、或度量不同的验证集，这些数字就不能直接这样比。
