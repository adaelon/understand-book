# CQ8 范围正反例与评分器修正 — 2026-09-26

## 实施

Agent 的收尾策略从 v6 更新为 v7，加入三组正反例：局部段落未说明、将原则应用到新场景、询问全书是否涉及某主题。明确指出“根据本轮读到的材料，书中从未……”仍是全书否定；例子覆盖开头、表格和结尾。来源交付策略仍为 v10。

评分器只返回 `source_id/part/quote`，程序在指定已交付来源部分精确定位，计算 UTF-16 区间。保存的标准评分继续使用数值位置；原始模型输出另外保留，历史评分不改写。错误来源、缺失原文、重复歧义以及自行填写 start/end 都使新评分无效。

评分语义新增前后文公式、互补来源、总结沿用与阅读范围例子。支持成立与定位合格分别判断：所有交付部分都参加支持核验；高亮只有孤立词语则定位不满足，即使后文充分。已高亮具体原则、后文给出对应公式的情况可以接受。总结仅复述有依据的正文无需重复引用，新增保证或条件须独立核验。

## 工程验证

新增位置回归先红后绿，覆盖长度 185 的来源、after 公式、UTF-16 非 BMP 前缀、互补来源、错误/歧义 quote、旧数值记录，以及不把缺失 basis 数组自动变成有效 unknown。质量测试最终 **35/35** 通过。提示装配 6 项、来源工具装配 1 项通过，Server 构建成功。编译仍有既存 ts-rs serde 警告。
