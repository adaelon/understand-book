# WB6 正式网页与画板预览部署纠正

2026-10-26：正式网站的两个部署遗漏已修正，截图中公式显示为普通方括号的问题也已修复。当前 release 为 `board-book-20261026`，schema 20、服务 PID 211799。此次修复没有模型请求、数据库迁移或用户画板写入；Windows 0.3.8 下载文件保持原版。

## 故障与原因

用户先报告浏览器阅读页为空，并显示 `Operation or request origin is not permitted`。正式站点误用了 `packages/web/dist` 的本地版入口，页面选择 LocalApp，向云端服务发送了不适用的请求。服务仍有书籍、账号和聊天，错误来自发布包选错前端构建。正式浏览器复现与配置定位后，19:27:17 HKT 换成多人云端构建。

第二张截图只出现“问答讲解”卡片，正文称“本轮讲解尚未准备完成”。该轮实际上已准备 16 个新条目，但 `board.author preview` 返回 `BOARD_PREVIEW_UNAVAILABLE`：它查找 `packages/web/dist/board-preview`，实际资源在 `packages/web/dist-multi/board-preview`。生产多用户启动脚本没有设置 `UNDERSTAND_BOOK_WEB_DIST`；隔离模型验收显式设置过该目录，所以漏掉生产启动差异。后续 deliver 没有成功，系统只保存了 incomplete 的文字兜底，未保存草稿图元。最终回复泛化了错误，没有向用户说清真实原因。

截图底部的独立 `[` 是另一处显示问题：答案使用 `\[...\]` / `\(...\)`，已有 Markdown 渲染只识别美元符号公式。这两个 TeX 分隔符现在在 Markdown 反斜杠转义之前解析；代码示例和未闭合分隔符保持原有行为。
