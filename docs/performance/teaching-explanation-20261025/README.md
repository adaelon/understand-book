# 解释职责与文字审核分离

## 真实失败

2026-10-25 的 AI Infra 2.3 接续讲解收到“复述教材、罗列数字，没有教学”的反馈。该轮已注入此前交付、用户原话、解释偏好及教师工作状态，并实际引用了它们。问题不能归为没有历史：主讲用历史决定接下来覆盖什么，却未充分改变解释方式；文字审核把公式、数值和结论齐全判为已经解释。

原始证据保存在本机 `tmp/teaching-latest-20261025/`；本次请求、公开输出、usage、错误及对照材料在 `tmp/teaching-explanation-20261025/`。这些是私有实验材料，不写回读者历史。未保存模型隐藏推理。

## 已验证的选择

主讲、文字审核和页面审核共用首要准则：禁止用复述教材、罗列事实或数字代替解释。数字、公式和引用可以参与具体过程；明确要求摘录、摘要、清单或窄确认时遵守该范围。一个有效例子不能替其他中心机制的缺失解释作证。

仅提高准则并补回目标、方法与背景，仍不足以解决失败。第一次真实回放把原稿退回的理由只是未读小节标题；删去解释过程的稿仍被接受。作者收到该反馈后只改了三个标题，其他内容原样保留。

进一步将判断依据分开：解释审核只看当前请求、相关已给帮助、真实用户表达、背景／偏好和实际交付；事实审核继续核对当前已读来源、条件、数字范围及教师知识记录。教材、教师计划和事实审核结论不能进入独立解释判断，两项都通过才接纳文字交付。页面和影音仍走其现有观察审核。每份纯文字候选增加一次独立模型请求，两道审核与各自的格式修复均计入现有调用预算及实际 usage；中途失败、取消或预算不足不存半份接受结论。

## 内容实验

模型均为 `deepseek-v4-flash`、`reasoning_effort=low`，各例独立上下文，模型看不到预期标签。首次混合审核上限 32768 输出 token；隔离候选上限 16384。没有把失败、截断或不符合格式的响应算作通过。

| --- | --- | --- |
| A：网站原稿 | 退回 | 指出固定状态仍缺逐项写入、累计与读取过程 |
| B：补足过程 | 接受 | 两次写入及一次查询已实际展开 |

隔离初版仍漏过 A；补明确“分别判断正文实际选择的中心机制”后，以上七例才按预期区分。保留两版结果，不能把首版遗漏隐藏。原混合审核对 E 引用了历史请求而非当前问题，该响应也不能作为有效教学判断。

正式生产投影复测同样得到七例预期区分。A/B/C 实际包含全部 12 条真实表达，以及当前表达引用的 929 字前轮帮助，逐字核对一致；没有把最后一条较早帮助误当紧邻前文。七例的问题引文和正文引文都通过生产校验。

实际作者只收到原稿、已读材料和两份真实反馈，没有看到手工 B。新稿补出了 2×2 外积、第二次状态累加、查询逐项乘加、逐 token 路径核对及汇总丢失位置次序的解释。事实审核仍将它退回，具体指出全模型字节数与单状态元素数混比；因此解释通过不会覆盖事实缺陷。

作者随后根据事实反馈与维护者的条件、时间指代及表格格式修正意见修改。维护者另外删去了新添但未在本轮来源中读到的配置细项，改用已读的 8192 token / 1.125 GiB 折算 144 KiB，并让矩阵文字保留行列。[最终示例](example-after.md) 的事实审核与解释审核均接受，两份真实输出都通过生产引文及依据校验。该示例含人工复核，不将其描述成全自动一次成功。

## 其他链路修正

- 文字审核恢复产出带已读原文依据的 `agent_work`，沿现有校验和持久化路径保存；这不是用户掌握证明。
- 审核输入保留学习目的和已确认背景。历史真实话语辅助解释当前请求，不能替换它。
- 动态片段按完整内容直接比较，只追加变化；保留当前有效键和原前缀，压缩后重建完整状态。未变化的读者历史不再每次复制。
- 服务明确返回余额不足时准确说明原因并跳过必然失败的补救请求；一般服务故障不再冒充书籍材料不足。

## 已知问题与边界

解释审核 v2 已明确不得把相邻步骤强加成本轮义务，v3 进一步澄清背景提及和后续预告不自动变成解释中心，G 的真实接受理由也明确“只问打分，不必展开值加权”。但 F 的退回理由在两次范围修订后仍夹带“打分与加权”的措辞，超出用户明确要求的打分展开；F 应退回这一判断正确，修订范围措辞尚未完全解决。事实审核抓住了容量口径，却没有稳定抓住固定条件与时间指代问题；规则和示例已修正，不能声称模型能够稳定检出所有这些错误。

上述内容实验验证具体解释缺口的识别与作者响应，不证明真实用户已经学会，也不证明跨书跨问题的长期稳定性。动态状态测试验证重复消除和压缩恢复；没有完整生产请求回放，不宣称整轮 token 或延迟降低了某个百分比。当前工作区修复尚未部署到线上，也未重写旧对话。
