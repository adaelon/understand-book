## 原因和调整

注册事务通过 `grant_default_books_to_new_user` 触发器复制 `default_book_grants`。原名单只有补刀、宏观经济学和舒伯特的三个版本，其他已经发布的资料没有加入默认名单；`grant-all` 会追加指定发布，不会替换旧版。

本次使用现有授权表，在停止服务并持有 `service.lock` 的窗口中完成一个事务：默认名单从 5 个发布调整为 14 个不同资料的默认发布，向已有账号补齐 104 条授权；两个邮箱账号各移除两条未使用的舒伯特旧版授权。操作前确认这些旧版没有他们的阅读现场、学习工作区成员或运行记录。旧账号和运营者已有的历史授权保持；没有删除资料或阅读数据。

程序仍是 `registration-only-20261027`，schema 21，维护窗口 5.09 秒。完整当前名单见 [default-materials.json](default-materials.json)；注册、登录、免费 Token 文案沿用同日已发布版本。
