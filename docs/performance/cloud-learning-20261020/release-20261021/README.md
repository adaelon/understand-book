1. 正式商品和课程尚未开售，个人上传与付费转写仍受未配置权益／费率限制。服务器未运行常驻 DSH 资料准备宿主；正式开放个人资料准备前，须按既有运营流程接入本轮 Engine／DSH 版本、根 Agent、共享目录和处理配置。本次部署没有把仅入队能力声明为已运营的自动处理服务。
2. Windows 安装包已公开下载，实际 WebView2 会话行为及线上授权已验证；未对用户现有安装执行安装／覆盖升级。
3. 原有 PDF 小地图中文标签接口 501 限制沿用；此次没有修改该功能，见此前 OM6 发布记录。
4. 发行版 LibreOffice 7.1 实测只导出两页，丢失隐藏页；替换为 26.8.1.1 后两种课件均通过三页验收。系统 Python SQLite 不支持既有 STRICT 表，升级比较改用项目已经安装的 Node SQLite；旧数据未受影响。
5. 默认 Python 下载探针被 CDN 返回 403；沿用既有发布 User-Agent 后下载内容核对通过。浏览器前两次等待整页资源超时，改为等待 DOM 与实际界面；第三次脚本漏点“套餐与权益”展开按钮，补上操作后通过。失败原始回执保留在本目录，未因此重启或再次升级生产数据。
6. 自动审批拒绝清理本地新建的临时依赖副本。该目录保留，前端使用独立依赖入口完成构建；此限制未影响上线。
