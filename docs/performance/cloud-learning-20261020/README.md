## 实现范围

- 三档商品共用月付与 1／3／7 天期限，人工核款原子产生收款、原额度期授额和已售权益快照。续期接续、下一期换档、补充额度和不可售草稿进入真实页面与服务接口。

- 视频准备和学习原声复核按实际音频时长记录处理用量，与模型共享账号余额及任务上限。未知结果保留占用，明确继续与回执重传有不同语义。
- 课程分档权限贯穿资料读取、模型、目录及接续。个人目标、考试日期、作答和历史独立保存；外部链接导览与已经准备的教材、视频分别表达。
- Windows 0.3.0 使用系统浏览器授权与独立会话访问同源云 Reader，正式包移除本地核心执行和媒体处理程序；原维护功能保留在独立工具中。

## 真实模型与成本

[真实模型与成本报告](costs/README.md)保留初次失败、修复后四场景、原始问题与回答、实际供应商 usage、工具结果、可打开的来源和账户归属。未以任务状态 `completed` 代替语义验收。

首轮发现页面否定误判与工作区资料发现缺口，修复后四个场景完整交付，日期、范围和来源定位通过。直接讲题仍把较宽引用范围错误推成不支持结论；原创讲义补清证据支持、定位精度和必要上下文的区别后，第三轮核心解释通过，但又将广泛目标中的知识列为被新考纲明确排除的考试要求。Runtime 增加通用考纲优先规则后，第四轮修正了范围，仍有错误的补充例子。每轮均保留完整回答与人工语义结论。

进一步定位确认：普通考试终答处于 observing 状态，原先没有接入已有的教学审阅。该路径现已复用原审阅、工作记录和运行账本，覆盖流式发布、引用修复和失败降级。第五轮验证了接入，但回答仍虚构评分后果，审阅放过了该问题。随后在既有作答与审阅指引中补充通用考试依据规则，明确区分学习建议、已确认考纲与有依据的评分标准。

[最终原题回答](costs/grading-grounded/direct-question-answer.md)及[人工语义结论](costs/grading-grounded/semantic-review.json)通过。本轮实际发生两次审阅：先指出初稿从考试范围推导答题要求的错误，作者沿原循环修订，第二次接纳后才发布正文。核心证据支持与定位精度的区分正确，考试范围正确，没有强制诊断；自构示例与原材料明确区分，两个真实文字引用可打开。SSE 中审阅完成序号为 39／48，正文首次发布为 49／51，被拒原稿没有显示。

最终一轮主循环 5 次、审阅 2 次，共 **7 次调用、207,916 tokens**，供应商请求耗时 **112.035 秒**，端到端 **115.973 秒**。7 条费用均已结算，账号、运行、工作区、额度期、供应商、模型和实际 token 对齐。六轮累计 **53 次调用、1,587,128 tokens、373.461 秒供应商请求耗时**，包括全部失败和复验；真实金额仍未知，隔离测试费率不是供应商成本。
