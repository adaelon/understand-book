# 今天 30 分钟（10-20，距考试 3 天）

范围三项是**一条链**：陈述是入口，版本和时间片段是必须交出的两个坐标。今天先练这条链的**反向定位**，也就是给你一条陈述，你去把它的版本和时间片段找出来，这是考场上真正要做的动作，也是三天里最难以靠背诵解决的环节。

| 时间 | 练什么 | 具体做法 |
|---|---|---|
| 0–3 分 | 确定格式 | 挑 1 条陈述，写出固定答题格式：陈述 → 版本 → 片段起止时间。形成填空习惯。 |
| 3–18 分 | 核心练习 | 挑同一主题的 3 条陈述，每条限时 5 分钟：先在版本列表里确定是哪一版，再在视频时间轴上确定起止点。写下每次卡住的环节。 |
| 18–26 分 | 纠错 | 只重做最慢的那 1 条，判断卡点在“版本判断”还是“时间边界”，找出后当场再定位一次。 |
| 26–30 分 | 固化 | 把今天的定位规则压缩成 3 行检查清单（例如：先看版本差异点 → 再按片段主题词扫时间轴 → 边界取整后±验证），明天直接沿用。 |

**为什么这么排**

- **先练定位链，不先泛读**：三天里，判断“这条陈述属于哪一版”和“落在哪个时间段”比完整覆盖更影响得分，而且这两个动作可以相互验证，错一次就能看出是哪一步出错。
- **单主题 3 条、有计时约束**：同主题的陈述会共用一部分线索，能在 15 分钟内模拟出考场上反复出现的检索节奏；没有计时，你就无法知道自己是不会还是太慢。
- **留 8 分钟给纠错**：定位类错误常常只在一处出错，重做的那一次才是真正记住的地方。

后续两天可以按“今天清单 + 换主题提速 → 混合三主题限时 → 全真模拟一套”推进。如果你把具体的陈述条目发给我，我可以把上面的练习直接换成对应的题目。
