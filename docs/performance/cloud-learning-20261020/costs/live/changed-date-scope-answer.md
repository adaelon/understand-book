**固定答题格式（先确定下来，不要中途增加）**
每条只写两行：`陈述 → 起止时间`；第二行写一句“我凭哪句话认定它在这个片段”，例如片段中出现该术语、或说出该结论的那一帧。两行缺一行，这条就不算做完。

| 0–4 分 | 确认要求 | 确认两件事：起止时间写到什么精度（能否只给“大概第 3 分钟”这类粗略位置）；边界按什么取。若老师没给容差，就自己固定一条规则：起点取该内容第一次被说出的位置，终点取它讲完的位置。今天全程用这一条，不再临时更换。 |

| 26–30 分 | 固化 | 把今天的规则压缩成 3 行清单，明天开考前直接读。示例格式（内容按你今天的实际卡点改）：先挑 2 个定位词；用两个词都出现的片段；边界取“第一次说到”到“讲完为止”。 |

**为什么这么排**
- 只剩一天时，定位依赖于反复执行和计时，真正需要熟的是流程而不是背内容；限时是为了把“不会”和“太慢”分开，这两者在考场上的后果不同。
- 把“片段选错”和“边界偏”分开处理，是因为它们的修复动作相反：前者要增加限定词缩小范围，后者要回去核对端点。混在一起重做，改了也不知道改对了哪一步。
- 留 7 分钟纠错而不是再刷新题，是因为定位错误通常只差一处，同一处修一次比多做三条更可能带进考场。
