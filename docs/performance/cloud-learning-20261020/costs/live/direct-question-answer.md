**直接回答**

证据窗口是判据：窗口里的内容要么支持这条陈述，要么反驳它。窗口比陈述宽，判据就不再只针对这条陈述——第二秒里出现、第一秒里没有的内容会被算进同一条证据。结果，“只有这条陈述成立”和“这条陈述连同它的加强版都成立”在这段窗口上表现完全一样，窗口分不开这两种情况。

**用这道题的两秒视频走一遍（下例为假设，只为说明机制）**

假设第一秒里出现“数值持续上升”，第二秒里出现“上升到顶后不再变化”。

- 陈述：“这段视频里数值持续上升。”这句话只涉及第一秒。第一秒能不能找到持续上升——能找到就成立，找不到就不成立。
- 若窗口取 0–2 秒，同一个窗口既支持“数值持续上升”，也支持“数值先上升后持平”这条陈述没说的说法。一个窗口同时支持两条内容不同的说法时，它检验的只是“这段视频里有内容”，没在检验其中任何一条。

**“精确”指什么**

窗口两端要落在陈述所指内容的起止处：起点取该内容最早出现的位置，终点取它讲完的位置。陈述只管第一秒，终点就落在第一秒附近；把终点拉到两秒，等于替陈述加了一句它没说的话。

**整段视频什么时候是对的**

当陈述本身覆盖两秒时（例如“这段视频说明了完整过程”），窗口就是 0–2 秒，取短了反而漏内容。决定窗口的是陈述的涉及范围，视频总长本身不决定窗口。

**落到答题格式上**

1. 这条陈述只涉及第一秒，就写 0–1 秒（按老师给的精度和容差写具体数值）。
2. 写完做一次自检：另想一条内容不同的陈述，看它是否也能套进同一个窗口。如果两条不同陈述在同一窗口上都显得成立，就说明窗口取宽了，把一端收回到陈述实际所指的位置。
3. 若某条陈述措辞确实指向整段，就写 0–2 秒并在理由里说明它覆盖整段——这两行的作用就是让评分者看出你是按陈述范围定的窗口，还是按视频长度定的。
