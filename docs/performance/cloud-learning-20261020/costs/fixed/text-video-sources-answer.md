我已经查过这个工作区的原创讲义《来源窗口与证据范围》和样例视频的人工字幕，下面分别回答。

**1. 讲义要求保留原始来源引用的原因**

讲义规定，解释一个结论时要给出三项信息：来自哪份资料、哪个发布版本，以及原文位置或视频时间片段。只写“这门课讲过”，读者无法据此找到支持结论的证据。

保留原始引用的具体理由在“版本”这一层：课程以后发布新版本时，原来的回答仍要保留原资料的发布编号和来源位置；这样读者换了新课程之后，仍然能回到当时实际读取的那段原文或那段视频。 也就是说，原始引用是留在证据上的坐标；课程更新后，坐标仍然指得回去。

**2. 字幕中动态图案的持续时间**

样例视频的人工字幕写的是“动态图案在两秒内持续变化”，也就是说，变化的范围覆盖整段两秒。这段字幕在视频开头（00:00 处）出现。

**3. 应回看的时间窗口**

应当回看 **0–2 秒（整段）**。如果把字幕里的这句话当作一条陈述，它讲的就是“整段一直在变化”，而讲义对时间窗口的划分规则是：问题只涉及第一秒的画面时，来源指向 0–1 秒；陈述涉及整段变化时，才可以指向 0–2 秒。 因此，这句话与“整段变化”这一档对应，回看的窗口就应当是 0–2 秒。
