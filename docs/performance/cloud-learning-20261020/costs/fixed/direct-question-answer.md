**直接回答**：你标的那个时间片段，是给读者回看用的“这条陈述到底由哪几秒的画面支持”的记录。你的陈述只用到第一秒的画面，若标成 0–2 秒，窗口里就多出第二秒那一段——而第二秒在你的陈述里没有出现，读者按这个窗口回看时，看不出第二秒对结论起了什么作用，也就没法用它核对你的陈述。

**课本给出的规则**

来源窗口就是“证据覆盖的具体位置或时间范围”；写结论时要交代它来自哪份资料、哪个发布版本，以及原文位置或视频时间片段。

这条规则落到这段示范视频上有明确写法：视频是持续两秒的动态图案，人工字幕是“动态图案在两秒内持续变化”。若问题只涉及第一秒的画面，来源应指向零至一秒；若陈述涉及整段变化，才可以指向零至两秒。

**把规则用到你这道题上**

视频总长是固定的（两秒），能选的只有窗口的宽窄。你这条陈述要成立，只有第一秒的画面被用到；把窗口拉到 0–2 秒，等于向读者声明你的结论覆盖了整段变化，而这一声明超出了你实际用到的画面。这就是“不精确”的具体含义：窗口比陈述的证据覆盖面宽，多出的部分无人核对。

反过来也可以自查：假设（示例，用来说明写法）某条陈述写“图案从第一秒到第二秒换了样子”，它要成立必须同时看两处画面，标 0–1 秒就缺了比较对象，那时才该标 0–2 秒。这类判断与视频里图案具体长什么样无关，取决于你的陈述需要回看哪几秒。

**答题时的一个动作**：写完一条陈述，问自己“这条陈述要成立，读者必须回看哪几秒”，答案就是窗口边界；若陈述里出现“整段”“一直在变”“和第一秒相比”这类说法，边界才推到整段。
