## 读取范围与交付视图的区别

target-l4 第二份候选说“这里读到的原文……没有点名 MSE”。交付的 C8 前文确实包含 MSE，初步核查因此提出疑点；进一步检查所有实际工具正文，MSE 没有进入模型读到的正文，而是在来源视图自动展开的前文中出现。

该句明确限定到实际阅读，不能仅凭交付弹窗中的扩展前文就判为虚假陈述。最终保留其范围合格判定，核查过程与证据另存 `02-target-l4-candidate-mse-evidence.json`。评分来源支持时可以使用全部交付视图；判断 Agent 声称“我读过什么”时，要对照实际模型输入。这两种问题不能混为一谈。
