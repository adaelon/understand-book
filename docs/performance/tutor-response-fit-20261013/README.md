## 实现

`crates/runtime/src/tutor.rs` 的 `COMMON / SELECT / UNDERSTANDING` 升至 `tb4.v2`，沿原有状态按需装配。当前表达与读过的来源优先于历史 `current_target / expected_performance / teaching_implication`；撤回不成立的教学前提后重新选目标。判断依据是用户表达的关系，接受自然措辞；遗漏保持未确认，明确冲突才构成纠错依据。重讲需要改变具体入口或表示方式，完整解释请求直接完成。

工具中的期望表现、理解解释和后续教学建议说明同步更新，示例不再默认把缺少原因变成下一道必答题。数据字段、工具操作和评分协议沿用。`docs/工具契约参考.md` 与 `docs/tool-contracts.json` 已从当前 Rust 导出重新生成。

指定生产假设通过现有 `MemoryStore / append_evidence / supersedes / rebuild_learner_projection` 追加更正。更正认可已表达的网络处理负担与卸载关系，将未表达细节保留为未知，并撤销从“共享 CPU”推到“没有空闲余量”的无来源推断。当前适用目标改为解释工作转移与应用受益，去除旧目标中的 TPU 对照前提。原记录与历史教学交付保持，维护者更正有独立身份和说明。

## 验证目的

真实内容对照检测：正确概括被强制改写、未表达被误判为错误、重讲沿用原有入口、当前明确表达仍被旧诊断覆盖、真正的概念冲突未获纠正。若出现这些失败，修改对应判读／选讲规则，保留原始失败，不改写模型产出冒充通过。

确定性回放检测：模型产出的引用或工具参数无法接纳、修订没有替代旧解释、真实帮助条件或用户原话丢失、普通表达被记为能力证明。失败修对应合同或执行路径；工程通过不代表教学内容正确。

日常内容实验沿用 TB2 的成本约束，使用隔离 Codex 子代理，改前改后保持同一模型与设置；不新增 DeepSeek API 调用。模型预读材料后的固定产出回放不覆盖生产 Provider 的自主工具循环。
