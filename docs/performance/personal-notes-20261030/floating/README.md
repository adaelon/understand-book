# 随手记浮窗与默认产生现场

2026-10-30 15:16 HKT 已随 `all-pending-20261030` 上线，见[合并发布记录](../../all-pending-release-20261030/README.md)。依据用户对停靠栏的反馈，改为可弹出、拖动和缩放的便笺窗口。

## 当前行为

桌面默认 400×360px，暖白纸面，顶部可拖动，八个方向可缩放，右下角有缩放手柄。方向键可移动/缩放，Shift 加快步幅。窗口按账号保留当前设备上的位置和大小；可视区缩小时保持窗口可操作，键盘收回后恢复偏好。最小尺寸 300×280px，屏幕不足时收敛到可视区。原页面不缩窄、不压低，不因记录增加遮罩或模糊；阅读组件及其滚动位置保留。

收起后显示右下角小入口。打开直接聚焦正文；Ctrl/Cmd+Shift+M 打开或继续，窗口内 Ctrl/Cmd+Enter 保存、Esc 收起。草稿在设备保留，正式保存成功收起并显示回执；保存失败在输入区显示一次错误并保留重试。列表、版本、联系沿用原能力。

全局新记从 App 读取当时可确认的普通阅读位置，包括材料、发布版本、工作区、阅读 LID，视频模式记录实际时刻。来源在创建草稿时冻结，继续旧草稿不会改绑。新建且没有预先选定确切来源的草稿可在底部选择当前位置或独立想法。书架等无来源页面默认为独立想法。画布/来源弹层、全屏对话或演示覆盖阅读页时，不把后台阅读页误记为现场；这些对象的确切来源继续通过其既有记录入口捕获。

## 产品规则与实现范围

产生现场与展示位置分开。默认记录现场、仅保存想法；放到某个元素是用户的独立动作。多个位置引用同一条想法，移动展示位置不改写来源。完整交互规则已更新到[产品方案 §4.1](../../../设计方案-以个人想法为核心的笔记与学习.md#41-产生现场与展示位置2026-10-30-交互补充)。

已存在原文选区、对话回合、演示状态捕获及想法导入画板。浮窗阶段未实现画布元素连接、对话句下展示或跨宿主统一“放到…”入口；这些能力随后已在[放置续作](../placements/README.md)中接通。演示关联按页面或状态显示，任意页内图形、像素位置的摆放仍未实现。

## 实现位置

- `ApplicationShell.vue`：原阅读区域保持全尺寸，浮窗位于内容层之外。
- `note-window.ts`：指针拖动、八方向缩放、键盘操作、边界与偏好恢复。
- `PersonalNotes.vue`：便笺视觉、全局入口、来源选择、草稿及保存状态。
- `personal-notes.ts`、`App.vue`、`VideoReaderPane.vue`：可见阅读现场的快照与既有明确来源入口。
