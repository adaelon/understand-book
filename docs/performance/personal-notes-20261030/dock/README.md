# 随手记录停靠栏

2026-10-30 的历史方案，尚未上线。用户随后明确要求可拖动、可调整大小的小窗口，当前实现与验证以[随手记浮窗](../floating/README.md)为准；本目录保留此前方案的截图和验证记录。

## 行为

**决策：随手记录与当前内容并排，不遮盖阅读。** 全局底栏提供“记个想法”和“我的想法”；记录直接进入正文，列表、版本与联系按需打开。宽屏使用 360px 侧栏；不足 1384px 时停靠底部，保留内容宽度。1024–1383px 的底栏至多 220px，其余窄屏至多占 42% 高度且不超过 340px。

打开记录不等待列表请求，不加遮罩、不模糊内容、不重建阅读组件、不锁定原内容操作。原文、演示与学习记录浮层挂载在 `application-overlays`，使用内容区的实际宽高。记录栏内的 Esc 和保存快捷键不传给原文窗口；Tab 可以离开记录栏。

Ctrl/Cmd+Shift+M 打开或继续当前设备草稿。收起、切换材料与刷新继续复用原草稿；来源和用户文字沿用既有持久化。新记录保存成功自动收起并显示回执，失败保留输入和重试入口。标题选填，保留的来源摘录默认折叠。编辑已有版本保存后仍留在详情。

## 入口与实现

- `ApplicationShell.vue`：记录区与内容区的网格布局，阅读浮层宿主和内容尺寸。
- `personal-notes.ts:openThoughtCapture / startThought`：恢复现有草稿，区分记录、列表和详情视图。
- `PersonalNotes.vue`：直接聚焦、局部快捷键、单列笔记视图、保存收起及回执。
- `application-overlay.ts` 与既有原文/演示/阅读浮层：浮层停留在内容区；独立组件预览继续使用 body。

## 验证

- 74 项相关单元与组件测试通过：草稿、保存重试、输入法、异步保存期间切换草稿/列表、来源阅读、演示、学习记录及键盘视口。完整相关批次 73 项通过，最后新增的切换列表用例与组件其余 6 项再次通过。
- `pnpm --filter @understand-book/web exec playwright test --config playwright/thought-dock.config.ts`：7 条场景通过。实际应用外壳、实际原文组件和实际 ReaderWorkspace，HTTP 使用内存测试数据。
- 1440×1000、1024×768、390×844、320×568：打开即聚焦；原内容可点击；收起/重载后恢复；保存及列表回读；无横向溢出。
- 原文窗口滚动、焦点与实例保留，手机端标题与关闭按钮完整；1440px 与 1024px 的阅读/问答双栏保持可见。
- 模拟软键盘将可视高度缩至 460px，记录及保存仍可操作；保存失败信息可见，同一次操作重试成功。
- Vue 类型检查、普通生产构建和 `pnpm --filter @understand-book/web build:multi` 多用户生产构建均通过。

## 已知限制
