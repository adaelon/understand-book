## 先看一个小矛盾

同一个人，做一道步骤清楚的题很少出错；把他放进书里的“塔纳兰”——一个由计算机模拟出来的地区，要他在六个规划期里决定这个地区十年的命运——他却可能一步步把自己送进最难收拾的局面。差别来自局面本身的性质，与聪明程度关系不大。（塔纳兰是书中的模拟对象，不是真实国家，这里借它做个例子。）

## 它研究的是哪一类局面

作者把三个场景摆在一起看：模拟里的塔纳兰、规划实验里的格林韦尔、真实的切尔诺贝利。它们表面上毫无关系，共有的却是四条性质：

| 系统的性质 | 对处理者意味着什么 |
|---|---|
| 由许多相互关联的变量构成 | 动一处，别处也跟着变 |
| 至少部分不透明 | 内部看不清，判断只能依靠观察到的表象 |
| 不受外部操控，按自身内部动态发展 | 你不动作，局面也在变 |
| 处理者只掌握部分知识，还带着错误假设 | 自己心里那个“情况”可能就是错的 |

这四条同时成立，就是全书设定的难点。后面出现的每一种错误，都长在这个设定上。

## 核心主张：失败按自己的逻辑逐步长出来

书里给出的判断是：失败按自己的逻辑逐渐发展，它不会像晴天霹雳那样突然降临。作者观察人解决问题的过程时发现，复杂情况会诱导出一种节省式的思维习惯，这种习惯从一开始就埋下了失败的种子；随着任务变复杂、对失败的忧虑上升，又长出一批使失败更可能、乃至不可避免的决策方法。

其中一条链条写得相当具体：

1. 分析不充分；
2. 于是出现一种说不清的不确定感，“不知道自己该做什么”；
3. 为了摆脱这种不确定感，人出去找“问题”；
4. 找到一堆问题后，必须决定先解决哪个；如果没有按目标定出来的优先次序判据，
5. 那就挑最明显的那个，或者挑自己已经会处理的那些。

关键落在第四步：目标没有变成判据，选择权就交给了“显眼”和“好办”。

## 塔纳兰：把这条逻辑放到能看见的地方

书里最有代表性的一处观察来自塔纳兰实验。参加者用六个规划期决定这个地区十年的命运；每一期可以尽其所能地采取措施，下一期还能总结前面的成败，取消或修正早期的决定。

前期的参加者像谨慎的哲学家，大量收集信息、分析形势。第一个规划期之后，情况反转：分析活动变少，决策活动稳步增加。他们认定自己画出的形势图已经足够准确，不必再收集信息，也不必再有分析地反省已取得的结果，于是错误地相信自己已经掌握了解决问题所需的知识。

这一步值得停一下：一个本来在转的循环断了。“观察—行动—看结果—修正”这个循环，在“我已经懂了”的判断出现时就不再需要转动；此后行动仍在继续，修正却停止了。

## 为什么用模拟，而不是只讲现实事故

现实里，时间跨度和空间距离会把错误的后果藏起来，人很少有机会把一次危机里学到的东西带到下一次同类危机里去。模拟改的正是这两个条件：计算机里时间过得快，距离也不存在，决策和规划的后果因此能当场看见，人对这类情境的敏感性也就能提高。

## 它给出的改进方向

最后一个环节是系统视角：在复杂系统里不能只做一件事情；不管愿不愿意，任何一步都会牵动其他许多事情。所以要学会应付副作用，也要预料决策的影响会出现在自己从没想过的地方。

## 一句话

它研究人在复杂、不透明、会自行演化的局面里，怎样用看似合理的每一步把自己带到失败，并用模拟把这条路径显出来，好让人提前看见它。

先不用翻书：假设你现在被放进塔纳兰，只有六个规划期安排这十年。第一期你会先把时间花在摸清这个地区怎么运作上，还是先动手解决最显眼的问题？说说你的理由。
