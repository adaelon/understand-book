## 有证据的问题

1. **负局部导数并不保证该支路贡献为负。**“负数和零贡献的意思”写 y 为负时“u 支路给 x 的贡献也带负号”。实际补测 x=2、y=-2.5，页面正确算出 g_u=-3，故该支路贡献 (-3)×(-2.5)=+7.5；指定相消状态下该贡献则为 0。证据：`negative-fixed-example.png`、`local-sign-counterexample.png`。

2. **漏算开头说一定变小，与负数和零状态冲突。**x=-1、y=2 时，表格正确显示只留 u 支路为 -6，完整值 -12，前者更大；x=2、y=-1 时两者都为 -3。固定文字却仍说“得到一个比正确值小的数”。表和零提示是对的，这句话不对。证据：`negative-omission.png`、`interaction-results.json`。

3. **负数平方代入缺少括号，写成错误等式。**(-1,2) 时记录显示 `L = v² + 3u = -3² + 3×-2 = 3`。正确代入应为 (-3)²；按通常优先级，写出的 -3² 是 -9，整条表达式应得 -15。相消状态也出现 -1.5²。计算结果正确，展示出来的算式错误。证据：`negative-forward-record.png`、`mobile-record.png`。

4. **固定负数例子把函数值说成梯度值。**“把 x、y 代入展开式 L = (xy + x)² + 3xy 也得到 -12”不成立：代入得到 L=3，先求 x 导数再代入才是 -12。后面的独立求导卡是正确的。证据：`negative-fixed-example.png`。

5. **第 10 步 y 已收到完整贡献，梯度仍显示问号。**边标签、步骤说明和记录都已算出 y 收到 19×2=38，y 又只有这一条路，但节点和结果栏仍显示 dL/dy=?，到第 11 步才显示 38。这是较轻的步骤状态不一致。证据：`step-10.png`、`interaction-results.json`。
