# Amber 独立评估

Amber 的主要推导和必需交互没有发现实质错误。它先用恒等式及两个中心化和为零消掉交叉项，再用非负平方确定每个 a 下的 b(a)，明确说明后面的 J(a) 是逐个优化 b 得到的剖面。接着一元求导与配方求出全局最小，再把非负 b 项加回来说明二维结论，最后用 Hessian 写出一般唯一性判据。对只学过一元微积分与配方的读者，这条主线较容易跟随。

总和与平均的说明区分了“整个目标除以n”和“只平均误差、保留相同λ”，没有混淆相对惩罚强度。正常 λ=0/2/10 的 (a,b,RSS,P,J) 实测分别为 (1.400,−1.200,1.600,0,1.600)、(1.167,−0.733,2.144,2.722,4.867)、(0.700,0.200,6.500,4.900,11.400)。退化 λ=0 写 a“不唯一”、b=1.6−2a，RSS=J=21.2；λ=2 正确为唯一水平线 a=0、b=1.6，RSS=J仍21.2。切回正常也恢复正确。

两图与读数一致：退化 λ=0 的示例线确实经过均值点，右图在21.2水平；正 λ 时改为唯一点和抛物线。残差平方方块与目标剖面分开表示，未把系数、SSE与惩罚混作面积。动态公式、当前数据组、行列式和唯一性说明全部同步；操作说明也按顺序明确区分常规状态和退化分支。

## 有证据的问题

1. **手机数值表拆散数字。** 320×420 的六列表中 λ=10显示为两行“1”“0”，a=1.167拆成“1.1”“67”，b=−0.733、J=4.867也被拆行。读者需要拼接数字来核对结果。普通长公式和正文的换行可读，动态读数卡也可读；问题集中在固定表格。证据 `320-table.png`。
2. **恢复上次选择的承诺在实际 Reader 中未兑现。** 页尾说重新打开会恢复 λ 与数据组。本次在同一浏览器上下文选择退化数据、λ=0，再重新载入页面，实际回到原始数据、λ=2。记录见 `interaction-evidence.json` 的 `reloadObservation`。这是附加便利功能的限制，不影响本题必需交互；没有据此推断其他宿主环境。
