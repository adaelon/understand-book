# Coral 初步独立评估

Coral 的主推导路线完整：先展开二变量目标，再给出中心化残差恒等式，利用两个离差和为零消去交叉项；固定 a 消掉非负的 b 项，对 a 配方；最后保留 a、b 的完整双平方形式证明全局下界可达和唯一性。退化数据用 u=2a+b 重写，正确区分任意斜率族与 λ>0 的唯一水平线，并明确说零斜率来自惩罚选择而非数据信息。

正常 λ=0/2/10 的 (a,b,RSS,P,J) 实测分别为 (1.4,−1.2,1.6,0,1.6)、(1.167,−0.733,2.144,2.722,4.867)、(0.7,0.2,6.5,4.9,11.4)。退化 λ=0 写“不唯一”、b=1.6−2a，RSS=J=21.2；退化 λ=2 写唯一 a=0、b=1.6，RSS=J=21.2。切回正常恢复正确读数。初始值、范围、步长和预设按钮均正常。

图示的退化最优族正确交于 (2,1.6)，没有把代表线误说成唯一。正文也解释了 λ=10 只把斜率降到0.7，只有 λ→∞ 才趋于0。RSS、惩罚与总目标各自清楚。

## 有证据的问题

1. **Sxy 恒等式的文字展开多了两处系数2。** 第2节把展开后的两项写成 `−2ȳΣx` 与 `−2x̄Σy`，再加 `nx̄ȳ`。正确两项各只有一次：`−ȳΣx−x̄Σy`。页面最后的 Sxy=14 正确，但按这段展开实际会算出−18，妨碍复现。定位 `desktop-expansion.png`。
2. **把剖面函数导数写成完整目标的偏导。** 第5节写 `∂J/∂a=2(Sxx+λ)a−2Sxy`，漏掉由 `c=1.6−2a−b` 带来的 `−20c`。这个短式适用于已经优化掉 b 的 f′(a)，不是任意 (a,b) 上的偏导。以 a=b=0 为例，完整目标偏导为−60，页面式子为−28。主配方证明仍正确，但该求导核对有误。定位 `desktop-proof.png`。
3. **退化数据的当前曲线图注未切换。** D、λ=2 时，图正确画在 a=0，旁边也正确说明读数不随正 λ 改变；图注却仍写“曲线在0到10上单调下降：分母10+λ变大，分子14不变”，且没标明这是 A 的固定参照。定位 `desktop-degenerate-2-summary.png`。
