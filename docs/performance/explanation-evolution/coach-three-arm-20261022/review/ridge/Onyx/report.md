# Onyx 初步独立评估

Onyx 的推导完整，换元理由尤其清楚：它先解释 (a,b) 与 (a,c) 的一一对应，再逐项展开残差，分别指出两个消失的交叉项和仍保留的 −2aSxy。配方后同时证明下界可达、a 与 c 唯一，再换回 b；没有停在驻点。正文也正确解释了退化数据的解族与正则化选择，不把选择结果当成数据提供的斜率信息。

指定状态全部正确，SSE、惩罚项与 J 分开显示。正常 λ=0/2/10 分别显示 (a,b,SSE,P,J) 为 (1.400,−1.200,1.600,0,1.600)、(1.167,−0.733,2.144,2.722,4.867)、(0.700,0.200,6.500,4.900,11.400)。退化 λ=0 写 a“不确定”、b“示例线”，SSE=J=21.200；λ=2 写唯一 a=0、b=1.600，SSE=J=21.200。切回正常恢复 λ=2 的相应值。

额外的对比斜率控件有实际教学价值：在退化 λ=0 时将 a₀ 从 0 调为 1，示例 b 从 1.6 变为 −0.4，SSE 与 J 保持 21.2；正常 λ=4、a₀=1 时，动态说明正确写“与最优点重合”。固定正文与当前状态也有明确文字区分。

## 有证据的问题

1. **退化 λ=0 的两条灰虚线不是最优族成员。** 设置对比 a₀=1，红色示例线正确经过 (2,1.6)，但灰虚线相交于约 (0,−0.4)，在 x=2 时分别约为 −1.4、4.6。旁边却说“灰色虚线是同一族里另外两条直线，它们的 J 也都等于 21.2”。截图 `desktop-degenerate-0-a1-plot.png` 和可见 SVG 几何 `degenerate-visible-geometry.json` 支持该判断。
2. **切换状态后，剖面图可能留下“不唯一”的旧水平线与文字。** 实际顺序为：正常 λ=2 → 退化 λ=0 → 正常 λ=0 → 正常 λ=2 → 退化 λ=0 → 退化 λ=2。最后的当前状态已唯一，剖面却同时显示新抛物线、`a=0.000, J=21.200` 和旧的“整段水平：J 恒为 21.200，a 任取都同样好”。等待 1.2 秒后仍存在，文字还相互重叠。证据为 `profile-degenerate-2-after-0.png`、`profile-state-transitions.json`。另一次离开退化状态后，在正常 λ=4 也观察到同样旧线，见 `desktop-normal-comparison-equality.png`。
3. **手机图内字体偏小。** 320×420 下散点图刻度及均值点标记明显小于周围正文，精确读图吃力。正文、公式、数值卡仍可读，见 `320-graph.png`。

## 视口与操作

960×720 的全文结构和数学公式清晰。320×420 长公式换行，整体没有横向溢出，宽数据表使用局部横向滚动；λ、数据集和对比斜率都已实际操作。640×240 需要按普通长文滚动到控件，但没有固定层遮挡，全部控件可用。没有观察到运行异常。

本报告仅针对 Onyx，暂不作样本间比较。完整可见文本在 `initial-dom.json`，指定操作记录在 `interaction-evidence.json`。
