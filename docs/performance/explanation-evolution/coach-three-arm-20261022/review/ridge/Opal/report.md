# Opal 初步独立评估

Opal 完成了这道题的主要阅读任务：从目标函数、中心化恒等式、交叉项消失，到先定 b、对 a 配方，再到两个平方同时为零的全局最小与唯一性论证，理由连续且可以自己复现。退化数据讨论也完整；实际操作的全部指定数值正确。当前有一处重要的图文矛盾：退化数据 λ=0 的两条斜虚线没有经过均值点，却被称为最优直线族的成员。

正文优点是逐项解释中心化恒等式，而不是只给记号；五行计算表能复核 10、14、21.2；全局最小的双平方表达式明确要求同时确定 a 与 b；还解释了正则化在退化情形仅选择一个系数组合，并没有创造斜率信息或降低 SSE。长文和公式服务于用户要求的深入推导，不构成问题。

## 有证据的问题

1. **退化 λ=0 的示例直线画错。** 第5步图A旁写“三条虚线只是其中三个例子（斜率 −0.8、0、1.3）”，但两条斜虚线实际经过约 (0,1.6)，没有经过橙色 (2,1.6)。在 x=2 时它们分别约为 y=0 和 y=4.2；只有水平虚线合格。截图 `desktop-degenerate-graph.png` 清楚可见。可见 SVG 几何记录进一步确认：均值点屏幕坐标 (337,195.5)，负斜虚线在 x=337 时 y=255.05，正斜虚线在这里 y=98.55。这与正确的正文及 21.2 读数相矛盾。
2. **中心化说明有一句过强。** “如果换一个不是均值的参照点……后面‘先定 b’这一步也就不成立了”把简化路径说成了求解必要条件。换参照点确实不能直接消去这些交叉项，但仍然可以先最小化 b，得到同一解。定位截图 `desktop-center.png`。
3. **手机图内字很小。** `320-graph.png` 中图的刻度、线标签和最小值注释显著小于周围文字，精确阅读吃力。图形形状、正文论证和数值卡仍可使用，这是辅助图清晰度问题。
