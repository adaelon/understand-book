# Pearl 初步独立评估

Pearl 完成了要求的主要推导链：目标与口径、截距方程、中心化恒等式与交叉项、联立偏导、闭式解、双平方全局最小证明、唯一性条件及退化讨论。它特别提醒对 a 求偏导时 r 也含 a，并保留 −20r 项，之后通过另一偏导令 r=0；这个细节有助于自行复现。正文再用配方与 Hessian 说明驻点为何是唯一全局最小。

固定示例有逐节标签，交互单列当前数据、均值及三个中心化和，状态区分清楚。实际正常 λ=0/2/10 分别显示 (a,b,SSE,P,J) 为 (1.4,−1.2,1.6,0,1.6)、(1.1667,−0.7333,2.1444,2.7222,4.8667)、(0.7,0.2,6.5,4.9,11.4)。退化 λ=0 显式写 a 任意、b=1.6−2a，SSE=J=21.2；λ=2 显示唯一 a=0、b=1.6，SSE=J=21.2。切回正常恢复正确状态。初始 λ=2、范围与步长均正确，端点快捷按钮也已操作。

退化 λ=0 的多条示例直线确实共同经过 (2,1.6)，文字也指出蓝线只是一条代表。斜率随 λ 的辅助图明确区分 λ=0 的未定与 λ>0 的零斜率。正文说明惩罚是在解族中选择，不把 a=0 解释成数据提供的斜率证据。

## 有证据的问题

1. **第1节把整体除以5与只平均误差项混在一起。** 同一段先说换成 `J/5` 不改变极小点，接着说相同 λ 的相对强度改变、等价换成 λ/5，所以 a、b 会不同。实际整个 `J/5=SSE/5+(λ/5)a²` 的最优系数完全不变；若仅把 SSE 改成平均并保留惩罚系数 λ，才等价于总和口径的 5λ。段落对用户明确关心的口径给出了矛盾解释，虽然后续计算使用了正确的总和口径。定位 `desktop-objective.png`。
2. **退化 λ=0 的“最小值 Jmin”卡错误显示“不适用”。** 此时失效的是带 0/0 的闭式表达式，最小值本身仍为 21.2，且可以达到。旁边的 J 和无穷多最优解说明也是正确的 21.2，因此卡片与自身正文冲突。定位 `desktop-degenerate-minimum-card.png`。
3. **320×420 的核对表拆散了数字。** λ=10 被拆成上下两行“1”“0”，λ=7.5 被拆成“7.”“5”，1.1667、−0.7333、2.1444、2.7222 等读数也被拆成多行。表格没有横向滚动而是将六列挤在窄幅中，使精确数值比较难读。定位 `320-comparison-table.png`。这与长推导本身无关；普通公式块的换行是清楚的。手机图内标注也偏小，但数值表的影响更直接。
