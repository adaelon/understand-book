# 带惩罚直线拟合：六页匿名独立比较

## 选择结论

如果现在必须只选一份给这位“学过一元微积分和配方、希望完整复现推导”的读者，我会选 **Amber**。它先对每个 a 最小化 b，明确解释剖面目标，再用一元配方证明最小值，最后回到二维；指定状态的公式、图形、读数与唯一性说明一致。它的主要不足是手机数值表拆散数字，另一个问题只是页面额外承诺的恢复状态未兑现。

**Jade 是同一优先组，尤其适合需要在手机上完整阅读的人。** 它的数字表、换行公式和控件更稳妥，核心数学与实际图数状态也正确。它落后于 Amber 的地方在于交互之后未限定数据组的核对说明：选退化数据后，仍要求常规数据的系数和最小值算法，读者会被引导去怀疑正确结果。这个问题不在求解器，却直接碰到本题要求的“固定示例与当前状态要清楚”。

因此，**没有一页在全部维度都无条件明显胜出**；Amber 与 Jade 构成有理由的首选组。按本题“深入推导且图数一致”的主要用途，Amber 是我的默认取舍；若手机数值复现与桌面同等重要，Jade 的相对优势会更大。这个判断依据问题影响，不按问题条数排序。

## 共同完成了什么

六页都提供了连续、未被折叠成几张结论卡片的推导。它们都解释了中心化与交叉项，求出系数，并通过配方、非负项或相应二阶论证走到全局最小及唯一性；退化 λ=0 与 λ>0 的正文也都讨论到了。长文、长公式和图不在第一屏都不是这里的缺点。

我对每页都实际执行了常规数据 λ=0、2、10，退化数据 λ=0、2，再切回常规数据。六页的 **a、b、未加惩罚平方和、惩罚项和总目标 J** 在这些状态下都符合独立数学依据；退化零惩罚时也都写明不唯一。Pearl 另有一个单独的“最小值 Jmin”卡片错误，这不改变其邻近 J 读数正确的事实。

六页在320×420和640×240下都能操作数据与 λ，没有发现固定层遮挡控件。移动端的差别主要是公式/表格如何处理宽度、图内标注能否轻松读到，而不是控件完全不可用。所有页面都保留，六页均已生成并被评估，没有以缺样本作负面判断。

## 推导正确性与可复现性

| 页面 | 实际判断 |
|---|---|
| **Amber** | 主路线完整且贴合一元背景，尤其明确 J(a) 是对每个 a 优化 b 的结果，随后把一元下界抬回二维。总和/平均的相对惩罚说明正确。主求解与全局证明未发现实质错误。 |
| **Jade** | 明确区分消失的整体位移交叉项与保留的 −2aSxy。完整偏导路线不遗漏耦合项，配方同时证明下界、可达与唯一。局部“斜率最小a=0”应指绝对值最小。 |
| **Onyx** | 解释性很强：(a,b)↔(a,c) 的一一对应理由写清，逐项展开保留和消去的项，全局性与唯一性也完整。单看主推导，它有竞争力。 |
| **Opal** | 算术核对、先定b、剖面配方、完整双平方与退化讨论均充分。局部声称换非均值参照后“先定b不成立”过强，但主推导仍有效。 |
| **Coral** | 主公式与双平方证明正确，但两处解释破坏自行复现：Sxy展开文字把两项各误乘2；把剖面函数导数标成完整目标偏导并漏−20c。其正确最终数值不能抵消这些中间步骤错误。 |
| **Pearl** | 中心化、联立偏导和全局证明完整。开头却把整个J/5与只平均误差项混淆，并先说极小点不变再说系数改变，正好混淆了题目强调的口径。 |

这部分不以“有没有额外写 Hessian”判高低。用户已会一元微积分和配方，用先消掉b再证明一元最小的路线足够；更复杂的二阶判据只有解释清楚时才有帮助。

## 图示与当前状态一致性

**Amber 的状态联动最完整。** 常规散点拟合、残差平方块、剖面抛物线、当前公式、Hessian行列式与唯一性文本在实测状态下相互一致。退化零惩罚时，左图是一族真正经过均值点的直线，右图在21.2处水平；正λ时两图共同变成唯一解。探索顺序也明确从常规数据转向退化条件。

**Jade 的实际图数也正确。** 九条退化最优示例线经过均值点，两个最小值读数在退化状态仍是21.2。缺点是交互下方的无条件核对指令仍说λ=2应读到1.167和−0.733，且最小值应用21.2−196/(10+λ)；截图同时显示这套要求与当前正确的退化读数。这是说明范围错误，而非动态求值错误。

**Opal 和 Onyx 的实质风险在非唯一性示例图。** 两页文字都正确说整族应经过(2,1.6)，但各自画出的两条斜示例线没有经过该点。Opal 的两条线在x=2时约为0、4.2；Onyx将示例斜率设为1时，两条灰线在x=2时约为−1.4、4.6。它们不是所述最优族成员。这两项分别由各页自己的截图和可见SVG几何确认，未借用对方结果代替检查。

Onyx 另有状态遗留：在正常/退化及λ切换后，旧的“整段水平、每个a都同样好”水平线和文字会与当前唯一解的抛物线叠加；等待1.2秒仍存在。它的可调对比直线本来是有价值的教学交互，但这两类图示矛盾使它目前不如文字质量所暗示的可靠。

**Pearl 和 Coral 的退化示例线画得正确。** Pearl却把退化λ=0的“最小值Jmin”写成“不适用”，将闭式商失效与最小值存在混淆；邻近J=21.2和正文解族说明仍正确。Coral的D数据斜率图正确水平在0，图注却继续声称分子14、分母10+λ及单调下降，未限定为A的固定参照。

## 阅读路径与移动阅读

六页都有完整正文，可以从目标读到退化结论，不需要靠动画猜理由。Onyx 的换元说明、Opal 的逐项算术表、Jade 的“消失与保留交叉项”辨析、Amber 的一元剖面解释各有具体优点。Pearl 的固定示例标签与当前统计量展示也很清楚；Coral 明确区分λ=10与λ→∞。这些优点都在页面实际内容中，而非由篇幅长短推断。

在320×420下，**Jade 的数值表保留完整数字，公式自然换行，是最均衡的移动阅读结果**。Opal和Onyx的宽表格有局部横向滚动，正文与公式可读。Coral用局部滚动保留许多长公式与表格；我实际把中心化长式和表格滚到最右侧，内容可读全，代价是阅读时要更多横向移动。

**Pearl与Amber将多列表格挤在屏幕内，导致数字本身拆行。** 两页都有λ=10变成上下“1”“0”的截图，系数与目标值也断在小数内部。这不是对长公式的否定，而是精确读数难以直接辨认。它们的普通公式、正文、动态数值卡和控件仍可用。

手机图内字号在多页都偏小，尤其图内刻度与注释比正文小得多。由于本题图形仅辅助推导，且主要数值另有文本，这没有被用作压倒数学正确性的理由。640×240下六页控件均未被固定层遮挡，也没有因视口低就失去操作入口。

## 为什么不按问题数量排名

Onyx 的换元教学可能比部分页面更清楚，但错误最优族与旧“不唯一”状态会让读者亲眼看到与定理相反的现象；影响比一般措辞或字号问题大。Coral的最终数值正确，仍不能代替中间推导可复现。Pearl的口径混淆和Jmin标记触及两个用户明确要求理解的概念。Amber的重载恢复承诺失败是附加功能问题，不应与这些数学问题等量计数。

Jade与Amber也都不是无瑕疵成品：前者要让读者自行识别一段核对说明的适用数据，后者要让手机读者拼接部分表格数字。本次选择Amber，是因为它在主要推导及实际图数解释中最少要求读者纠错；选择Jade作为移动优先版本同样有明确依据。
