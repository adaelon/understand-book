# Jade 初步独立评估

Jade 的核心推导、全局最小理由、唯一性与退化计算都正确。中心化部分明确分开“消失的 r 交叉项”和“保留的 −2aSxy”；求 a 偏导从完整残差式出发，先有残差和为零，才将 x 换成中心化 x，步骤可复现。配方论证依次说明下界、可达和唯一取等点，并用 a=b=0 核验恒等式。

正常 λ=0/2/10 的 (a,b,SSE,P,J) 实测分别为 (1.4,−1.2,1.6,0,1.6)、(1.167,−0.733,2.144,2.722,4.867)、(0.7,0.2,6.5,4.9,11.4)。退化 λ=0 明确写“不唯一”、b=1.6−2a，SSE=J=“配方给出的最小值”=21.2；λ=2 则唯一 a=0、b=1.6，三项仍正确。切回正常恢复正确结果。初始 λ=2、范围和步长也正确。

退化 λ=0 的九条直线确实都通过均值点，λ>0 图上变为水平线。静态等值线辅助说明唯一谷底与平坦方向，未替代正文证明。关于负 Sxy 时斜率绝对值收缩的说明也正确。

## 有证据的问题

1. **交互下方的核对指令没有限定常规数据。** 在退化 λ=2 时，面板正确显示 a=0、b=1.6、J=21.2，但紧接着的“三处核对”仍说“λ=2时面板应给出a*=1.167、b*=−0.733”，并宣称最小值另一算法是 `21.2−196/(10+λ)`，“不相等就说明代数或代码错了一处”。该公式针对常规数据，当前退化数据应为21.2。这会让按说明操作的读者错误判断当前正确结果。截图 `desktop-degenerate-check-instructions.png` 同时呈现正确读数与冲突指令。
2. **“斜率最小的那条a=0”措辞不准确。** 退化解族允许任意负斜率，没有最小斜率；λa² 选的是绝对值或平方最小的斜率。前面的平方证明和结果正确，因此这是局部表述问题。定位 `desktop-degenerate-explanation.png`。
