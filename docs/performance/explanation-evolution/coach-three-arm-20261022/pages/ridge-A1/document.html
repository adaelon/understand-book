带惩罚的直线拟合：把最优解从头推出来

这是一页可以连续往下读的推导。目标函数固定为误差平方的总和再加 λa²，惩罚只落在斜率 a 上。读完后你应该能自己重写整条链子：目标函数 → 消掉 b → 中心化 → 联立偏导 → 闭式解 → 全局最小的理由 → 唯一性判据 → 退化数据里哪些系数根本定不下来。

页内数字全部由同一组公式算出：正文、表格、图形和交互读数共用同一套 Sxx、Sxy、λ。第 1–4、6 节是固定示例（数据 A）；第 5 节切换两组数据并拖动 λ；第 7 节专门讨论 x 全为 2 的退化组；第 8 节回到一般结论。

1 目标函数与口径

固定示例：数据 A

五个观测点，n=5：

yi−10225

两个均值：x̄=(0+1+2+3+4)/5=2，ȳ=(−1+0+2+2+5)/5=8/5=1.6。拟合直线 ŷ=a·x+b，要最小化的是

J(a,b) = Σi=15 [yi − (a·xi + b)]² + λa²，λ ≥ 0

先定口径。累加号把五个平方加起来，量纲是 y²。如果把目标换成平均误差平方 J/5，同一个 (a,b) 的优劣次序和极小点都不变，但同一个 λ 的惩罚相对强度变了（等价于把 λ 换成 λ/5），因此给定 λ 算出的 a、b 会不同。本页从头到尾用总和：正文里的 10、14、21.2 以及交互读数都是总和口径。

还有一个后面要用到的结构事实：J 是 (a,b) 的二次函数——平方和提供二次部分，λa² 也落在二次部分，剩下是一次项和常数。二次函数的下界、驻点和唯一性可以一次说清，不必逐点比较。

2 先消掉 b：最优直线必过均值点

固定示例：数据 A

记第 i 个残差 ri=yi−a·xi−b。它对 b 的导数是 −1，而 λa² 里没有 b，所以

∂J/∂b = −2·Σi(yi − a·xi − b)

令它为零，得到 Σ(yi−a·xi−b)=0，即五个残差之和为零。把求和拆开：Σyi − a·Σxi − 5b = 0，两边同除 5：

b = ȳ − a·x̄ = 1.6 − 2a

这一步里 λ 一次都没出现，因为惩罚项不含 b。所以无论 λ 取 0 还是 10，最优截距都满足 b=1.6−2a。把它读成几何事实：a·x̄+b=ȳ，直线在 x=x̄ 处的取值正好是 ȳ，因此最优直线必过 (2, 1.6)。这个结论在第 5 节的图里始终成立，第 7 节数据 B 也成立。

作为对照，如果目标写成 Σri²+λ(a²+b²)，b 的方程会多出一项，变成 5(ȳ−a·x̄−b)=λb；残差之和一般不再为零，"必过均值点"这条性质随之消失。本页的目标只惩罚 a，所以这条性质在整页都有效。

3 中心化：交叉项为什么消失

固定示例：数据 A

记离差 x̃i=xi−2、ỹi=yi−1.6，再记 r=1.6−2a−b。r 就是每个残差里"与下标 i 无关"的那一块。把单个残差拆成两块：

yi − a·xi − b = (ȳ + ỹi) − a(x̄ + x̃i) − b = r + (ỹi − a·x̃i)

平方后对 i 求和，展开成三项：

Σ[r + (ỹi−a·x̃i)]² = 5r² + 2r·Σ(ỹi−a·x̃i) + Σ(ỹi−a·x̃i)²

看交叉项：Σỹi=Σyi−5·ȳ=8−8=0，Σx̃i=Σxi−5·x̄=10−10=0。两个和各自为零，于是 2r(0−a·0)=0，交叉项整项消失。同一个事实用了两次：离差之和为零，因为中心化时正好减掉了均值。

改写后的目标是三块，每块只含一个"变量"：

J = 5r² + Σ(ỹi−a·x̃i)² + λa²，r = 1.6−2a−b

第一块只随 b 变（固定 a 时），第二、三块只随 a 变。中心化能把两个系数分开，靠的就是这一点。

三个和的数值（离差列表 x̃=(−2,−1,0,1,2)，ỹ=(−2.6,−1.6,0.4,0.4,3.4)）：

  • Sxx=Σx̃²=4+1+0+1+4=10
  • Sxy=Σx̃·ỹ=5.2+1.6+0+0.4+6.8=14（逐项：(−2)(−2.6)=5.2，(−1)(−1.6)=1.6，0·0.4=0，1·0.4=0.4，2·3.4=6.8）
  • Syy=Σỹ²=6.76+2.56+0.16+0.16+11.56=21.2
Σ(ỹi−a·x̃i)² = Syy − 2a·Sxy + a²·Sxx = 21.2 − 28a + 10a²

4 联立两个偏导，得到 a 和 b 的闭式解

固定示例：数据 A

把上面两块合起来，只保留 λ 的符号：

J = 5r² + (10+λ)a² − 28a + 21.2，r = 1.6 − 2a − b

对 a 求偏导时要注意 r 里也含 a（∂r/∂a=−2），所以 5r² 会贡献一项 −20r：

∂J/∂a = −20r + 2(10+λ)a − 28，∂J/∂b = −10r

两个偏导同时为零：第二式给出 r=0；把它代进第一式，−20·0 消失，剩 2(10+λ)a=28，即

a* = 14/(10+λ)，b* = 1.6 − 2a* = 1.6 − 28/(10+λ)

5 交互检验：λ 与两组数据

面板用同一组公式 a*=Sxy/(Sxx+λ)、b*=ȳ−x̄·a* 计算，所以读数和上面的推导出自同一套数。拖动 λ 时看三件事：直线绕均值点 (2,1.6) 转动；a* 变小、b* 变大；未加惩罚的误差平方和 SSE 与惩罚项 λa*² 分开显示，两者之和是目标值 J。λ 在 0 到 10 之间增大时，SSE 从 1.6 升到 6.5，惩罚项从 0 升到 4.9，J 从 1.6 升到 11.4——约束越紧，能达到的最小目标值越高。

6 为什么这是全局最小，什么时候唯一

固定示例：数据 A

"令偏导为零"只交出了候选点。要说明它是全局最小并且唯一，把目标配方成平方和。把二次式 (10+λ)a²−28a 配成平方（28=2·14）：

J(a,b) = 5·(1.6 − 2a − b)² + (10+λ)·(a − 14/(10+λ))² + [21.2 − 196/(10+λ)]

先核对这确实是同一个函数。右边展开：a² 的系数是 5·4+(10+λ)=30+λ，ab 的系数是 5·2·2=20，b² 的系数是 5；常数是 5·1.6²+196/(10+λ)+21.2−196/(10+λ)=12.8+21.2=34。左边 J 展开也是 34−60a−16b+(30+λ)a²+20ab+5b²，两者逐项相同。

三项各有角色：第一项衡量"a·x̄+b 有没有对上 ȳ"，只在直线在均值点处偏离时为正；第二项衡量"斜率偏离 a*"；第三项只含数据和 λ，与 (a,b) 无关。因为 λ≥0 使 10+λ>0，三项都非负，于是

J(a,b) ≥ 21.2 − 196/(10+λ)，等号当且仅当 a=14/(10+λ) 且 b=1.6−2a

下界由常数项给出，而且能被取到：只要 a=a*、b=b*，两个平方同时为零，J 正好等于这个下界。所以 (a*, b*) 是全局最小点，并且是唯一的——任意别的 (a,b) 至少让一个平方项严格大于零。这条论证在 λ=0 时同样成立，因为 Sxx=10>0，第二项的系数仍为正。

用二阶条件说同一件事：J 的二次部分为 (30+λ)a²+20ab+5b²，Hessian 是

H = [[2(30+λ), 20], [20, 10]]，det H = 20(30+λ) − 400 = 20(10+λ)

det H>0 且对角元为正，H 正定，J 严格凸，驻点即唯一全局最小。一般数据的判据是 det=4n(Sxx+λ)，所以"严格凸"这件事取决于两个量：样本量 n>0 与 Sxx+λ>0。λ≥0 时，只要 x 有变化（Sxx>0），任何 λ 都给唯一解；x 没有变化（Sxx=0）时，唯一性就全靠 λ>0 撑着——这正是第 7 节要说的事。

7 退化数据：五个 x 全是 2

数据 B：x=(2,2,2,2,2)，y=(−1,0,2,2,5)

把 x 换成常数 2，y 不变。此时 x̄=2、ȳ=1.6 不变，但两个和变了：x̃ 全为 0，所以 Sxx=0、Sxy=0；Syy 仍是 21.2。第 2 节的截距方程完全不变，所以 b=1.6−2a 仍然成立。

关键在于：所有残差只通过 c=2a+b 这个组合依赖 (a,b)。写出来更清楚，令 c=2a+b：

yi − c = (1.6 − c) + ỹi ⟹ Σ(yi−c)² = 5(1.6−c)² + 21.2
J(a,b) = 5(1.6 − c)² + 21.2 + λa²，c = 2a + b

交叉项又消失了，理由和第三节一样：Σỹi=0。这个式子把两种情形一次说清。

λ=0：无穷多最优解

此时 J=5(1.6−c)²+21.2，只依赖 c。任何让 c=1.6 的 (a,b) 都取到最小值 21.2，也就是整条直线族

b = 1.6 − 2a，a 任意 ⟹ J = 21.2（每一条都同样好）

可确定的量只有 c=2a+b=1.6，它等价于"直线在 x=2 处的预测值"。斜率 a 与截距 b 各自定不下来：取 a=1 要配 b=−0.4，取 a=−0.5 要配 b=2.6，五条残差一模一样。二阶判据在这里正好失效：det=4n(Sxx+λ)=20·0=0，H 半正定，最优点构成一条直线而不是一个点。任何把这件事说成"最优斜率是某个数"的讲法都会丢掉全部信息。

λ>0：唯一解，而且是 a=0

λ>0 时 det=20λ>0，H 正定，解唯一。从公式看：a*=Sxy/(Sxx+λ)=0/λ=0，b*=ȳ−x̄·a*=1.6，J=21.2+λ·0=21.2。也就是说惩罚项把等优族里"斜率绝对值最小"的那一条挑了出来，拟合结果是水平线 ŷ=1.6，而且这个结果与 λ 的具体数值无关。

这里要说清边界。λ>0 让答案变唯一，靠的是惩罚项对 a 的偏好（同样好的解里挑 a² 最小的），数据本身对斜率没有提供任何信息：所有等优直线在 x=2 处都给 1.6。正则化在这里解决的是"解不唯一、无法报出一个系数"的问题，没有解决"x 没有变化，所以学不到斜率"的问题。把 a=0 当成数据得出的结论会误导读者的判断。

对比第 4 节的数据 A：那里 a* 随 λ 连续变化（1.4→0.7），因为 Sxx=10>0 记录了 x 的变化。数据 B 的 a* 在 λ>0 时恒为 0，与 λ 无关。两组数据的差别不在 λ，而在 Sxx。

8 四个收束问题

增大 λ 为什么改变斜率

公式给出 a*=Sxy/(Sxx+λ)=14/(10+λ)，对 λ 求导：da*/dλ = −Sxy/(Sxx+λ)² = −14/(10+λ)²<0。分母随 λ 变大，|a*| 单调变小，斜率的符号由 Sxy 决定（这里 Sxy=14>0，所以 a* 从 1.4 一路降到 0.7）。机制上是两种边际量的平衡：拟合项希望 a 停在对数据最贴的地方，惩罚项对 a 的边际成本是 2λa，λ 越大，同一个 a 位置上的边际成本越高，最优点就向 a=0 移动。代价也看得见：SSE 从 1.6 升到 6.5，拟合变差是被主动买下来的。

截距为什么会跟着变

因为 b*=ȳ−x̄·a*=1.6−2a*：截距被钉在"直线过均值点"这个条件上，没有独立自由度。a 每减少 1，b 就增加 2，保证直线仍通过 (2,1.6)。λ 从 0 到 10，a 从 1.4 降到 0.7（减少 0.7），b 从 −1.2 升到 0.2（增加 1.4），正好是 2 倍关系。第 5 节拖动 λ 时看到的"绕点转动"就是这个约束的几何形态。

为什么仍经过均值点

因为 ∂J/∂b=0 等价于残差之和为零，而残差之和 = n(ȳ−a·x̄−b)，于是 b=ȳ−a·x̄。这一步里 λa² 完全不参与，所以对任何 λ 都成立；它成立的根据是惩罚项不含 b，而不是 λ 恰好取某个值。反例见第 2 节末尾：一旦惩罚也含 b，方程多出 λb，残差和不再为零，直线就不必过均值点了。

正则化在 x 没有变化时解决了什么

它把"无穷多个同样好的解"变成"一个可报出的解"，挑选规则是让 a² 最小，于是 a=0、b=1.6、直线水平。它没有、也不可能提供斜率的信息：能由数据确定的组合只有 c=2a+b=1.6，所有等优解在 x=2 处预测同一个值。所以"λ>0 时斜率唯一且为 0"是惩罚项的选择结果，说成"数据支持斜率 0"就错了。若要研究斜率，前提是 x 有变化（Sxx>0），这一点正则化替代不了。

复现清单

  1. 写出 ∂J/∂b，解出 b=ȳ−a·x̄，并说明 λ 为什么不出现在这一步。
  2. 把残差拆成 r+(ỹ−a·x̃)，指出交叉项为零用的是哪两个"和为零"。
  3. 算出 Sxx=10、Sxy=14、Syy=21.2，写出 a*=14/(10+λ)，并检查 λ=0 时回到 1.4。
  4. 配方成三项，写出下界 21.2−196/(10+λ) 与取等条件；再写出 det H=20(10+λ)，说明它为什么等价于"严格凸"。
  5. 对 x 全为 2 的数据，先写 c=2a+b，再分别说明 λ=0（c 可定、a 与 b 不可定）和 λ>0（a=0、b=1.6，且与 λ 数值无关）各能定下什么。
