u 被用两次，反向传播为什么要把两份贡献相加

u = x·y 算出来以后被用了两次，x 也同时进入两处。这份页面就沿着这张小图的真实依赖走：先算值，再从 L 逆着箭头回来，看着两份贡献在哪里汇合、为什么必须等到齐了才能继续往回传。

1. 只看这三个公式

u = x · y
v = u + x
L = v² + 3u

x、y 是输入，可以自由选；u、v、L 都是算出来的。有两处"共用"值得先盯住：

  • u 被用两次：一次进 v（v = u + x），一次直接进 L（3u 那一项）。同一个计算结果，两条出路。
  • x 进入两处：一次进 u（u = x·y），一次直接进 v（v = u + x）。

反向传播要处理的就是这两处共用：从 L 出发，回到 u 有两条路，回到 x 也有两条路。

3. 一步一步走：先前向，再反向

整个回放一共 13 步：前 4 步前向，后 9 步反向。拖动上面的步骤滑杆或点按钮，下面的列表会跟着亮到当前这一步；图上的节点和边也会同时高亮当前在处理的对象。

反向有两条规则，整套账都靠它们：

  1. 从 L 出发，逆着箭头走。先离开 L 最近的 v 和 u，最后才到输入 x、y。
  2. 到一个节点，要等它的所有出边都把贡献送回来，才能把合计继续往回传。一个节点正向流出几条边，就要收回几笔。

先算哪一条出边无所谓，加法可以交换；必须遵守的是"到齐"。下面每一步都只用当前这组输入算出的数字。

    4. 每个节点的账本

    反向时每个节点都在等自己的几笔贡献。下面这张账本显示：正向流出几条边、已经收回几笔、合计是多少、有没有到齐。没到齐的节点会写明"先不往回传"。

    5. 为什么要相加，而不是二选一

    沿一条边反向走时，你乘的是这条边的局部导数：上游动一点，这个节点跟着动多少。从 L 到某个量如果只有一条路，把沿路的局部导数乘起来就够了，这就是你熟悉的链式法则。

    麻烦在于 u 和 x 都有两条路。以 u 为例：把 u 挪动一个很小的量 h。经过 3u 这一项，L 变化约 3h；同时 v 变化约 1·h，而 v 的变化又让 v² 变化约 2v·(1·h)。这两件事同时发生，所以 L 的总变化约 (3 + 2v)·h。除以 h，就得到 dL/du = 3 + 2v。

    相加的来源就在这句话里：同一份 h 被两条路同时送出去，两条路的效果叠在一起。两条路的终点都是 L，所以它们共用同一个上游数（这里是 1），不同的只是沿途乘了哪些局部导数。每一笔对应一条不同的路径，路径不同，乘的局部导数就不同，所以和里没有重复计算。

    把五条路径摊开

    把 x 的路径重新分组，正好就是账本里的两笔：经 u 的两条（x→u→L 和 x→u→v→L）加起来是 ，直达 v 的那条是 。所以"u 收到 3 和 16、合计 19"与"x 收到 57 和 16、合计 73"说的是同一件事的两个层次：先在 u 处汇总，再把汇总后的数继续往回乘。

    顺序本身不重要：先算哪条出边，和都不变。真正卡住的是"完整"——一个节点少收一笔就往下传，缺的那块会跟着再乘一次局部导数，被放大到所有更上游的节点。

    把账本故意弄错一次，看数字怎么变。下面全部用当前这组输入算。

      两种错法的共同点：得到的数看上去都像一个正常的导数，光看图看不出问题。第 7 节的差分和展开核对就是为了抓这种错。

      为什么漏掉会错：dL/dx 描述"x 动一点，L 总共动多少"。x 通过两条通道影响 L，漏掉一条就只算了一部分变化。所以梯度不是挑一条最"主要"的路，而是把所有路径的效应加起来。

      7. 贡献是 0 或负数时

      每一笔贡献 = 上游的数 × 这条边的局部导数。乘积为 0 只有两种可能：上游是 0，或者这条边的局部导数是 0。它的含义是"沿这条路，此刻 L 不随这个量变化"，而不是"这条路不存在"：换一个输入，同一条边立刻又会有贡献。

      负号表示方向相反：沿这条路，这个量增加会让 L 下降。相加时直接按带符号的数相加，不要取绝对值。

        8. 独立核对：把 L 直接展开求导

        前面的 73 和 38 是沿图算出来的。现在换一条完全不同的路：把 u、v 代进去，让 L 变成只含 x、y 的一个多项式，再直接用多项式求导。

        u = x·y，　v = u + x = x(y + 1)
        L = v² + 3u = x²(y + 1)² + 3xy
        ∂L/∂x = 2x(y + 1)² + 3y
        ∂L/∂y = 2x²(y + 1) + 3x

        再把平方项整个拆开，得到最朴素的多项式形式：

        L = x²y² + 2x²y + x² + 3xy
        ∂L/∂x = 2xy² + 4xy + 2x + 3y
        ∂L/∂y = 2x²y + 2x² + 3x

        展开式和图算的是同一个东西，但展开式把经过 v 的两条路合并进了 2x(y + 1)² 这一项里：2x(y + 1)² = 2v·(y + 1)，正是"直达 v 的 2v"加上"经 u→v 的 2v·y"。所以展开式能核对总数，却看不出每条路径各乘了什么——这正是需要计算图的地方。

        9. 把这件事压成四句

        • 前向按箭头算值：u 只算一次，被读两次（进 v、进 L）。
        • 反向从 dL/dL = 1 出发逆着箭头走；每到一个节点，等它的所有出边都到齐，再把合计乘上局部导数往回传。
        • 两份贡献相加，是因为同一份变化被多条通道同时送出，一阶效应叠加；每笔各对应一条路径。
        • 漏一笔，或没到齐就下传，都会得到一个"看起来像导数"的错数；展开求导和差分能把它抓出来。
