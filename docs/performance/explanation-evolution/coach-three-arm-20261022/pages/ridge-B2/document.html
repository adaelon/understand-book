带惩罚的直线拟合：从目标函数推出最优解

固定五个观测点，从 J(a,b) = Σ[yi − (a·xi + b)]2 + λa2 开始，逐步推出 a*(λ)、b*(λ) 与 Jmin，说明为什么得到的是全局最小值、什么时候唯一，再用 x 全等于 2 的退化数据检验这套推理。

1 先读目标函数：三条约定各自带来什么

本页只用这一组数据：x = (0, 1, 2, 3, 4)，y = (−1, 0, 2, 2, 5)，拟合直线 ŷ = a·x + b，最小化

J(a, b) = Σi=15 [ yi − (a·xi + b) ]2 + λa2，　λ ≥ 0

三条约定决定了后面每一步的形态，先把它们的后果说清：

  • 用总和，不用平均。把 J 整体乘上 1/5 会得到一个"平均"目标。正的常数不改变谁的 J 更小，最小点 (a, b) 完全一样，只有最小值的数值按同一比例缩小。本页所有数字都是总和口径。
  • 罚项只含 a。这会带来一个具体结果：b 出现在每个残差里又不受罚，于是最优时残差之和为零（第 4 节），直线因此始终穿过样本均值点。
  • λ ≥ 0，范围取 0 到 10。λ = 0 时 J 退化成纯误差平方和；λ 越大，斜率被压得越厉害。交互面板的滑块步长是 0.5。

2 展开成二次式，并算三个中心化量

把每个残差平方展开再求和：

Σ[yi − (a xi + b)]2 = Σy2 − 2aΣxy − 2bΣy + a2Σx2 + 2abΣx + nb2

本组数据的汇总量：n = 5，Σx = 10，Σy = 8，Σx2 = 30，Σxy = 30，Σy2 = 34。代入：

J(a, b) = 30a2 + 20ab + 5b2 − 60a − 16b + 34 + λa2

接着算后面一直要用的三个中心化量：

x̄ = 10/5 = 2，　ȳ = 8/5 = 1.6
Sxx = Σ(xi − x̄)2 = 30 − 102/5 = 10
Sxy = Σ(xi − x̄)(yi − ȳ) = 30 − 5·2·1.6 = 14
Syy = Σ(yi − ȳ)2 = 34 − 82/5 = 21.2 = 106/5

Sxy 用了恒等式 Σ(xi−x̄)(yi−ȳ) = Σxy − n·x̄·ȳ：把括号乘开后，含 x̄ 与 ȳ 的一次项分别合成为 −2ȳΣx 与 −2x̄Σy，再加上 n x̄ ȳ 的修正，恰好等于 Σxy − n x̄ ȳ。

3 中心化改写：交叉项为什么消失

记残差 ri = yi − a xi − b，再记 c = ȳ − a x̄ − b。c 的含义是：把 x̄ 代进直线后，预测值与 ȳ 的差。把 ri 按 ȳ、x̄ 重排：

ri = (yi − ȳ) − a(xi − x̄) + c

平方后求和，得到四类项：

Σri2 = Σ(yi−ȳ)2 − 2aΣ(xi−x̄)(yi−ȳ) + a2Σ(xi−x̄)2 + 2c·[ Σ(yi−ȳ) − aΣ(xi−x̄) ] + n c2

方括号里的两个求和都是零：Σ(yi − ȳ) = Σy − nȳ = 0，Σ(xi − x̄) = Σx − nx̄ = 0。所以含 c 的交叉项整体为零，剩下

Σri2 = Syy − 2aSxy + a2Sxx + 5c2

这就是"可以换成中心化写法"的理由：它把同一个平方和按 (y−ȳ) 与 (x−x̄) 重新分组，没有做任何近似。交叉项消失不依赖 a 取什么值，也不依赖 λ，只依赖两个中心化量各自求和为零。加上罚项：

J(a, b) = Syy − 2aSxy + a2(Sxx + λ) + 5c2

4 先定 b：b 只出现在一个非负项里

在上一节最后这个式子里，b 只通过 c = ȳ − a x̄ − b 出现，并且以 5c2 的形式出现。给定 a，5c2 的最小值就是 0，取到它的唯一方式是 c = 0：

b = ȳ − a x̄ = 1.6 − 2a　（对每个 λ ≥ 0 都成立）

三条推论：

  • 最优直线在 x = x̄ 处的预测值等于 ȳ：把 x = 2 代入得 a·2 + b = 1.6，直线穿过点 (2, 1.6)。
  • b 跟着 a 移动。x̄ = 2 为正，所以 a 减小时 b 增大，两者由 b = 1.6 − 2a 绑定。
  • 这个关系与 λ 无关，因为罚项里没有 b。

导数版本是同一件事：∂J/∂b = −2Σri，令其为零得 Σri = 0，即 y 的平均值等于 ŷ 的平均值。

对照（本页不计算这种情况）：若罚项写成 λa2 + μb2，则 ∂J/∂b = −2Σri + 2μb = 0 给出 Σri = μb，一般不为零，直线就不再保证穿过均值点。

5 只剩 a：配方给出全局最小与唯一性

把 b = ȳ − a x̄ 代回，c 归零，J 变成 a 的一元二次式：

f(a) = (Sxx + λ)a2 − 2Sxya + Syy = (10 + λ)a2 − 28a + 21.2

配方时令 a* = Sxy/(Sxx+λ)，把一次项 −2Sxya 写成 −2(Sxx+λ)a·a*：

f(a) = (Sxx + λ)(a − a*)2 + Syy − Sxy2/(Sxx + λ)

代入数值，得到本页后面反复使用的三个式子：

a*(λ) = 14/(10 + λ)，　b*(λ) = 1.6 − 2a*(λ)，　Jmin(λ) = 21.2 − 196/(10 + λ)

把 b 也留在式子里，配方后的完整形式是

J(a, b) = (Sxx + λ)(a − a*)2 + 5[ b − (ȳ − a x̄) ]2 + Jmin　(*)

为什么这是全局最小，而不只是一个驻点

(*) 右边两项都是"正系数 × 平方"。对任意 (a, b)，两项都 ≥ 0，所以 J ≥ Jmin 恒成立。取 a = a* 并让方括号为零（即 b = ȳ − a* x̄），两项同时为 0，J 恰好等于 Jmin。下界被取到，所以 Jmin 是全局最小值，不存在更低的点。

求导只提供必要条件：∂J/∂a = 2(Sxx+λ)a − 2Sxy 在 a* 处为零，∂J/∂b = −10c 在 b = ȳ − a* x̄ 处为零。把"驻点"升级为"最小值"的，是上面那个下界论证。

什么时候唯一

  • a 那一项的系数 Sxx + λ = 10 + λ ≥ 10 > 0，严格为正；a ≠ a* 时这一项就 > 0，所以 a* 唯一。
  • b 那一项的系数 5 > 0，且它要求 b 恰好等于 ȳ − a x̄；a 唯一，b 也随之唯一。
  • 二阶检查：(a, b) 的二阶偏导矩阵是 [[2(30+λ), 20], [20, 10]]，行列式 = 20(10+λ) > 0，矩阵正定，与上述结论一致。

唯一性依赖 Sxx + λ > 0。本组数据 Sxx = 10，所以 λ = 0 时也唯一——"有惩罚才唯一"在这里不成立。要让唯一性失效，必须 Sxx = 0 且 λ = 0，第 9 节正是这种情况。

8 四条应该能讲清的事

(a) 增大 λ 为什么改变斜率

a*(λ) = 14/(10+λ)。分子 Sxy = 14 > 0 与 λ 无关，分母随 λ 增大，所以 a* 随 λ 增大而减小。只要 λ 有限，a* 仍是正数；λ → ∞ 时才趋于 0（本页 λ 最大到 10，a* 最小到 0.7）。

机制是两笔代价的交换：把 a 从 λ = 0 的 1.4 往下拉，RSS 变大（拟合变差），但 λa2 变小，而且 λ 越大，同样减小 a 能省下的罚项越多。平衡条件是 (Sxx + λ)a = Sxy，解出 a* = 14/(10+λ)。

(b) 截距为什么也跟着变

因为 b* = 1.6 − 2a*。x̄ = 2 为正，a* 每减少 0.1，b* 就增加 0.2。λ 从 0 走到 10 时，a* 从 1.4 降到 0.7，b* 从 −1.2 升到 0.2。几何上直线绕 (2, 1.6) 旋转：斜率变小，与 y 轴的交点上移。

方向来自两件事相加：a* 在下降，x̄ 为正。若这组数据的 x̄ 是负数，同样的 a* 下降会把 b* 推向相反方向。罚项直接惩罚的始终只有 a。

(c) 拟合直线为什么仍经过均值点

最优时 ∂J/∂b = −2Σri = 0，残差之和为零。两边除以 n：ŷ 的平均值等于 ȳ，即 a x̄ + b = ȳ。这条性质与 λ 无关，启用它的条件是 b 在每个残差里出现、并且不被惩罚。页面上把 λ 从 0 拖到 10，绿色空心圈 (2, 1.6) 始终落在直线上。

(d) 正则化在 x 没有变化时解决了什么

第 9 节用同一套推导回答。简短版：那里 Sxx = Sxy = 0，λ = 0 时有一整族同样好的直线；λ > 0 时答案唯一，但唯一的那个 a = 0 是罚项选出来的，数据并没有提供斜率信息。

9 退化数据：五个 x 全等于 2

这里是另一组数据。观测点换成 x = (2, 2, 2, 2, 2)，y 仍是 (−1, 0, 2, 2, 5)。第 1–8 节的数字都属于数据集 A，不与本节混用。

新数据的汇总量：x̄ = 2，ȳ = 1.6（没变），Sxx = 0，Sxy = 0，Syy = 21.2（只由 y 决定）。残差平方和可以先按 u = 2a + b 重写，u 是五个点共同的拟合值：

J(a, b) = Σ(yi − (2a + b))2 + λa2 = 21.2 + 5(2a + b − 1.6)2 + λa2

中间那一步用的是第 3 节的同一个改写 Σ(yi − u)2 = Syy + 5(u − ȳ)2；这里 xi − x̄ 全为零，所以 a 不再直接出现在残差里，只能通过 u 出现。

λ = 0：一整族最优解

J = 21.2 + 5(u − 1.6)2

最小值 21.2，条件 u = 1.6，也就是 2a + b = 1.6。

  • a 可以是任何实数，b = 1.6 − 2a，两者一一对应。
  • 每个候选 (a, b) 都让五个点的拟合值等于 1.6，残差完全相同，所以 RSS 与 J 都等于 21.2。没有一条直线比另一条更好。
  • 数据只确定了组合 2a + b，即 x = 2 处的拟合值；a 与 b 各自的取值没有被确定。这一族直线都经过 (2, 1.6)，可见"过均值点"与唯一性无关。

λ > 0：唯一，但唯一的来源是罚项

J = 21.2 + λa2 + 5(u − 1.6)2

两项分别是 a 与 u 的严格正系数平方，最小值在 u = 1.6 且 a = 0，于是 b = 1.6 − 0 = 1.6，最小解唯一：(a, b) = (0, 1.6)。二阶检查：(a, b) 的二阶偏导矩阵是 [[2(20+λ), 20], [20, 10]]，行列式 20λ，λ > 0 时正定；λ = 0 时行列式为 0、矩阵秩为 1，最小解集退化成一条直线。

把 λ 从 0.5 拖到 10，这组数据的读数一动不动：a = 0，b = 1.6，RSS = 21.2，罚项 = 0，J = 21.2。这正是"数据没有提供斜率信息"的直接表现——每个 λ > 0 都给出同一个答案。

要区分的两件事。"唯一"说的是 J 只有一个最小点；"可辨识"说的是数据能否区分不同斜率。这组数据不能，所以 a = 0 是罚项在众多同样好的直线里挑出的一个约定，把 a = 0 读成"斜率就是 0"超出了这组数据能支持的范围。另外 J 的最小值 21.2 始终大于 0：这五个 y 的波动无法由 x 解释，正则化也不能把它消掉。

10 复现清单

  1. 写出 J，把平方展开，代入 n、Σx、Σy、Σx2、Σxy、Σy2 六个汇总量。
  2. 换成 Sxx、Sxy、Syy，并说明交叉项为零用的是 Σ(xi−x̄) = Σ(yi−ȳ) = 0。
  3. 固定 a 处理 b：对 b 取条件，或直接看 5c2 ≥ 0，得 b = ȳ − a x̄。
  4. 代回得 (Sxx+λ)a2 − 2Sxya + Syy，配方读出 a*、b*、Jmin。
  5. 用"两项非负、系数为正"说明全局最小，用 Sxx+λ > 0 说明唯一，并指出 λ = 0 时本组数据仍唯一。
  6. 对退化数据重做第 3–5 步，写清 λ = 0 时最小解集是一条直线而不是一个点。
  7. 用 λ = 2 对一遍数：a* = 7/6，b* = −11/15，RSS = 193/90，罚项 = 49/18，J = 73/15。
