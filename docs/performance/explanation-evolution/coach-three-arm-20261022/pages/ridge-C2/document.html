带惩罚的直线拟合：从目标函数推到最优解

五组观测、一条直线、一个只罚斜率的二次项。下面把最优的 a 和 b 从头推出来，并说明它为什么是全局最小、什么时候不唯一。

0. 数据与目标：先把口径定死

固定示例 A 用五个观测点：x = (0, 1, 2, 3, 4)，y = (−1, 0, 2, 2, 5)，n = 5。拟合直线写作 ŷ = a·x + b，目标是

J(a,b) = Σi=1..5 [ yi − (a·xi + b) ]² + λa²，λ ≥ 0

目标里的平方和是总和，没有除以 n。惩罚项 λa² 只含斜率 a，与截距 b 无关。这两条约定决定了后面每一个数字，所以先说清它们各自的影响：

  • 总和口径。把 J 整个除以 n 不会改变最优的 (a, b)，因为比例缩放不移动最小点；但同一句“λ = 2”在两种口径下的含义不同。若误差仍取平均而 λ 不跟着改，等于把惩罚的相对权重放大 n = 5 倍。本页所有数值、图形与交互读数都按总和口径计算。
  • 只罚 a。b 只出现在残差项里，所以 b 的一阶条件完全由数据决定，λ 不进入。这一点在后面会直接给出“直线必过均值点”的结论。

1. 第一步：用配方把 b 一次消掉

要同时处理两个未知量，先把 b 摘出来。下面这个恒等式对任意 a、b 都成立（这就是你说的配方，只是配在两个变量上）：

Σi (yi − a·xi − b)² = Σi ( (yi − ȳ) − a(xi − x̄) )² + n( ȳ − a·x̄ − b )²

它为什么成立，看两处：

  1. 令 ui = (yi − ȳ) − a(xi − x̄)，c = ȳ − a·x̄ − b。把 c 加回 ui 时，−ȳ 与 +ȳ、−a·x̄ 与 +a·x̄ 逐项抵消，正好得到 yi − a·xi − b。所以每个残差都能拆成“中心化残差 + 同一个常数”。
  2. 关键一步：Σi ui = 0。因为 Σ(yi − ȳ) = 0，且 Σ(xi − x̄) = Σxi − n·x̄ = 0，两项分别归零，a 乘上去仍然是零。

于是 Σ(ui + c)² = Σui² + 2c·Σui + n·c² = Σui² + n·c²。交叉项 2c·Σui 消失的机制就在这里：一个对所有 i 都相同的常数 c，乘上“求和为零”的 ui 再相加，结果必然是零。若把平方直接展开成 Σy² − 2aΣxy − 2bΣy + a²Σx² + 2abΣx + nb²，那个把 a 和 b 缠在一起的项是 2abΣx；中心化之后 Σ(xi − x̄) = 0，这个缠绕项就没有了。两处说的是同一件事：均值让常数方向与中心化方向正交。

恒等式把 b 隔离到了单独的 n(ȳ − a·x̄ − b)² 里，其余部分与 b 无关。对任意固定的 a，这一项非负，取零时最小，所以

b(a) = ȳ − a·x̄

把 b 换成这个值，右边第二项消失，J 只剩中心化部分。同时顺带得到一个几何事实：ŷ(x̄) = a·x̄ + b(a) = ȳ，也就是最优直线必过均值点 (x̄, ȳ)。这个结论只用到了“惩罚不含 b”，所以它对任意 λ ≥ 0 都成立，后面会反复用到。

3. 第三步：只剩一个变量，求导

用 b(a) = 1.6 − 2a，前面那个括号也归零，得到只含 a 的剖面目标

J(a) = (10+λ)a² − 28a + 21.2

这里的 J(a) 不是“随便固定了 b”，而是“对每个 a 都让 b 取它的最优值”之后的 J 值。换句话说，J(a) 画的是曲面 J(a,b) 沿曲线 b = 1.6 − 2a 的剖面。这个区别在讲唯一性时很要紧。

对 a 求导：

J′(a) = 2(10+λ)a − 28，  J″(a) = 2(10+λ)

令 J′(a) = 0，只要 10 + λ ≠ 0 就得到唯一驻点

a* = 14 / (10+λ)，  b* = 1.6 − 2a*

5. 第五步：为什么是全局最小，什么时候唯一

令导数为零只说明“驻点”，还欠两件事：它是否为全局最小，以及它是否唯一。

用一元视角看

因为 J″(a) = 2(10+λ) > 0（λ ≥ 0），J(a) 是开口向上的抛物线。配方后

J(a) = (10+λ)·( a − 14/(10+λ) )² + 21.2 − 196/(10+λ)

平方项非负，取到零当且仅当 a = a*，所以 a* 是 J(a) 的全局最小点，最小值是 21.2 − 196/(10+λ)（λ = 0、2、10 时分别为 1.6、4.867、11.4，与上表一致）。再回到二维：J(a,b) 等于 J(a) 加上一个非负的 5(1.6 − 2a − b)²，那一项在 b = b(a) 时恰好为零，所以 (a*, b*) 也是 J(a,b) 的全局最小点，最小目标值相同。

用二维视角看（判据更直接）

在 (a, b) 坐标下，J 的二阶偏导是常数：∂²/∂a² = 2(Σx² + λ) = 2(30+λ)，∂²/∂a∂b = 2Σx = 20，∂²/∂b² = 2n = 10。所以

H = 2 · [[30+λ, 10], [10, 5]]，  det H = 4n(Sxx + λ) = 20(10+λ) > 0（λ ≥ 0）

左上元素 2(30+λ) > 0 且行列式为正，H 正定，J 严格凸，驻点就是唯一的全局最小点。一般地，b 那一块永远是 2n > 0，所以唯一性只由 Sxx + λ > 0 决定。示例 A 的 Sxx = 10 > 0，因此即使 λ = 0，解也唯一——这一点在第 7 节会和退化数据形成对照。

7. 退化数据：五个 x 全部等于 2

现在换一组数据，y 与样本数都不变：x = (2, 2, 2, 2, 2)，y = (−1, 0, 2, 2, 5)。此时 x̄ = 2、ȳ = 1.6，而

Σx² = 20，Σx = 10，Σx·y = 16  ⟹  Sxx = 20 − 5·2² = 0，Sxy = 16 − 5·2·1.6 = 0

Syy 仍是 21.2。同一个恒等式给出

J(a,b) = 5·(1.6 − 2a − b)² + λa² + 21.2

λ = 0：一族同样好的直线

λ = 0 时 J = 21.2 + 5(1.6 − 2a − b)²。最小值 21.2，在所有满足 2a + b = 1.6 的 (a, b) 上取到，也就是整族 b = 1.6 − 2a。a 可以随便取，b 跟着它走。

这一族里的每一条直线在观测点上给出同一个预测值：x = 2 时 ŷ = 2a + (1.6 − 2a) = 1.6，与 a 无关。所以五条残差都是 (−2.6, −1.6, 0.4, 0.4, 3.4)，RSS 都是 21.2。挑不出哪条“更好”，因为在这组数据上它们完全一样。用公式看，a* = Sxy/(Sxx+λ) 在这里是 0/0：分母的曲率没了，代数本身就在提示问题没有唯一答案。Hessian 的判据也一致：det H = 4n(Sxx+λ) = 20λ，λ = 0 时为零，二阶信息不足以定出方向。

若在这组数据上给 a 报一个确定数字，就等于把“惩罚约定”说成了“数据结论”。数据里没有任何关于斜率的信息，因为 x 从未变化。

λ > 0：只有 a = 0 被选中

λ > 0 时 J = 21.2 + 5(1.6 − 2a − b)² + λa²。先让括号为零（任何 2a + b = 1.6 的直线都能做到），再最小化 λa²，只能取 a = 0，于是 b = 1.6。此时 det H = 20λ > 0，解唯一。公式同样给出 a* = 0/(0+λ) = 0、b* = ȳ − x̄·0 = 1.6。

代价与收益要分开看：J 仍然是 21.2，残差、预测值、对观测点的拟合都没有任何变化。变的是系数从一参数族收缩到一个点，以及对 x = 2 之外的取值给出了确定的水平线 ŷ = 1.6。那条水平线的斜率 0 是“惩罚最小的那个表示”，并非从数据估出来的斜率。

8. 回到你列的四个问题

增大 λ 为什么会改变斜率

看剖面目标 J(a) = (10+λ)a² − 28a + 21.2：λ 只加在二次项系数上，一次项 −28a 完全由数据决定。抛物线像一只碗，λ 增大只是把碗壁加陡，碗底的倾斜没变，所以最低点被推向 a 更小的一侧，a* = 14/(10+λ) 从 λ = 0 的 1.4 降到 λ = 10 的 0.7。用边际的眼光说：在 a 处，惩罚给出的边际阻力是 2λa，残差给出的边际拉力是 2(Sxy − a·Sxx) = 28 − 20a；最优点就在两者相等处，λ 越大，平衡点越靠左。

截距为什么也跟着变

因为 b* = ȳ − x̄·a*，而这里 x̄ = 2 ≠ 0。斜率每减少 1，截距必须增加 2，直线才能继续穿过 (2, 1.6)。λ 从 0 到 10 时 a 从 1.4 掉到 0.7，b 就从 −1.2 升到 0.2。这个联动依赖 x̄ 是否为 0：若先把 x 中心化使 x̄ = 0，则 b* = ȳ 保持不变，只有斜率收缩。

拟合直线为什么仍经过均值点

把 J 对 b 求导并令其为零，得到 Σi(yi − a·xi − b) = 0，即残差之和为零。对 ŷ = a·x + b 取平均得 mean(ŷ) = a·x̄ + b = ȳ，正是“过均值点”。这个方程里没有 λ，所以它对任意 λ ≥ 0 都成立；退化数据下 a = 0、b = 1.6 的直线也照样过 (2, 1.6)。

x 没有变化时，正则化究竟解决了什么

它解决的是表示不唯一，而这里并不存在拟合不足的问题：λ = 0 时已经达到最小 RSS = 21.2，λ > 0 时 RSS 依旧是 21.2。惩罚的作用是在一整族“拟合同样好”的直线里按斜率大小排序，选出 a = 0 那一条。因此它买到两样东西：系数被唯一确定，以及对观测范围之外给出一个确定的（水平的）预测。它拿不到的是数据里本来就不存在的斜率信息——那需要 x 有变化才可能出现。

9. 复现清单

  1. 写出目标，确认口径：平方总和，惩罚只含 a。
  2. 写出恒等式，用 Σui = 0 说明交叉项消失，得到 b = ȳ − a·x̄ 与“过均值点”。
  3. 算出 Sxx、Sxy、Syy，代回得 J(a) = (Sxx+λ)a² − 2Sxya + Syy。
  4. 配方或求导得 a* = Sxy/(Sxx+λ)、b* = ȳ − x̄·a*，最小值 Syy − Sxy²/(Sxx+λ)。
  5. 用 J″ 与 det H = 4n(Sxx+λ) 说明全局最小，并把唯一性判据写成 Sxx + λ > 0。
  6. 换 x ≡ 2 复算：Sxx = Sxy = 0，λ = 0 时给整族 b = 1.6 − 2a，λ > 0 时给 a = 0、b = 1.6，并说明拟合值未变。
