带惩罚的直线拟合：把最优解从头推出来

五个观测点、一个惩罚项。下面从目标函数一路走到唯一性条件，再用一个可拖 λ 的面板核对同一组公式，最后讨论五个 x 都等于 2 的退化情形。文中的数值都来自这组固定数据；交互区切换数据组后，读数按新数据重算。

1. 目标函数：五个残差被压成两个数

要最小化的量是

J(a,b) = Σᵢ₌₁⁵ [yᵢ − (a·xᵢ + b)]² + λ·a²， λ ≥ 0

三个说明，后面每一步都会用到：

  • 第一项是总和。把五个残差 rᵢ = yᵢ − (a·xᵢ + b) 各自平方再相加，单位是 y 的平方。如果换成平均值口径 (1/5)Σrᵢ²，整条目标差一个常数因子：平均值 + λa² = (1/5)[Σrᵢ² + 5λa²]，等于把惩罚系数放大成 5λ。本页的 λ 一律按总和口径读，这也是这里不除以 n 的原因。
  • 第二项只含 a。截距 b 不进入惩罚，这一条会在第 4 节决定"直线为什么始终经过均值点"。
  • λ 是给定常数，不是被优化的量。J 的自变量只有 (a, b) 两个数。

2. 换坐标：把直线写成"均值点处的取值 + 斜率 × 横坐标偏差"

先算两个均值：x̄ = 10/5 = 2，ȳ = 8/5 = 1.6。再定义偏差 uᵢ = xᵢ − x̄（表第 4 列，合计为 0），以及一个新量 c = a·x̄ + b。

a·xᵢ + b = a·(x̄ + uᵢ) + b = (a·x̄ + b) + a·uᵢ = c + a·uᵢ

c 就是直线在 x = x̄ 处的取值。反过来 b = c − a·x̄。所以 (a,b) 与 (a,c) 是一一对应的换元：给定 (a,c) 唯一决定 (a,b)，反之也唯一。既然只是换写法，"在 (a,b) 上最小化 J"和"在 (a,c) 上最小化 J"有同一批最优点。这就是这次改写可以用的理由。

2.1 逐项展开残差

rᵢ = yᵢ − c − a·uᵢ = (yᵢ − ȳ) − (c − ȳ) − a·uᵢ Σ rᵢ² = Σ(yᵢ−ȳ)² + n·(c−ȳ)² + a²·Σuᵢ² − 2(c−ȳ)·Σ(yᵢ−ȳ) − 2a·Σuᵢ(yᵢ−ȳ) + 2(c−ȳ)·a·Σuᵢ

2.2 交叉项消失的地方，以及留下的那一项

  • 含 (c−ȳ) 的项 −2(c−ȳ)Σ(yᵢ−ȳ)：因为 ȳ 是均值，Σ(yᵢ−ȳ) = 0（表第 5 列合计为 0），这一项整体消失。
  • 含 (c−ȳ)·a 的项 +2(c−ȳ)aΣuᵢ：因为 uᵢ 是相对均值的偏差，Σuᵢ = 0（表第 4 列合计为 0），这一项也消失。
  • 留下的交叉项 −2a·Σuᵢ(yᵢ−ȳ) = −2a·Sxy。它一般不为零：uᵢ 与 (yᵢ−ȳ) 可以同号，本组数据 Sxy = 14 > 0，横坐标偏大的点纵坐标也偏大。

机制一句话：中心化让两组偏差各自求和为零，于是"整体抬高/压低的那个位移 c−ȳ"与"斜率 a"之间没有可搭的乘积项；a 的一次项只剩下来自数据同向程度的那一份，权重正是 x 的偏差与 y 的偏差的同向程度。

2.3 加上惩罚并代入这组数

Sxx = Σuᵢ² = 4+1+0+1+4 = 10 Sxy = Σuᵢ(yᵢ−ȳ) = 5.2+1.6+0+0.4+6.8 = 14 Syy = Σ(yᵢ−ȳ)² = 6.76+2.56+0.16+0.16+11.56 = 21.2 J = Syy + n(c−ȳ)² + (Sxx+λ)a² − 2·Sxy·a = 21.2 + 5(c−1.6)² + (10+λ)a² − 28a

每一项的角色：21.2 是"只用 ȳ 预测全部点"时的误差平方总和；5(c−1.6)² 是把整条线搬离均值高度的代价；最后两项决定斜率。注意 −28a 与 λ 无关，它来自数据本身的倾斜。

3. 配方：下界、取到点、唯一性

把只含 a 的两块合并成一个平方。λ ≥ 0 时 10+λ ≥ 10 > 0，除以它是安全的：

(10+λ)a² − 28a = (10+λ)·(a − 14/(10+λ))² − 196/(10+λ)

核对：右边展开得 (10+λ)a² − 28a + 196/(10+λ)，再减去 196/(10+λ) 就回到左边。代回 J：

J = [21.2 − 196/(10+λ)] + 5·(c−1.6)² + (10+λ)·(a − 14/(10+λ))²

3.1 全局最小值

  • 两个平方项的系数 5 > 0 与 10+λ > 0 都是正的，平方本身非负，因此对任意 (a, c) 都有 J ≥ 21.2 − 196/(10+λ)。
  • 等号当且仅当 c = 1.6 且 a = 14/(10+λ)。这两个条件互不牵制，可以同时满足。
  • 下界被真正取到，所以这个点就是全局最小点。这一步直接给出"最小值"，而不只是"某个点导数为零"。

3.2 什么时候唯一

正系数乘非负平方，只有平方等于零才取到下界。当 Sxx+λ = 10+λ > 0 时，a 只有唯一取值能取到下界；同时 n = 5 > 0 使 c 也只有唯一取值。于是 (a,c) 唯一，换回 (a,b) 也唯一。对本组数据，λ = 0 时 10+0 = 10 > 0，所以 λ ≥ 0 的每一档都有唯一最小解。要让唯一性失效，需要 Sxx+λ = 0，也就是 Sxx = 0 且 λ = 0——第 6 节的数据正是这种情形。

3.3 与求导对照

∂J/∂a = 2(10+λ)a − 28，∂J/∂c = 10(c−1.6) 令两式为零：a = 14/(10+λ)，c = 1.6

结果与配方一致，两种看法分工不同：求导只给出候选点，配方给出"这是最小值、并且唯一点"的理由。J 关于 (a,c) 是二次函数且二次项系数全正，所以候选点就是全局最小点。

λ = 2 的具体数值：a = 14/12 = 7/6 ≈ 1.167，c = 1.6，J 的最小值 = 21.2 − 196/12 = 21.2 − 16.333 = 4.867。

4. 回代 b：截距为什么跟着变

b = c − a·x̄ = 1.6 − 2a λ = 0：a = 1.4， b = −1.2， J = 1.6 λ = 2：a ≈ 1.167， b ≈ −0.733，J ≈ 4.867 λ = 10：a = 0.7， b = 0.2， J = 11.4

变化率（对 λ 求导）：da/dλ = −14/(10+λ)² < 0，db/dλ = 28/(10+λ)² > 0。在 λ = 2 处，λ 每增加 1，斜率约减少 0.097、截距约增加 0.194。这是该点的局部速率，整段并不匀速。

截距为什么会动，来自 b 的最优条件：∂J/∂b = −2Σ(yᵢ − a·xᵢ − b) = 0 给出 Σrᵢ = 0，即平均残差为零，等价于

a·x̄ + b = ȳ，本组数据即 2a + b = 1.6

这条条件里没有 λ，因为惩罚项不含 b。所以每一档 λ 的最优点都必须落在这条约束上：a 被 λ 压低，b 只能在约束上反向补偿。几何上就是直线绕着 (2, 1.6) 转动。λ = 0 时这条同样成立，普通最小二乘的残差和也是零。

6. 退化数据：五个 x 都等于 2

把数据换成 x = (2,2,2,2,2)、y 不变，仍用第 2 节的分解式。此时 x̄ = 2、ȳ = 1.6 不变，偏差 uᵢ 全部为零：

Sxx = 0，Sxy = 0，Syy = 21.2 J = 21.2 + 5(c−1.6)² + λa²，其中 c = 2a + b

6.1 λ = 0：一整族并列最优

J = 21.2 + 5(2a+b−1.6)² 最小值 21.2，条件只有 2a + b = 1.6

对任意 a 取 b = 1.6 − 2a，J 都等于 21.2：a = 0 → b = 1.6；a = 1 → b = −0.4；a = −1 → b = 3.6。三条直线的 J 完全相同，无穷多条直线并列最优。数据能确定的只有 c = 2a + b（也就是 x = 2 这一处的预测值 1.6），a 与 b 单独都不被确定。此时给出一个"唯一 a"的读数，等于隐瞒了一个自由度；面板因此显示"不确定"，并只把示例线当作族中的一条画出来。

6.2 λ > 0：唯一

J = 21.2 + 5(c−1.6)² + λ·a²，λ > 0

λa² 除 a = 0 外严格为正，所以最小化必须先取 a = 0，再由 c = 1.6 定出 b = 1.6。解唯一，J 的最小值仍是 21.2（惩罚项在最优点上为 0）。公式 a = Sxy/(Sxx+λ) = 0/(0+λ) = 0 在 λ > 0 时照样成立；λ = 0 时它变成 0/0，公式失效的位置与唯一性失效的位置是同一处。

6.3 正则化在这里做了什么

x 没有变化时，数据只能定位"在 x = 2 处的预测值"。任何通过 (2,1.6) 的直线，配合相应的截距，都给出同样的残差：把 a 改大造成的整体倾斜，可以在这一列上完全用 b 抵消。也就是说数据无法区分斜率与截距。

λa² 给斜率的绝对值附加代价（因为平方，a > 0 与 a < 0 都要付费），于是在同样好的族里按"a 离 0 最近"挑出一条，选出 a = 0、b = 1.6。它做的是一件事：把并列解变成一条按规则选出的解。关于 y 随 x 怎样变化，它没有增加任何信息，J 的最小值也一点没降。

这个挑法依赖"惩罚只落在 a 上"这一设定。假设同一道题把惩罚换成 λb²（λ > 0），退化数据的解就变成 b = 0、a = 0.8（因为 2a + b = 1.6 且 b² 最小），最小值仍是 21.2。两者都能选出唯一解，选中的点不同；本页的 J 只惩罚 a，所以上面被选出的是 a = 0、b = 1.6。

7. 回到你列出的四个问题

  1. 增大 λ 为什么改变斜率。a 方向上的二次系数从 Sxx = 10 涨到 10+λ，同样大的 a 要付 2(10+λ)a 的边际代价，平衡点 a = 14/(10+λ) 因此向 0 移动；Sxy = 14 > 0 时单调下降，局部速率 −14/(10+λ)²。
  2. 截距为什么跟着变。b 的最优条件恒为 2a + b = 1.6，与 λ 无关。a 下降 0.1，b 必须上升 0.2 才留在这条约束上，直线绕 (2,1.6) 转。
  3. 为什么仍经过均值点。惩罚不含 b，所以 Σrᵢ = 0 在每一档 λ 都成立，等价于 a·x̄ + b = ȳ，即直线在 x̄ = 2 处的取值永远等于 1.6。
  4. x 没有变化时正则化解决什么。解决"并列最优里取哪一条"，也就是解的选取（可识别性与唯一性）。代价是把斜率压向 0；它不改善拟合，也不提供 x 与 y 之间关系的信息。

要自己复现这条推导，顺序是：换坐标 (a,b)→(a,c) → 展开并消掉两个交叉项 → 对 a 配方读出下界与取到点 → 换回 b = c − a·x̄ → 检查 Sxx+λ > 0 判断唯一性。第 3 节与第 6 节用的是同一个分解式，差别只在 Sxx 与 Sxy 是否为零。
