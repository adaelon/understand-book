带惩罚的直线拟合：从目标函数推出最优斜率与截距

这一页用你给的五个点做同一件事：先写出目标函数，把它改写成一眼能看出哪部分管截距、哪部分管斜率的形式，解出 a 与 b 关于 λ 的完整表达式，再用配方说明它为什么是全局最小值、什么时候唯一。最后用同一组数字做交互核对，并把五个 x 都等于 2 的退化数据单独推一遍。文中所有数值都按误差平方的总和计算，不除以 5；公式、图形与交互读数共用同一组常量。

固定示例（第 1–5 节与第 7 节前半共用）：观测点 x=(0,1,2,3,4)，y=(−1,0,2,2,5)，n=5，目标为 Σᵢ₌₁⁵[yᵢ−(a·xᵢ+b)]²+λa²，λ≥0。
由这五个点算出的全部常量：x̄=2，ȳ=1.6，Sxx=10，Sxy=14，Syy=21.2。

1 先把目标写清楚固定示例

xᵢ01234
yᵢ−10225
J(a, b) = Σi=15 [ yi − (a·xi + b) ]² + λ a² ， λ ≥ 0

动笔之前把三件事定下来，后面每一步都要用到它们。

  • 求和不是平均。Σ 里是五项直接相加。如果目标改成平均值（整体除以 5），最优 (a, b) 一点不会变，但报出的 SSE 与 J 都会小 5 倍。本页所有读数都是总和口径。
  • 罚项只含 a。λa² 里没有 b。这一条后面会决定：关于截距的方程完全不受 λ 影响，于是每个 λ 的最优直线都经过均值点。
  • 每个 λ 是一个新的目标函数。λ 变了，被最小化的函数就变了，所以最优斜率是一个函数 a*(λ)，不是一个数。不同 λ 的 J 值不能直接比大小。

先把五个点压缩成五个常量。这一步只是算术，但后面每个公式都只用它们：

x̄ = (0+1+2+3+4)/5 = 2
ȳ = (−1+0+2+2+5)/5 = 1.6
Sxx = Σ(xi−x̄)² = 4+1+0+1+4 = 10
Sxy = Σ(xi−x̄)(yi−ȳ) = 5.2+1.6+0+0.4+6.8 = 14
Syy = Σ(yi−ȳ)² = 6.76+2.56+0.16+0.16+11.56 = 21.2

Sxx 度量 x 围绕自己平均值的分散程度，Sxy 度量 y 与 x 同向变动的强度，Syy 度量 y 本身的总波动。三者都是“总和”口径，量纲里带着 n。

2 把平方和拆成“整体水平”与“围绕均值的形状”固定示例

对任意的 a、b，下面这个恒等式成立：

Σi [ yi − (a xi + b) ]² = 5 ( ȳ − a x̄ − b )² + ( Syy − 2a Sxy + a² Sxx )

推导只有两步。记 r = ȳ − a x̄ − b（它对每个 i 是同一个常数），记 ui = (yi − ȳ) − a(xi − x̄)，则 yi − (a xi + b) = ui + r，展开：

Σ (ui + r)² = Σ ui² + 2r Σ ui + 5 r²

关键就在中间那一项：Σ ui = Σ(yi − ȳ) − a Σ(xi − x̄) = 0 − a·0 = 0。于是 2r Σ ui 整块为零，剩下的 Σ ui² + 5r² 展开就是上面的恒等式。

为什么这个改写成立：x̄ 与 ȳ 恰好是这五个数的算术平均，所以每个中心化量 (xi−x̄)、(yi−ȳ) 加起来都是 0；r 又不随 i 变化，可以提到求和号外，它唯一能乘上的东西就是 Σ ui，而那是 0。也就是说，“整体水平”和“围绕均值的形状”在这个数据集里是正交的两块，改动其中一块不会牵动另一块。用数值验一下（a=0，b=0）：左边 Σyᵢ²=34，右边 5(1.6)²+21.2=12.8+21.2=34。

哪一类交叉项消失，哪一类不消失（这里容易记错）。消失的是 r 与中心化部分之间的 2r Σ ui。不消失的是 Σ ui² 里面的 −2a Sxy：Sxy=14≠0，这一项随 a 变化，正是后面斜率的来源。如果把这二者混作一谈，就会得出“斜率和 y 与 x 的协方差无关”这种错误结论。

3 两个一阶条件：一个管截距，一个管斜率固定示例

先对 b 求偏导。罚项里没有 b，所以导数只有误差项：

∂J/∂b = −2 Σ [ yi − (a xi + b) ] = −2·5 ( ȳ − a x̄ − b )

令它为零，得到

b = ȳ − a x̄ = 1.6 − 2a

这个式子里没有 λ。它的含义不是“某个 λ 下的巧合”：对每一个 λ，最优直线都必须让残差之和为零，也就是必须经过点 (x̄, ȳ) = (2, 1.6)。第 6 节会看到，退化数据在 λ=0 时解不唯一，但每一条最优直线仍然过这个点。

再对 a 求偏导。这次要把罚项算进去：

∂J/∂a = −2 Σ xi [ yi − (a xi + b) ] + 2λ a

用上面的 b 把括号里的残差写成 (yi − ȳ) − a(xi − x̄)。又因为 Σ 残差 = 0，把 xi 换成 xi − x̄ 不改变这个和：

Σ xi·残差i = x̄ Σ残差i + Σ (xi − x̄)·残差i = Σ (xi − x̄)·残差i = Sxy − a Sxx

代入并令 ∂J/∂a = 0：−2(Sxy − a Sxx) + 2λa = 0，即 Sxy = a(Sxx + λ)。解出

a*(λ) = Sxy / (Sxx + λ) = 14 / (10 + λ)
b*(λ) = ȳ − x̄ a*(λ) = 1.6 − 28/(10 + λ)

λ 只出现在斜率那个分母里；截距不含独立信息，它被“经过均值点”这条约束牵着走。代进去算几个值：

λ=0 时 a*=14/10=1.4，正是普通最小二乘解。λ 增大时 a* 单调下降趋向 0，b* 从 −1.2 单调上升趋向 1.6：斜率被压平的同时，直线绕 (2, 1.6) 向水平位置转动，所以截距必须跟着上移。λ 趋于无穷时，最优直线就是水平线 ŷ ≡ 1.6。

4 为什么是全局最小，以及什么时候唯一固定示例

把第 2 节的恒等式右端对 a 配方：先把 (a 的二次项) 收成完全平方，(10+λ)a² − 28a 与常数 21.2 合起来给出

J(a, b) = 5 ( ȳ − x̄ a − b )² + (10 + λ) ( a − a* )² + Jmin
Jmin = Syy − Sxy²/(Sxx + λ) = 21.2 − 196/(10 + λ)

λ=2 时可以逐项核：右边是 5(1.6−2a−b)² + 12(a−7/6)² + 73/15。你也可以把它当作一条恒等式在任何 (a,b) 上验算，比如取 a=0、b=0：左边 J=34，右边 5(1.6)²+12(7/6)²+73/15 = 12.8+16.333+4.867 = 34。

从这个形式一次读出三件事，这正是“不要停在令导数为零”的地方。

  1. 有下界。两个平方项都非负，系数 5>0、10+λ≥10>0，所以对任何 (a, b) 都有 J(a,b) ≥ Jmin。Jmin 是一个显式的下界，推导里不需要先假设最小值存在。
  2. 下界被取到。取 a = a*、b = ȳ − x̄a* = b* 时两项同时为 0，J = Jmin。所以 (a*, b*) 是全局最小值点，最小值就是 Jmin。
  3. 取到的点只有一个。上面两个等号同时成立，当且仅当 a = a* 且 b = b*。唯一性依赖的量写得很清楚：10 + λ > 0。本数据 Sxx=10>0，所以每一个 λ≥0 都唯一；若 Sxx=0 且 λ=0，这个系数就变成 0，唯一性随之失效（第 6 节）。

另一个角度是曲率：∂²J/∂b² = 2n = 10，而把 b 优化掉之后关于 a 的曲率是 2(Sxx+λ) = 2(10+λ)。两者都为正，目标严格凸，驻点就是全局最小点。配方比“凸性 + 驻点”多给了一样东西：最小值本身，以及每项各占多少。

把 (a*, b*) 代回去，最小值可以拆成“拟合误差 + 罚金”两部分：

SSE(λ) = 21.2 − 196(10 + 2λ)/(10 + λ)² ， 罚金 = λ a*(λ)² ， Jmin = SSE + 罚金

6 退化数据：五个 x 都等于 2退化示例

现在 x 换成 (2,2,2,2,2)，y 仍是 (−1,0,2,2,5)。均值和 y 的波动不变：x̄=2，ȳ=1.6，Syy=21.2。但 x 没有任何变化，于是

Sxx = Σ(xi−x̄)² = 0 ， Sxy = Σ(xi−x̄)(yi−ȳ) = 0

第 2 节的恒等式因此只剩两块：

J(a, b) = 5 ( 1.6 − 2a − b )² + λ a² + 21.2

λ = 0：整条直线都是最优解

此时 J = 5(1.6 − 2a − b)² + 21.2 ≥ 21.2，等号成立当且仅当 b = 1.6 − 2a。a 可以是任意实数：最小值的集合是整条直线 {(a, 1.6 − 2a)}，图上就是所有经过 (2, 1.6) 的直线。

所以可以确定的和不能确定的要说清楚：斜率的取值没有确定，b 也不能单独确定，只能说“b 随 a 一起由 b = 1.6 − 2a 决定”。每一条这样的直线给出同样的 SSE = 21.2，而这个 21.2 正好是“所有预测都取 ȳ = 1.6”的误差 Σ(yi − ȳ)²。原因很直接：x 全是 2，任何直线的预测都是 a·2 + b = 1.6，残差全是 yi − 1.6，与 a 无关。

代数上同一件事也能看见：把 Sxx=Sxy=0 代入第 3 节的公式，得 a* = 0/(0 + λ)。λ=0 时是 0/0，公式本身失效——这个 0/0 就是“解不唯一”的症状。

λ > 0：唯一解，但拟合没有变好

J 比上面多了一项 λa² ≥ 0，等号只在 a=0 时成立；再由 b = 1.6 − 2a 得 b=1.6。唯一最优解是水平线 ŷ ≡ 1.6，最小值 J = 21.2，和 λ=0 时的最小值相同。

这一句别读错：λ>0 并没有让拟合变好。SSE 仍是 21.2，最小值仍是 21.2。惩罚做的事是在这一族“拟合一样好”的直线里指定了一条——斜率最小的那条 a=0。它改变的是“给你哪条”，不是“误差多大”。

于是可以回答“正则化在 x 没有变化时解决了什么”：解决的是解的可辨识性。没有惩罚时，目标函数沿 b = 1.6 − 2a 这个方向完全平坦，“令偏导为零”只得到这条约束本身，得不到一个点，任何单一斜率都不是数据选出来的。加上 λa² 等于在原本平坦的方向上加了一点曲率，谷底从一条线收成一个点。要保留一句边界：a=0 是 λ>0 时的选择，不是数据把斜率定成了 0——数据的形状只要求预测值等于 ȳ。

7 四个问题的回答

增大 λ 为什么会改变斜率

一阶条件 Sxy = a(Sxx + λ) 把 a 与 λ 绑在同一个分母里：a* = Sxy/(Sxx+λ)。本例 Sxy=14>0 固定，λ 只增大分母，所以 a* 单调下降。配方里看是同一件事：λ 让 (a − a*)² 前面的系数从 Sxx 增到 Sxx+λ，斜率方向的曲率变大，最优解被压向 0；λ 趋于无穷时 a* 趋于 0。若换一组数据使 Sxy<0，则 a*<0 且随 λ 增大趋向 0，绝对值同样变小。

截距为什么会跟着变化

因为 b* = ȳ − x̄a*，而 x̄=2≠0。a* 每减少 1，b* 就增加 2。λ 从 0 到 2 时，a* 从 1.4 降到 1.167，b* 相应从 −1.2 升到 −0.733。注意这不是惩罚项直接作用在 b 上——罚项里没有 b——而是“必须经过 (2, 1.6)”这条约束在直线被拉平时把截距顶了上去。如果改用中心化变量 t = x − x̄ 作自变量，截距就固定是 ȳ=1.6，不再随 λ 变；此时被惩罚的斜率与原斜率是同一个数，所以 a* 不变。

为什么拟合直线仍然经过均值点

对 b 的偏导是 −2Σ残差，令其为零即 Σ残差 = 0；而 Σ残差 = 5(ȳ − x̄a − b)，所以 b = ȳ − x̄a，等价于 ŷ(x̄) = a x̄ + b = ȳ。罚项 λa² 里没有 b，这个方程与 λ 无关，因此每个 λ 的最优直线都过 (2, 1.6)。配方里也看得见：含 (ȳ − x̄a − b)² 的那一项系数是 5>0，最小值处它必须为 0。

正则化在 x 没有变化时究竟解决了什么

它解决了“最优解不唯一”。λ=0 时整条 b = 1.6 − 2a 都是最小值点，任何单一斜率都不是数据选出来的；λ>0 时唯一解是 a=0、b=1.6。同时要看清它没有做什么：SSE 与最小 J 都仍是 21.2，误差没有下降。它做的是在一族同样好的直线里指定一条，让“最优解”重新成为一个点。

8 复现清单

想自己从零推一遍，照这八步走，每一步都能对上本页的数字。

  1. 写出 J，确认两点：求和不是平均；罚项只含 a。
  2. 算 x̄=2、ȳ=1.6、Sxx=10、Sxy=14、Syy=21.2。
  3. 令 r = ȳ − a x̄ − b、ui = (yi−ȳ) − a(xi−x̄)，说明 Σui=0，得到第 2 节的恒等式；同时分清哪一类交叉项消失、哪一类不消失。
  4. 对 b 求偏导 → Σ残差=0 → b = ȳ − x̄a。
  5. 对 a 求偏导，用 Σxi·残差i = Sxy − a Sxx，得 a* = 14/(10+λ)。
  6. 配方得 J = 5(ȳ − x̄a − b)² + (10+λ)(a − a*)² + Jmin，检查两个系数为正 → 全局最小且唯一。
  7. 用 λ=2 核对：a*=7/6≈1.167，b*=−11/15≈−0.733，SSE=193/90≈2.144，罚金=49/18≈2.722，J=73/15≈4.867。
  8. 换退化数据：Sxx=Sxy=0；λ=0 时解集是整条 b=1.6−2a，λ>0 时唯一 (0, 1.6)，最小值仍是 21.2。
