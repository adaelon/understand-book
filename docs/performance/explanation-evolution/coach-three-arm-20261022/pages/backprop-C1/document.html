计算图 · 反向传播

u 被用了两次，反向传播怎么不漏算

这里只有一个模型，全部是实数：u = x·y，v = u + x，L = v² + 3u。u 只算一次，却有两处用它；x 也有两条路进入 L。下面先分清图上同时出现的三种数，再按依赖顺序算前向，然后从 L 往回走，看两份信息在哪里汇合、汇合之后才继续传回输入。

1 先分清图上的三种数字

节点代表一个量，箭头代表"这个量由那个量算出来"。同一张图上写着三种数，它们的作用完全不同：

  • 节点的前向数值：这个量当前等于多少，例如 u = 6。
  • 边上的局部导数：只对这一条边求导，把其他量都当作不变。例如边 x→u 上，u = x·y 对 x 的局部导数是 y；边 u→v 上，v = u + x 对 u 的局部导数是 1。
  • 节点的整体导数（图上写 dL/d·）：从 L 出发、沿所有路径回到这个量得到的总效果，例如 dL/du = 19。

最容易混的一对数字都落在 u 上。边 u→L 的局部导数是 3，来自 L 里的 3u 这一项；节点 u 的整体导数是 19，是两条来路合起来的结果。图上把局部导数写成 ×3、×1 这样的乘数，表示"把收到的梯度乘上它，再往下交"。

3 前向：三个数怎么算出来

前向只有一个方向，每一步只用手上已经有的数。

第一步，u = x·y = 2 × 3 = 6。这个 6 就是后面两处用到的同一个数。

第二步，v = u + x = 6 + 2 = 8。这里出现两个来源：u 用的是刚算出的 6；x 用的是输入本身 2，没有经过 u。

第三步，L = v² + 3u = 8² + 3 × 6 = 64 + 18 = 82。u 在这里第二次被使用，代入的还是 6。3u 里的系数 3 就是 L 对 u 在这一条边上的局部导数。

前向走完，每个节点有了一个数，每条边也有了一个数。边上的数这样来：只对这一条边求导，其余量当作不变。u = x·y 对 x 求导得 y，所以边 x→u 上是 3；u 对 y 求导得 x，所以边 y→u 上是 2；v = u + x 里 u 与 x 的系数都是 1；L = v² + 3u 对 v 求导得 2v = 16，对 u 求导得 3。

4 反向：三条规则和一个顺序

反向只重复三件事，一直做到输入为止。

  1. 在 L 上放种子。L 对 L 的导数是 1，这是唯一的起点。
  2. 一条边做一次乘法。把上游那个量的整体导数，乘以这条边的局部导数，交给下游的量。
  3. 一个量收齐所有来路再相加。它在图上有几条出边，就会收到几份；相加得到它的整体导数，这个整体导数才有资格继续往回传。

顺序由依赖关系定。u 的值喂给 v，所以 v 的整体导数要先算出来，u 才可能收齐。反向的顺序就是前向的倒序：L → v → u → x、y。

反过来做会缺数：先算 u 的时候，dL/dv 还不存在，边 u→v 就没有东西可乘，u 只能拿到直接边上的 3。

5 在 u 汇合：3 加 16 等于 19

从 L 往下走一步到 v。边 v→L 的局部导数是 2v = 16，上游的种子是 1，所以 dL/dv = 16 × 1 = 16。

再往下到 u。u 有两条出边，因此收到两份：

  • 边 u→L（来自 3u）：局部导数 3，乘上游的 1，得 3。
  • 边 u→v（来自 v = u + x）：局部导数 1，乘上游的 16，得 16。

两份相加：dL/du = 3 + 16 = 19。这两份记的是同一个 u 的两次使用，所以都进账。

为什么相加，用具体运算看：把 u 单独放大一点点 ε，其余都不动。3u 这一项让 L 增加约 3ε；v 跟着增加 ε，L 里 v² 这一项让 L 增加约 2v·ε = 16ε。两件事同时发生，L 总共增加约 19ε。少记任意一项，估出的变化量都会偏小。

这里"把 u 单独放大"是记账用的说法。实际上 u = x·y 跟着 x、y 走，而 dL/du 记的正是"u 变化时 L 跟着变多快"，u 有两处使用，两处都要记进来。19 收齐之后，才轮到 u 把梯度交回去——这一点决定了顺序：u 必须先等 v。

回到 x。x 也有两条出边：

  • 边 x→u：局部导数 ∂u/∂x = y = 3，乘 u 的整体导数 19，得 57。
  • 边 x→v：局部导数 ∂v/∂x = 1，乘 v 的整体导数 16（这条边从 v 出发，用的是 16，不是 19），得 16。

dL/dx = 57 + 16 = 73。

回到 y。y 只有一条出边 y→u，局部导数 ∂u/∂y = x = 2，所以 dL/dy = 19 × 2 = 38。

6 漏掉一份会怎样

假设只保留经 v 的那一份，忘了边 u→L 上的 3。这时 dL/du 被算成 16，缺口继续往回传：dL/dx 变成 16×3 + 16×1 = 64（正确值 73），dL/dy 变成 16×2 = 32（正确值 38）。

少掉的 9 和 6 有明确来路：漏掉的 3 在 u 处亏空，传到 x 要乘 ∂u/∂x = y = 3，于是差 9；传到 y 要乘 ∂u/∂y = x = 2，于是差 6。一个漏项会在每个下游输入上留下按局部导数缩放的误差。

这种错误在图上不容易看出来，因为所有数字都像正常算出来的。它会在核对时暴露：展开式求导给出 73 和 38，与漏算的 64、32 对不上。

8 负数与零怎么读

输入可以取负，局部导数也可以取负，整体导数随之变号。导数为负的意思是：在这一点附近把该输入增大一点，L 会变小，那个负数是变化率。把 x 拖到 -3、y 保持 3，图上仍有同样的六条边和同样的加法，只是每份贡献带上了符号：dL/dv = -24，dL/du = 3 - 24 = -21，dL/dx = -21×3 - 24 = -87，dL/dy = -21×(-3) = 63。

某一份恰好是 0 也有确定含义：那一条边的局部导数是 0，这条路径在这一瞬间不贡献，路径本身仍然在，别的路径照常贡献、照常相加。

点预设“x=0：∂u/∂y 变 0”可以看到：u = 0，∂u/∂y = x = 0，于是 dL/dy = dL/du × 0 = 0。y 变化一点，L 的一阶变化为零。同时 v = u + x = 0，∂L/∂v = 2v = 0，经 v 的那一份对 u 的贡献也归零，dL/du 剩下直接边上的 3；x 的梯度是 3 × 3 = 9，全部来自 x→u 这一条路。

点预设“y=-1：v 变 0”可以看到：v = u + x = x(y + 1) = 0，于是 ∂L/∂v = 2v = 0，经 v 的那一份对 u 的贡献是 0，dL/du = 3。这时如果把直接边上的 3 也漏掉，dL/du 会变成 0，两个输入梯度跟着全部变成 0——这正是"漏算"最安静的失败方式。

9 自检

先自己想，再展开对答案。

漏掉 u→L 上的 3，为什么 dL/dy 会错成 16 × 2 = 32？

y 只通过 u 影响 L，所以 dL/dy = dL/du × ∂u/∂y = dL/du × x。漏掉 3 之后 dL/du 少 3，传到 y 时又乘上 ∂u/∂y = x = 2，于是 dL/dy 少 3 × 2 = 6，从 38 掉到 32。缺口大小取决于漏掉的那一份在 u 处是多少、以及 u 到 y 的局部导数是多少。

为什么一定要先算 v 再算 u，不能反过来？

u 的一份贡献来自边 u→v，它要乘的是 dL/dv。dL/dv 还没算出来时，这一份没有数可乘，u 只能拿到直接边上的 3，dL/du 会是 3 而不是 19。反序并不违反哪条公式，它只是让 u 在收齐之前就被定了值。

两份贡献一正一负（或都为负）时还相加吗？

照样相加。每一份的符号由那条边的局部导数决定，和就是这些一阶效果的总和；和可能落在两份之间，也可能比两份都更负。相加这一步记的是"同一个量有几处使用"，与每份的正负无关。
