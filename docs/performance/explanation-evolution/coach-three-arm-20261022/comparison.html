教练在什么时机介入

本轮的实际顺序是：用户需求 → 作者公开提出框架与重点 → 教练规划并选方法 → B 自主决定是否读取，C 获得选中方法全文 → 作者首次写页面。

所以本轮测试的是初步方案之后、写页面之前的干预。它没有测试“先由教练定方向，再让作者构思”的流程。

教练规划也需要核对

B2 反向传播的教练规划将漏掉贡献概括成“低估输入梯度”“梯度怎样变小”；这条概括没有出现在同次作者公开方案里。允许负数时它并不总成立：x=2、y=-1，正确的 x 梯度是−3，漏掉3u的直接贡献后变成0。

这证明规划本身可能引入不成立的概括，不能把教练当成天然正确的答案。A组也出现同类错误；本观察不证明最终页面错误由教练造成。

本轮是否验证了 CS336 教师反例

含CS336图表反例的 chart-reveal@3 在共同方法目录里，但本批没有被选择、主动读取、完整提供或声明采用。C组实际获得的是过程展开与单因素比较方法。

本轮能够判断这套教练与材料交接策略的首次交付表现；CS336图表反例本身的迁移效果仍未由这批样本验证。

下一步优先改变什么

先明确教练真正先行的时机：教练从用户目标出发提出阅读路径和选型，再由作者构思页面。保留完整供给作为可观察的实验条件，继续用未参与示范的新题判断实际页面，而不以读了多少材料代替效果。
