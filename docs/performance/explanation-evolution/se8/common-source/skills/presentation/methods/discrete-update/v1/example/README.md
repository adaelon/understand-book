# 运行与适配

直接用浏览器打开同目录 `index.html`，无需依赖、构建或网络。用于 Reader 时，将该文件作为 `presentation.author.write.html`，选择 `state` 和 `continuous_scene` 指导；本例不用外部库或资源。先经三环境 preview 观察，再 deliver。

## Author 内容字段

- title：追踪一次离散更新
- assumptions：固定一维二次函数、固定学习率、初值 4、无动量和噪声；变量无量纲；展示前 8 次更新。
- source_ref_ids：空。本例依据下面的显式教学模型推导，没有绑定书源；迁移到真实书籍时重新建立来源。
- initial_state：`{"eta":0.25,"semantic_state":0,"transition_progress":0}`。
- state_contract：eta 为固定学习率 `0..1.2`；semantic_state 为已完成迭代整数 `0..8`；transition_progress 为到下一迭代的视觉插值 `[0,1)`，第 8 步为 0。
- readable_content：从 x₀=4 出发，在 f(x)=(x−2)² 上按 xₖ₊₁=xₖ−2η(xₖ−2) 更新。方框表示当前迭代，空心圆表示下一迭代，橙色实心点沿曲线连接两者，只是视觉插值。当前值、梯度、更新量与下一值属于整数步 k。可前进、回退、播放/暂停、重置和定位；改学习率暂停并回到初值。η=0 静止；0<η<0.5 同侧接近；η=0.5 一步到达；0.5<η<1 交替接近；η=1 等幅往返；1<η≤1.2 在本初值下发散。第 8 步只显示终值。保存小数位置后重开保持参数和精确进度，并暂停。

## 数学依据与预期观察

`f′(x)=2(x−2)`，令 `eₖ=xₖ−2`，则 `eₖ₊₁=(1−2η)eₖ`、`e₀=2`，所以 `xₖ=2+2(1−2η)ᵏ`。独立检查采用此闭式，页面使用逐步递推。

| η | 预期 |
|---|---|
| 0 | 每步 x=4，Δx=0，整个更新箭头隐藏 |
| 0.25 | x₀=4、x₁=3、x₂=2.5；第 2 步过渡 0.35 时插值为 2.4125 |
| 0.5 | x₁=2，此后梯度和更新量均为 0 |
| 0.75 | 4→1→2.5→1.75，交替接近 |
| 1 | 4→0→4，等幅往返 |
| 1.2 | 4→−0.8→5.92，交替远离 |

`presentationScene.seek({semantic_state:7,transition_progress:0.999})` 必须保持 7+.999；`snapshot()` 返回真实播放状态。seek 和恢复都暂停；前后步定位到整数步。Reader 保存由现有宿主负责，本地直接打开用于观察与操作，不写本地存储。

坐标范围由该 η 的完整 8 步及初始可见范围确定，同一参数下前后定位尺度相同。图形线段是状态连接示意；运动点用线性 x 插值在函数曲线上定位，不能解释成算法中间迭代。

## 改为新内容时

保留单一状态、`renderAt(parameters,k,p)`、对象身份、公开 seek/snapshot 与宿主保存恢复的接口；替换 `iterates`、梯度/更新计算、坐标范围、文字和边界说明。每个新增参数同步进入 state_contract、initial_state、reader/restorer。若参数语义或域改变，修改合同定义。先独立推导或取书源核对新关系，再更新 [checks](../checks.md)；不要保留二次函数的收敛条件。
