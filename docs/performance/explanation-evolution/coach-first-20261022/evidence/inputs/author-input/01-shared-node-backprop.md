# 一个中间量被用两次，反向传播怎么不漏算？

我会求多项式的导数，也知道一条复合函数链可以把局部导数相乘，但看计算图时总弄不清：同一个中间量被两个地方使用，反向传播到底应该先算什么，回来的两份信息为什么要相加？请做一份完整可读的演示页，帮助我从具体运算理解这件事。

只使用这个自包含的小模型：输入为 x、y，先算 u=x·y，再算 v=u+x，最后输出 L=v²+3u。u 是同一个计算结果，供 v 和输出里的 3u 共用；x 既进入 u，也直接进入 v。所有量都是实数，无须讨论矩阵、神经网络层或实现性能。

初始输入 x=2、y=3。请让我能沿着实际依赖关系理解前向值如何算出，再看从 L 开始反向求导时每条路径怎样贡献，在哪里汇合、汇合之后才把什么继续传回输入。要分清节点的前向数值、边上的局部导数、最终对 L 的导数，不能只给一张标满符号的图或把全部导数公式直接列出来。

交互允许将 x、y 分别调到 -3 至 3，步长 0.5；也允许逐步查看前向和反向计算。希望修改输入后仍能清楚知道当前显示的是哪组输入和哪一步。负数或某条贡献恰好为零也应有正确含义。完整讲解要让我在不操作时也能读懂默认例子，并能自己回答：如果把其中一条回传贡献漏掉，为什么会得到错误的输入梯度？最后用直接展开 L(x,y) 后求导的方式作一次独立核对。
