# 评估专用：共享节点反向传播

本文件不传入教练或作者，也不参与方法库制作。作者只读 `../author-input/01-shared-node-backprop.md`。本题与前轮 KV 显存、质检误报和候选 token 配对示范不同。

## 独立数学依据

前向：u=xy，v=u+x，L=v²+3u。

设 g_z=∂L/∂z。反向种子 g_L=1。输出对 v 的贡献为 2v，对 u 的直接贡献为 3；因此 g_v=2v。v=u+x 向 u 和 x 各传回 g_v。共享节点 u 必须累计 g_u=2v+3，随后 u=xy 向 x 传回 (2v+3)y，向 y 传回 (2v+3)x。x 也有两条出边，其总梯度为：

- g_x=2v+(2v+3)y。
- g_y=(2v+3)x。

独立展开：L=x²(y+1)²+3xy，所以 g_x=2x(y+1)²+3y，g_y=2x²(y+1)+3x。这个展开式与图上的逐边累计分别计算，二者一致才构成独立核对。

默认 x=2、y=3 时 u=6、v=8、L=82；g_v=16，u 的两个贡献为16和3，总 g_u=19；x 的两个贡献为16和57，总 g_x=73；g_y=38。只沿 u→v→L 分支回传会漏掉3u的贡献；只保留 u 的一条回传或忽略 x→v 直达路径均错误。

| 2 | 3 | 6 | 8 | 82 | 16 | 19 | 73 | 38 |
| -1 | 2 | -2 | -3 | 3 | -6 | -3 | -12 | 3 |
| 2 | -1 | -2 | 0 | -6 | 0 | 3 | -3 | 6 |
| 0 | 2 | 0 | 0 | 0 | 0 | 3 | 6 | 0 |
| 0 | 0 | 0 | 0 | 0 | 0 | 3 | 0 | 0 |
| 1 | -2.5 | -2.5 | -1.5 | -5.25 | -3 | 0 | -3 | 0 |

最后一行特别区分“分支贡献相消”与“没有路径”：u 接收到 -3 和 +3，总导数为0；x 仍有直达 v 的 -3。若页面将0梯度画为该节点完全未参与前向计算，属于解释错误。

## 读页与操作的判断

关键是共享身份与依赖：u 应是一个值被使用两次，而非两个独立输入；x 的直达路径也需要保留。图可重复画局部视图，但必须清楚是同一节点的两次使用。节点值、局部导数和累计梯度不应混用符号或数值。并不要求某一种固定图型、颜色或首屏布局。

完整阅读应解释乘法沿一条路径传递、加法累计来自不同路径的影响，以及为什么要等贡献齐全才向上游传播。允许逐分支计算并把各分支输入贡献最后相加，只要明确等价，不能机械要求某一种拓扑执行顺序。

先读默认状态和全文，再做负数、零路径、相消状态。步进、后退和修改输入后检查当前值、阶段和文本是否来自同一状态；不能将尚未计算的梯度用0冒充已计算结果。不能仅凭动态图“看起来顺滑”判定理解目标已完成。
