一个中间量被用两次，反向传播怎样不漏算

模型固定为：u = x·y，v = u + x，L = v² + 3u。u 同时供给 v 和 3u；x 同时进入 u 和 v。默认输入 x = 2，y = 3。

这个图里，谁用了谁的结果

u = x·y　　v = u + x　　L = v² + 3u

u 只计算一次，却被两个下游取用：v = u + x 取一次，L 里的 3u 再取一次。x 也出现在两处：它进入 u = x·y，又直接进入 v = u + x。

一句话答案：反向传播从 L 出发，按与前面相反的顺序走；走到被多处使用过的量时，先把各条路径回来的贡献加在一起，再用这个总数乘入边的局部导数，继续往上游传。默认输入下最终得到 dL/dx = 73，dL/dy = 38。

图上会出现三种不同的量，先分清

  • 节点里的大字：这个节点的前向数值，例如 u = 6。
  • 边上的小框：这条边的局部导数，例如 ∂u/∂x = y = 3。它只描述这条边两端的两个量之间的关系。
  • 节点下面的蓝字：这个节点对 L 的总导数，例如 dL/du = 19。它把从 L 回到这里的所有路径都算进去了。

反向的顺序由依赖决定：一个节点的总导数要用它下游节点的总导数来算，所以先算靠近 L 的节点。u 的总导数需要用到 dL/dv，因此 v 必须先算完，u 才能把两路信息相加。

    还没走到的步骤不会提前写进这份记录，所以它始终只包含已经算过的量。

    两份信息为什么要相加

    拿 u 做一次小实验。假设 u 从当前值增加一个很小的量 Δ，这件事会同时影响 L 的两处：v = u + x 跟着增加 Δ，于是 v² 增加大约 2v·Δ；同时 3u 这一项增加 3Δ。

    L 的总变化就是这两部分之和，系数加在一起是 2v + 3。所以 L 对 u 的变化率等于 2v + 3：两处效应同时发生，少算任何一项，就漏掉了那部分变化。

    换成路径的说法：从 L 到 u 有两条路。每条路上的局部导数相乘，得到这条路的贡献；同一个节点收到的所有路径贡献相加，才是这个节点的总导数。

    从 L 到 u 的路径沿路相乘贡献

    节点 x 也按同样的规则处理：它从 u 支路收到一份，从 v 直连收到另一份，两份相加才是 dL/dx。

    漏掉一条贡献，会错在哪里

    假设在 x 这个汇合点只把 u 支路的贡献算进去。你会得到一个比正确值小的数，因为 x 还直接进入 v：x 变一点，v 立刻跟着变，这部分完全不经过 u。漏掉的正是这条路径的贡献。

    做法得到的 dL/dx与正确值之差

    判断有没有漏，办法很具体：数一数每个节点有几条出边。u 有两条（通向 v 和 L），x 有两条（通向 u 和 v）。到达这种节点时，必须把各条出边回来的贡献都收齐再相加。只有一条出边的节点（本例的 v）不需要相加。

    负数和零贡献的意思

    局部导数可以是负数。∂u/∂x = y，当 y 为负时它就是负数，u 支路给 x 的贡献也带负号。两份贡献符号相反时会部分抵消，相加的结果可能比每一份的绝对值都小，这正是正确的答案。

    局部导数为 0 时，这条边回传 0。这只说明这条边此刻没有传递影响：节点自己的总导数仍然可能非零，并继续沿别的边往回走。

    两个可以直接点开的对照：

    • 取 y = 0：∂u/∂x = y = 0，u 支路对 x 的贡献变成 0；但 dL/du = 2v + 3 仍然非零，并通过 ∂u/∂y = x 继续传给 y。
    • 取 x = 0：v = 0，于是 ∂L/∂v = 2v = 0，v 支路对 u 的贡献为 0；u 仍然从 3u 那一项收到 3，所以 dL/du = 3，没有变成 0。

    负数可以这样核对（这一句固定用 x = -1、y = 2 说明）：u = -2，v = -3，∂L/∂v = 2v = -6，dL/du = -6 + 3 = -3，dL/dx = -3×2 + (-6) = -12。把 x、y 代入展开式 L = (xy + x)² + 3xy 也得到 -12。

    独立核对：把 L 直接写成 x、y 的函数

    把 u 和 v 代进 L = v² + 3u。因为 v = xy + x，所以 L = (xy + x)² + 3xy。这条式子只含 x 和 y，可以直接求偏导，不经过任何回传规则。
