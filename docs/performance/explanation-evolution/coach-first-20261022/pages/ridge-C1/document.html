带惩罚的直线拟合：把最优解从头推出来

这一页只做一件事：把 J(a,b)=Σ(yᵢ−a·xᵢ−b)²+λa² 的最优 a、b 从头推出来，并说明它为什么是全局最小、什么时候根本不唯一。全程只用你学过的配方与逐参数求导。

本页所有数字都来自同一组五个点；第 5 节的交互只改 λ 与数据集，从不改 y。

第 0 步

先把要算的东西钉住

固定的五个观测点（后面每一步、每张图、每个读数都用它）：

x = (0, 1, 2, 3, 4)，y = (−1, 0, 2, 2, 5)，n = 5
模型：ŷ = a·x + b
目标：J(a,b) = Σi=15 ( yi − a·xi − b )2 + λa2，λ ≥ 0

先把三个记号分开，后面会一直用到：

  • SSE = Σ(yi − ŷi)²：未加惩罚的误差平方总和。它没有除以 n，所以不是平均平方误差；它的单位是 y 的单位平方。
  • P = λa²：惩罚项。它只含斜率，完全不含 b。
  • J = SSE + P：真正被最小化的那个数。

读完这一页，你应该能自己回答四个问题：

  1. λ 增大，为什么最优斜率会变小？
  2. 惩罚只打在 a 上，为什么截距 b 也跟着变？
  3. 为什么不管 λ 取多少，拟合直线都穿过 (x̄, ȳ) = (2, 1.6)？
  4. 当五个 x 全等于 2（x 完全没有变化）时，正则化到底解决了什么，又没解决什么？

第 1 步

把五个残差平方拆成两股

要最小化的是 5 个残差 ri = yi − a·xi − b 的平方和。关键一步是把每个残差改写成“围绕均值”的样子：

ri = ( yi − ȳ ) − a( xi − x̄ ) + ( ȳ − a·x̄ − b )

这是恒等式，不是新假设：把括号展开，−ȳ + a·x̄ + ȳ − a·x̄ = 0，剩下的正好是 yi − a·xi − b。记 d = ȳ − a·x̄ − b（这个量对五个点都相同），平方后求和：

Σ ri2 = Σ[ (yi−ȳ) − a(xi−x̄) ]2 + 2d·Σ[ (yi−ȳ) − a(xi−x̄) ] + 5d2

交叉项为什么消失

中间那一项里的求和是

Σ[ (yi−ȳ) − a(xi−x̄) ] = Σ(yi−ȳ) − a·Σ(xi−x̄) = (Σyi − nȳ) − a(Σxi − n x̄) = 0 − a·0 = 0

原因就是中心化之后各自的求和为零。它和“残差与谁正交”无关：如果换一个不是均值的参照点，这两个求和就不为零，交叉项会留下来，后面“先定 b”这一步也就不成立了。

剩下的第一块再展开，用三个中心化平方和来记：

Sxx = Σ(xi−x̄)2，Sxy = Σ(xi−x̄)(yi−ȳ)，Syy = Σ(yi−ȳ)2
Σ ri2 = 5(ȳ − a·x̄ − b)2 + ( Syy − 2a·Sxy + a2·Sxx )

第一块只数“整条直线相对均值点的整体偏移”，第二块只数“斜率 a 造成的倾斜代价”，两块之间没有交叉。

这组数据的具体数字

x̄ = (0+1+2+3+4)/5 = 2，ȳ = (−1+0+2+2+5)/5 = 8/5 = 1.6。

第 2 步

先处理没有被惩罚的 b

在刚才的分解里，b 只出现在第一块 5(ȳ − a·x̄ − b)² 中。这一块是平方乘正数，恒 ≥ 0，取到 0 当且仅当

b = ȳ − a·x̄   （对固定的 a）

第二块 Syy − 2a·Sxy + a²·Sxx 里没有 b，惩罚项 λa² 里也没有 b。所以对这个 a，使 J 最小的 b 就是上面这一个，而且这个结论与 λ 完全无关。

把它代回去看预测值：

ŷ(x̄) = a·x̄ + b = a·x̄ + (ȳ − a·x̄) = ȳ

也就是说：拟合直线在 x = x̄ 处的取值恒等于 ȳ，既不受 a 影响，也不受 λ 影响。用这组数据讲：直线永远穿过 (2, 1.6)。

这条也就是“截距为什么会跟着变”的答案

因为 b = ȳ − a·x̄ = 1.6 − 2a。a 每减少 1，b 必须增加 2，直线才能继续压在那个均值点上。b 不是被惩罚项直接推着走的（λa² 里根本没有 b），它是被“必须过均值点”这条约束推着走的。第 3 步会看到：λ 增大使 a 变小，于是 b 变大。

第 3 步

只剩 a：剖面目标与配方

把 b = 1.6 − 2a 代回，第一块变成 0，J 就只剩一个变量。把这个“b 已取最优”的目标记作 φ(a)：

φ(a) = J( a, b(a) ) = Syy − 2a·Sxy + a²·Sxx + λa²
= 21.2 − 28a + (10 + λ)a²

配方（就是从 a² 的系数提出来的那一步）：

φ(a) = (10+λ)[ a2 − (28/(10+λ))·a ] + 21.2
= (10+λ)[ a − 14/(10+λ) ]2 + 21.2 − 196/(10+λ)

核对一下系数：括号里 −2a·14/(10+λ) 乘上 (10+λ) 正好是 −28a；常数项 14²/(10+λ) = 196/(10+λ) 被减掉，留在外面。

于是得到闭式解：

a* = 14/(10+λ) = Sxy/(Sxx+λ)
b* = 1.6 − 2a* = 1.6 − 28/(10+λ)
Jmin = 21.2 − 196/(10+λ)

用四个 λ 核对同一组公式

读法：λ 从 0 加到 10，a 从 1.4 降到 0.7，b 从 −1.2 升到 0.2；未加惩罚的 SSE 从 1.6 涨到 6.5（拟合变差了），惩罚项 P 从 0 涨到 4.9，而被最小化的 J 从 1.6 涨到 11.4。λ → ∞ 时 a → 0、b → 1.6，直线退化成水平线 y = ȳ。

注意 SSE 与 P 不是同一件事：SSE 只数竖直残差，P 只数斜率大小，J 才是两者相加后被最小化的那个数。所以“J 变大”不等于“拟合误差变大”——中间还隔着惩罚项。

为什么 λ 增大会让斜率变小

在 φ(a) = (10+λ)(a − a*)² + Jmin 里，a² 的系数是 10+λ。λ 越大，这条抛物线越“陡”，它的最低点就越靠近 a = 0；而 a = 0 恰好是惩罚项 λa² 最偏好的位置。换个说法：λ 加大等于给“偏离 0 的斜率”加价，最优解就向 0 挪。从 a*(λ) = 14/(10+λ) 直接看也一样：分子固定、分母变大，a* 严格递减。

第 4 步

这是全局最小，且在什么条件下唯一

“令导数为零”只给你候选点：它不排除别处还有极小，也不排除那是鞍点。要把全局性真正证出来，把第 1 步的分解和第 3 步的配方接成一行，对 a、b 一起配方：

J(a,b) = 5( 1.6 − 2a − b )2 + (10+λ)( a − 14/(10+λ) )2 + [ 21.2 − 196/(10+λ) ]

前两项都是“平方 × 正系数”：5 > 0，10+λ ≥ 10 > 0，所以它们都 ≥ 0。因此

  • 对任意 (a,b)，都有 J(a,b) ≥ 21.2 − 196/(10+λ)。这条下界与 (a,b) 无关，这就是“全局”两个字的来源。
  • 等号成立当且仅当两个平方同时为 0，即 b = 1.6 − 2a 且 a = 14/(10+λ)。联立得唯一的 (a,b)。
  • 所以下界被摸到，且只被摸到一次：全局最小、且唯一取到。

另一个角度看同一件事：J 是若干平方（外加 λa²）的和，对 (a,b) 是凸函数；这里还是严格凸的，而严格凸函数的驻点就是唯一的全局最小点。

唯一性到底需要什么条件

第二个平方的系数是 Sxx + λ。只有它 > 0，配方才能把 a 单独“卡”在一点上。所以唯一性的条件就是

Sxx + λ > 0

这组数据 Sxx = 10 > 0，所以连 λ = 0 也唯一（那就是普通最小二乘）。如果 Sxx = 0（x 全相同），条件就退化成 λ > 0——这正是第 6 节要用的地方。

用二阶导核对同一件事

你熟悉的另一条路：∂²J/∂a² = 2(Σxi2 + λ) = 2(30+λ)，∂²J/∂b² = 2n = 10，∂²J/∂a∂b = 2Σxi = 20。Hessian 的行列式是 4[5(30+λ) − 100] = 20(10+λ) > 0，两个对角元都为正，故正定、J 严格凸。注意行列式里的 10+λ 就是 Sxx + λ——两条路说的是同一件事，但配方还额外告诉了你最小值等于多少。

第 6 步

换一组数据：五个 x 全等于 2

现在把 x 全部改成 2，y 保持不变：(2,−1), (2,0), (2,2), (2,2), (2,5)。均值没变：x̄ = 2，ȳ = 1.6；Syy = 21.2 也没变。变的是两个中心化交叉核：

Sxx = Σ(2−2)2 = 0， Sxy = Σ(2−2)(yi−ȳ) = 0

这一步改动的实质是：a·xi + b = 2a + b 对每个点都等于同一个数，两个参数被焊成了一个组合

c = 2a + b

模型能对数据说的话只剩下这一个数 c。第 1 步的分解在这里照样成立（此时 ȳ − a·x̄ − b = 1.6 − c）：

J(a,b) = 5(c − 1.6)2 + Syy + λa2 = 21.2 + 5(2a + b − 1.6)2 + λa2

λ = 0：无穷多条同样好的直线

此时 J = 21.2 + 5(c − 1.6)²，最小当且仅当 c = 1.6，也就是 2a + b = 1.6。满足这条等式的 (a,b) 有无穷多组：a 取任意数，b 取 1.6 − 2a 即可。每一条这样的直线都过 (2, 1.6)，在每个点上都预测 1.6，SSE 都是 21.2，J 都是 21.2。

于是答案必须分两半说：数据能确定 c = 1.6（以及由此得到的预测值 1.6），确定不了 a 和 b 各自是多少。问“最优直线是哪一条”，此时没有唯一答案。

这也解释了第 3 步的公式为什么在这里“失效”：a* = Sxy/(Sxx+λ) = 0/0，在 λ = 0 处没有定义。公式没有定义的地方，正好就是不唯一的地方——这不是巧合。

λ > 0：唯一，而且是 a = 0

J = 21.2 + 5(2a + b − 1.6)² + λa²。第一项只关心 2a + b 是否等于 1.6；一旦满足它，J 就退化成 21.2 + λa²，而 λ > 0 时这个量只在 a = 0 取最小，于是 b = 1.6。对应直线 y = 1.6，也就是过 (2, 1.6) 的水平线，J = 21.2。用第 3 步的公式也一致：a* = Sxy/(Sxx+λ) = 0/λ = 0。

那么，正则化在“x 没有变化”时解决了什么

它把“无穷多条同样好的直线”缩小成“一条”，靠的是给斜率定价：在所有 SSE 相同的候选里，挑斜率绝对值最小的那条（a = 0）。这解决的是解不唯一 / 参数不可识别。

它没有做到、也不可能做到的事，要一起说清楚：

  • 没有改善拟合：SSE 从 21.2 到 21.2，一点没降，P 也恒为 0（因为 a = 0）。
  • 没有提供关于斜率的信息：a = 0 是惩罚项选的，不是数据选的。λ 换成任何正数，a 仍然是 0。
  • 没有让预测变可靠：在 x = 2 处的预测仍是 1.6；若拿去别的 x 上预测，那条水平线完全来自“斜率为 0”这个人为选择，数据并没有支持。

所以在交互里把 λ 拖到 0 再看退化数据时，读数会写“不唯一”，图上画的是同一族里的几个例子——因为此时给出一个具体的最优 a 就是在编造信息。

第 7 步

四个问题的答案，与一张自复现清单

1. λ 增大，为什么最优斜率变小？φ(a) 里 a² 的系数是 10+λ，λ 越大抛物线越陡，顶点 a* = 14/(10+λ) 越靠近 0；机理是惩罚项提高了“偏离 0 的斜率”的价格。
2. 惩罚只打 a，为什么 b 也变？b 不自由：直线必须过 (2, 1.6)，所以 b = 1.6 − 2a。a 每降 1，b 必须升 2。b 的移动来自这条约束，不来自惩罚项。
3. 为什么恒过均值点？b 不被惩罚，固定 a 时 J 中只有 5(ȳ − a·x̄ − b)² 含 b；它 ≥ 0 且可被 b = ȳ − a·x̄ 取到 0，与 λ 无关。等价说法：有截距时残差和为零。
4. x 全相同时，正则化解决什么？把 2a + b = 1.6 这一族无穷多解收成 a = 0、b = 1.6 一个解，解决参数不可识别；它不改善 SSE（恒为 21.2），也不提供任何斜率信息。

自己重做一遍的六步

  1. 算 x̄ = 2、ȳ = 1.6，再用 Σxi² − n x̄²、Σxiyi − n x̄ȳ、Σyi² − n ȳ² 交叉核对 Sxx = 10、Sxy = 14、Syy = 21.2。
  2. 写出 Σri² = 5(ȳ − a·x̄ − b)² + Syy − 2a·Sxy + a²·Sxx，并说明交叉项消失是因为 Σ(yi−ȳ) = 0、Σ(xi−x̄) = 0。
  3. 固定 a 求 b*，并验证 ŷ(x̄) = ȳ，说明这一步用到了“b 不被惩罚”。
  4. 代回、配方得 a* = 14/(10+λ)，对 λ = 0、2、4、10 各算一遍 a*、b*、SSE、P、J，与第 3 步的表格对齐。
  5. 写出完整配方，指出两个非负项、下界 Jmin 与唯一的取等点；说出唯一性条件 Sxx + λ > 0。
  6. 换成 x 全为 2，写出 c = 2a + b，说明 λ = 0 时解集是一整族、λ > 0 时唯一为 a = 0、b = 1.6，并解释 SSE 为什么一直是 21.2。

适用范围。数值与结论都针对这一组固定数据（x = 0,1,2,3,4；y = −1,0,2,2,5）和这一个目标函数：误差用平方之和（不除以 n），惩罚只作用于斜率 a 且为二次型，λ ≥ 0。第 6 节的退化数据另起一组固定条件，不与主数据的 λ 变化混成同一次比较。图形呈现的是残差位置、直线转动与剖面曲率，它们帮助你观察，但推导与唯一性的依据在正文的恒等式、配方和非负项里。
