结论：可用于本题的连续深入推导。正文、正常/退化数据的数值及最优解条件一致，未发现核心数学或状态更新错误。两处图形文字问题影响视觉阅读，但不改变推导结论。

## 评审范围与方法

只读取本题作者输入与评估依据，并在 Edge headless 中打开匿名 index.html，阅读实际渲染正文、操作真实控件、观察可见 SVG 图元与截图；未读取生成 HTML/JS 源码、作者请求、条件或其他评审。使用 960×720、320×420、640×240。完整关键状态在 960×720 操作；小视口另外实际操作滑块并阅读公式、控件和图形。正文实读文本见 [visible-text.txt](visible-text.txt)，交互观测见 [observations.json](observations.json)。

## 优点

- 推导从总和口径、只罚斜率开始，先把残差写成中心化部分加常量，明确用 Σuᵢ=0 消掉交叉项，再固定 a 优化 b、展开统计量、求 a。读者能逐步复算，篇幅服务于本题的深入阅读目的。
- 全局性没有停在驻点：配方给出非负项与下界，再把一维结果接回二维；同时给出 Hessian 与 Sxx+λ>0 的唯一性条件。退化分支直接处理 λ=0 的整族解及 λ>0 的唯一水平线。
- 固定示例 A、数值表和当前交互区域有明确边界。正常数据三个 λ 的 a、b、RSS、惩罚和 J 均正确；切回正常数据后全部恢复。
- 退化 λ=0 时直接显示 a“不唯一”、b=1.6−2a，图上三条代表线均经过 (2,1.6)，剖面为水平线。λ=2 时显示唯一 a=0、b=1.6；SSE 与 J 都为21.2。
- 五个观测和五条竖向残差保留；退化时两个 (2,2) 点重合，但可见图元仍各有一条观测与残差，正文也保留五项残差，没有把数据改成四个点。
- 320px 宽度正文和公式换行，页面不产生整体横向溢出；640×240 下数据切换按钮与滑块仍可操作。见 [窄屏中心化推导](mobile-centering.png)、[低高度控件](short-controls.png)。

## 具体缺陷

### H1：退化剖面图说明与纵轴标题轻微重叠

复现：960×720，滑块调到 λ=0，点击“退化数据 x 全为2”，看右侧剖面图左上角。橙色“整条水平线都是最低值：每个 a 都同样好”与蓝色 J(a) 轴标题占用同一位置。见 [退化状态](degenerate-lambda0.png)。

影响：轴标题被遮叠，图的局部阅读显得拥挤；水平目标曲线和“不唯一”读数仍清楚，因此是低影响排版问题。应把状态说明移到图内空白处或图外，不需要改变推导内容。

### H2：320px 宽度图内文字缩得过小

复现：320×420，滚到第6节图形。刻度、均值点、剖面最低点文字随整个 SVG 缩放，实际约7px；正文图注仍为正常阅读字号。见 [窄屏图形](mobile-plot.png)。

影响：图的走势可看，但手机尺寸下难直接读刻度与点标签，需要依赖图下读数。可让小屏图内文字保持可读字号或允许图形独立横向查看，正文公式无须折叠。
