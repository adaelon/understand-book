# 岭回归三页盲评：定性选择

以本题“能连续深读，并自己复现从目标到全局最优与退化条件的推导”为目的，**现有页面首选 Harbor**。它的核心推导、关键数值、正常及退化图形彼此一致，发现的问题局限在图内文字排版。Quartz 的正文也适合深入学习，但退化多解的图画错；Lumen 的交互有独特价值，正文却含核心残差符号错误，当前不适合让读者独立照着复现。

如果必须按本题当前成品状态给出次序：**Harbor → Quartz → Lumen**。这不是总分或方法优劣判断，也不代表其他用途下相同排序。

## 评审依据

三页都在匿名状态下用真实浏览器打开，完整阅读渲染正文，执行正常数据λ=0、2、10，退化数据λ=0、2，切回正常数据；查看960×720、320×420、640×240，并在小视口操作滑块。Lumen 还操作了页面自带的退化代表斜率−2、1、2与重置。只读题目作者输入、评估依据与匿名页面的实际可见表现，没有读生成源码、作者自述、请求条件、别名映射、历史报告或他人评审。

全文长不是扣分理由。三页均保留了中心化、交叉项消失、系数推导、全局性与唯一性、退化分析的连续正文；本次差别来自这些论证是否成立，以及图形是否在讲同一件事。

## Harbor：当前最稳妥的完整推导页

它先用一个恒等式把b隔离，再解释中心化零和如何消掉交叉项，继而求a、配方证明全局性并回到二维。它还明确说明一维目标是“对每个a都取最优b”的剖面，避免把固定b和消去b混淆。退化λ=0时给整族b=1.6−2a，λ>0时用两个非负项选出a=0、b=1.6；图中的代表线确实都过均值点。

其视觉风格较朴素，但段落、公式框、数值表和交互边界清楚。发现的两处问题是退化剖面说明与J(a)轴标题重叠，以及320px图内文字约7px偏小，均未破坏数学结论。适合现在就按本题目标连续阅读与复算。

## Quartz：正文与比较图设计有优势，须先修正退化代表线

它用φ(a)区分剖面目标，用完整二维配方直接串起“下界对任意点成立—可以取到—只有唯一点取到”。逐点统计量表、λ=0参照曲线、SSE与惩罚的分段条形都能支持复算和比较。交互数值、唯一性说明和五个残差都正确；手机宽表能单独横向阅读。

决定性的缺陷在退化λ=0：图注称三条虚线同样最优，但两条非水平线在x=2时分别约为y=0和4.2，均未经过(2,1.6)。它们的SSE分别是34和55，而不是21.2；正确残差却画向1.6。这不是颜色或标签风格问题，而是把非最优线画成最优族，与本题核心概念直接矛盾。小屏图内文字约5px也偏小。

适合参考其正文证明和误差/惩罚比较方式。修复两条代表线的截距后，才适合完整使用退化图；目前不能直接作为三页中的首选。

## Lumen：可操作的代表解最有特色，推导文字需要修正

Lumen 允许在退化λ=0下改变示例a，直线始终通过均值点，同时SSE和J保持21.2、a读数始终“不唯一”。这段交互确实做到了让使用者直接检查“参数不同、观测位置的预测相同”。a*(λ)、b*(λ)曲线也分别展示收缩与截距联动；所有规定数值状态正确，快捷λ与重置可用。

但正文从δ=ȳ−a x̄−b出发，却把残差写成中心化残差减δ，应当加δ；第7节复现步骤又重复了错误。虽然后面的平方和因零和交叉项消失仍得到正确公式，读者却无法按第一条恒等式展开复现。其余需要分开修正的内容包括：把“只平均误差”与“整个目标除以5”混为一谈；退化λ=0直接援引含0/0的配方恒等式；把10a误称为向1.4的数据净拉力。主图手机标签约5.5px，系数曲线标签相对更清楚。

适合参考其退化代表解交互与系数随λ变化的呈现。若目的是由正文建立推导能力，它比Quartz需要更多数学文字修订，因此当前排在最后。

## 三页共同已证实的事实与限制

三页的正常λ=0/2/10数值都符合a=14/(10+λ)、b=1.6−2a；SSE、λa²和J都分开显示且数值正确。退化λ=0均明确不唯一，λ>0均给唯一a=0、b=1.6；五观测没有被合并删减，残差均为同一x下的纵向差。三种视口未发现整页横向溢出；正文公式可读，图内文字普遍需要针对小屏改善。

评审依据是实际页面和可复现操作，没有真实学习者实验，因此不宣称学习效率或学习增益提升。页面全部保持原样；报告里的修法是范围内建议，未实施。
