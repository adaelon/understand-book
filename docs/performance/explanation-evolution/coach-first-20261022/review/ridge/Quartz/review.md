# Quartz 独立评审

结论：连续推导和交互数值完整，正文组织与误差/惩罚分解清楚；但退化 λ=0 的两条代表线画错，正好落在本题最重要的“哪些直线同样最优”概念上，修正前不宜作为三页中的首选。

## 评审范围与方法

只读取本题作者输入与评估依据，并在 Edge headless 中打开匿名 index.html，完整阅读实际渲染正文、操作真实控件、观察可见 SVG 图元与截图；未读取生成 HTML/JS 源码、作者请求、条件或其他评审。视口为960×720、320×420、640×240；桌面执行完整状态序列，小视口另做滑块操作、公式与表格阅读。原始观察见 [observations.json](observations.json)，正文见 [visible-text.txt](visible-text.txt)。

## 优点

- 残差恒等式、交叉项展开、中心化和为零、统计量逐行计算、固定a先优化b、剖面配方、二维全局下界和唯一取等点连成完整论证。主要证明只需配方即可理解，Hessian 作为额外核对，没有让它承担唯一证明。
- 使用 φ(a) 明确区分消去b后的剖面与原始J(a,b)。既写出全局下界，又说明两个平方同时为零才取到，唯一性条件 Sxx+λ>0 明确。
- λ=0参照曲线与当前曲线、SSE/惩罚的分段条形、均值点预测读数相互补充。条形的满格标准随数据集变化并有文字说明，没有把系数与平方误差混作可加量。
- 正常 λ=0/2/10 与退化 λ=0/2 的所有数值、唯一性文字均正确，切回正常后同步恢复。退化时正文明说只确定2a+b、a与b不分别确定，正则化不改善SSE也没有创造斜率信息。
- 五观测及五条竖向残差保留（退化两个(2,2)重合）；正常图的直线、均值点与残差方向正确。
- 小屏正文和长公式可换行；两个宽数据表可单独横向滚动读全，没有造成整页横向溢出。见 [中心化公式](mobile-centering.png)、[表格左侧](mobile-table.png)、[表格右侧](mobile-table-right.png)。640×240控件仍可操作，见 [低高度控件](short-controls.png)。

## 具体缺陷

### Q1：退化 λ=0 时，两条“同样最优”代表线没有经过均值点

复现：960×720，滑块调到0，数据集选择“退化：五个x全为2，y同上”。观察图A的三条虚线和橙色均值点。水平线通过(2,1.6)，但负斜率线在x=2时约为y=0，正斜率线在x=2时约为y=4.2；两者都没有通过橙色圈。

证据：[退化代表线错误](degenerate-family-error.png)，[对应状态读数与图元](observations.json)。页面图注写明斜率−0.8、0、1.3，并宣称每条都过(2,1.6)、同样好；实际可见端点显示两条非水平线均在x=0时通过约y=1.6。五条残差却仍被画到y=1.6，与这两条线的预测也不一致。

数学影响：最优族必须为 b=1.6−2a，三个斜率对应的截距应分别为3.2、1.6、−1。实际两条非水平线对应的可见预测约为0和4.2，其SSE分别为34与55，均大于最小值21.2，不能称为最优代表。它会让读者误以为任意斜率都可配同一个截距，直接破坏“均值点/可识别组合/多解”的图解。正文、读数和水平剖面本身正确，错误局限在退化 λ=0 的两条代表直线。应按每条代表斜率分别取 b=1.6−2a 画线。

### Q2：320px宽度的图内文字约5px，难以阅读

复现：320×420，滚到第5节两张图。均值点、直线式、顶点a*、最小值与参照图例随整个SVG缩放，实际约4.8–5.2px。见 [窄屏剖面图](mobile-plot.png)。

影响：趋势仍可辨，但不能方便地直接读图内信息；图外段落与读数可补充，因此是次要可读性问题。小屏应保留图内文字可读尺寸，或提供图形独立横向查看。
