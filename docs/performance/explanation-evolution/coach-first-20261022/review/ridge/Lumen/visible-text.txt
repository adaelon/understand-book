全篇共用 · 五个固定点、一个目标函数

带惩罚的直线拟合：从 J(a,b) 推到 a*(λ)、b*(λ)

五个固定点、一个目标函数。下面从残差分解开始，一步步推到最优斜率与截距；再把 λ 和退化数据放回同一套公式里核对，图形与读数只用来检验推导，不用来代替推导。

主示例 · x 有变化

1. 固定的数据与要最小化的 J

全页只用一组数据：x=(0,1,2,3,4)，y=(−1,0,2,2,5)，共五个点。模型是 ŷ=a·x+b，其中 a 是斜率、b 是截距。要最小化的是

J(a,b) = Σᵢ₌₁⁵ [yᵢ − (a·xᵢ + b)]² + λa², λ ≥ 0

第一项把五个残差平方逐个相加，每个残差按 1 计入一次，没有除以观测数。第二项只含 a。若改成“误差平方的平均值”，整个目标会被除以 5，λ 的相对强度随之改变；本页全部读数都按总和口径，λ 的取值 0–10 也在这个口径下理解。

前面还会反复用到两个平均值：x̄ = 10/5 = 2，ȳ = 8/5 = 1.6。把每个点相对这两个平均值的偏差列出来，后面所需的三个量就一次性到手：

i	xᵢ	yᵢ	xᵢ−x̄	yᵢ−ȳ	(xᵢ−x̄)²	(xᵢ−x̄)(yᵢ−ȳ)
1	0	−1	−2	−2.6	4	5.2
2	1	0	−1	−1.6	1	1.6
3	2	2	0	0.4	0	0
4	3	2	1	0.4	1	0.4
5	4	5	2	3.4	4	6.8
合计	10	8	0	0	10	14

窄屏下这张表可以左右滑动，查看全部七列。

最后一行给出三个后面一直要用的量：

Sxx = Σ(xᵢ−x̄)² = 10
Sxy = Σ(xᵢ−x̄)(yᵢ−ȳ) = 14
Syy = Σ(yᵢ−ȳ)² = 21.2

这三个 S 都是总和，不除以 n，与 J 第一项同口径。λ 的起点 2 只是交互的初始位置；本节到第 4 节的推导对任意 λ ≥ 0 成立。

主示例 · 第 2–4 节都用这一组数

2. 先解 b：把残差拆成“中心化部分 + 常数偏移”

每个残差可以写成同一个中心的偏差加上一个对全部 i 都相同的偏移。做法是给每个残差同时加上再减去 ȳ 与 a·x̄：

yᵢ − a·xᵢ − b = [ (yᵢ − ȳ) − a(xᵢ − x̄) ] − δ, δ = ȳ − a·x̄ − b

δ 与 i 无关，它只取决于 (a, b) 这一对系数。把两边平方再对 i 求和，逐项展开：

Σ rᵢ² = Σ[(yᵢ−ȳ) − a(xᵢ−x̄)]² − 2δ·Σ[(yᵢ−ȳ) − a(xᵢ−x̄)] + 5δ²

中间那一整项为零，依据是两个中心化偏差的合计都是零：Σ(yᵢ−ȳ) = (−2.6)+(−1.6)+0.4+0.4+3.4 = 0，Σ(xᵢ−x̄) = (−2)+(−1)+0+1+2 = 0。于是 Σ[(yᵢ−ȳ) − a(xᵢ−x̄)] = 0 − a·0 = 0，交叉项 −2δ·0 消失。它消失的原因是这两个和为零，与 a、b 取什么值无关。

第一个平方和再展开一次。把 (yᵢ−ȳ) 与 a(xᵢ−x̄) 各自平方、再减两倍乘积：Σ(yᵢ−ȳ)² = Syy，乘积项给出 Σ(xᵢ−x̄)(yᵢ−ȳ) = Sxy，而单独的 Σ(xᵢ−x̄)·ȳ 与 x̄·Σ(yᵢ−ȳ) 都含一个零和，所以只剩

Σ[(yᵢ−ȳ) − a(xᵢ−x̄)]² = Syy − 2a·Sxy + a²·Sxx

把两段合起来，J 被改写成一个等价的形式：

J(a,b) = (Syy − 2a·Sxy + a²·Sxx) + 5(ȳ − a·x̄ − b)² + λa²

括号外的第二项 5(ȳ − a·x̄ − b)² 对任何 a 都 ≥ 0，并且只在 b = ȳ − a·x̄ 时取零。所以给定 a，使 J 最小的 b 唯一，而且可以写下来：

b*(a) = ȳ − a·x̄ = 1.6 − 2a

求导给出同一条结论：∂J/∂b = −2Σ(yᵢ − a·xᵢ − b) = −2·5·δ，令它为零正好是 δ = 0。两种说法都在讲同一件事——最优点上残差之和为零。

这条结论有一个可以直接读出来的几何含义。把 b*(a) 代回模型：ŷ = a·x + (ȳ − a·x̄)。在 x = x̄ 处，ŷ = a·x̄ + ȳ − a·x̄ = ȳ，所以最优直线总要经过均值点 (2, 1.6)。惩罚项 λa² 里没有 b，因此这个关系与 λ 无关：λ 从 0 加到 10，直线始终穿过 (2, 1.6)。

3. 代入 b：J 变成关于 a 的一元二次函数

把 b*(a) 代回，δ = 0，那个平方项整段消失，只剩 a 的二次式。代入 Sxx=10、Sxy=14、Syy=21.2：

J(a, b*(a)) = Syy − 2a·Sxy + (Sxx + λ)a² = 21.2 − 28a + (10 + λ)a²

把 (10+λ) 提出来配方：

J = (10+λ)·(a − 14/(10+λ))² + 21.2 − 196/(10+λ)

顶点位置就是最优斜率，再代回 b*(a) 得截距：

a*(λ) = Sxy/(Sxx+λ) = 14/(10+λ) = 1.4 · 10/(10+λ)
b*(λ) = ȳ − x̄·a* = 1.6 − 2·a*

λ 为什么改变斜率，可以从 ∂J/∂a = −2·Sxy + 2(Sxx+λ)a = 0 这个平衡读出来：

Sxx·a + λ·a = Sxy, 即 10a + λa = 14

左边第一项是数据把 a 往 1.4 推的强度，它正比于 Sxy；第二项是惩罚把 a 往 0 拉的强度，它正比于 λ。λ 增大后，同样大小的 a 会带来更大的回拉，平衡点就向左移。把它解出来也能看到同一件事：a* = 1.4·10/(10+λ)，收缩因子 10/(10+λ) 随 λ 增大而减小，λ→∞ 时 a*→0。

截距跟着变，依据是直线被钉在均值点上。b* = 1.6 − 2a*：a* 减小时 2a* 减小，b* 就增大。λ 取 0、2、10 时，a* 分别是 1.4、7/6≈1.167、0.7，b* 相应是 −1.2、−11/15≈−0.733、0.2。斜率越平，为了仍然经过 (2, 1.6)，截距就得越高。

4. 为什么是全局最小，以及什么时候唯一

上面那一步配方可以对任意 (a, b) 写成恒等式。这是本页的主证据，因为它不依赖“先求导、再比较”的顺序：

J(a,b) − J_min(λ) = (Sxx+λ)(a − a*)² + 5(ȳ − a·x̄ − b)²
其中 J_min(λ) = Syy − Sxy²/(Sxx+λ) = 21.2 − 196/(10+λ)

用法是逐项比较。右边两项都是平方乘以正系数：(Sxx+λ) = 10+λ ≥ 10，另一项系数是 5。所以对平面上的每一点都有 J(a,b) ≥ J_min(λ)，并且等号成立必须两个平方同时为零。三件事一次得到：

全局：下界对每个 (a, b) 成立，不是某点附近的局部结论。
取到：把 (a*, b*) 代入左边，两个平方都是 0+0，所以 J − J_min = 0，下界确实被某对系数取到。
唯一：系数为正，两个平方同时为零只可能发生在 a = a* 且 b = ȳ − a·x̄，所以最小点只有一个。

唯一性依赖的条件在这里很清楚：只要 Sxx+λ > 0，第一项就只在 a = a* 时为零。本例 Sxx=10、λ ≥ 0，条件恒成立，因此每一条最优直线都是唯一的。下一节会把 Sxx 换成 0，这条判据立刻变成分界线。

数值核对（λ=2）：a* = 7/6 ≈ 1.1667，b* = −11/15 ≈ −0.7333；SSE = 21.2 − 28·(7/6) + 10·(49/36) = 193/90 ≈ 2.1444；惩罚项 λa² = 2·(49/36) = 49/18 ≈ 2.7222；两者相加 J = 73/15 ≈ 4.8667。用闭合公式另一条路算：J_min = 21.2 − 196/12 = 21.2 − 16.3333 = 4.8667。两条路给出同一个数，下面交互的读数就是按这两条路分别计算、再对照显示的。

退化数据 · x 全部等于 2

6. 五个 x 都是 2：预测唯一，直线不唯一

把 x 换成 (2,2,2,2,2)，y 仍是 (−1,0,2,2,5)。平均值不变：x̄=2、ȳ=1.6；但两个中心化量变成 0：Sxx = Σ(2−2)² = 0，Sxy = Σ(2−2)(yᵢ−ȳ) = 0，而 Syy 仍是 21.2。

因为所有 x 相同，模型在每个观测横坐标上都给出同一个数，把它记作 c：

c = 2a + b = ŷ（所有点共同的预测值）

把 Sxx = 0、Sxy = 0 代入第 4 节的那个恒等式，J 自动变成

J(a,b) = 21.2 + 5(1.6 − 2a − b)² + λa², J_min = Syy = 21.2

λ = 0 时，λa² 整段消失，只剩 J = 21.2 + 5(1.6 − 2a − b)²。要取最小值只需要 2a + b = 1.6，此时 J = 21.2；a 可以是任意实数，对应 b = 1.6 − 2a。每一条这样的直线在唯一的横坐标 x = 2 上给出的预测都是 ŷ = 1.6，残差、SSE、J 全都一样。能够确定的是预测值与目标值 21.2，a 与 b 都不被数据确定：同样好的直线有无穷多条。这正是第 4 节判据的边界：Sxx+λ = 0+0 = 0，第一项整段消失，唯一性随之丢失。

λ > 0 时，λa² 回来把 a 单独定住。两个系数 λ 与 5 都为正，两个平方要同时为零才取到最小值，于是 a = 0，再由 2a + b = 1.6 得 b = 1.6。系数唯一：直线变成水平线 ŷ = 1.6。

λ > 0 时的最小值仍是 J = 21.2，与 λ = 0 时相同。罚项没有压低目标值——λ = 0 时的最好预测已经取到；它改变的是参数的唯一性：λ = 0 时无穷多组 (a, b) 给出同一个预测，λ > 0 时只剩一组。x 没有变化时，数据对 a 不提供任何约束，惩罚补上的是一条选取规则（把 a 定为 0），截距随之落回 ȳ。

在交互里切换到这个数据集、把 λ 拖到 0，读数只会给出确定的那几项：c = 2a+b = 1.6、SSE = 21.2、J = 21.2；a 显示为“不唯一”，b 显示为 b = 1.6 − 2a。此时“示例 a”滑块才可用，它画出一条具体的解，用来验证换成别的 a 之后预测值、SSE 与 J 都不变。

回顾 · 主示例与退化数据

7. 读完应该能自己讲清的四点
增大 λ 为什么改变斜率。正规方程是 10a + λa = 14，把数据项 Sxy 分摊到更大的分母上；等价地看，惩罚对 a 的拉力 λa 随 λ 增大，平衡点 a* = 14/(10+λ) 向 0 移动，收缩因子 10/(10+λ) 随 λ 减小。
截距为什么也跟着变。b* = 1.6 − 2a*。直线必须经过均值点，斜率变小时截距必须变大，才能继续经过 (2, 1.6)：λ 从 0 到 10，a* 从 1.4 降到 0.7，b* 从 −1.2 升到 0.2。
为什么仍经过均值点。∂J/∂b = 0 给出 Σrᵢ = 0，等价于 ȳ = a·x̄ + b，于是在 x = x̄ 处 ŷ = ȳ。惩罚项只含 a，这条关系对每个 λ ≥ 0 都成立。
x 没有变化时正则化解决了什么。预测值 c = 2a+b 已经唯一且取到最好（SSE = 21.2）；不确定的是参数：λ = 0 时任何满足 2a+b = 1.6 的直线都同样好，λ > 0 时由 λa² 选出 a = 0、b = 1.6。它解决的是参数的可识别性。

自己复现时可以按这五步走：① 算 x̄、ȳ、Sxx、Sxy、Syy（都是总和）；② 把残差写成 [(yᵢ−ȳ) − a(xᵢ−x̄)] − δ，用两个零和消掉交叉项；③ 由 5δ² ≥ 0 得 b*(a) = ȳ − a·x̄；④ 代入得 Syy − 2aSxy + (Sxx+λ)a²，配方读出 a*、b*；⑤ 用同一配方写成 J − J_min 的两个平方，确认全局最小与唯一性条件 Sxx+λ > 0。

本页全部段落使用同一组 x、y 与同一个 J：第 1–5 节是主示例（x 有变化），第 6 节是退化数据（五个 x 都等于 2），第 7 节同时回顾两者。所有读数按误差平方的总和口径，惩罚只进入斜率 a；图形与读数由同一段计算生成。
