# Lumen 独立评审

结论：辅助交互完整，尤其是退化λ=0时可直接改变代表斜率并保持预测、SSE和J不变；但本题首先要求读者自己复现完整推导，正文的中心化残差符号错误破坏了这条主线，另有口径解释和退化边界论证缺口。修正前不推荐作为独立深入推导教材。

## 评审范围与方法

只读取本题作者输入与评估依据，并在 Edge headless 中打开匿名 index.html，完整阅读实际渲染正文，操作真实控件，观察可见SVG图元与截图；未读生成HTML/JS源码、作者请求、条件、别名映射或其他评审。视口为960×720、320×420、640×240。桌面执行正常λ0/2/10、退化λ0/2、切回正常；额外操作页面提供的代表斜率−2、1、2与重置。小视口实际操作滑块，检查正文、公式、表格和图形。观察记录见 [observations.json](observations.json)，全文见 [visible-text.txt](visible-text.txt)。

## 具体缺陷

### L1：中心化残差恒等式的δ符号错误，复现步骤再次重复

位置：第2节首个公式框定义δ=ȳ−a·x̄−b，却写 yᵢ−a·xᵢ−b = [(yᵢ−ȳ)−a(xᵢ−x̄)]−δ。按照这个δ定义，右侧必须是中心化残差加δ。紧接着平方展开也沿用了−2δ的交叉项，第7节“自己复现”第二步再一次写成减δ。见 [第2节符号错误](centering-sign-error.png)，原文可在 [visible-text.txt](visible-text.txt) 搜索“− δ”。

复现与反例：按页面自己的数据，取a=b=0、第一点y₁=−1。原残差是−1，中心化部分为−2.6，δ=1.6；页面右侧得到−4.2，不等于−1。正确的加δ得到−1。

影响：读者按“加上再减去均值”的解释展开时会发现等式不成立，无法逐项复现推导。后面的平方和和最优解最终仍正确，是因为交叉项正负两种写法在中心化求和后都归零；这不使前面的点对点恒等式正确。应统一采用“+δ”及“+2δ”并同步复现步骤，或反向定义δ后同步其余公式。属于核心推导错误。

### L2：把“仅误差改平均”与“整个目标除以5”混为一谈

位置：第1节目标函数下面写：“若改成‘误差平方的平均值’，整个目标会被除以5，λ的相对强度随之改变。”见 [桌面初屏](desktop-initial.png)。

影响：整个目标除以5得到SSE/5+(λ/5)a²，最优系数与相对惩罚强度都不变；仅把SSE改平均、仍保持λa²，才是相对惩罚增强5倍。页面把两种操作连在同一句里，和本题强调的总和口径相冲突。例如λ=2时，整体除5仍得a=7/6；SSE/5+2a²则得a=0.7。交互实际按总和算对了，问题是解释会教错换算关系。应明确区分这两种操作。

### L3：退化λ=0时，直接套用了含除零的配方恒等式

位置：第6节写“把Sxx=0、Sxy=0代入第4节的那个恒等式”，并在λ=0段落说“Sxx+λ=0…第一项整段消失”。第4节的恒等式已经含a*=Sxy/(Sxx+λ)和J_min=Syy−Sxy²/(Sxx+λ)，该式只在Sxx+λ>0时有定义。见 [退化推导段落](degenerate-derivation.png)。

影响：在λ=0、Sxx=0处，不能把0/0当作可消掉的值，再说0乘平方所以消失。这正是本题要求解释的不唯一边界。第6节最终写出的J=21.2+5(1.6−2a−b)²+λa²和整族解结论是正确的，但目前给出的取得该式的理由不成立。应回到第2节未除以Sxx+λ的展开式，再独立分析λ=0；无需增加任何新理论。

### L4：平衡方程后的“数据拉力”解释指错了项

位置：第3节写10a+λa=14后，将“左边第一项”10a称为“数据把a往1.4推的强度”，并说它正比于Sxy。见 [平衡解释](force-explanation.png)。

影响：10a本身不是把a拉向1.4的净数据作用，也不正比于Sxy；数据一侧的净作用应为Sxy−Sxx·a=14−10a（忽略共同因子2），它才和惩罚λa平衡。最直接的检验是在无惩罚最优a=1.4处，净数据作用为0，而10a=14。公式与最终收缩因子正确，但这段机理解释会让读者误认各项的作用，应改成(14−10a)=λa后解释。

### L5：320px宽度主散点图的文字约5.5px

复现：320×420，滚到第5节主图。主图整体缩小，刻度、均值点和图例实际约5.5px；下方a*(λ)、b*(λ)小图约10px，相对更清楚。见 [窄屏图形](mobile-plot.png)。

影响：主图趋势能辨，但图内标签和小残差难直接读；图注和数字区可补充，是次要可读性问题。可保持小屏主图文字尺寸或提供图形独立横向查看，不必折叠正文公式。
