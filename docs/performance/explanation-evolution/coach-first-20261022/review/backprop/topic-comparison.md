# 反向传播题：三份匿名页面的定性比较

如果只保留一份用于桌面上的完整概念讲解，我选择 **Sable**。它不仅说明 u 的两份贡献相加，还解释 x 收到的 57 已经合并了两条更长路径，并明确区分“y 的一条直接下游边”与“y 到 L 的两条完整路径”。这正面回答了本题共享节点与逐边累计最容易混淆的地方。它不是无缺陷成品：核对区会残留默认贡献，320 像素宽时图中文字过小，需要修正。

三份页面的**六组完整前向值与梯度全部正确**，都保留 x 的直达分支，都在 (1,-2.5) 显示 u 收到 -3 与 +3 后 g_u=0，同时 g_x=-3、g_y=0。没有一份把这个零画成“u 没参与前向计算”。三份都能在不操作时读到完整默认例，独立求导也与图中结果相符。选择差异主要来自讲解中的概念精度、输入同步的文字，以及不同屏幕上的可读性。

## Sable：整体概念讲解首选

它把共享身份、直接依赖、累计后的局部传递和完整路径展开连接得最好。反向时箭头真正翻转，路径贡献分色，独立求导还追踪到 x 的三条完整路径。漏项卡片同时展示 u 的错误怎样传给 x、y，改变输入后数字都正确。[完整报告](Sable/review.md)；[相消状态](Sable/960-cancellation.png)。

需要先修正“图中累计的结果”卡片里的固定说明：输入变成 (1,-2.5) 后，结果是 -3 与 0，说明却仍称由 19×3 和 16×1 等贡献得到。这是当前输入的数值来源说明错误，而不是结果计算错误。[截图](Sable/960-stale-check-caption.png)。320×420 下整图约 256×148 像素，长局部导数标签几乎不可读，虽然下方文字列表仍能完成阅读。[小屏截图](Sable/320-graph.png)。此外有一处上/下游文案、翻转步骤序号和三条式子写成四条的轻微编辑问题。

相消时图和算式足够诚实，但没有单独命名“零来自两份非零贡献相消”；若用于完全自学，可加一句这层对照。它已经具备正确材料，不能将缺少专门提示说成错误计算。

## Aster：细粒度步进和小屏阅读首选

Aster 的 0–11 步把局部导数、传回一份贡献、u 汇合与 x 汇合拆得细；未计算量用问号，后退与改输入后的图、解释、记录同步。微小扰动段落用同一个 u 变化同时影响 v² 和 3u，解释相加的理由直接。320 与 640 宽采用逐边列表，文字可读，按钮可用，没有横向溢出。[完整报告](Aster/review.md)；[小屏列表](Aster/320-graph.png)。

它的主要问题是文字规则比计算器粗糙：声称 y 为负则 u 给 x 的贡献也负，但 (2,-2) 时正确计算是 (-1)×(-2)=+2；声称漏掉一份得到更小值，也不适用于负贡献。负数平方显示成 -3² 而不是 (-3)²，导致所写等式不成立；“y 只有一条路径”又把一条直接边与两条完整路径混为一谈。[负号说明](Aster/960-negative-prose.png)；[负数平方](Aster/960-negative-square.png)。这些问题落在本题的核心概念上，不能只凭最终数字全对而忽略。漏项演示主要围绕 x 的两份贡献，对 u 少收一份如何传到两个输入的具体演示弱于另两页。

## Rowan：漏项比较练习最直接

Rowan 的“漏掉哪一份”按钮最适合主动做错误对照：默认漏掉 3 得到 g_x=64、g_y=32；漏掉经 v 的 16 得到 25、6；相消输入的对应错误结果也正确。它逐项展开多项式，正文完整，三项自检均能展开。[完整报告](Rowan/review.md)；[漏项操作记录](Rowan/omission-observations.json)。

但“正确”模式下的一句总结反而把 u 的累计总数用于 x→v 直达边；照这句话做，默认会用 19 代替 16，相消例会错误地把 x 的直达 -3 也抹成 0。正文前面本来强调过这条边必须用 16，因此是页面内部冲突。[截图](Rowan/960-incorrect-propagation-caption.png)。它还把零贡献概括成局部导数为零，把贡献符号仅归给局部导数，并把负变化率说成绝对值；这些说法无法解释页面已经算对的负数与相消状态。320 宽时图缩得偏小，但比 Sable 更易辨认，且下方有文字明细。[小屏图](Rowan/320-graph.png)。

## 判断范围

评审只用给定题目、独立数学依据及三份匿名页面的实际浏览器表现；没有读页面实现、生成条件、别名映射或其他评审。先完整读文再操作六组输入，操作全部步骤、后退、中途改输入、所有预设与额外控件；三视口均实际打开并截图。前两页先完成，Sable 就绪后再审，未把等待状态评为差。

没有要求某种固定首屏、图型或唯一执行顺序。Sable 的淡色完整计算预览和 Rowan 预先保留前向值属于呈现方式；它们的未知梯度没有被 0 冒充，因此不按数值失败处理。报告区分计算正确、解释错误和可读性问题，不给总分，也不从本次观察推断真实学习者的学习增益。

证据目录均可独立阅读：[Aster](Aster/review.md)、[Rowan](Rowan/review.md)、[Sable](Sable/review.md)，各目录有结构化 review.json、数值/步骤/预设/视口观察与关键截图。
