# Rowan — 独立浏览器评审

Rowan 的默认例讲解和“故意漏掉一份”实验很完整，所有受检数值正确。核心缺陷位于正确模式总结句：它把 u 的总导数误用于 x→v 直达边；零与符号的概括也过于简单，不能解释相消。

## 优点与实际交互

- 先区分局部导数 3 与 u 的整体导数 19，再沿前向、反向、漏项、独立展开连成完整论述，不操作也能读懂默认例。
- 正文明确强调 x→v 使用 16 而非 19，并说明 u 要等 v 的贡献。
- 漏项按钮真正改变 u 的假设梯度，并把误差乘局部导数传到 x、y。默认漏 3 得 (g_u,g_x,g_y)=(16,64,32)，漏经 v 得 (3,25,6)；相消例两模式也都正确。见[漏项操作记录](omission-observations.json)。
- 多项式完全展开到各项，独立导数逐项列算，六组输入都同步。
- 1–8 步的反向梯度用破折号表示尚未计算；全部前向值保留在图中作为参考，当前边按步骤突出。后退、改输入与预设操作正常，没发现旧数值混入当前计算。
- 相消时图仍保留节点和全部依赖，显示 g_u=0、g_x=-3、g_y=0。自检折叠项可打开，答案已经读完。
- 三视口没有横向页面溢出。320 宽正文仍可读；640×240 需要正常纵向滚动查看完整图。

## 具体缺陷

### R1 正确模式文案把 u 的累计梯度用到了 x→v 直达边

选择漏掉哪一份／两份都算（正确）下方说明。默认输入阅读该卡片；再输入 (1,-2.5) 并选择“两份都算（正确）”。

实际：“这个总数再分别乘 x→u、x→v、y→u 的局部导数传回输入”。相消时“这个总数”为 0，卡片却正确显示 g_x=-3。

正确含义：g_u 只乘 x→u 和 y→u；x→v 直达边使用 g_v。默认应为 19×3 + 16×1，相消时为 0×(-2.5) + (-3)×1。

影响：与前文正确解释正面冲突；照此句操作会丢掉/算错本题要求保留的 x 直达分支。

证据：[960-incorrect-propagation-caption.png](960-incorrect-propagation-caption.png)、[omission-observations.json](omission-observations.json)。

### R2 将零贡献和符号只归因于本边局部导数，漏掉上游累计的作用

第 8 节与第 9 节第三个自检答案。输入 (1,-2.5) 阅读第 8 节；输入 (-1,2) 并展开“两份贡献一正一负…”。

实际：第 8 节说某份为 0 意味着“那一条边的局部导数是 0”；自检说“每一份的符号由那条边的局部导数决定”。相消输入所有六个局部导数均非零，仍有 u→输入回传为 0；(-1,2) 时 u→v 局部导数 1 对应回传 -6。

正确含义：回传贡献是下游累计梯度乘局部导数，零可来自累计梯度相消；符号也由两因子共同决定。

影响：相消时数字、图与路径保留均正确，但概念总结无法解释这些正确结果。当前输入提示仅提示负号，没有补充相消原因。

证据：[960-cancellation.png](960-cancellation.png)、[numeric-observations.json](numeric-observations.json)、[default-visible-text.txt](default-visible-text.txt)、[已展开自检答案](self-check-visible-text.txt)。

### R3 动态提示把有符号变化率说成绝对值

当前输入下的提示。输入 (-1,2) 或 (2,-1)。

实际：“L 会变小，变化率就是那个负数的绝对值”。

正确含义：变化率是负数本身；绝对值可称为下降速率的大小。

影响：对导数符号的定义不准确，与前一句正确的下降方向相混。

证据：[numeric-observations.json](numeric-observations.json)。

### R4 320 像素宽时图中文字缩得过小

工作台计算图。使用 320×420 视口，滚到图。

实际：整张 SVG 缩至约 242×249 像素，节点梯度及 × 标签明显小于周围正文。

正确含义：保留可读图中文字，或提供明确的移动端图替代。

影响：图的路径乘数难以读清。下方完整文字清单仍可读，所以不是内容缺失或操作阻断。

证据：[320-graph.png](320-graph.png)、[responsive-observations.json](responsive-observations.json)。

## 适用目的与限制

适合拿同一组输入反复比较“漏哪一份、误差怎样继续乘回输入”。主计算与漏项模拟未发现数值错误；图上反向阶段仍沿用前向箭头方向，依赖关系可追踪，但读者需要结合“回传”的文字理解，方向呈现不如实际翻转的图直观。此项视作表达取舍而非数值故障。本次没有真实学习者测试，不推断学习增益。
