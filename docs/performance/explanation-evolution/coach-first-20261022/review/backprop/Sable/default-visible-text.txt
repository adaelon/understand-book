同一个 u 被用两次，两份回传贡献在哪里相加

模型只有四条式子：u = x·y，v = u + x，L = v² + 3u。u 供两处使用（v 和 L 的 3u 项），x 也供两处使用（u 和 v），y 只供一处。下面用同一组节点，先把前向值算出来，再沿边回传：节点数值、边上的局部导数、累计到节点的 dL/d 分开放，最后看漏掉一份会错成什么样，并用展开求导核对。

3前向：三个数按依赖顺序算出来

用默认输入 x = 2、y = 3 走一遍。

u = x·y = 2 × 3 = 6　（x 和 y 都进了这个乘法）
v = u + x = 6 + 2 = 8　（这里用的 u 就是上一步的 6，同一个数）
L = v² + 3u = 8² + 3 × 6 = 64 + 18 = 82　（3u 又取了同一个 u = 6）

顺序由依赖关系决定：一个节点要等它用到的量都算好才能算，所以先 u、再 v、最后 L。反向传播沿这个顺序倒着走。

4反向：先算谁由下游决定

下面把靠近输入的一端叫上游，靠近输出的一端叫下游。L 在最下游，x、y 在最上游。反向传播分三步做。

第一，从 L 出发，取 dL/dL = 1 作为种子：L 对自身的变化率是 1。

第二，沿一条边从下游往上游回传时，用下游已有的 dL/d(下游) 乘上这条边的局部导数 ∂(下游)/∂(上游)，得到送给上游节点的贡献。

第三，上游节点把它每条下游边送来的贡献相加，得到自己的 dL/d(上游)。

顺序也由依赖关系决定：v 唯一的消费者是 L，所以 dL/dv 必须先算出来，u 才能凑齐经 v 回来的那一份。于是顺序是 L → v → u → x、y。把 u 提到 v 前面，u 就只收到 3u 项那一份。

v：只收到一份

边 v→L 的局部导数是 ∂L/∂v = 2v = 2 × 8 = 16。v 只有一条下游边，所以 dL/dv = 1 × 16 = 16，v 到此完成。

u：两份贡献，在这里相加

u 有两条下游边：u→v（局部导数 ∂v/∂u = 1）和 u→L（局部导数 ∂L/∂u = 3，来自 3u 这一项）。

经 v 回来：dL/dv × ∂v/∂u = 16 × 1 = 16
3u 项直接给：dL/dL × ∂L/∂u = 1 × 3 = 3
dL/du = 16 + 3 = 19

两份都要算，因为 u 是一个数：它在 v 里和在 3u 里取的是同一个 6。让 x 变动一点，u 就动一点，v 和 3u 会同时跟着动，L 的总变化是这两处变化之和。只算一处，等于假设 L 只有一种方式受 u 影响。

x：两份贡献，也在这里相加

x 有两条下游边：x→u（局部导数 ∂u/∂x = y = 3）和 x→v（局部导数 ∂v/∂x = 1）。

经 u 回来：dL/du × ∂u/∂x = 19 × 3 = 57
经 v 直接回来：dL/dv × ∂v/∂x = 16 × 1 = 16
dL/dx = 57 + 16 = 73

57 这一份里其实合进了两条更长的路径：x 经 u 到 v 再到 L，以及 x 经 u 直接到 3u 项。两条都在 u 那里加过了，所以在 x 这里只以 57 这个数出现。

y：只收到一份

y 只有一条下游边 y→u（局部导数 ∂u/∂y = x = 2），于是 dL/dy = dL/du × 2 = 19 × 2 = 38。y 到 L 其实有两条路径（经 v、经 3u 项），但它们都在 u 合过并了，到 y 这里只剩一个数。

5相加的理由，和一个可数的检查

把上面的做法写成一个式子：对任意一个量 n，

dL/dn = Σ（n 的每条下游边）［ dL/d(该边的终点) × ∂(终点)/∂n ］

求和号覆盖 n 的所有下游边，一条不漏。每一项对应一种「改变 n 就能改变 L」的方式：n 动一点点，每一处用到 n 的地方都会跟着动，L 的变化是这些地方的变化之和，所以对 n 求导要把每一项都算进来。

这个式子还给了一个可数的检查办法：一个节点收到几份贡献，等于它有几条下游边。u 有 2 条，x 有 2 条，y 有 1 条，L 有 0 条（它是起点，只有种子 1）。数一遍边，就知道那个位置该不该出现第二个加号。

6漏掉一份会怎样

下面用当前显示的 x = 2、y = 3 计算。把 u 的两份贡献故意少算一份，看错误怎样传到输入。

正确：两份都算

dL/du = 19　两份相加

dL/dx = 73

dL/dy = 38

漏掉 L→u 的 3

dL/du：19 → 16　只剩经 v 的一份

dL/dx：73 → 64　差 9 = 3 × y

dL/dy：38 → 32　差 6 = 3 × x

漏掉 v→u 的 16

dL/du：19 → 3　只剩 3u 项的一份

dL/dx：73 → 25　差 48 = 16 × y

dL/dy：38 → 6　差 32 = 16 × x

两张漏算卡片的差值有统一规律：漏掉的那一份会乘上从 u 到该输入的局部导数，再传到这个输入。所以误差的大小随 x、y 变化，不是一个固定偏差。

反向传播每一步只沿边把信息送一次。u 收齐之后才继续往 x、y 传；漏掉的那一份不会在后面被自动补回来，也没有第二次机会。

某一份贡献恰好为 0 时，路径仍然存在：它在当前输入下被局部导数乘成了 0。这时漏掉它和保留它数值相同，但那是因为它本来就等于 0。点上面「v = 0」那个预设就能看到这种情形。

7用展开求导做一次独立核对

把 u 和 v 代进 L，只留 x 和 y：

L = (x·y + x)² + 3xy = x²y² + 2x²y + x² + 3xy
对 x 求偏导时把 y 当常数：∂L/∂x = 2xy² + 4xy + 2x + 3y
对 y 求偏导时把 x 当常数：∂L/∂y = 2x²y + 2x² + 3x

代入当前显示的 x = 2、y = 3，先算展开式，再和图中的累计结果对照。

图中累计的结果

dL/dx = 73

dL/dy = 38

由 19×3 与 16×1 等贡献相加得到

展开式求导的结果

∂L/∂x = 2xy² + 4xy + 2x + 3y
= 36 + 24 + 4 + 9 = 73

∂L/∂y = 2x²y + 2x² + 3x
= 24 + 8 + 6 = 38

两者之差

dL/dx：73 − 73 = 0

dL/dy：38 − 38 = 0

两边一致。

每项都能追到一条路径：从 x 到 L 有三条，x→u→v→L 给出 2xy² 与 2xy，x→v→L 给出 2xy 与 2x，x→u→L（3u 项）给出 3y；三项相加正是 2xy² + 4xy + 2x + 3y。展开式一次算完整个和，计算图只是把同一个和按边组织起来，两边必须相等。
