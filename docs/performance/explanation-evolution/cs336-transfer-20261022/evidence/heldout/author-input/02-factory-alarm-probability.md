# 报警的零件，大多真的有缺陷吗？

我在学习工厂质检数据分析，懂百分比和基本乘除，但总是分不清“缺陷件会报警的比例”和“报警件中有缺陷的比例”。请制作一份完整、连贯的入门讲解，并配一个可交互可视化，让我能把这两句话对应到正确的人群与数量，知道一个看起来灵敏的检测器为什么仍可能带来大量误报。

考虑一批10000件零件，每件只有“有缺陷”和“无缺陷”两种真实状态，检测器对每件只给出“报警”或“不报警”。只需要三个主要可调参数：缺陷率p（0%至10%）、检出率d（0%至100%，意思是有缺陷的零件中会报警的比例）、误报率f（0%至10%，意思是无缺陷的零件中会报警的比例）。初始值为p＝1%、d＝95%、f＝5%。检测器的d和f不因这批零件的缺陷率变化而变化。

这里讨论长期平均比例与理论期望数量，不模拟某一批的随机波动，因此期望数量可以出现小数。请清楚说明分母分别是什么，并解释从10000件出发，如何得到正确报警、漏检、误报和正确放行的数量，以及一次报警究竟提供了多大把握。所有输入都按上述定义理解，不引入复检成本、多个检测器或现实设备选型。

我特别想知道：为什么保持检出率不变，仅换一批缺陷更少的零件，报警结果的可信程度就可能下降；降低误报率和提高检出率各自在改变什么；“误报率5%”是否就意味着“报警里只有5%是误报”。请用给定初始值走完一遍解释，再让我通过交互核对其他情况。如果某组参数下根本没有报警，也请说明此时该怎样理解“报警件中的缺陷比例”。不操作控件时，我也应当能读懂主要概念和结论。
