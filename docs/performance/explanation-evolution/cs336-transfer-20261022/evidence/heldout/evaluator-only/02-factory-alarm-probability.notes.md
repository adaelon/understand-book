# 评估专用：报警的零件，大多真的有缺陷吗？

本文件不进入作者输入。对应输入为 `../author-input/02-factory-alarm-probability.md`。输入共656个字符，其中526个汉字（计入标题与换行）；三个主要操作变量为p、d、f。

## 检验假设

该题观察作者能否明确呈现条件概率各自的分母，并把三个输入比例转化为同一批零件中的可比较数量，再得出报警可信程度。关键迁移是识别“有缺陷时报警”与“已报警时有缺陷”的方向差异，以及基数变化对结果的影响；不要求使用特定树图、矩阵或人群图。

## 内容真值与单位

设N＝10000，p、d、f在公式中均使用0至1的小数。p＝缺陷件／全部零件；d＝正确报警／缺陷件；f＝误报／无缺陷件。四类期望数量为：

`正确报警 TP = N × p × d`。

`漏检 FN = N × p × (1 − d)`。

`误报 FP = N × (1 − p) × f`。

`正确放行 TN = N × (1 − p) × (1 − f)`。

四类之和恒等于N；前两项之和是缺陷件总数，后两项之和是无缺陷件总数。总报警数A＝TP＋FP。只在A＞0时，报警件中的缺陷比例为：

`P(缺陷 | 报警) = TP / A = p × d / [p × d + (1 − p) × f]`。

报警件中的误报比例为FP/A，且在有报警时等于1−TP/A；它的分母与f不同。比例、百分比和“件”不能混用。期望数量允许小数；显示为整数时不能把四舍五入后的数量再当作精确分母计算结果。

固定p与f，提高d把部分漏检转为正确报警，不改变误报数量。固定p与d，降低f把部分误报转为正确放行，不改变正确报警数量。固定d＞0、f＞0时，降低p会降低报警件中的缺陷比例。题中初始d和1−f恰好都是95%，所以总体正确比例也为95%，但这仍不等于报警件中的缺陷比例。

## 独立数值核验依据

表中的百分比均先以精确分数代入，四类数量使用理论期望，没有模拟采样。PPV仅为下表简写，指“报警件中的缺陷比例”，并非要求面向初学者使用这个术语。

在默认值下，一百件缺陷件中95件报警，九千九百件无缺陷件中495件报警。所以报警共590件，其中真缺陷95件、误报495件；报警中的误报比例为495/590≈83.898305%。无缺陷件数量是缺陷件数量的99倍，足以让5%的误报形成比95%的正确报警更多的件数。

在默认检测器d＝95%、f＝5%下，报警中的缺陷比例恰好达到一半时，p＝f/(d＋f)＝5%。这一结果可作为关系交互的独立核验点，无须要求作者在首页主动推导。

## 首次阅读应能回答的问题

读者在初始状态应能说出：95%的分母是100件缺陷件，5%的分母是9900件无缺陷件，报警可信程度的分母是590件报警件。由此应能算出正确报警95件、误报495件，以及报警件约16.1%真的有缺陷；“误报率5%”不代表报警中只有5%是误报。

读者应能解释为什么d、f都保持不变时，缺陷更少的一批零件会让报警更不可信。还应能分清提高d是在减少漏检，降低f是在减少无缺陷件的误报警；不应从本题推出任意情况下二者收益大小固定不变。交互可以帮助检验这些变化方向，并应使没有报警时的条件比例得到明确解释。

## 可能造成误解的视觉表达

把d和f各画成大小相同的人群中的百分比，却直接比较这两个视觉面积来推断报警组成，会抹掉100与9900的基数差异。若四类数量使用不同的尺度却被并排呈现成可比较的面积或高度，也可能使95个正确报警显得大于495个误报。

把“报警件中的缺陷比例”标为检出率、把“报警件中的误报比例”标为f，或将一个只有比例的图直接标成零件数量，都混淆了分母或单位。总报警数量改变时，若图形保持相同总面积却不说明它代表的是报警内部组成，读者可能误认为报警总量不变。

只给出95%、5%和16.1%三个孤立数字，缺少人群和数量的连接，会让结论无法被初学者复述。没有报警时用0%或100%冒充TP/A，会产生不存在的条件比例。允许期望数量为小数，不应把9.9件解释为现实中切分一个零件，也不必为了画整数图标而更改题设。

## 范围与限制

本题只有一个检测器、一次检测以及明确给定的三种比例；不包含复检、设备选择和真实工厂统计估计。p＝0时d仍可作为检测器给定参数存在，但当前批次没有缺陷件，不能从该批次数据估计d。无需引入平滑、先验或随机模拟来处理零分母，直接说明没有报警、该条件比例无定义即可。
