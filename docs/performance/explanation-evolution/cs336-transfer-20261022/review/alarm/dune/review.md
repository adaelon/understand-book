# dune 匿名教学页独立评审

只依据blind/alarm/dune中的可见正文/控件记录、截图，以及index.html真实allow-scripts iframe的运行结果。实际以960×720、320×720阅读并操作公开滑块和按钮。未读HTML源码、项目代码、其他评审、runs或分组映射；未修改页面。

核心算术与无报警主读数正确。这页先给默认答案，再解释两个分母、从10000件逐步拆出四格，接着讲基率和两个性能参数，最后提供交互核对。用户不操作也能完成整条讲解。主要需要修正的是一个基率推论的范围，以及“减半”按钮实际执行固定情景的语义。

**有效的讲解**

开头将“95件缺陷报警/590件全部报警”直接算成16.1%，并以约每6.2次报警中1次真缺陷解释。随后明确另一条95%使用100件缺陷作为分母，没有把误报率的分子混进来。

四步算账从10000×1%开始，每一步只处理一类分组，并解释这一行的百分数除的是谁。正确报警、漏检、误报、正确放行的名称和颜色贯穿正文、四格与条带。默认全部数量可直接复核，特别适合只会百分比乘除的读者。

p从1%减至0.5%的静态例子给出47.5件正确报警和497.5件误报，在交互之前就让读者看到期望数量可以不是整数。95变47.5而495只变497.5的对照，具体说明了基率下降如何改变报警构成。正文也正确给出提高d至99%/100%与降低f至1%/0.1%的数值结果。

无报警章节和动态读数都明确分母为0，不能写成0%或100%；p0/f5则说明500件报警全是误报，0%有定义。手机下这段动态解释也完整显示。

**需要修正的地方**

1. **不能单凭无缺陷件至少多9倍，推出本参数范围里误报占多数。** 原文：“本场景p最多10%，两堆至少相差9倍，所以报警里误报占多数是常态。”相同段落还说“两者要接近，需要两堆零件数量相当，也就是p接近50%”。对初始d95/f5，p接近50%时两个百分数接近这一特例本身可以成立；问题是后面把人群规模差距直接用作报警多数的理由，省掉了d/f相对大小。公开范围内保持d95/f5，仅将p调至10%，正确报警950件、误报450件，可信度67.9%，误报只占32.1%。保持这台检测器，p=5%时两种报警已经各475件，超过5%后正确报警更多。这里没有批次分布依据来定义“常态”，不能从p范围推出它。

   建议限定为“初始p1%的这一批里误报占多数”，并说明多数由(1−p)f与pd的比较决定；无需增加额外模型。原文与可复现状态分别见960-majority-claim.png、960-p10-result.png。

2. **“缺陷率减半”没有对当前缺陷率减半，而是固定切到0.5%。** 从p10/d95/f5点击该按钮，实际变为p0.5/d95/f5，重复点击仍为0.5%。名称是相对当前值的动作，界面没有注明“默认1%的半值情景”。第一次操作若真为减半，应得到p5，而不是p0.5。当前实现可以保留，只需把按钮写为“默认情景：p降到0.5%”并交代其他参数；也可改成只对当前p执行减半。证据：960-halving-before.png、960-halving-after.png，及behavior-cases.json的halve-from-ten/halve-again。

   同组按钮也会恢复其他基准参数，例如先把f降到1%，再点“检出率提到99%”，f回到5%。这可作为固定基准情景使用，但应在控件附近说明整组替换。静态章节虽说“用同一个初始情形单独动一个参数”，它离实际控件有距离，且控件没有标出完整参数组。

**阅读路径与视觉效果**

960宽度下，文本从定义、分组、计算到反直觉结果连续展开；四格合计、全批条、报警条和可信度读数位于同一区域，稳定后的绿色/红色比例正确。“把报警这一列单独拉出来”的标题能帮助读者从四格找到图示来源。交互放在全文末尾，是完成理论阅读后的核对，不影响不操作时的完整性。

320宽度下，段落与控件能够顺序阅读；公式会自动折行，没有发现文字横向裁掉。四格所有列都在视窗内，默认95.0、495.0、9405.0、9900.0等主要数字完整；10000.0会被拆成“10000.”与“0”两行，属于数字辨认上的小摩擦。图例文字仍清楚，两个条带与结果卡也能在纵向阅读中对应。证据：320-calculation.png、320-ratio-formula.png、320-four-cells.png、320-result.png、320-no-alert.png。整体宽度与滚动宽度均为320，没有整页横向溢出。

交互额外展示“误报÷正确报警”的倍数。它有助于看出两个来源的数量比，但比主要的95/100与95/590多引入了一个分式；入门者需要先明白主要概率，再把这行当作补充解释。页面中的主要结果无需靠这条附加分式才能读懂。

已核对正常范围关键数量、两种无报警、有报警但全误报，以及按钮语义。图条一致性基于稳定后的可见结果，不推断内部数据来源。没有为有限显示精度另扩展案例，也没有把整数显示格式或动画中间状态列为算术错误。
