### 采用决定

**chart-reveal@3 保留为经过验证的本地候选，正式 `catalog.json` 维持 revision 5，不登记采用、不发布。** 候选本身可运行、反例与改法成立，但“独立作者实际读取、适配并改善首次生成”的证据链没有打通。

下一次改动应集中在现有制作步骤：作者先明确读者要理解的关系和阅读目的，按需要选择相关方法；选定后实际读取卡片、示范与适配说明，再制作页面并记录确切版本。确实无合适方法时仍可自行设计。验证应先确认真实读取发生，再用新题比较交付效果，不能只检查目录是否注入或 `method_refs` 是否非空。

这个选择与读取调整**未在本批实施**，避免改变冻结条件。当前两道题已用于评审和诊断，后续用作回归材料；若围绕这些发现调提示，再做迁移实验须另留未参与调试的新题。

## 已知限制

- 每题每组只有两次，不能估计稳定胜率或真实学习收益；同一返回模型名称也不等于供应商后端不可变版本。
- 本批测初次请求中的自然首次交付，包含模型正常预览和自修订；不是禁止自查的第一次 HTML 写入，也没有启用 active Tutor 审核循环。
- 原页历史回合不完整，截图版本与缺失的产品反馈、历史修复不能补造；本轮完整调用证据可用于判断具体方法是否读取。
- KV B1 的 960px 首次自动截图为空且无就绪回执；独立重开正常，其他视口正常。保留原截图，对照页明确展示重开截图；没有把这个单次异常判作已确认的作品缺陷。

## 方法没有被读取时，代码能说明什么

只读调查见 [方法选用路径](evidence/method-selection-path.md)。冻结实现明确允许 Choose zero or more methods；方法目录随 Author 首次可见注入，早于 prepare，并非工具不可见。prepare 不选择方法；制作主线提示 local prepare 后进入 write/patch。新建 write 省略 method_refs 会得到空引用，因此直接自行设计是合法路径。

只有作者声明了一个新的方法引用，服务端才要求该确切版本至少有一段非空读取已进入后续采样；它不强制完整读取卡片、作品及适配说明。目录被看见、方法正文被读到、作者声明采用，是三种不同事实。

这些代码事实支持把后续改进集中在制作步骤中的按需方法选择，而不是继续只往库里增加材料。它们不能证明某次模型的内部原因是忽略目录、上下文太长或判断不匹配；这类原因仍未证实。本轮没有在运行中修改选择提示或强制读取。
