# 情境练习修复与发布验收

已于 2026-10-31 11:05:57（香港时间）发布到 [understandbook.top](https://understandbook.top)。当前版本为 `practice-20261031`，切换维护窗口 17.45 秒。切换后的主页、阅读器、后台资源及读者、管理员接口均通过验证。

## 修复结果

- 练习使用自己的分级提示，不再被普通教学的单条提示校验阻断；普通教学仍要求有效提示。回归经过真实注册的工具参数校验和服务端选择入口。
- 开放题判为正确后释放完整解答；重复接收同一次判分不会重复生成解答。读回活动时恢复已释放的提示或解答，前端历史恢复和结束通知均有回归覆盖。
- 练习出题说明对齐当前设计、目标和参与方式字段，去掉旧接口要求，明确评分来源、`source_sufficient`、提示、解答必须随完整题目一起提交；题面必须直接给出可作答的问题。
- 同一章节里的不同知识关系可以交替练习；同一关系仍受交错与难度递进约束。绑定同一正式学习对象时，改写名称不能绕过约束。
- 用户点击练习按钮、没有键入文字时，回答降级流程保留实际按钮请求，不再把它当作空问题。
- 每道练习必须提供改答动作。出题说明与服务端约束一致，漏掉改答的题目会在交付前被拒绝，避免首次答错后无路可走。
- 阅读器侧栏的练习设置与热身提示分行布局，避免多项控件挤在同一行、把中文标签压成竖排。
- 明确提示与解答在释放时会原样显示给读者，要求提供面向读者的解题过程，评分标准保留在评分字段，避免混入“私有解答”等标签或给教师的操作提示。
