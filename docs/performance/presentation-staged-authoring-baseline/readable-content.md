# 1.3 用几个数字估算一次模型执行：零基础版完整心智模型与逻辑链

这是一页可交互的讲解（HTML + Konva 画布 + 原生滑块），目标读者是完全不了解 GPU 显存、带宽、算术强度、KV 缓存、批处理的初学者。页面把原书 1.3 的一步生成预算估算拆成一条不跳步的链条，每一步都写明"为什么可以这样写"和"用了哪个假设"。

## 开头的词表（把默认前提全部摊开）
权重、token、矩阵乘加、显存 HBM、带宽 β、算力 Π、下界，各自先用一句白话解释，并指出初学者最容易漏掉的默认：芯片里有两个互不相同的"每秒"（每秒搬多少字节 vs 每秒做多少次浮点运算），以及"权重被读过之后并不会消失，下一步还要再搬一遍"。

## 交互核心（主图与它的控制）
- 画布上半是"舞台"：显存盒（内含权重方格）、显存接口（带宽 β_eff）、计算单元（算力 Π_eff），以及一个沿接口移动的搬运方块。
- 画布下半是共享的同一条时间轴（0 → 一步下界）：蓝条 = 权重读取下界 R_W/β_eff，橙条 = 矩阵计算下界 F/Π_eff，红色竖线是游标。
- 四个语义步：第 0 步搭舞台；第 1 步游标扫过读取 lane（方块沿接口移动到计算单元）；第 2 步游标扫过计算 lane（读取保持满，可看出计算早已结束）；第 3 步取 max 判定瓶颈，并把四个改动画成同一基准下的横条与"缩短量"箭头。
- 控制：播放/暂停、上一步、下一步、重置为例题 1-1、预设 B=8 批内复用、预设练习 1-3（带宽 70%、算力 50%）；位置滑块 q（= 步号 + 步内进度，0–4，与预览 seek 走同一条路径）；7 个参数滑块（N、b_W、β、Π、B、有效带宽比例、有效算力比例）。参数一改就暂停并回到第 0 步（模型初始条件），推导行与改动表立刻按新参数重算。
- 常显单行结果文本（含参数、步骤名与步号、进度、当前值）；实时推导面板（读取下界、计算下界、一步下界与瓶颈、算术强度与机器平衡、转折点 B*、吞吐上界与每输出分摊）。
- 实时改动表（第 4 步）：算力 ×2、带宽 ×2、权重减半、批内复用四行，给出新的一步下界/每输出分摊、相对提速和原因；没有改善时箭头消失，只留一个点并写明"无改善"。

## 页面计算的关键数值（页内计算，非书中原文）
默认参数（例题 1-1）下页内算出：R_W = 70.0 GB、F = 140 GFLOPs、读取下界 20.90 ms、计算下界 0.1415 ms、一步下界 20.90 ms（瓶颈 = 读取）、两者相差约 147.7 倍、算术强度 2.00 FLOP/byte 对机器平衡 295.3 FLOP/byte、B* ≈ 147.7、吞吐上界约 47.9 token/s。这些与书中给出的 20.90 ms、0.1415 ms、约 148 倍、B* ≈ 147.7、47.9 token/s 一致。按 B=8 预设，同一式子给出每输出分摊约 2.61 ms、吞吐约 382.9 token/s，与书中 2.61 ms、383 token/s 一致。
练习 1-3 参数（带宽 70%、算力 50%、b_W=1）下页内算出：读取下界 29.85 ms；B=1/16/64 的一步下界均为 29.85 ms，每输出分摊 29.85/1.87/0.4664 ms，吞吐上界 33.5/535.9/2144.6 token/s，全部超过 10 ms 目标；权重减半后读取下界 14.93 ms、B* ≈ 52.7，B=1/16 仍为 14.93 ms，B=64 改由计算决定（18.11 ms），所有 batch size 仍不满足 10 ms。

## 讲义部分
第 0 步舞台；第 1 步三个量（M_W = b_W N、R_W = b_W N、F ≈ 2BN）与单位如何相乘得出；第 2 步两条时间下界与单位演示；第 3 步为什么取 max 而不是相加；第 4 步四个改动逐个代入；第 5 步转折点 B* 与算术强度；第 6 步与实测对照（Qwen3-8B 在 RTX PRO 6000 上的测量：1→64 请求吞吐约 ×31、单请求输出间隔 26.5→40.5 ms，以及加入状态读写项后的式子）；第 7 步五个问题（搬什么、搬多少、搬几次、经过哪里、谁在等待）；练习 1-3 的页内复算表；本页刻意留下的假设与边界；三个常见误解。
