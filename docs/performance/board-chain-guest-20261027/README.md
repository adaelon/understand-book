## 集成发现与修正

首个合并程序在现网数据副本中读取老账号和原问题画板成功，但游客兑换返回 503。已有 `grant_default_books_to_new_user` 会在建号时自动继承 `default_book_grants`，随后游客重复插入已继承的材料授权，事务因唯一约束失败。

修正为在同一个建号事务内清除新游客继承的授权，再写入本次兑换选定的材料。这样同时保证不继承项目书或旧发布。既有账号及普通注册的自动授权规则保留，不修改表结构或线上触发器。带真实默认授权机制的新回归及原有游客回归共 5 项通过，1 项浏览器 fixture 按既有约定忽略，见[测试日志](server-guest-trigger-tests.log)。首个失败程序、源码、503 结果与未核销内测码状态单独保留。

## 使用边界

游客会话和体验额度有效期均为 30 天，暂不支持跨设备登录或会话丢失后的自助恢复。清除浏览器数据、退出或过期后，原码不可再次登录；退出前有提示。额度用完后，有效会话可继续读取已有记录。

真实模型验收在隔离的现网账号副本中进行。正式旧失败记录保留，验收结果没有直接写入正式用户历史。用量未知的预留按原账目保留，不作为已花费用；用户当天增加的正式额度已生效，第二轮隔离测试的旧小额上限错误及纠正见[额度调查](../board-candidate-chain-20261027/allowance-investigation-20261027.json)。

新游客书库中的既有视频发布标题当前显示 `external`，原账号使用自己的 CS336 显示标题；这是既有资料元数据的展示差异，本次未改写资料或私人标题。材料授权、默认版本选择及书籍阅读验收通过。
