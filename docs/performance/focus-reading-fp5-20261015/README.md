# FP5 原文操作与显示连续性

2026-10-15。基线 `6612932` 与 FP4 已验收工作区。FP5 本地实现与验收完成，P4、操作接入后的 P1/P2/P5/P6 均通过；未提交、未部署。依据：[切片方案](../../切片方案-专注阅读双页与无感翻页.md#fp5-原文操作与显示连续性)、[ADR-0166 §4.1](../../adr/0166-focus-reading-pagination-and-performance.md#41-fp5-原文操作与可见读位)、[FP1 预算](../focus-reading-fp1-20261014/README.md)。

## 实现

`当前可交互屏 → 规范范围与片段几何 → 高亮 / 笔记 / 公式 / 问 AI / 来源返回`。

- 选择复用已经准备的语义映射，支持同一叶跨双页、多个叶、代码与表格的局部文字。公式保持完整对象身份。两个端点必须属于当前可交互屏；隐藏屏、动画预览和控件文字不能进入引用。
- 标注、来源高亮及批注按钮在准备或批注变更时投影到实际片段，翻页复用成品。浮层共用既有笔记编辑、删除、来源和返回入口。
- App 使用当前屏的实际来源替代已释放的连续 `segments`。冻结引用保留规范范围；默认问 AI 使用实际可见范围。来源预览传递保存范围，重复文本也定位到原来选中的出现位置。
- 原生选择、拖选、输入法组合及笔记落点操作暂停破坏选区的准备/重排；工具、字体、旋转、单双页及进入退出保留原文位置和草稿。工具条按实际大小限制在视口内。高亮在提交时消费旧选区，异步回执不会清除随后建立的新选区。
- `reader/position` 在翻页收尾后合并异步保存可见范围及字符锚点；预取只读。Reader 只把确认显示的叶送入既有异步已读队列，不改变逻辑布局 revision。本地 session 与多人 workspace checkpoint 均恢复精确读位。
- 几何包含字体、字号、行距、中文字距和版心；新首屏发布前保留旧画面，发布后先给浏览器绘制机会，再补邻屏。
- 已完成片段/页面复用资源计数，批注改变时重算。字体就绪按来源对象和字体族复用，短片段共享4ms准备时间片；进入时复用已渲染公式，转移载荷计入解析预算。
- 显示调整在原四屏预算内保留同锚点上一种几何；当前及前后屏优先，翻页立即释放旧几何，恢复向阅读方向多准备一屏。退出在连续布局恢复前冻结当前屏，释放邻屏/未消费原文，并将保留屏移出连续正文容器；热返回复用，换源/现场/卸载销毁。

源码接点见 [架构](../../架构.md) 与 [代码链路 FP5](../../代码链路.md)。

## 测量与复跑

验证先检测具体失配：原文范围/草稿/返回失败修来源或状态链；显示变化超过100ms修首屏准备/呈现；翻页P95超过50ms、缺失帧超过1%或交互中准备增量非零则修交互调度；长期预算或回返DOM增长则修所有权/回收。性能运行串行，不同时执行编译和图像分析。

```powershell
pnpm --dir packages/web exec vitest run src/useReaderSelection.test.ts src/reader-pagination.test.ts src/reader-focus.test.ts src/components/ReaderPane.test.ts src/markdown-note-placement.test.ts src/markdown-source-map.test.ts src/useReadingContinuity.test.ts
```

## 失败与修正

- 最初重复文本来源跳到首次出现、分页隐藏导航导致无法返回，以及刷新后进入偏移被连续采样覆盖：分别传递规范范围、增加来源返回入口、保存/恢复明确读位。原日志 `browser-first.log` 至 `browser-fifth.log` 保留。
- 左侧代码选区工具条越界：读取实际工具条尺寸并限制视口；公式、代码和表格的公开操作回归保留。高亮回执覆盖后续选区的问题在最终快速连续选择回归中发现，消费选区移到提交时。
- 显示准备反复统计完整公式DOM、重复字体准备、连续正文重复渲染及多余几何重建造成P4失败。CPU记录 `results/prepare-cpu.json` 与各轮 `p4-*.log / results/p4-*-1440.json` 保留；采用有界计数/渲染复用、4ms批次、首屏绘制优先、同锚点几何复用及退出前冻结。
- 保留屏最初混入连续正文的来源查询，后移出正文容器并禁用交互；仅在当前屏可交互时发布接管事件，避免提前移除旧画面。退出/热返回回归验证。
- 夹具原先把可选LID元数据差异当成游标变化，或把尚在准备且aria-hidden的屏计入可见页。改为校验材料内叶序/规范偏移，并明确只统计可交互屏；未放宽原文位置判定。
- 普通tsc不能解析Vue单文件组件，独立入口改用仓库既有vue-tsc。所有中间失败日志保留；未用重复成功覆盖历史失败结论。

## 已知限制与下一片

- 本片为Chromium桌面、移动视口和触摸模拟的浏览器渲染证据；实体手机、系统选择手柄、实际高刷与物理面板时延未测。WebKit/WebView2联合验证沿FP7。
- 资源计数为本阅读实例拥有的页面、正文/解析载荷、DOM及解码图片名义面积，包含准备区；不等于浏览器总堆或GPU内存。API慢网由生产App的本地回执夹具注入，真实持久化另由后端接口测试覆盖。
- 首次字体/未缓存来源准备及缓冲外快速跳转保留完整等待。P95通过不意味着每个新排版的单次延迟都低于100ms。
- PDF专注双页/单页归FP6；完整平台联合验收归FP7。本片完成后再接FP6。
