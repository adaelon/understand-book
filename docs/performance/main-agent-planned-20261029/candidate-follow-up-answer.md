**直接回答**：这里的“即使”是让步假设连词，相当于“就算、哪怕”。它把“交通量逐渐恢复到原来的水平”作为一个让出来的设想；句子没有断定这件事已经发生。作者真正断定的是后半句——噪声和空气污染依然相当严重。所以读到这句，不能把“交通量恢复”当成已经确认的事实。

**先做一个替换测试**

把“即使”换成“虽然”，读一遍：

> 因为虽然交通量逐渐恢复到原来的水平，可噪声和空气污染依然相当严重。

意思马上多出一个承诺：交通量确实恢复了。原文没有这个承诺。紧挨着的前文说，限速后进城买东西变麻烦，“进城的人也就变得越来越少”——当时的趋势是进城的人变少，文中也没有“后来又恢复了”的交代。所以“恢复到原来的水平”只能是作者让出来的一种可能情形。

这个替换显示的，是两类让步的分工：

| 说法 | 对“交通量恢复”的态度 | 读者被要求接受什么 |
| --- | --- | --- |
| 因为交通量已经恢复到原来的水平…… | 当作事实 | 交通量确实恢复了 |
| 虽然交通量逐渐恢复到原来的水平，可…… | 当作事实，用来让步 | 交通量确实恢复了，只是结果仍不理想 |
| **即使**交通量逐渐恢复到原来的水平，可…… | 只当作假设，可能不会发生 | 不必相信它发生；只需接受后半句 |
| 如果交通量逐渐恢复到原来的水平，就…… | 当作条件 | 后半句的成立依赖这个条件 |

表格里几种连词的对比，是我对这几类用法的说明；书里实际用的是“即使”这一种。判断它是不是假设，不能只看连词，还要看让出的内容在上下文中是否被当作已知事实。这句里，前文正在说进城的人变少，文中没有恢复的交代，所以它是假设。

**句子里谁被断定**

“即使 P，可 Q”的结构中，P 是让出来的假设，Q 是作者实际主张的内容。“可”在这里相当于“还是、仍然”，和常见的“即使……也……”属于同一类用法。于是：

- 被断定的：噪声和空气污染依然相当严重。
- 没有被断定的：交通量逐渐恢复到原来的水平。

句首的“因为”管的是整个“即使 P，可 Q”，不是只管 P。它说明作者为什么说“不尽然”，并不能把 P 变成事实。

**作者为什么用“即使”**

这句话在回答前文的“总算达到了预期结果？不尽然”。作者要说明：交通量下降并不能证明限速方案成功。前文已经交代，限速让车总挂二挡，“噪声更大，产生的废气更多”，进城购物从 20 分钟变成 30 分钟，市区汽车数量明显增加。每辆车的噪声和废气都增加了，所以交通量即使回到原来的水平，噪声和污染仍然严重：总量相同，单车更吵更脏。交通量增加的时段还会更糟。

“即使”在这里的论证作用，是让“污染仍然严重”这个结论不依赖“交通量是否恢复”。作者要表达的是：无论交通量是否恢复，噪声和污染严重这一点都成立。他因此不必先证明交通量恢复了，也能说方案没有真正解决问题。

**一句话检验**：读到“即使 P”时，把 P 换成“虽然 P”；如果句子多了一个“P 真的发生了”的承诺，就说明原文没有确认 P。
