### 读图：一个存量，两个流量

图的上排是三个对象。左边的**补给**往地下加水；中间的**地下水储量**是地下那一大块水，也就是存量；右边的**取水**是从井里抽走的流出量。箭头在这里只表示水往哪个方向走，不表示那一头有无限的水。

储量怎么变，由两个流量相减决定：补给大于取水，储量上升；取水长期大于补给，储量下降。这个减法里没有出现「井口水位」，因为水位是另一个对象，画在下排。

左侧的补给一项是我做的示意：这段原文讲的是从井里取水、周围的水流进井中 ，没有给出补给量，所以图上不标数字，也不把补给说成原书的结论。

### 假象怎么形成：水位回到原位，水是从储量里挪来的

取水后，井筒里的水面先降下去；接着周围的地下水流入井筒，把井筒重新填满，于是水位看起来又稳定了 。

关键在于水的来路。流进井筒的水来自周围含水层，也就是中间那个储量。井筒细、含水层大，重新填满井筒只需要含水层失去很少一点水。于是井口读到的是「稳定」，地下发生的是「存量在减少」。作者正是把这种稳定称为可能产生的一种假象：它让人觉得自己面对的是一份用之不竭的资源 。

所以图上把井中水位单独画成一个椭圆，再用一条「流进井的水来自储量」的箭头连回存量：水位是井筒这个局部的读数，被消耗的是储量。

### 走到极限：缓冲用完的那一刻

水位能不能一直稳定下去，取决于储量还剩多少。作者对这类系统的判断是：负反馈带来的缓冲能力通常有限，而反馈系统靠消耗物质或能量维持，一旦被消耗的东西用尽，系统就可能崩溃 。

具体到井上：到某一极限，地下水会被用尽，水井就不能自我补充了；一旦发生这种情况，系统可能长期不能用，或者遭到永久性的破坏 。

图中「极限」一框接在储量之下，因为决定极限的是存量，不是井口的水位读数。越过它之后，那条「周围水流入井筒」的回流就填不满井筒了，图左下方的「井不再自我补充」才真正出现。前面的稳定和这里的干涸，是同一套关系的两个阶段。

### 书里的另一个后果：越缺水，越打井

作者还写到另一条回路：水越少，打的井将越多，而出水将更少 ；而当地下水已经严重衰竭时，新井只能加快其衰竭 。这一段的终点写得很直白：几乎所有的地下水被耗尽，水井实际上是干的 。

这条回路说明了为什么增加井数会把衰竭推得更快。单口井的取水看不出明显变化，井数增加却让总抽取量上升，储量下降更快，于是每口井的出水更少，又促使人继续打新井。

图右下角的紫色框用三个短句标出这个循环，它接在「井中水位」之后：触发这个循环的，正是你盯着看的那个指标——出水变少。
