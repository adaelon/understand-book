这句里的“即使”是让步标记：它把“交通量逐渐恢复到原来的水平”先让出去，再说明主句在不管这个条件成不成立的情况下依然站得住——噪声和空气污染依然相当严重 。所以单看“即使”，书里没有确认交通量已经回到原水平；它让出的只是一个条件。

把三个常见标记摆在一起，对同一件事的承诺强弱就看得出来了：

| 说法 | 对“交通量恢复”的承诺 |
| --- | --- |
| 既然交通量已经恢复了…… | 当成已有的前提，后面的话由它推出 |
| 虽然交通量已经恢复到原来的水平，可…… | 当成真事说出来，主句讲的是与它相反的结果 |
| 即使交通量逐渐恢复到原来的水平，可…… | 让出去：主句结论不取决于它是否已经发生 |

那“恢复”这层意思从哪来？来自前一句：进城买东西变得太麻烦，进城的人越来越少 。人少了，车流才逐渐回落，用的是“逐渐”这类表示过程的词，作者并没有报出一个已经回到原点的读数。同一段随后还提到交通量上升的时段情况会更糟，可见流量并没有停在一个固定水平上。

作者偏要在这里让掉车流量，因为这是这段论证的支点。措施实施以后，车开得慢，被迫用二挡而不是三挡行进 ，结果是噪声更大、废气更多 。变化落在每一辆车上：即使车的数量和过去一样多，每辆车的噪声与废气都比过去重，合起来的总量只会更糟。这一步是按“总量＝车数×每辆车排放”做的推算，原文给出的是车数与每车排放两端的事实，这个乘法式是我补的。

换个角度看，这个让步预先挡掉了一句反驳。“车都开回来了，说明限速没闹出什么影响”——作者先把这个说法接过来，再指出车回来了、污染没回来。这也解释了为什么这里用“即使”而不是“既然”：他要给出的结论，不能建立在“车流量到底恢复到什么程度”之上。

还有一个容易误导的地方：常见搭配是“即使……也……”，原文用的是“即使……可……”，让步和转折叠在一起，读起来更接近“尽管……可是……”，确实容易让人觉得是在承认既成事实，你的疑问大概就是从这个搭配来的。但“恢复”算不算既成事实，这层信息要由上下文（进城的人越来越少、逐渐回落）提供，“即使”本身只负责把条件让出去。

一句话分清：用“既然”，恢复是前提；用“虽然”，恢复是事实，只是结果与它相反；用“即使”，恢复只是让出的条件，主句的回答不变。
