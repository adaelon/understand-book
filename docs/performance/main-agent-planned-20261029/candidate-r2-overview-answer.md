# 这本书在讲什么

一句话：它用实验拆解“人为什么会在复杂的局面里，把事情一步步办坏”。作者是德尔纳，书里登场的是他设计的一整系列模拟实验。

## 先看一个有点刺人的结果

书里报告说，参加者的一系列心理学测验对预测他们的实际行为是没用的；更具体地说，**智商测验得分和格林韦尔实验、或其他解决复杂问题实验中的表现之间，不存在显著的相关性**。

这条结果值得停一下：把事情办坏的能力，看不出是“笨”的专利。书里后来拿切尔诺贝利核电站操作员的行为做对照，发现他们的行为特点和模拟实验里的普通参加者有共同之处——难以控制时间、难以评估指数发展过程、难以估定副作用和长期影响，也就是倾向于根据孤立的因果关系来思维。一流专家和普通参加者，掉的是同一批坑。

## 一、中心问题

书里交代主题时说得很直接：它要讲的是**处理复杂问题时我们思维的特性**——人在试图处理这些复杂问题时为什么会犯各种错误、怎样走入死胡同。

更关键的是作者对“失败”的定位。失败“并不像突如其来的晴天霹雳，而是按照自己的逻辑逐渐发展的”：复杂的情况似乎会诱导出一套思维习惯，这套习惯从一开始就埋下了失败的种子；随后任务越来越复杂，人对失败的忧虑也越来越重，两者又促成了让失败变得更可能、乃至不可避免的那些决策方式。

这里有个会自己咬自己的回路，值得记住：**失败 → 焦虑上升 → 决策方式变差 → 更失败**。书里还有一句相关的观察：我们解决不了问题时会恼怒，而恼怒又会影响思维；思维和情绪是互相牵扯的。所以这本书讨论的失败，多数不是一次意外，而是一段会自己加速的下坡。

## 二、作者怎么取证，以及它能说明什么

德尔纳没有只靠讲故事。他造了不存在的城镇，用计算机模拟这些城镇的主要特征，让人在里面当市长——格林韦尔实验里，随着时间推移，先后有 48 位不同的人担任格林韦尔市市长。

这个办法的长处很明确：真实世界里，人的规划、决策、估价过程大部分藏在事后回忆里，你只能问“你当时怎么想的”；而在模拟里，这些过程的背景能被直接观察和记录，心理学上的决定因素也可以被单独拎出来研究。

边界也要说清楚。格林韦尔是假想的，模拟能揭示的是**人在这种受控的复杂情境里倾向于怎样思考和决策**，它本身不构成对真实城市治理的预测。作者把结论向现实延伸的方式，是拿切尔诺贝利这类真实事件的行为特征去对照——那是事后对照，不是模拟“预测”了事故。

## 三、全书的组织路线

读到的章节标题是这样排的（最右一列是我按标题理解的“它在这一环检查什么”，不是书里的原话）：

| 章 | 标题 | 检查的环节 |
|---|---|---|
| 第二章 | 要 求 | 这类任务本身对我们提出了什么要求 |
| 第三章 | 确定目标 | 目标怎么定、在哪里定错 |
| 第四章 | 信息和模型 | 我们对现实建了什么模型、取了什么信息 |
| 第五章 | 时间序列 | 事情随时间怎样演变、我们怎样把握 |
| 第六章 | 规 划 | 从前面这些前提怎样走到行动方案 |
| 第七章 | 那么现在我们怎么办? | 那还能怎么改 |

这条线值得注意：它顺着一个人真正处理复杂任务的流程走——先弄清任务要什么，再定目标，再搞清现实长什么样，再考虑时间，最后才谈规划。所以各章读起来更像对同一条链上不同环节的逐段体检，而不是零散话题的集合。

## 四、几个具体的失效样式

**1）不考虑此刻并不存在的问题。**

书里把这称做“第四种心理学机制”，并承认它造成的失败似乎没有“忽略”那么多。人的思维默认只对付眼前存在的东西：不存在的环节，就压根不去想。这个习惯在日常里很省力，可它一旦撞上动态的复杂现实就会出问题——行动会带来副作用，而副作用在行动之前**并不存在**，按“只看眼前”的习惯，你根本不会把它列入考虑。作者的要求正是在这里：解决这类问题时，必须考虑此刻可能没有、但可能作为行动副作用而出现的问题。

举一个假设的例子（不是书里的案例，只是让你看清这条关系）：假设一座城市为解决拥堵而拓宽主干道。短期车流确实更顺。但如果因此有更多人改回开车、沿街小店客流结构改变、几年后维护成本压上来——这些在动工那天都不存在，却都是这次行动自己制造出来的。副作用之所以难，不是因为它隐蔽，而是因为它在你决策的那一刻还没有实体。

**2）时间与指数过程。**

与切尔诺贝利操作员共有的另一个特点，是难以评估指数发展过程。指数式变化的样子是前期平缓、后期突然失控；而人的直觉习惯按直线外推。两者一对上，早期判断就会系统性偏乐观。

**3）不知道该按什么顺序做。**

书里给了一个“合理处理复杂问题”的次序：先（至少试验性地）把目标定清楚，然后建立或改进这个具体问题的模型；可能还得观察相当一段时间，弄明白模型各变量之间的联系，并收集系统当前状态的信息，从而知道它现在怎样、将来可能怎样——做完这些才进入规划。反过来说，目标还没定清、模型还没有，就先排方案，正是书里反复出现的那类失败来源。

## 五、它想给你什么

书前的一段介绍文字把它定位成一件“矫正工具”、一种明智的规划和决策指南。这个定位比较准：它的价值在于给失败画出一张可辨认的画像，让你在自己的计划里认出“我这是在忽略副作用”“我这是在拿直线推指数”“我目标还没定就急着排方案”。至于一套必胜的决策术，它没有许诺。

比较实用的读法是：读到每一章讲的那种走偏方式时，立刻回想一件你正在推进的事，看能不能对上号。对上了，那一章才算真读到。
