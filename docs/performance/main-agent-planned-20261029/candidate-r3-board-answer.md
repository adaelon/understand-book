## 一、井口看到的水位，只是井这一处的读数

先跟着一次取水走：从井里取水，周围的水就会流进井里，井内水位于是回升。 这一步说明的是“井这一小段空间又被填满了”。

图上把这条水流画成从**地下水储量**指向**井**的箭头：水是从地下水库那边挪过来的，井只是它的通道。取水箭头则从井指向用水。所以水位回升与地下水的总账下降可以同时成立——读数在恢复，账本在变少。

## 二、水位背后是一笔有上限的存量

地下水储量是另一笔账：它没有水位刻度，只有取水与补给谁更多。书里把水井放在“缓冲能力有限”的系统里讲：这类系统能靠负反馈吸收大量扰动，但缓冲能力通常有限；它在消耗物质或能量，其中任何一种耗尽，系统就可能崩溃。

落到井上就是：到某一极限，地下水会被用尽，井就不能自我补充了。 图上的“到某一极限”正是从储量这一笔账推出来的，而不是从水位推出来的。

## 三、为什么这个假象特别牢

水位回弹容易骗人，是因为它看起来是稳定的。 稳定本身给了一个很自然的印象：既然每次取完都能回到原样，资源就像用不完。

另一头，储量下降的信号又很不显眼。摩洛人的案例里，水井出水量减少被解释成气温、耗水量或降雨的临时变化，被当成局部波动，而没有当成地下水供应不足的指标。 两个量朝相反方向走的时候，显眼的那个（水位）盖住了不显眼的那个（储量）。

## 四、到达极限之后

越过极限，后果不是“水位低一点”：一旦发生这样的情况，系统可能长期不能用，或者遭到永久性的破坏。

案例把这条路走完了。因为既不能停止灌溉、也不能停止给牛喝水，唯一的办法是钻更多井；新井加快衰竭，几乎所有的地下水被耗尽，井实际上是干的。 钻更多井本身还是一条正反馈回路：水越少，打的井越多，出水更少。 第二条回路同时恶化：水越少，植被越少；饥饿的牛越多，破坏草地越普遍。

崩溃之所以显得突然，是因为多年逐渐减少要么没被觉察，要么没被认真对待。 于是“水位一直正常”的记录，最后被一次井干推翻。
