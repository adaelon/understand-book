## 实现结果

- **MA0**：冻结源码、原工作区差异、可运行二进制、书籍材料、模型配置与三个原始问题。比较从问题接纳开始，包含取材、初稿、修改和保存。
- **MA1**：沿用 `ResidentGoal.working/items`。多步请求先保存具体成果计划，按阶段写回结果与缺口；短追问无需增加规划往返。TeachingDesign 继续组织教学关系，工作计划不证明交付或学习者掌握。
- **MA2**：没有本轮审核就没有 current_work 审核状态；旧审核按历史身份保留。后台教练从原回合成功读取记录恢复完整原文，继续取得真实用户表达及帮助顺序。
- **MA3**：默认 select 移出独立教师事实、解释及视觉审核。宿主仍校验来源、实际预览、确切版本、私有题目合同及保存结果；finish 使用选定的确切成果。不生成空 accept 或虚假的 AgentWorkReviewed。
- **MA4**：保留制作前表达教练及缓存、后台教学教练、正式学生 assess。图板直接工具名额得到正确计算，不再挤掉进展工具。当前视觉设计可由已核对的原生图板满足，无需另做 HTML 页面。
- **MA5**：三个原问题各完成一次真实配对；依据第一轮实际缺口追加概览和图板第二候选，图板第二候选暴露页面限定错误，再定向修复与复测。全部失败和质量不足样本保留。

## 条件与版本

三个输入为 [overview.json](overview.json)、[follow-up.json](follow-up.json)、[board.json](board.json)。材料为《失败的逻辑》，冻结 source revision `57e6d2c1f044b95362ef7ee22dfa95ef25f27821ae1df0603b4fcb4547e43915`。每次使用独立空会话、相同确认偏好、相同 `deepseek-v4-flash` 原生模型及相同材料；短追问的引文直接在题面，不继承另一轮随机答卷。水井场景及其书中答案没有写进作者提示词。

配对前台均无已就绪教学教练指导，后台教学教练与个人记忆抽取设为不可用。表达教练真实运行并单列。连续教练和学生评分使用另行记录的功能夹具，不据此声称其真实模型成本为零。供应商缓存与远端负载无法固定，各场景没有重复样本分布。

候选 1 完成默认路径调整；候选 2 只加强一般指导：先记录多步计划、整书概览解释研究方法的作用、核对图文对象与箭头、引用匹配失败时纠正或回读。候选 3 在候选 2 上修复原生图板被错误要求附加 HTML 页的程序校验；文字路径不变。

回放复用 [teaching-revision-replay.mjs](../../../evals/semantic/teaching-revision-replay.mjs)，[provider recorder](../../../evals/semantic/teaching-replay-provider.mjs) 原样转发生成请求与响应，按调用用途保存供应商原生用量。模型发现接口未列出原配置别名时，仅对发现列表补充同能力别名；生成模型与请求不替换。没有保存密钥或推理正文。实际单价／账单不可得，费用标为未知。

## 已知限制

本轮没有单价或实际账单，不能把 token 数当作费用。总 token、非缓存输入、输出和失败尝试均计入；模型缓存及远端负载不同，单样本时间不能给出可靠分位数或普遍加速幅度。后台教练真实运行的延迟和费用没有在本配对中测量。

整书与追问的本次候选等待缩短，但总 token 增加；没有证明整个架构更省 token 或更省钱。图板初次质量失败及第二次未交付表明，移除同步审核后仍需真实取证、观察和交付后评测。功能接线与有限真实案例通过不等于所有材料、请求和模型均保持质量。

最终图板仍有 9 次引用匹配失败的返工；末句“水位一直正常的记录”比原文的稳定印象更强，不能当作额外历史证据。主体关系和图文对应可用，不据此宣称所有表述已无事实扩写。

服务端全量仍有 12 项已归因的原有失败，未将相关回归通过表述为全仓绿色。本次工作区包含用户原有改动，尚未提交或部署。
