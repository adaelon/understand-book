# T16 来源教学与首轮上下文验证

日期：2026-10-09，Asia/Hong_Kong。基线：`4e0b68e feat: integrate book structure, tutoring and multi-user reader`；未创建 commit、未部署。

## 实现

`start_request/freeze_prepare` 使用 T15 必要接纳就绪。来源与 BookStructure 及其必要前置有效时，即使没有地图、对象或认知素材也能进入同一个 Resident TutorLoop。

有地图时保留原不可变修订读取；无地图时按 `teaching_assets` 读取已接纳的独立对象/素材，在私人 TurnBound 事件保存本轮快照。模型先得到对象摘要，按需调用 `material`。后台替换独立文件不会改变本轮所用版本，下一轮可读取新接纳版本。

来源动作必须携带 TeachingTarget；核对焦点、期望表现、能力、来源身份/版本与完整范围。目标区间由本轮实际读取的原文 UTF-16 区间覆盖，局部摘录不能证明整个目标。搜索位置保留原来的字面命中语义，不进入教学原文证明。正式对象存在时继续核对当时修订和材料读取事实。

交付保存目标与实际回答，显式回读和活动可用性允许无地图绑定；普通追问继续保留原目标和帮助归属。下一轮从已交付事实恢复 current_target，并取得当前请求、会话意图与约束、已确认背景/偏好及近期交付/回应。未知背景与缺少表现证据保持未知。

Runtime 的工具合同、首轮指导及未完成动作修复接受来源教学，并继续要求实际交付。首次零阅读请求从必要的对象、关系及因果过程组织解释，演示承接本次期望表现与理解障碍。
