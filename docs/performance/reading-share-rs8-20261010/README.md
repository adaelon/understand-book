# RS8 理解空间的单项阅读

2026-10-10。功能／Web 完成；接续 RN1–RN4、RS1–RS7 未提交工作树，未提交、未发布。

## 已交付

“学习会话 → 我的理解”以两组短预览展示当前解释与概念能力。点击后集中阅读一项，按原证据身份读取完整系统解释与用户原话；长内容只在列表预览收短，详情保留全部文字与换行。未知概念显示未知，不生成作答或能力结论。

详情分别显示暂定理解、活动表现、帮助条件、作答次数、改答、原判定状态及用户纠正。对象能力概况保持独立／帮助后／改答后支持次数及未定解释；对象历史版本和历史依据有明确标识。依据与完整解释历史按需展开，历史翻页继续传递原对象、修订和能力。

详细依据展开且引用进入可见区域后才发送原反馈展示回执；隐藏反馈继续提示回到活动请求直接讲解。原话、判定引用与来源引文分别显示。打开列表或读取单项本身不创建新的能力判定。

纠正草稿按原证据保留在当前组件内，切换条目后可以继续填写。保存使用原证据和幂等操作身份；连接失败可原样重试，服务端已确认写入后仅重读返回记录。成功后显示替代解释与用户纠正，并刷新已加载的对象分页。返回列表恢复原入口焦点；原入口被修订记录替换时聚焦列表。

反馈展示回执与纠正命令分别保留错误和重试入口，延迟失败不会覆盖待重试的纠正。沿原接口和服务端存储运行，本片没有修改证据生成、能力投影或纠正的服务端语义。
