# Tutor T1–T2 实现与验证

日期：2026-09-29。实施基线：`5e10516`，包含此前已确认但未提交的 T0 设计。T1/T2 源码与文档保留在工作区；本记录不代表安装包或线上部署。

## 已实现行为

T1 使用 App 的原聊天、运行和草稿。RightRail 在同一 DOM 树上将演示和对话投影为可调整两区，窄屏按需展开讨论，工具栏高度由实际布局测量；展开/收起、来源往返不重建 iframe。发送绑定确切版本和现场，保存失败保留草稿；消息绑定卡读取旧快照摘要。定位不改参数，显式恢复先保存当前现场，再读取指定快照。新版本在当前工作区中先显示引用卡，点击后打开；旧实例保持可返回。历史 API 投影持久回执，旧消息不改引新版。

T2 在 memory.json 同目录新增 learning.db。`tutor_events` 保存动作、操作身份、revision 和时间，`tutor_projection` 保存可重建的控制与会话状态；事件和投影在同一事务提交。全局开启默认 false，关闭暂停当前会话。显式开始、暂停、继续/历史切换、结束及默认教法分别保存；最多一个 active 会话。用户学习意图、约束、当前焦点和参考材料分字段持有，当前焦点在 Agent 尚未接入时保持空值。

`GET /tutor/state` 与 `POST /tutor/mutate` 沿现有 Reader 服务入口。Mutation 带 operation_id 和 expected_revision；相同请求重试返回原结果，错版动作不写库。TopBar、问答全屏和演示工作区使用 App 中同一个控制对象；没有收到成功回执时保留上次已知状态。重试保留原操作身份，状态不可读取时显示未加载，不伪造为关闭。

## 验证结果

| 检查 | 结果 | 发现的具体失败范围 |
| --- | --- | --- |
| `cargo test -p memory -- --test-threads=1` | 120 通过 | 真实临时 SQLite 的生命周期、重启/回放、单一当前会话、幂等/冲突、事务失败回滚；全部既有画像/记忆回归 |
| Server `tutor_` | 1 通过 | HTTP 状态与动作、聊天新建不换学习目标、重开、幂等结果、实际不可写数据库路径返回失败 |
| Server `presentation_follow_up` | 2 通过 | 确切旧快照进入模型和持久历史；公开历史投影回执；错误归属在预提交前拒绝 |
| Web 六个定向测试文件 | 41 通过 | Tutor 保存失败/相同操作重试；RightRail、AgentPresentation、ReaderWorkspace、运行状态及内容装配回归 |
| Web `typecheck` | 通过 | Rust 生成合同、API、App 及组件字段/事件一致 |
| Playwright 五个场景文件 | 11 通过 | 同屏回复、不可变快照、保存失败、磁盘重开、来源/主题/错误语义、显式恢复与换版、窄屏输入、Tutor 控制持久化与失败重试 |

浏览器使用真实 Chromium 和 Rust presentation_browser_host：现场、归属、来源、历史及 Tutor 数据库经过实际 API。模型使用记录请求的确定性适配器；新版本“点击前不读取、点击后才挂载”的场景以浏览器路由提供第二版交付，持久版本与旧现场读取由既有 Server 用例验证。新版场景不声称调用了真实模型重新制作。

截图检查发现窄屏展开讨论仍露出底层控件，增加工作区背景遮挡并按工具栏实际高度布局；相关工作区与全局控制场景定向复验。测试中把夹具 3/3 的显示预期写成了“3/3”，实际约定显示“1”，核对夹具后修正预期。

## 已知限制

- T3–T13 尚未实施。正式教学素材、readiness、TutorLoop、Trace、评分、Evidence 和学习状态投影均未接入；“教学准备中”如实表示已保存设置，并不表示后台已经启动构建或教学。开启后依材料与就绪状态自动建立/恢复会话由 T5/T7 接通；T2 只在明确开始/继续动作下修改会话。
- 本轮为 Windows 源码、组件与 Chromium 验证，没有部署 Linux、安装桌面包、真实 iPhone 或新增真实模型教学验收。草稿连续性限同一存活应用页面。
- 旧演示缺少自定义 restorer 时，沿用现有局部恢复提示；不能将原生控件恢复视为所有自定义参数都恢复。
- 既有 ts-rs serde 属性告警仍存在；内容装配单测会记录 happy-dom 尝试加载 localhost 样式的连接错误，测试断言通过。初次使用 D 盘旧缓存遇到系统拒绝执行，后续使用仓库 target 正常完成；浏览器宿主存活时重链接出现文件占用，关闭宿主后完成验证。
