# FP1 首轮探针失败

首轮：13 项浏览器场景中 9 项通过；1024、390、844、320 宽的列布局范围检查失败。具体复现为 `mixed / 19px / 1.5.3`，范围 `[0,850)` 处于第 6 列，尾部 `[850,851)` 被探针记为第 0 列。真实原文末尾为 `cipes, yield an approximately  `，含两个空格。

浏览器把跨列时未绘制的尾随空格返回为零矩形，原探针将 `(0,0)` 当作正常位置计算页号。修复只作用于实验探针：未绘制空白继承前一片段，保留原 UTF-16 范围；未绘制的非空白仍作为错误抛出。修复后五种窗口尺寸的源范围、单调性和原生选择测试通过。

原失败数据见 `probe-1024-19-mixed.json`；同批 EPUB 和复杂材料探针一并保留。完整性能数据以 `../results/` 的最终运行结果为准。
