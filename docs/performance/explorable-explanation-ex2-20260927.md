## 决定

EX2 Gate 未通过：v1/v2 已观测的 C 样本都超过成本门槛，v1 的 B 样本无可比交付。按预先写明的停止条件，没有为已经失败的 Gate 继续消耗重复运行；普通短答、非数值机制与静态换视角的新版退化对照也未完成，因此不作这三题的新版结论。没有把两版样本混为稳定性分母。

生产 `skills/presentation/SKILL.md` 和 Runtime revision 已恢复为 `ed3.v1`；候选及实验入口留在本报告指向的文件中供后续有明确成本策略时再研究。EX1 的手工样板、状态和动画测量是独立工程成果，不依赖启用这两版候选说明。
