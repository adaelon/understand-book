接上一段。上一段的收尾说了「平均速度是按时间加权的」,这次把它从一句比喻变成能算的东西——原文里的提醒正是入口:

> Average speed is total distance divided by total time. Equal distances need not take equal times. The total time must be positive. 

## 第一步:把定义拆成「加权平均」

把整趟拆成两段,速度分别记 v₁、v₂,各自花的时间记 t₁、t₂。那么:

- 总路程 = v₁t₁ + v₂t₂
- 总时间 = t₁ + t₂

代回定义:

**平均速度 = (v₁t₁ + v₂t₂) / (t₁ + t₂)**

这就是一个标准的加权平均——每个速度 vᵢ 的权重正好是它自己花掉的时间 tᵢ。所以「按时间加权」不是修辞,它直接写在分子分母里。

## 第二步:「Equal distances need not take equal times」在拦什么

如果两段路程相等、各为 d,那两段的时间是被速度**反过来决定**的:t₁ = d/v₁,t₂ = d/v₂。

哪一段慢,哪一段的时间就更长,权重就更大,平均速度于是被拉向慢的那一段,比 (v₁+v₂)/2 更小。

代入上一段的例子(各 60 km,60 km/h 与 30 km/h):

- t₁ = 60/60 = 1 小时,t₂ = 60/30 = 2 小时
- 平均速度 = (60×1 + 30×2)/(1+2) = 120/3 = **40 km/h**

用加权形式得到同一个 40,也就顺带确认了上一段那个例子的答案。(等路程这种情形其实可以化简成调和平均 2/(1/v₁ + 1/v₂),60 与 30 代进去:2 ÷ (1/60 + 1/30) = 40,一样。)

## 第三步:换一个条件,结论就变

现在把条件从「等路程」换成「等时间」。设两段各走 t 小时:

- 总路程 = v₁t + v₂t = (v₁+v₂)t
- 总时间 = 2t
- 平均速度 = (v₁+v₂)t / 2t = **(v₁+v₂)/2**

权重相等,于是退化成了普通的算术平均——同样的 60 和 30,这时才得到 45。

所以 45 与 40 的分歧点,不是「该不该做平均」,而是**权重是不是按时间给的**:

| 条件 | 谁占的时间长 | 平均速度 | 60 与 30 代入 |
|---|---|---|---|
| 路程相等 | 慢的那段 | 偏向慢速(调和平均) | 40 |
| 时间相等 | 两段一样 | 算术平均 | 45 |

## 回头看三句话怎么咬合

- 第一句给出算法:总路程 ÷ 总时间。
- 第二句排除一个隐含假设——「路程相等就意味着时间相等」;一旦承认时间可以不等,「把速度数值直接平均」就站不住了。
- 第三句守住分母:总时间必须为正,否则这个加权平均根本没有定义。

三句合起来就是一句话:**平均速度 = 按各段实际时间加权的速度平均。**
