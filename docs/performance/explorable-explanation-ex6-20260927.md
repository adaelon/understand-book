# EX6：时间预览合同与验收

日期：2026-09-27。此记录随 EX6 实施更新；入口与 Gate 见[实施方案 §8](../切片方案-可探索解释方法库与连续视觉演示.md#8-ex6时间预览合同)。EX1 样板提供 `seek({semantic_state,transition_progress})` 与 `snapshot()`；本切片把相同约定暴露给真实浏览器 preview。

## 运行前验收范围

- `seek` 的目标为已完成的语义步数 0–1000 与下一步视觉进度 `[0,1)`；定位时页面停止播放、重建场景。动作序号 `step` 仍是预览动作序号，目标与截图前后实测场景另记。
- 实际浏览器先等待渲染，再读 DOM/layout、截图、截图后场景。目标不符、仍在播放或采集期间位置变化都会使预览失败，同时保留截图供修订。
- EX1 页面依次定位中途（第 1 步 50%）、终点、起点、同一中途；重复中途帧的数值与画面应一致。窄触控、矮触控、桌面三视口都要通过；原 click/key、交付与 Reader 状态路径不得回归。
- 一次真实 Resident 模型请求明确要求制作小演示、定位中途帧、依据截图修订、重新预览三视口后交付。该试验验证模型实际收到中途帧图片与目标/实测位置，并在其后写出不同候选；失败时看原始请求和响应决定是否需调整工具说明。模型用量照实记录，沿用用户对 EX2 的成本决定，不设新上限。

## 结果

- Runtime `seek` 有界值测试先红后绿；真实 Server/Chromium 的 EX1 三视口定位、终点、回退、重复中途帧及交付 1/1；错误页面忽略定位且持续播放时，预览保留截图并报告 `scene_position_mismatch` 与 `scene_not_paused` 1/1。重复中途截图经像素解码，仅见浏览器的单像素抗锯齿差异，不是轨迹残留。原有 EX1 三视口 click 预览和动态语义预览均通过。
- 第一轮真实模型请求确实发起了含 `seek(1,0.5)` 的 preview，但 `serde_json` 在 Server 使用 `arbitrary_precision` 时把内部标记枚举内的 `f64` 解析为错误 map；该轮 5 次模型请求、136,827 tokens、未交付，原始数据在 `ex6-windows/real-middle-1/`。新增 Server 参数反序列化红测后，把 Seek 的进度线值保留为 JSON number，在 `scene_position()` 中解析与校验；红测转绿，Browser 正反路径复测通过。
- 第二轮在 `ex6-windows/real-middle-2/`：7 次请求、201,924 tokens、未交付。`response-03.json` 发起 `seek(1,0.5)`，`request-04.json` 收到目标/实测均为第 1 步 50% 且暂停的截图。模型从该帧看出点仍在最优点右边，提出显示跨越发生在本段 62.5% 的标记；随后的修订 `write` 把未交付候选 ID 误填为 `based_on.presentation_id`，得到 `PRESENTATION_NOT_FOUND`。工具说明与候选保存回执现已明确：未交付候选的修订应写完整新候选并省略 `based_on`；`based_on` 只接受已交付版本引用。
- 第三轮在 `ex6-windows/real-middle-3/`：真实 `deepseek-v4-flash` 9 次请求、430,131 tokens、223.485 秒，交付 `presentation-1790505711035132500-4` revision 1，`view.json` 可按该引用读取。`response-02.json` 定位第 1 步 50%；`request-03.json` 收到同一目标/实测场景的截图。`response-03.json` 指出该帧 w=2.240 尚未越过 w*=2、现有过渡条未标出本段 62.5% 的跨点，随后以省略 `based_on` 的 `write` 加入跨点刻线和状态文字。模型对修订候选再次定位，并在发现短视口高度溢出后写出最终候选；320×420 touch、640×240 touch、960×720 mouse 三视口预览通过并交付。最终说明里的 w₀=0、w₁=3.2、w₂=1.28、w₃=2.432 及损失值与给定递推一致。此轮原始请求、响应、截图、结果和读取回执均保留在该目录。
- EX1 Reader Playwright 回归 3/3：三视口、保存中途现场、重开及追问、五秒播放观察均通过；浏览器 `click/key` 回归与 EX6 的正反场景测试均通过。Playwright 首次调用因未启动验收宿主报连接拒绝，启动既有 Rust 验收宿主后重跑 3/3。EX6 Gate 的工程路径已满足。

## 已知限制

- EX6 模型演练是明确要求中途帧的小任务，证明工具能力、模型可见性和据图修订链路；它不替代 EX7 的自然请求对照，也不证明真实读者学习收益。
- 两轮失败分别暴露真实参数解析和候选修订提示问题，均保留原始结果；第三轮完整交付。模型成本按用户已接受的观察口径记录，没有套用 EX0 的旧上限。
