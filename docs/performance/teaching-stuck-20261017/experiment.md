# 连续卡住的教学验证

先上线已验证的主动邀请版本，再使用隔离的 gpt-6.1-sol 教师与模拟学习者，通过实际服务器 ModelAdapter 回合验证。教师只消费实际请求、工具结果及其公开任务，不读取评估目标、学习者设定或实现分析。学习者只看实际可见回答；正文已经承载的普通邀请不重复追加。需要页面时只提供真实生成并展示的页面内容。

学习者是基础有限的读者：对集合符号、并集和多条选择路径缺少可用概念，能接住单个具体事实，却难以一次把抽象规则应用到变化情境。每轮自然表达所接住的碎片和真实卡点，不指定教学步骤、方法、演示或提问时机。获得足够具体帮助时允许局部进步，不随机答错、不为了轮数拒绝已经能用的支持。主线程原样转交学习者表达。

主要观察教师是否缩小当轮要连接的关系，补充缺少的可操作前提，保留尚未解决的问题并据实际表达接续；用户卡住时是否只是重述同一个完整框架、换措辞重问或给出所有答案。首轮观察内容是否能形成起点，而非一次覆盖整个结构。

代码回归与语义判断分开记录。若发现问题，保留原始运行，修改系统实现后新开运行；不改写旧对话为成功记录。部署与后续本地真实回合分别标注，不能把本地模拟称为线上真人效果。
