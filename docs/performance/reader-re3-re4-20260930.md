# RE3–RE4 正文批注、动效与来源往返

日期：2026-09-30。基线为实时工作树，HEAD `5e10516`，包含既有 RE1–RE2 与 MU8；本次改动未提交。合同：[ADR-0148](../adr/0148-reader-typography-annotations-and-motion.md)、[RE 方案](../切片方案-阅读体验排版批注与动效.md)。

## 实现

RE3 将正文中的笔记卡、摘录卡和段后操作行改为段侧计数标记、单个按需预览与正文流外的紧凑操作条。标记按可见 LID 汇集原有笔记和高亮；引用的触发位置消费既有来源范围，组内切换保持同一触发点。`AnnotationPreview` 区分每条记录并显示对应引用摘要。桌面有侧边空间时就近展开，窄屏使用底部面板；正文几何保持不变，长内容在面板内滚动，关闭与操作区保持可达。

标记和预览均在 `.prose` 之外，带选择/放置排除属性；已保存高亮沿原渲染。预览连接 App 的原编辑器、删除确认、重锚和 Notes 管理。`RightRail.showMemory` 展开并聚焦同一记录，完整 Notes 也可编辑和删除。保存后重新读取记录，旧 mem_id 不再保留为活动预览；在 Notes 发起移动或从回答创建无引用笔记时，窄屏切回阅读区选择落点。

原句滚离触发位置、缓冲回收、记录更新、Reader 隐藏或现场失效会关闭只读预览。编辑草稿继续归 App 原编辑器；保存完成只关闭发起保存的编辑器，并核对原现场。MU 的 `bindSceneApi/networkFetch` 继续限定用户、workspace、generation 和 PublishedBookRef，旧响应不能更新新页面。打开预览时若仍在拖选、IME 或保有原生选区，不主动转移焦点；键盘打开、Escape 关闭及回到标记均可达。

RE4 将按钮、预览、标签和面板分别接入 120/180/180/240ms 的共享时长和缓动。内容和命令立即生效；到达正文后显示约 900ms 的临时强调，结束后保留原有高亮。原生键盘滚动直接跟随输入，远距离定位沿既有导航。减少动态效果偏好关闭动画、位移、过渡及已有加载旋转，保留文字状态与静态反馈。

批注和 Notes 的来源入口沿原 `readingContinuity` 返回栈，增加原区域及可选 mem_id；返回按钮分别显示“返回阅读位置”“返回笔记”“返回回答”。窄屏切到伴读区前保存可见段内锚点，隐藏后不从零尺寸 DOM 重算读位。来源加载保留本地请求代次；关闭、后续请求、切现场和卸载均使旧结果失效。显式导航和用户滚动取消旧恢复，返回过程同时核对 MU 场景与本地恢复代次。

浏览器的正文几何以开合前后同一段的实际矩形比较；选择覆盖整段正文，结果不含标记、按钮或批注内容。窄屏长段先滚到 900px，再经 Notes 打开来源并返回，验证恢复原读位。组内切换的补充修正只稳定显示层触发位置，相关长段测试随后在两引擎重新通过。

普通页面测试使用仓库既有 API 路由夹具及真实 Vue 组件。MU 用例使用现有 Rust 测试二进制 `server-043ad5bb0820ff9d.exe`、本地 HTTPS 代理、独立 TEMP/TMP 与停止文件；不改认证限额。数据位于 `tmp/re3-re4/mu-chromium-final`、`tmp/re3-re4/mu-webkit`，夹具在结束后正常停止。
