## 切换与恢复

候选目录为 `/opt/understand-book/releases/full-release-20261019`，旧版本为 `review-delivery-20261018`。切换时短暂进入维护状态，确认没有执行中或未保存的回答，再停止服务并用旧维护程序制作完整备份。新程序升级数据库后先检查本机接口，再开放新前端和服务。

数据库已升级时，旧程序不能直接读取新版本数据库。公开访问恢复前若失败，应将切换前备份恢复到独立目录，并让旧程序指向该目录。恢复公开访问后，不自动用旧备份覆盖可能新增的数据。

切换回执、静态资源比对和实际浏览器结果由发布过程写入同名服务器验收目录。公开浏览器检查覆盖工作区入口、共享目录、额度与费用汇总、桌面和手机宽度的阅读器，以及后台构建、共享发布和用量页。

- 后台构建执行宿主尚未配置 DSH 根会话和共享资料目录。网站入口、队列和费用接口可以发布，但上传后的后台构建尚不能视为已接通。
- 本次发布未重新运行付费模型质量实验。v13 保留自足规则，但之前第一轮的“必要机制”缺口仍有漏检证据，不能据此宣称已解决。
- 冷备份为释放服务器空间压缩归档，归档前后逐文件比较内容；当前版本及最近恢复点保留。构建使用的临时交换文件在发布准备完成后移除。
- `tmp/`、私人凭据、缓存、构建产物和大量原始实验材料留在本地。部分历史报告引用这些本地证据，单独克隆仓库不能重现全部历史现场。
