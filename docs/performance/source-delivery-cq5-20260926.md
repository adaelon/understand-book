# CQ5 原文驱动来源定位验收 — 2026-09-26

## 结论

`source.present({quote})` 已实现，Agent 提交连续原文，工具在本轮已观察范围中确定位置并生成来源绑定。原来必填的 `start_lid`、可选 `end_lid` 已从工具接口移除。确定性回归、实际入模合同和 Reader 交付通过；三次自然请求全部完整交付。来源支持与定位充分性的正式语义评分仍为 `calibration_not_reviewed`。

## 实现与合同

- `TurnEvidenceLedger` 合并重叠/相邻观察区间；重复读到同一位置不增加歧义。只有实际观察范围参与匹配，工具不会搜索全书后擅自授予已读身份。
- `Book::match_source_quote` 精确匹配原文，计算跨 LID、公式节点及 UTF-16 范围。首尾空白忽略，CRLF/CR/LF 按边界映射归一；标点、公式、内部空白及段落结构保持原样。
- 一个位置命中即绑定；多个位置返回 `SOURCE_AMBIGUOUS` 和最多四条已读上下文，提示扩充引文。无匹配返回 `SOURCE_NOT_OBSERVED`，提示先核对已有正文，所需内容确实未读时才补读。
- 来源策略 v8 和工具 description 共用 `SOURCE_PRESENT_CONTRACT`；工具注册路由提示同步。Agent 仍负责选择足以支持完整论断的文字，工具负责位置。
- 新跨节点引用保留原书的节点间换行。历史显式 ranges 的保存摘要若对应旧的无间隔拼接，则按该摘要返回旧文字；已有来源不因本次换行修正而变 stale。该分支只在旧摘要与新拼接不一致时使用，不改写历史绑定。
