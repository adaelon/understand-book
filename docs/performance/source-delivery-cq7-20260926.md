## 实施

回答 Agent 的来源策略 v10 新增四组正反例：复合论断合用多个来源、具体规则补交原文、充分来源不重复堆叠、总结沿用清楚的前文引用。示例采用保存条件、任务调度和备份场景，不包含 target-l4 的书内答案；仅在来源策略注入一次，工具说明不重复示例。完整连续句子的 `source.present` 示例说明相邻事实应合并选取，开头和结尾新增的事实也须有依据。

通用收尾策略 v6 限定否定声明的范围：局部阅读不能推出全书没有讨论某事；迁移题直接说明将原文原则应用到题设；只在必要时说明实际已读材料的缺口。增加“每天备份原则应用到 08:00”的错误结尾/正确结尾示范，明确用户要求证据不足时说明，不等于要求机械追加证据边界段。该策略在没有阅读或来源工具时也会注入。

`Book::match_source_quote` 优先返回精确匹配；没有精确命中且引文含美元分隔符时，容忍成对 `$`/`$$` 内侧边界空白变化。归一后的索引映射回原书 UTF-16 范围，最终来源保留原书文字。公式内部字符、普通正文、已读范围和歧义规则保持原有约束。工具合同与无匹配错误同步说明新行为。
