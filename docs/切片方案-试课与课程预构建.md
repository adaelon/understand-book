# 试课与课程预构建

2026-11-19 · [ADR-0190](adr/0190-representative-lesson-before-course-design.md)

## 从一本书开始

委托人说“想把这本书做成课”，Agent 根据可读取的书源和章节结构选材。它向委托人说明为什么挑这段，随后交付可以打开的一节。只有书源或实际使用条件会改变选材时才先追问。若委托人已经给定课程路线并要求直接制作，构建从该路线开始。

## 实施切片

| 切片 | 用户路径与产物 | 验收依据 |
| --- | --- | --- |
| 1 · 制作并打开代表课 | Agent 从原文选择一个可以收束的问题，给出暂定起点、选材理由和来源。用户打开单课草稿，形成预测，取证，再独立解决变式。 | 构建只产出这一课。草稿和同书正式课各自可打开、暂停、恢复；来源能定位到当前书的确切版本。 |
| 2 · 根据试课修订 | 用户指出卡住的具体一步。Agent 对照题面、原文和实际帮助，说明修改理由，交付可重试的版本。 | 重开可定位反馈和对应课件，旧作答归原版本。问题属于某一题时，修改集中在该活动。 |
| 3 · 形成并选择路线 | Agent 结合试课提出受众、总问题、独立结课任务、所选章节和后续一两课。用户可接受、调整或暂缓。 | 暂缓后可接续；修改后的路线需要用户对本版的选择。接受时能指出下一次构建会制作哪些章节。 |
| 4 · 按选定路线扩建 | 引擎消费已采用的路线，沿原执行器生成课件、独立解题、核对来源、处理预算与发布。代表课目标、来源及核验依据适用时复用。 | 正式课程的范围和顺序可与所选章节逐项对应；不适用的样课重新制作；构建报告列出实际接纳内容。 |

## 学习与制作记录

阅读器按原有课程合同展示材料与问题，私人尝试保存用户看到的帮助和作答。修订记录关注题目所缺的条件、应替换的例子等可重新检查的事实。面向其他人的发布说明记录实际试学范围。用户在试课时说“太难”可以触发回看当时的任务；要调整全课起点，Agent 还需给出调整理由和具体的后续课程示例。

## 验证入口

按书源检查所选段落和新情境能否支撑题解；按[功能交付流程](../CONTRIBUTING.md)分别验证构建范围、本地存储归属和阅读器操作。实际参与试课的读者提供反馈后，再记录其使用的帮助、解释变化与独立作答。

## 本地使用

让制课 Agent 按[建课入口](../skills/build/SKILL.md#teach-one-trial-lesson)操作。给出一本已准备好的书就能开始。Agent 可以从现有结构选择段落，制作并独立审题，随后给出本地 Reader 的试课链接。修课后使用新链接回看新版，旧链接保留原题和原尝试。

在仓库复跑时，使用包含本次改动的 Build Engine、Reader 和 Web 构建。操作顺序及 JSON 字段由建课入口维护。查看试课进度时，先按书和版本读目录，再按该目录的尝试 ID 读学习现场。暂缓或修改路线后，从同一试课版本的 `course-trial state` 找回提案。用户采用某一版提案后，`--course --course-route` 将该版的章节顺序、受众、总问题和结课任务写入既有构建计划。

仓库的 Windows 引擎打包入口是 `node scripts/desktop/build-sidecar.mjs`。本次打包产物位于 `dist/build-engine/x86_64-pc-windows-msvc/`，使用目录内的可执行文件和配套资源。已用该程序读回试点的版本与路线状态。通过 DSH 根会话建课时，`ub_build_prepare_and_confirm` 接受 `build_course` 与 `course_route_path`，让用户沿原确认流程查看将制作的章节。[DSH 操作说明](../packages/dsh-plugin/README.md)

### 在 Windows 源码工作区重开试点

从仓库根目录运行以下命令，会从本机的试课进度继续。首次从源码准备 Reader 时先运行 `cargo build -p reader-service --bin reader` 和 `pnpm --filter @understand-book/web build`。Reader 会打印本次本机地址，在地址后加上 `/?course_book=justin-sun-z-library-sk-1lib-sk-z-lib-sk&trial=pilot-1`。

```powershell
$trialProfile = Join-Path $env:LOCALAPPDATA 'app.understandbook.local/course-trial-reader'
$env:UNDERSTAND_BOOK_MEMORY_DIR = Join-Path $trialProfile memory
$env:UNDERSTAND_BOOK_PRIVATE_DIR = Join-Path $trialProfile private
$env:UNDERSTAND_BOOK_ADDR = '127.0.0.1:0'
$env:UNDERSTAND_BOOK_LIBRARY_ROOT = (Resolve-Path .understand-book).Path
.\target\debug\reader.exe .understand-book/justin-sun-z-library-sk-1lib-sk-z-lib-sk
```

## 2026-11-19 实施记录

- **试点课件。** 选用了本地已有的孙宇晨《财富自由革命之路》作为试点。第 011 期的三个自然段（13.6–13.8）支撑“领了稿费，就算为钱让出了周末吗？”这一问题。读者比较两位译者的选择，再面对另一份有报酬的工作独立提问。独立审题发现，乙愿意免费翻译尚不足以判断他是否愿意按指定速度赶稿，讲解据此修订。预计 10 分钟，实际用时待试。[审题记录](evidence/course-trial-20261119/wealth-pilot/review.json)
- **制作与恢复。** [制课命令](../packages/core/src/course-trial.ts)保存单课修订、反馈、提案和决定；[阅读器](../crates/reader-service/src/local_course.rs)将草稿绑定到书和试课版本，沿原私人存储保存学习尝试。Rust 定向测试验证同一课时 ID 下，正式课和两版草稿的操作、重放和进度分别归属各自版本。
- **实际阅读。** 本机浏览器操作覆盖 1440 与 390 像素宽度下的进入、原文往返、暂停、刷新与续学。试课中的开放题可以在没有模型反馈时提交，并按课程合同结束本次体验。离线验收回执为 `completed`，开放题评价为 `unassessed`。[桌面首屏](evidence/course-trial-20261119/01-initial.png) · [手机恢复现场](evidence/course-trial-20261119/05-resumed-mobile.png) · [综合应用](evidence/course-trial-20261119/06-transfer-task.png) · [完成回执](evidence/course-trial-20261119/trial-completion.json)
- **正式扩建。** [课程构建器](../packages/core/src/course-build.ts)按已接受的真实章节标识生成单元计划。可复用的试课正文仍经独立解题和来源核验；不相符时走逐课制作。Windows 构建程序在隔离书库中执行安装、提案、暂缓、恢复、接受和生成计划，核对两个所选章节及其顺序。另用受控候选走通执行器与课件接纳。[隔离书库的计划回执](evidence/course-trial-20261119/packaged-course-route.json)

最终本地 Web 构建还走通了包含反思作答的完整试课。开始、预测、取证、反思、进入新情境、提交与结束共九次操作由真实服务接纳，刷新恢复到同一已结束的尝试。[浏览器操作回执](evidence/course-trial-20261119/trial-browser-steps.json) · [手机上的新情境任务](evidence/course-trial-20261119/06-transfer-task-mobile.png)

另在同一本书的隔离副本放入正式课件和试课草稿，两者采用同一课时 ID。在 Chromium 中分别输入不同的预测、暂停并再次打开，各自恢复了原题、原草稿和原尝试。正式目录与试课目录各有一条进度记录。[共存验证回执](evidence/course-trial-20261119/coexist-result.json) · [正式课恢复](evidence/course-trial-20261119/07-formal-resumed.png) · [代表课恢复](evidence/course-trial-20261119/08-trial-resumed.png)

### 复跑回归

从仓库根目录执行。课件构建与制课状态使用 `pnpm --filter @understand-book/core exec vitest run test/course-build.test.ts test/course-trial.test.ts`；私有进度与版本隔离使用 `cargo test -p reader-service --lib trial_courses_keep_versions_receipts_and_resumed_runs_separate`。本地入口使用 `pnpm --filter @understand-book/web exec vitest run src/App.learning-entry.test.ts`，本地前端使用 `pnpm --filter @understand-book/web build`。
