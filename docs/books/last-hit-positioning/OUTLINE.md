# 章节与写作范围

中心问题：面对一只将死的小兵，如何结合目标位置、对手位置和出手节奏，判断可选站位与行动时机？

| 章节 | 中心问题与承接 | 主要依据 |
| --- | --- | --- |
| 导读 | 从一次熟悉的补刀经历开始，约定图例和练习单位 | 上游研究对象；本书组织 |
| 1 为什么一补刀就挨打 | 把目标、对手和攻击时机放进同一个局面，建立距离概念 | 数学原理 §1–3 |
| 2 别只盯着一只残血兵 | 对手的目标如何确定朝向；为什么等射程也会出现不同机会 | 数学原理 §1、§12；solve_geometry |
| 3 往旁边挪一点会怎样 | 用范围交叠与候选线解释一段可站位置，比较三个代表点 | 数学原理 §3–7；Geo、reachI |
| 4 够不到时怎样换个办法 | 放宽施法参考条件、考虑技能、换方向；区别技能范围和命中 | 数学原理 §2、§6、§8；Skill |
| 5 对手刚出手能不能上前 | 反应、进场、前摇、回撤、继续退，以及追击后的距离 | 数学原理 §9；simulate_window |
| 6 手短也有自己的机会 | 同一角色参数下改变目标位置；辨认等待、技能和回撤路线 | 数学原理 §13；本书组合算例 |
| 7 把图上的判断带回对线 | 将局部距离判断纳入血量、技能和下一步站位；用回放形成观察习惯 | 数学原理 §14；标明性质的实践建议 |
| 附录 A 数学建模 | 变量、距离口径、全平面集合、切线区间、技能几何、时间与追击模型 | 上游数学原理与实现 |
| 附录 B 计算接口与案例 | 完整参数、调用方式、输出口径、可修改案例与数值解释 | 随书代码与实际计算 |
| 附录 C 模型与实战 | 集中交代小兵运动、伤害、技能、地形、计时和近似的适用范围 | 上游限制；本书计算条件 |
| 附录 D 可独立运行的参考实现 | 将核心代码作为书中原文收录，便于只拥有书籍正文的读者与 Agent 复算 | 固定上游核心的连续选段；独立运行示例 |
| 来源说明 | 原作与许可、版本、引文和附图出处 | 固定提交、MIT LICENSE |

覆盖关系：静态距离在第 1–4 章，动态时机在第 5 章，长短手案例在第 6 章，判断迁移在第 7 章。计算核心供附录使用，不按源码文件组织正文。

编辑原则：正文优先发展连续场景；需要数量关系时允许直接计算。附录承担完整建模及接口细节。每章充分讲清当前问题，再把未解决的具体问题交给下一章。
