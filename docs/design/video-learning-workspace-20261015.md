# 视频学习界面

## 使用路径

观看视频 → 对照当前字幕 → 框选画面或选择片段 → 在伴读中提问 → 回到视频继续观看。

视频伴读、双语对照、提问现场沿用现有领域定义。页面采用暖白底色、深色播放器和品牌陶土色强调，按观看、定位、提问组织操作。

## 实施步骤

- [x] 重排视频区域：材料标题、播放位置、紧邻画面的选择工具、当前双语字幕；转写支持搜索、语言显示和跟随播放。
- [x] 接入工作区：视频材料移除空书籍目录和文本进度，桌面保留伴读栏，手机正确切换视频与问答。
- [x] 验证并记录：组件回归检查播放器身份、框选与片段上下文、翻译接入；浏览器检查真实媒体和不同窗口尺寸。

## 验证依据

组件回归用于发现播放器重建、字幕跳转错误、问题绑定变化和译文接入后滚动位置丢失；失败时修正相应交互。生产构建用于发现类型或模板错误；失败时修正集成。浏览器检查用于发现画面或输入被挤出窗口、字幕跟随抢走用户滚动和移动端叠层；失败时调整布局或滚动行为。

## 实现与验证

`VideoReaderPane.vue` 保持播放器挂载，在同一组件内管理字幕搜索、语言显示、跟随与回看。宽视口把字幕放在视频旁，窄视口放在视频下方；`ReaderWorkspace.vue` 使用现有前景切换保留播放器和提问草稿。`TopBar.vue` 根据视频材料显示观看操作，`RightRail.vue` 使用视频伴读文案。

组件选择集 95 项通过，生产构建通过。真实 VI18 视频在 1440×900、1280×720、1024×768、390×844 下完成搜索、跳转、手动浏览、框选、片段选择、手机草稿保留和专注退出验证。[截图与结果](../performance/video-workspace-20261015/README.md)。
