# 阅读器加载动画

## 显示决策

**决策**：启动与工作区加载采用无文字翻页动画。

**命门**：入口 HTML 内嵌图形与样式，前端模块下载前即可显示；正式样式异步下载，就绪后再挂载 Vue，由现有加载状态接续。

**展开**：56px 书页图形，1.85 秒一轮，沿用阅读器纸色和珊瑚色；减少动态效果时显示静态书页。

## 加载流程

`入口 HTML 的静态占位 → 登录恢复 / 初始书架 → 工作区加载 → 可读正文`。

正文就绪立即移除动画；现有阅读工作区继续可用，历史与画像的后台加载不延长全屏等待。加载错误沿现有错误与登录入口处理。
