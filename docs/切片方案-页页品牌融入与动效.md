让读者在进入产品、接着阅读和发起问题时认得页页，在等待与完成时获得恰当反馈，同时保持正文、回答和操作的可用空间。设计类型为前端品牌与呈现调整，阅读接续、Resident／Tutor、教学事实和私人记忆沿现有归属。

## 2 视觉与页面合同

页页的识别来自圆润而清晰的轮廓、大头比例、奶油脸颊、稍带机灵的眼神和橙色书脊／书签。基础几何图形、轻微不对称和表情节奏承担趣味；页面留白、文字层级和操作位置保持稳定。现有主视觉继续使用已确认的 v7 造型。

| 色彩职责 | 基线 | 使用规则 |
| --- | --- | --- |
| 品牌强调 | 焙橙 `#B65A17` | 主操作、选中态、少量品牌线条；高饱和集中于小面积 |
| 纸张背景 | 沿现有 `#FAF9F5`／`#FBFAF7` 等暖纸色 | 正文和大面积底色；浅杏色只用于局部衬底 |
| 阅读文字 | 沿现有 `#141413`／`#252523`／`#3D3D3A` 等深色 | 正文、回答与主要说明保持清晰层级 |
| 交互派生色 | 从焙橙生成更深悬停色和浅色衬底 | 实际按钮、链接、焦点环连同背景一起验收 |
| 功能与内容颜色 | 沿既有错误、提示、高亮、引用及图解语义 | 首页示例的植物、图解数据等保留内容自身的配色 |

YY1 已增加共享品牌色文件 [brand.css](../packages/web/src/brand.css)，由阅读器和首页样式导入。现有 `--brand-green`、`--reader-coral`、`--focus-blue` 指向共同主色；`--brand-green-deep` 与用于小字的 `--accent` 指向深色 `#91420F`。浅色衬底为 `#F4E5D8`，悬停衬底为 `#ECD5C1`；阅读器的 `--reader-coral-soft` 保留 14% 透明混色，适用于正文上的定位覆盖层。品牌用途的硬编码和状态色已按实际用途调整，变量调用名称延续原有接口。

| 页面位置 | 形象与神态 | 版面与行为 |
| --- | --- | --- |
| 首页首屏情境 | 全身，机灵、友好，看向学习卡片 | 与原两张情境卡形成同一组插画；卡片内容及开始入口清晰可见 |
| 书架“接着上次读” | 全身抱书，欢迎继续 | 书名、真实读位与“继续阅读”优先；窄屏缩小或隐藏装饰 |
| 助手空态 | 全身，略带好奇 | “这一节，想先弄明白什么？”搭配既有示例问题与历史入口 |
| 正常问答 | 专用小头像，平静专注 | 放在助手标题／身份处；长回答、来源、学习操作和输入拥有主要空间 |
| 长等待 | 阅读姿态，随实际工作显示 | 翻页只是视觉反馈；阶段、失败、重试、停止由原状态文字与控件表达 |
| 任务完成 | 一次轻点头／短暂完成姿态 | 用现有身份或状态位表达，不新增遮挡回答的弹层 |
| 中央正文、专注阅读 | 安静呈现 | 正文不插入常驻动态形象；辅助区随现有专注布局收起 |
| 手机问答／演示讨论 | 空态全身、交谈小头像 | 保留当前输入、作答、键盘视口和返回阅读入口 |

尺寸以实际页面为准：首屏全身图可从约 220–300px、书架 120–160px、空态 128–160px、头像 24–32px 开始排版。全身与头像分别验收；空间不足优先保留内容与操作。图形不是操作控件时不进入键盘焦点；邻近文字已表达含义时将其作为装饰，真实状态沿现有可读文本提供。

语气温和、具体，轻微俏皮。例如“我们换个例子看看”“可以回到原文核对这一句”。用户困惑、执行失败或停止时采用专注／中性神态。对话文案不虚构“我记得你已经学会了”，完成文案明确说出哪个任务或结果已完成。

## 4 动效状态与生命周期

动效由页面事实派生。现有 Run、Goal、学习证据与阅读现场继续提供真实含义；动画不写入这些对象。

| 条件 | 视觉反应 | 结束或恢复 |
| --- | --- | --- |
| 可见欢迎／空态且无更重要状态 | 静态为主，偶尔眨眼一次 | 首轮从 12–20 秒静止间隔试排；不直接连续循环 4 秒样片 |
| 当前确实在等待，且持续超过短等待门槛 | 有插画空间时翻页；紧凑问答使用头像与原进度 | 首轮用约 1.2 秒门槛避免短操作闪动；结束、失败、停止即回静态 |
| 已有回答正在流式出现 | 平静头像与原进度 | 文字成为注意中心，保持头像安静 |
| 当前任务明确完成 | 一次完成反馈 | 播完回静态；普通回复结束不触发 |
| 失败、取消、断线重连或结果尚未保存 | 专注／中性静态图 | 原错误、恢复和停止入口继续工作 |
| 用户选择减少动态效果 | 静态图与完整状态文字 | 偏好变化即时生效 |
| 页面隐藏、宿主收起或角色离开可见区域 | 暂停播放与待机计时 | 回到可见时按当前事实恢复；旧完成事件不补播 |

以上间隔与尺寸是首轮调试值，页面验收可调整；角色定位、正文安静与真实状态含义是固定决策。单个可见页面只保留一个主要动画焦点，当前任务反馈优先于欢迎待机。紧凑头像默认静态；YY7 的 720ms 轻点头作用于头像容器，整只角色的 Lottie 不缩入头像框。

可见性必须包含宿主状态：`NetworkApp.vue` 当前通过 `v-show="!libraryOpen"` 隐藏已挂载的 `App`，仅靠卸载清理不能暂停它。由宿主传入当前阅读区域是否可见，结合现有辅助区／专注布局、页面可见性和角色是否在视口内决定播放；卸载时释放播放器、监听和计时器。恢复可见时不集中播放积压动作。

完成反馈首轮只绑定当前现场下的 `ResidentGoal` 完成，判定入口沿 `App.vue:finishResidentRun` 及其成功回读后的 `applyAgentHistory`，使用原 `id`、`revision` 和作用域：

```text
当次运行结果已保存，并回读到当前材料／聊天的任务事实
  → 比较本次现场内已有任务：open → completed
  → 任务有实际 result_refs，且当前反馈区域可见
  → 消费这次完成变化，播放一次

首次加载历史、切换聊天、恢复旧完成快照
  → 只建立当前事实基线，静态显示

同次完成重复回读、组件重挂载、先前隐藏期间完成
  → 不补播
```

这是一条保守的首轮呈现规则：单回合内新建并完成、未观察到 open 基线的任务可静态呈现完成事实。后续若要覆盖它，先确认原完成回执能直接关联当次任务，再扩展呈现入口。去重仅持有当前阅读作用域所需的短期状态，换材料／聊天即清理；新页面重建历史基线，不增加持久化庆祝记录。任务完成描述其交付结果，用户掌握仍以原学习证据为准。

## YY1 统一品牌色

## YY2 生产素材与静态组件

**输入**：v7 已确认形象和 §3 素材清单。

**产出与接点**：整理首批使用的图像至生产资源目录；制作同角色的专用头像；新增 `YeyeMascot.vue` 与 `yeye-assets.ts` 的静态部分。保留美术来源，按实际显示尺寸整理生产图像。
