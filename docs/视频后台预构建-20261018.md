## 行为与范围

同日默认策略补充：新计划默认关闭 Pass2 跨段关系复核，明确选择开启才纳入。后台材料、DSH 工具、底层 V1/V2/V3 计划编译、旧命令入口和论文投影采用同一默认值；已确认计划恢复时使用原已保存范围。Pass2 与额外 Tutor 材料分别选择，视频原讲解结构继续保留。

运营人员在后台选择本地视频、成果目录、可使用账号和平台预算后，提交一次即可进入构建队列。纯视频新资料不再需要先准备书籍计划再确认；包含新书籍的混合任务继续展示原书籍计划供确认。已有成果沿原入口复用。

默认准备字幕、中文译文、视觉索引、知识关系和原视频讲解结构，跳过额外 Tutor 教学资产。原材料的讲解结构保留，读时 Tutor 与预生成正式教学资产分别表达。书籍后台构建默认关闭正式对象、认知材料和教学发布阶段，保留原文理解和 BookStructure；需要时明确选择生成教学资产。

后台任务仍归 B1，视频执行复用原 Build Engine 和视频各阶段的接纳、恢复、发布机制。DSH 运营宿主从实际 Engine 进程接收进度并持久写回任务；进度来自复制字节、完成音频块和接纳语义单元，不按等待时间增长。尚无法得知总量的阶段显示正在处理，不伪造百分比。

每个实际外部执行先进入 Q3 平台父预算准入，回执沿原 Q2/Q3 账本和 Q5 汇总保存。重复读取进度、恢复已经接纳的成果和共享使用不会启动新执行。预算不足阻止后续外部执行；失败、暂停、宿主重启和回执重传保留已发生的费用事实。供应商未提供完整金额的记录继续占用待核算预算，不以 token 推算成已确认账单。

## 验收场景

- 新 MP4 在一次后台提交后实际执行，无书籍解析误路由，无额外 Tutor 生成；原书籍默认策略保持基础理解可用。
- 进度从磁盘和阶段回执读取：阶段计数与原成果一致，未完成阶段不显示整体完成。
- 暂停后继续、宿主重建和重复回执均沿同一任务、工作目录、已接纳产物；完成单元不重复生成或计费。
- 平台预算不足时外部执行不启动；提高预算后继续原任务，原待核算费用仍占用预算。
- 部分回执、未知结果、发送前失败和正式费用补记分别进入原账本；账号没有被扣减公共构建费用。
- 最终通过原导入器和共享发布，个人实例可以实际读取视频；复用成果不增加构建费用。

## 结果与证据

已完成的真实链路使用新编译 Engine、8 秒真实 MP4、本地 small.en 语音识别、原媒体工具、受控 Codex 执行器、Rust HTTP 服务和账本。生成视频来源理解的四次实际外部执行分别为翻译、视觉、图谱和讲解结构；4 份部分回执保持待核算，公共任务归平台，账号扣减为 0。一次预算不足发生在下一次外部启动前；提额后沿原任务继续，已接纳转写和翻译内容保持不变。

中间不可变快照写入构建专用暂存发布库，最终成果通过在线服务导入。在线服务独占其写入锁，构建发布器不直接打开该库。构建计划、草稿和任务进度不承载登录凭据。配置见 `packages/dsh-plugin/README.md` 的运营视频段落。

最终媒体 Range 请求返回 206 和 32 字节，原文与译文各 2 段；移走暂存库后仍能读取。最终编译程序继续已完成任务回传 8 条进度，新增外部执行为 0，原已接纳内容和预算均保持。不同运营任务共享输出根目录时，各自工作目录包含任务身份；同名资料的外部调用身份也包含父任务与完整目录。错误地把另一原始 MP4 放入已有转写任务会被拒绝，原成果保持不变。

## 已知限制

- 本轮没有外部付费模型调用。语义阶段使用实际原生 MCP 协议和原候选接纳机制，但输出来自受控执行器；本轮验证执行、恢复、费用归属和发布，不评价模型理解质量。
- Codex CLI 返回部分 token 观察而非完整供应商金额，已发生费用不能按 0 结算；保留待核算占用，后续回执沿原账本补记。预算约束在每次外部启动前生效，当前执行器不声明单次内部硬预算能力。
- 运营构建需要连接的 DSH 宿主、可访问的本地输入、Engine/Codex/发布器及媒体工具；部署配置见 `packages/dsh-plugin/README.md`。构建暂存发布库不能配置成正在运行的 Reader 服务根目录。
- B2 个人资料准备、跨资料取帧/原声、E1/E2 及真实供应商金额能力继续沿原切片推进，V1 保持部分完成。Control schema18、learning schema3 不变。
