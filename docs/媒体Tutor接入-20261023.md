# 视频与音乐的目标及连续教学接入

日期：2026-10-23。

验收结论：视频与音乐均已通过真实页面的目标保存、Tutor 开启、两轮连续教学、原媒体操作、来源解析和服务重启恢复；两轮讲解另外依据原材料完成内容复核。云端正式服务尚未切换。

## 行为与范围

视频和音乐可选择学习目的、保存自定义目标，并明确开启 Tutor 开始连续教学。保存目标不启动模型；“先了解重点”沿普通概览处理。连续教学采用当前资料的实际就绪状态，缺项显示具体原因。

视频以完整转写、时间定位、原片和全片原讲解结构作为起步基础；音乐沿谱面、音乐事件和作品结构准入。额外 TeachingMap、正式对象和认知素材保持可选。已有完整 CS336 发布可直接使用，不补造书籍 sidecar，也不改写原发布。

整份材料与当前片段分别保存学习范围。片段冻结视频帧、时间、框选或音乐录音、谱位与声部；继续原回答时沿原定位接续，不采用后来播放器的位置。切换明确范围会建立相应阶段。

## 实现入口

- `packages/web/src/App.vue`、`learning-purpose.ts` 及目标组件：媒体目的、真实媒体输入、自定义目标的保存与开始动作、就绪原因和媒体措辞。明确开始教学时，把刚确认的当前学习目标原文放入本次请求，使教学与审核引用同一请求；后续用户提问仍保留其原文。
- `crates/server/src/tutor_api.rs`、`workspace_publication.rs`：原生视频和音乐就绪判断、已有发布的实时 Tutor 能力。
- `crates/server/src/interaction_input.rs`、`video_draft.rs`、`lib.rs`：无需正文 LID 的媒体入口、冻结现场和回答接续。
- `crates/server/src/teaching.rs`、`teaching/continuity.rs`：本轮已读来源绑定教学目标，跨轮保持来源和音频复核范围。
- `crates/server/src/teaching_coach.rs`：教练使用冻结媒体定位与实际上一轮反馈；图片留给实际观察通道，不把 base64 当正文重复发送。
- `crates/runtime/src/tutor_coach.rs`、`lib.rs`：首次教练正文不是合法 JSON，或未通过结构／指导合同校验时，携同一冻结输入、原始公开正文和校验错误向同一模型请求一次修正；再次无效按既有 `failed/unavailable` 路径继续提供帮助。两次调用分别观察并计量，保持一次宿主任务尝试；传输、取消、输出截断和预算中止沿原路径返回。`reason` 的合法字段路径在提示中明确，指导合同不变。
- `crates/runtime/src/orchestrator.rs`、`video.rs`：教学独立审核获得冻结视频现场和教学所依赖的实际原帧／裁剪；只读取本轮已观察来源，无法重取原帧时明确拒绝审核，不以定位文本代替图像。
- `crates/runtime/src/tutor.rs`、`crates/server/src/teaching.rs`：意图来源按本轮真实上下文提供。保存目标不等于设置默认教学方式；没有默认方式时使用 `neutral/neutral` 也能围绕目标讲解。字段不一致分别给出具体修复信息。
- `crates/runtime/src/orchestrator.rs`：同一无进展阶段首次出现工具参数校验错误时，保留一次读取该反馈并修正的机会；重复参数错误、轮数和 token 预算仍按原边界停止。
- `crates/runtime/src/tutor.rs`、`tutor_coach.rs`：教学审核及阶段规划复用项目已有的 DeepSeek `reasoning_effort=low` 请求策略，保留 32768／8192 输出预算、来源证据与判断合同。此前实测中默认推理多次耗尽输出额度，未能返回完整判定；[DeepSeek 官方文档](https://api-docs.deepseek.com/guides/thinking_mode/)说明默认强度为 high，支持显式 low。
- `crates/runtime/src/tutor.rs`、`orchestrator.rs`：失败审核保留 Provider 已报告的用量，在映射原错误前计入本轮统计；未知用量保持未知，成功或失败重试都只累计各自一次。
- `crates/runtime/src/music.rs`、`tutor_review_rules.md`：音乐角色讲解依据当前片段的实际进入、节奏与音符关系；旋律可以重复音，伴奏也可以改变音高，不能把“每个音都变／不变”当作角色判据。审核 v27 同时核对重复单位、发声计数和播放区间的小节边界；初学者窄听辨只引入当前关系所需的记谱细节，矛盾句直接修正。
- `crates/memory/src/assessment.rs`、`crates/server/src/teaching/assessment_sources.rs`、`crates/runtime/src/tutor_assessment.rs`：媒体活动冻结真实评分来源；视觉开放评分读取原帧和裁剪。旧文本活动继续使用原精确引文合同。
- `packages/web/src/components/UnderstandingSpace.vue`：呈现文本引文与画面观察反馈。

## 已知边界

当前证据来自独立本地验收服务；线上 `understand-book-multi` 尚未切换。Windows 0.3.7 承载云端 Reader，正式生效需要发布同版 Linux 服务和多用户 Web，不能通过替换 Windows server.exe 完成。多用户 Web 构建已经通过（`web-multi-final-build.log`），这不代表 Linux 发布或线上验收完成。

当前模型链路仍有明显等待：本次视频每轮约 1.8–2.7 分钟，音乐约 5.2–5.4 分钟。原始模型记录中收尾中止的后台请求可能没有 usage，精简报告保留未知项，不把已知 token 下界当作完整费用。

准备未完成的材料可以保存目标；连续教学等待该材料所需的真实产物就绪。音乐谱面和分析资料不代表模型已经听过录音，浏览器播放回执只证明播放器执行。模拟学习者表达的联测用于验证软件与教学接续，不作为真人学习成效结论。
