3. **短补学返回（已实现并验证）**：围绕真实卡点给出短支撑，保留原题与草稿，返回后由新表达更新判断；浏览帮助不升级理解。
4. **提问与探索（已实现并验证）**：保留原问题，按需帮助明确情境、疑惑和验证目标；问题影响课程反馈与补学，允许回看和接续。提问反馈从原话直接进入帮助，省去推测提问者观点的二次转述。

## 设计约定

默认展示本次变化、已有表现和一个相关下一步。疑问、具体困难与缺少证据分别表述；独立应用尚未观察不撤销已经说清楚的理解。主题和关键问题来自既有课件与知识结构，学习状态来自同工作区同来源版本的真实证据，不用记录数量代替掌握。

资源下界课程的短补学按两条必要约束解释：总耗时至少为 `F/C`，也至少为 `R/W`，因此至少为两者较大值。`F/C`、`R/W` 不是实际执行中的完成时刻，不能据此编造逐毫秒硬件过程。先前的猜测、教师提供的帮助与新表达分别归属。
