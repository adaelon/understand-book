# 视频提问图片

## 决策

视频框选直接截取浏览器已显示的像素，作为问题图片显示在发送框；视频提问同时支持粘贴、上传、复制和移除一张图片。图片随冻结提问现场保存，发送失败保留，确认接收后清除。上传图片属于用户输入，不自动成为原视频的已验证来源。

## 实施与验收

- [ ] 框选截图、预览和草稿保存；覆盖贴边裁剪、播放后保持截图、发送失败保留。
- [ ] 问题图片进入首轮及后续模型请求；原视频工具不再是理解附件的前置条件。
- [ ] 粘贴、上传、复制、移除和历史预览；真实浏览器验证像素链路。
- [ ] 重新构建桌面版，打开窗口并验证新界面。
