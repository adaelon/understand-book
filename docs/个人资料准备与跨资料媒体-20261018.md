# B2 个人资料准备与 V1 跨资料媒体

日期：2026-10-18。对应[统一切片](切片方案-目标工作区与统一Agent额度.md)的 B2、V1。本轮延续 W1–W6、Q1–Q5、S1–S2、B1 和原视频工作区整合，默认关闭 Pass2，不额外预构建 Tutor 材料。

## 已实现行为

用户在学习工作区选择 EPUB、Markdown、文本或 MP4。上传按实际字节显示进度；资料准备任务固定绑定发起账号、学习工作区和上传来源。切到另一个工作区不改变归属，准备完成后由导入事务把确切成果加入原工作区，用户可以继续阅读。个人成果只授权给本人，个人任务不能经运营共享发布按钮直接转为共享发布。

已有可读成果可以直接引用，无模型调用、无新增构建费。同一上传重新请求创建时返回原任务；只修改大目标也不重建资料。完成、暂停、等待方案、等待确认等状态来自服务端，其他资料仍可正常使用。

书籍先生成实际 Build Engine 计划，再展示可估算部分的额度范围。尚缺估算依据的阶段明确保留未知状态。用户用百分比确认总上限与当前额度期，单次模型调用前按上下文估计量和输出上限预占，结束后按供应商用量与配置费率结算。额度不足会阻止下一次调用；补充额度或提高任务上限后，需要明确继续，已接纳单元沿原执行身份复用。

个人视频沿原视频导入和本地 Whisper 路径准备转写、播放和原文问答，模型额度预计为 0%。语义翻译、视觉索引、图谱和原讲解结构仍可由已有运营预构建及共享成果提供。视频原始画面和原声可以在学习中按需读取。

同一工作区的 Agent 可从书籍聊天中使用 `video.search`、`video.read_frames`、`video.review_audio` 读取另一份视频，显式提供 `published_book_ref`。省略时仍使用当前资料。检索和派生读取提示携带确切资料版本；返回的转写证据记入对应参考资料的证据记录。图片在成功送达主模型后才构成观察，音频由本地 Whisper 复核，结果保留不确定性，不声称主模型听过音频，不改写已保存转写。

## 接口与归属

- `GET /api/learning-workspaces/:id/preparations`：读取本人在该工作区的准备任务、估算、当前额度期、按原额度期分组的使用与待核算百分比。
- `POST` 同一路径：`upload/create/prepare/start/continue/pause`。上传块为 32 KiB，适配既有 64 KiB 请求限制；偏移、总长度和重复块内容直接比较。操作回执沿既有表保存，创建和状态迁移都在事务中完成。
- `start/continue` 接收 `period_id`、`max_milli_percent`、任务版本与操作标识。确认额度期变化、余额不足或任务版本过期会返回明确失败，保留原结果。
- `operator_builds` 既有任务 JSON 新增可空的 `user_id/learning_workspace_id/confirmed_period_id`，运营任务沿原平台路径。任务输出目录按账号、工作区、任务隔离，控制库 schema 仍为 18。
- 用户接口省略宿主目录、连接凭据和内部金额。后台继续保留原成本账本与调用证据。

代码入口：`crates/server/src/personal_preparations.rs`、`operator_builds.rs`；`packages/web/src/personal-preparations.ts`、`components/PersonalPreparations.vue`；`packages/dsh-plugin/src/operator-build-host.ts`。

## 逐次调用计量

新增 `ExternalBuildCostBinding.metering = provider_calls_v1`，适用于实际安装了逐次模型边界的 DSH 路径。旧 DSH 执行总额观察和 Codex CLI 仍保留原部分回执能力；此扩展不改变其能力声明。

1. 原生 DSH 的 `llm/stream` 边界在每次到达供应商之前调用 `metered-admit`，传递模型、上下文估计量和输出上限。传输重试再次经过该边界，具有独立实际调用身份；账本不接收完整模型输入。
2. 服务端选择当前配置费率，冻结费率快照，在原 Q3 事务内检查父预算、账号余额、原工作区及确认额度期。每个执行采用 `calls` 层级，不再提交一份执行总额。
3. DSH 的 `inputTokens` 是未缓存输入，和 `cacheReadTokens/cacheWriteTokens` 分开计数。适配后恢复总输入、缓存输入、输出与总量，服务端检查一致性再按冻结费率结算。
4. 无回执、缓存细分缺失或不可用用量保留待核算，不能补零当作精确费用。回执先落本地，再提交，离线恢复重传原回执；准入拒绝不消耗语义重试。
5. 全部实际成本保留，用户累计扣减受已确认任务上限封顶，差额由平台承担。迟到回执仍归原额度期；历史使用按原期基准分别展示，不用当前基准重算。

服务端端点为管理员宿主使用的 `POST /api/admin/build-tasks/:task/metered-admit` 与 `metered-receipts`，复用 `build_task_budgets/model_call_charges/external_build_calls`。已配置的 DSH provider 路由名和 model 必须与 `model-rates.json` 中的条目匹配；不可用或过期费率阻止个人付费启动。具体数值由运营配置，本轮没有写入商业价格。

## 跨资料媒体

`library.list` 返回可用视频的明确媒体身份与时长。`NetworkRunPort` 从本次运行冻结的成员集和当前账号授权加载目标资料，不切换阅读现场。长耗时媒体处理返回前再次检查授权。`library.read`、视频检索和原讲解关系中的读取提示都保留原资料版本。

`source.present` 使用目标资料的原文指纹与该资料已观察的文本范围校验，视觉/音频观察继续匹配确切发布、原始时段及画面区域。媒体来源保存后可供已有来源弹窗和私人理解引用；不会把参考视频的 LID 当作当前书籍的 LID。

E1联合验收补齐纯画面/原声的私人理解保存：`TeachingTarget.media_bindings`直接保存已绑定来源的媒体目标，纯媒体不补造文字行号。旧文字目标继续读取，普通Tutor输入合同保留；来源更新后的回读见[E1记录](联合验收-工作区与统一额度-20261018.md)。

代码入口：`runtime/src/{video,video_audio,run_context,orchestrator}.rs`、`server/src/{cross_book,workspace_registry,video_frames,agent_run}.rs`。本地单资料阅读仍受原发布身份约束。

## 已知限制

- 本轮使用受控语义模型验证原生执行协议和费用合同，没有调用真实付费供应商。生产部署、正式商业费率、真实模型自由学习行为及联合发布验收仍由 E1/E2 承接。
- 个人视频当前是本地转写与原文阅读准备。现有 Codex CLI 语义构建只有部分用量，完整语义预构建继续由平台承担费用；不能借此向个人声称完成精确扣费。
- 原始 PDF 需要现有工作台先完成来源对齐；本轮个人上传入口不接受原始 PDF。已准备好的 PDF 发布成果仍可按原授权加入工作区。
- 服务端和构建宿主需要共享受控资料目录，且已连接 DSH 根会话与新编译 Engine；个人视频需要 FFmpeg 和本地 Whisper。没有在用户生产环境部署这些配置。
- 付款仍沿 Q4 人工确认到账流程；本轮没有增加自动支付。
