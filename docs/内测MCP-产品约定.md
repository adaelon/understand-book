# 内测 MCP 产品约定

状态：产品范围、免费额度与预付调用包已确认；MCP1 凭证、MCP2 材料读取、MCP3 免费次数、MCP4 付费包、MCP5 远程协议与 MCP6 Agent 使用信息已实现，MCP7 读者界面和 MCP8 后台次数管理已实现，MCP9 集成与新 Agent 验收已完成，发布沿 MCP10。更新时间：2026-10-11。

决策见 [ADR-0162](adr/0162-beta-remote-mcp-and-prepaid-call-credits.md)，实施顺序与验收见[切片方案](切片方案-内测MCP与调用额度.md)。

内测用户将 Understand Book 接入自己使用的 Agent 后，由 Agent 发现获准材料、检索和读取原文，并依据来源完成回答。网站提供接入入口与必要的账号操作；工具的选择、参数使用、来源解释和额度状态应能由 Agent 自行理解。

## §1 使用资格

**决策**：仅内测用户可调用网站 MCP。
**否决**：
- 免内测码注册领取额度：不符合首版内测范围。
- 匿名调用内容工具：无法沿用已确认的内测账号资格。
**命门**：复用现有账号和材料授权；免费额度不扩大材料访问范围。
**展开**：[内测注册与账号](adr/0159-email-accounts-and-single-use-beta-invites.md)。

## §2 首版能力

**决策**：免费 MCP 提供已构建材料的检索与读取。
**否决**：
- 纳入服务端代答、综合和带读：会额外消耗托管模型费用。
- 纳入材料构建：前期构建成本与资料读取成本不同。
**命门**：用户自己的 Agent 负责推理与回答，来源随读取结果提供。
**展开**：[现有书籍工具合同](../crates/book-tool-contracts/src/lib.rs)、[现有 MCP 分发](../crates/server/src/mcp.rs)。

## §3 免费额度

**决策**：MCP 免费额度按调用次数单独计量。
**否决**：
- 使用托管模型费用余额表示读取次数：两者的计量单位与成本含义不同。
- 将免费 MCP 权益等同于免费托管 AI：超出已确认的服务范围。
**命门**：额度归属内测账号，各 Agent 客户端的使用汇总到同一账号。
**展开**：[现有账号使用额度](adr/0156-reader-admin-and-account-allowance.md)。

## §4 Agent 使用体验

**决策**：Agent 接入后可自主发现并使用内容工具。
**否决**：
- 要求人类逐项学习工具再教给 Agent：增加目标人群的使用负担。
- 工具仅提供名称和参数类型：不足以说明何时调用、如何引用与如何处理额度状态。
**命门**：工具描述与返回结果应提供完成下一步所需的信息。
**展开**：[工具与 Agent 使用合同](切片方案-内测MCP与调用额度.md#7-agent-与界面合同)。

## §5 预付调用包

**决策**：10 元购买 1,000 次，12 个月有效。
**否决**：
- 超额后累计欠费：用户难以预先控制 Agent 的使用支出。
- 已购次数随免费额度按月清零：不符合调用包权益。
**命门**：免费次数优先，之后使用有效已购次数；全部用完才停止内容调用。
**展开**：[购包与收款合同](切片方案-内测MCP与调用额度.md#6-收款与次数持久化)。

## 免费额度参数

| 项目 | 规则 |
| --- | --- |
| 免费额度 | 每个内测账号每自然月 1,000 次 |
| 重置时间 | 每月 1 日香港时间 00:00；未使用免费次数不累计 |
| 首次开通 | 立即获得完整的当月免费额度 |
| 客户端归属 | 同一账号的所有 Agent 客户端共用额度 |
| 每日额度 | 首版不另设每日次数额度 |
| 免费次数耗尽 | 使用有效的已购次数；全部用完后告知恢复时间和购买入口 |

服务端成功执行一次内容工具计一次，包括检索、原文读取、概念关系和章节结构查询。检索成功但结果为空也计一次。分页读取每一页计一次，重新发起并成功执行的调用计为新的一次。

接入、工具发现、查看可读材料目录和查询额度不计次。参数错误、权限拒绝、额度不足及服务器执行失败不计次。

远程原文读取以每页最多 8,000 个字符作为内测初始上限，超出范围分页提供，保留准确来源位置和继续读取入口。额度状态随内容结果返回，包含免费和已购剩余次数、免费恢复时间及调用包到期信息；全部耗尽时明确提示停止重试。

内测运行两周后，根据真实阅读任务的调用量、额度耗尽反馈与服务器负载调整额度。正常阅读经常耗尽且服务负载允许时增加额度；重复查找造成消耗时改善工具使用体验；大请求拖慢服务时调整单次返回范围和并发处理。

## 调用包参数

| 项目 | 规则 |
| --- | --- |
| 售价 | 每包 10 元，包含 1,000 次额外内容调用，可重复购买 |
| 有效期 | 确认收款并开通后 12 个月；有效期内跨月保留 |
| 使用顺序 | 免费次数优先，其次使用最早到期的有效调用包 |
| 购买方式 | 用户付款，管理员通过现有人工收款流程确认并开通 |
| 账号权益 | 购买只增加次数，内测资格与材料授权分别判定 |
| 价格调整 | 后续销售可调整，已购包按购买时约定使用 |

例如本月免费次数耗尽后，购买 1,000 次并使用 500 次，下月获得新的 1,000 次免费额度，已购剩余 500 次继续保留。新月份仍优先使用免费次数。

## 目标使用路径

内测用户取得接入入口 → 在客户端完成必要授权 → Agent 发现可访问材料 → 检索定位 → 读取原文与相关结构 → 带来源回答。

Agent 应能识别免费与付费剩余次数、恢复或到期时间，以及请求失败后是否适合重试。材料标识和原文定位从工具返回中获取；引用应能指回对应材料的具体原文。购买由用户完成，Agent 提供购买说明入口。

完成体验的判据是：一个没有本项目对话背景的 Agent，在用户完成必要授权后，能够仅凭接入说明、工具描述和返回结果完成上述路径；遇到额度用尽或材料无权访问时，能够向用户准确说明下一步。
