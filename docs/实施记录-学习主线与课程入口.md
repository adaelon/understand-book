## 讲后三图对照 · 普通阅读

在普通文本书里打开一条带有本书出处的讲解，点「我来解释一下」，在聊天输入框直接写下自己的理解。提交前可以取消与原回答的绑定。反馈中同时展开「书中推理」和「本次表达」两张图。点击焦点编号、节点或连线，两侧一起高亮，图下方显示这个焦点的判断。书中引句可跳回原段，读者引句可定位到当时的表达。想先收起资料独立练习，可选「练到会」。想把刚讲的关系用在新情境，可选「给我一道应用题」。

真实模型复验使用仓库的 AI Infra 书和既有模型配置。先执行 `cargo build -p reader-service --bin reader`，再执行 `node scripts/verify-teach-back.mjs --out docs/evidence/teach-back-YYYYMMDD/attempt-1`。每次使用新目录。脚本保存原讲解、逐次模型输入与响应、所选书句、结构化反馈和隔离的 Reader 存储。加 `--browser` 可从实际页面提交并观察卡片，阶段耗时以 `provider.json` 的请求记录为准。

选中一处焦点，先核对书中引句和自己的原话。若原话的意思被读反，点「你把我听反了」，指出被误读的部分。系统按首次原话重新解读，保留当时的帮助条件。若看过对照后有了新理由，点「改一下我的想法」，也可以直接在聊天主输入框回答卡片的追问。新表达单独占一个回合，可在卡片顶部切回「首次表达」，查看当时的关系、引句和帮助。换了书源版本仍可读保存的引句。

### 切片 3 · 课内解释、本机 ACP 与闭卷变式

正式文本课进入「我来解释」后，在「把观察变成自己的解释」中直接提交原话。原活动反馈显示书中推理、学生表达和对应关系。可以选行核对引句、纠正解读，也可以回答卡片的追问。刷新或重开原课后可回看各轮表达。多轮课收到反思后，由读者点「继续下一轮探究」推进。闭卷结果交回原课时，仍由原课检查是否满足本轮任务。

## 集成时发现并修复

1. 首次没有聊天的用户无法保存课程接续。显式开课先建立原私人聊天，再交付课程；后续练习和恢复复用它。
2. 空闭卷结果解包：合法 `result: null` 被错误替换为工作区 envelope，导致页面渲染异常。通用客户端改为按字段是否存在解包；没有增加播放器重挂或兼容层。
3. 手机课程前景：已恢复原课程却被最后一次聊天前景切换遮住。课程接续现在显示当前课程任务，闭卷和对话显示相应原现场。
4. 返回首页的显示归属：多根 App 使父级隐藏指令失效。恢复单根，闭卷沿原 Teleport 展示，隐藏阅读现场时同时收起弹层且保留原状态。
