# 前端体验改进 · 2026-10-11

完成七处阅读界面调整，延续现有暖纸风格，让内容、下一步操作和状态变化更容易理解。

## 已完成

| 页面 | 改动 | 保留的行为 |
| --- | --- | --- |
| 书库 | 从论文元数据、导入标题或原文一级标题读取材料名称；本地选书改为缩略封面列表；路径收进详情；同名材料显示目录名称辅助区分 | 打开仍使用原目录或发布引用，网络书架保留版本标识 |
| 目标成果 | 概念、步骤和章节直接展示标题与正文；常用字段使用中文名称；关系方向适应横向和纵向布局；空状态说明来源并提供已有准备入口 | 五种通用形态与四种既有视图、逐条来源引用、待准备与刷新状态 |
| 分享图 | 打开自动生成；编辑后等待 250 毫秒自动更新；生成期间保留旧图并暂停下载；手机预览按钮定位到图片 | 草稿内容、回答节选、分页、失败重试、保存取消与离开场景清理 |
| 画像 | 以“助手记住了什么”呈现；使用“这本书 / 所有书籍”；纠正和忘记显示文字；整理旧对话与同步详情下移 | 纠正、确认、改变范围、停止收集、忘记和历史整理操作 |
| 使用额度 | 突出本期可用、已用与到期时间；计算过程放入详情；有预留或待核算金额时显示说明 | 原金额精度、全部额度期明细、分页、身份切换与失败重试 |
| 阅读准备 | 三种方式说明实际结果；优先展示预计时间、范围与可获得的内容；估算和结构细节按需展开 | 原方案预览、修改、放弃与按当前方案确认的流程 |
| 桌面设置 | 以“AI 服务连接”命名；先显示服务地址、模型名称与密钥；工具调用模式进入高级选项并说明适用情形 | 原连接参数、空密钥保留语义与保存命令 |

## 验证

- 前端相关测试共 154 项通过：成果 8、分享 8、画像 4、额度 5、阅读准备 6、书架接续 5、应用启动与交互 65、阅读侧栏 50、桌面连接 2、标题回退 1。
- 后端标题提取与书库接口投影检查 2 项通过，覆盖名称优先级、缺失回退以及目录和材料身份不变。
- 前端类型检查与生产构建通过。
- 实际浏览器检查桌面 1280 × 720 和手机 390 × 844：完整长书名、空成果准备入口、分享自动更新、手机预览定位、画像纠正、额度详情和桌面高级设置。
- 分享检查确认：连续输入合并更新，旧结果晚到不会覆盖新图，下载接收最新预览的同一个图片对象，关闭后不再启动定时生成。

## 验证范围与已知限制

书库和阅读准备使用本地服务及演示材料；成果、画像、额度、分享使用实际组件和固定样例数据。桌面设置的界面检查使用命令桥接替身，测试验证了保存参数，未进行 Windows 安装包回归。

缺少元数据、导入标题和原文一级标题的材料，仍使用可读的目录名称或材料 ID。标题读取只取原文开头 16 KiB，避免为列书库读取整本书。构建保留现有 PDF 模块导入与大包体积提示，未阻止构建。
