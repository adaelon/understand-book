# 零基础教学默认

日期：2026-10-28。范围：当前工作树中的阅读 Agent、Tutor、教学与表达教练、讲解审核和画像抽取。

## 决策

默认用户对当前知识点没有已确认的前置理解，根据真实表达和当前明确要求调整支撑。未知保持未知；教学默认不写成用户能力、误解或掌握记录。用户直接提问可以沿用该术语，当前答案仍应给足理解它所需的含义；用户明确要求深入时直接深入。

共同指令以 `crates/runtime/src/learner_starting_point.md` 为权威正文。各角色保留自身职责，普通继续承接下一条关系，表达困惑或请求重讲才触发缩小一步或改变表示。

## 实现

- `agent_prompt.rs:policy_modules_for_tools_with_presentation` 无条件装配学习起点和实际讲解职责两个模块。没有工具、Tutor 关闭或暂停、旧聊天恢复均取得同一核心。既有 `tutor_explanation_principle.md` 的例子、操作和结果顺序也提升为常驻职责，Tutor 不重复注入。
- `tutor.rs` 的设计、实际交付和接续规则只补当前所需前置，允许材料自足的观察、比较或预测直接起步。`tutor_continuation.rs` 的选项使用可理解的语言，选择继续不产生理解证据。
- `tutor_coach.rs:execute_coach` 的初次和纠错请求、`tutor_coach/presentation.rs:execute` 的演示与原生画板请求共享该核心。原角色前缀保持稳定，兼容既有真实请求分类与回放。
- `tutor.rs:review_instructions/explanation_review_instructions` 接入核心；独立解释审核只看实际交付和真实表达，明确必要术语、符号与连接。文字事实审核保持事实职责，不引入教学判断。
- `memory_review.rs` 明确零基础默认与术语提及不能生成能力事实；对象级理解继续归 LearningMemory，ProfileFact 保留通用背景与偏好边界。
- `skills/presentation/SKILL.md` 要求新关键术语、符号及交互操作有具体所指。提示资产版本同步提升为 `coach-handoff.v2`；Tutor 指导为 `teaching-design.v20`，讲解审核为 `explanation-delivery.v5`。
- 现有生产提示导出入口补入主 Agent 常驻指令，同时导出普通回答与 Tutor 提示，避免只验证 Tutor 规则而漏掉共同默认。

## 验证

86 项不同自动回归通过，覆盖主请求装配、旧会话、Tutor 状态、两类教练及纠错、接续输入、画像抽取、独立解释审核、呈现指导和请求预算。生产提示导出也成功。没有增加能力等级、数据库字段或生产模型调用；共同规则进入既有请求。

运行的 Runtime 筛选为 `agent_prompt::tests`、`learner_starting_point`、`tutor_coach`、`teaching_writing_rules`、`followup_contract_tests`、`tutor_continuation_tests`、`memory_review::tests`、`explanation_projection`、`agent_prompt::presentation` 和 `model_runtime::tests`。重叠用例按名称去重计数；唯一被忽略的是需要另行指定录制目录的教练离线回放。

真实模型采用既有 Provider 配置的 `deepseek-v4-flash`，使用 Rust 生产构建器导出的系统指令。普通回答按真实多轮消息输入；审核输入经生产投影裁去教材与作者计划。每个样例调用一次，保留请求、公开回答及 Provider 用量，无自动重试。

首轮五个普通回答和三个审核样例完成。普通回答仍有过早引入公式、简单定义扩展到较深知识的情况，因此收紧共同指令：陌生概念先建立可跟随的具体关系，术语和公式在有具体所指后引入，问题完成后停止扩展。明确深入请求当轮直接获得推导。审核将术语堆叠稿判为 revise，将完整解释和窄确认判为 accept。

第二轮六个普通回答和一个窄确认审核样例完成。普通继续和明确推导更加聚焦，但首次解释仍出现术语列表和通式先于例子。因此将既有具体讲解职责提升为主 Agent 常驻模块；主动教学路径移除重复注入。

最终采用第三轮的通用实现。六个普通回答已从具体过程进入：陌生概念以袋中红白球展开，已知先验/后验后的新概念直接讲似然，明确要求推导时直接由条件概率推导，递归先用队伍报数解释，再对应代码；继续保留原来的两箱球场景。

累计进行了 23 次真实模型调用，Provider 返回合计 78,190 tokens（包含各轮输入与输出，重复场景不计作独立通过项）。前三轮分别为 8/7/6 次，另有两次针对概率措辞的实验。后两次追加的专题约束仍未稳定消除错误，因此未保留该补丁。所有调用均取得完整公开回答和用量，无自动重试。

原始证据：`tmp/beginner-default-20261028/`；第二轮：`tmp/beginner-default-20261028-v2/`；最终通用实现：`tmp/beginner-default-20261028-v3/`；未采用的专题约束实验：`tmp/beginner-default-20261028-v4/`。每个目录保留生产导出、执行脚本、原始请求/响应和用量；所有前序失败样例均保留。

## 限制

当前单次主模型草稿仍可能有错误简化：最终样例将“假设与证据同时发生”的联合概率称为“不是概率”，正确说法是它们尚未归一化为所求的条件分布。定向复测仍复现此错误，另有把归一化比例系数说成分母、实际应为分母倒数的措辞错误。教学入口改进不代表数学事实正确性已经全部通过；本轮没有增加针对词句的拦截器或新的审核调用。

单次模型样例用于判断这些具体失败是否仍出现，不证明所有模型、书籍和读者的教学效果。此轮不改界面，未进行页面视觉验收或部署；生产教练接入由真实请求捕获测试覆盖，语义样例不等同完整 Reader 工具循环。
