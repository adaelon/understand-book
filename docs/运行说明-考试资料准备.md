# 考试资料准备运行说明

## 已接入的路径

个人工作区上传 EPUB、Markdown、TXT、MP4 的现有入口继续使用。PDF 现在进入同一准备队列：读取文字层，建立正文、段落引用与 PDF 页映射，再生成原有学习构建计划。用户确认任务额度后，模型阶段沿原账户计量执行。

PPTX、PPT 通过服务器配置的 LibreOffice 导出 PDF，再走相同的正文和页映射路径。导出包含隐藏幻灯片，PDF 页按照幻灯片顺序排列；不导出讲义或备注页。原课件由上传存储保留，阅读时可回到导出的 PDF 来源页。

材料标题使用用户上传的文件名。新上传的内部原件名包含稳定的上传 ID，避免不同工作区里的 `source.pdf`、`source.txt` 等文件被派生为同一个书籍身份。同一次上传的重试仍使用同一原件、准备任务和工作区。

## 运行配置

PDF 使用项目已有的 PDF.js 文字与几何提取、混合阅读对齐能力，无需新增外部转换器。构建 Engine 已包含项目原有的 PDF.js worker。

课件转换需要在 Reader 服务与执行准备队列的构建宿主中配置相同的绝对可执行路径：

```text
UNDERSTAND_BOOK_LIBREOFFICE=/usr/bin/libreoffice
```

Windows 维护环境可指向安装目录的 `program/soffice.com`。该值由宿主传给 Engine；文件不存在或未配置时，上传 API 的 `supported_formats` 不包含 `ppt`、`pptx`，界面同步隐藏这两项。转换时使用独立临时用户配置目录，转换结束或失败后清理临时文件。

运行参数依据 [LibreOffice 命令行参数](https://help.libreoffice.org/latest/en-US/text/shared/guide/start_parameters.html) 和 [PDF 导出参数](https://help.libreoffice.org/latest/en-US/text/shared/guide/pdf_params.html)。正式开放课件前，应在实际构建宿主用一份含文字、表格、公式和隐藏页的原创课件完成导入与来源回看，确认该机器的 LibreOffice 和字体配置满足课程需要。

## 空间、额度与恢复

上传前由账户空间账本预留原件大小。原件与最终私人发布成果沿原上传及任务身份统计，转换临时文件不作为另一份长期材料计入。公共引用不经此上传转换流程。

文字层提取、确定性格式转换和初始计划不新增独立收费项。模型处理沿原有任务上限和账户额度扣减；视频转写沿统一非模型处理账本扣减。文档转换不会伪造模型 token 或音频秒数。

完整文档基座写入暂存目录后一次发布，失败时不留下半份可读基座。再次准备相同上传会复用已有基座、页映射及后续学习构建成果。源文件与旧基座不符时停止覆盖，要求使用新的资料准备任务。

## 验证

`packages/core/test/document-import.test.ts` 使用原创 PDF 内容覆盖以下实际失败：

- 两页内容不能定位回各自来源页，或公式符号、表格文字及原 PDF 丢失。
- 云端实际的异步 DSH `prepare` 命令没有先导入 PDF，导致无法生成学习计划。
- 混合 PDF 中的扫描页被静默遗漏，并发布了不完整的正文。
- 未配置课件转换器时把 PPTX 当作普通文本放行。
- 重新准备覆盖了已完成成果。

2026-10-20 已用 LibreOffice 26.8.1.1 实际完成原创 PPTX、PPT 转换、三页来源映射、恢复复用和云端准备计划。公式上标、表格数值与隐藏第三页已渲染核对，材料与结果保存在[课件转换验收记录](https://github.com/adaelon/understand-book/blob/625b4405af3b011e87d4eb256f819c8075f88613/docs/performance/cloud-learning-c9/README.md)。运行环境通过官方签名的安装包行政解包至任务临时目录获得，未作为 Windows 产品依赖打包。

## 已知限制

提取的文字用于检索与提问。公式、表格和图示的完整排版以原 PDF 来源页为准，不宣称文字提取已完整还原数学语义或表格结构。

本片不包含 OCR。任一页没有可提取文字时，准备停止并说明页号，原件仍可导出；扫描页、纯图片课件和没有文字层的公式图片需要先补充文字层。存在文字但文字层不完整的文件仍需结合来源页核对。

PPT/PPTX 字体和公式渲染取决于转换环境，正式开放依赖实际机器的课件验收。课程资料和具体价格仍未选定。
