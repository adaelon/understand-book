# 选书封面

选书页自动显示 EPUB 原书封面或 PDF 首页，缺图时显示书名封面。点击卡片沿用原有选书行为。

## 实施步骤

- [x] EPUB 资源提取：识别 EPUB 3 cover-image、EPUB 2 cover metadata 与 guide 封面页，保存封面资源。
- [x] 书库数据：本地书库与已发布书库提供对应封面来源，已发布资源沿用书籍授权。
- [x] 选书卡片：共用封面组件，PDF 首页按需渲染，缺图回退；验证展示与选书行为。

## 已知限制

旧 EPUB 书包若已有明确命名的封面图片，可直接展示；若旧书包没有保存封面图片，需要从原 EPUB 重新生成资源并重新发布。PDF 首页按需在浏览器渲染，每次至多两个任务；服务器不支持分段响应时沿用现有完整 PDF 读取。无图、图片损坏或 PDF 无法渲染时显示书名封面。
