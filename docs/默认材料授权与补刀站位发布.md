# 默认材料授权与补刀站位发布

`publish_book <service-root> grant-all <book-id> <publication-id>` 将指定发布版本授予当前全部账号，并让以后创建的账号自动获得同一版本。命令可重复执行；普通发布仍按账号授权。用户禁用和管理员针对单个账号撤权的行为保持。

Schema 13 增加 `default_book_grants`，记录明确开启默认授权的发布引用。`grant_all` 在一个事务中写入默认授权和现有账号授权；`users` 的插入触发器在账号创建事务内复制默认授权，因此邮箱注册与离线开户都覆盖，失败注册不会留下授权。旧 schema 顺序迁移，既有授权保持。默认授权绑定不可变的发布版本；后续发布新版本需显式执行命令。
