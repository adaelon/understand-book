# 整讲中文分批补齐（VI10）

## 构建与恢复

`video-translation.ts` 在全片英文覆盖就绪后冻结材料身份、英文段落和翻译任务。一个语义任务最多 32 段、约 3,200 英文字符；连续 120 段组成一个发布批次。原片 720 段分成六次发布，降低完整媒体物化频次。

外部 Codex Harness 沿 VI4 的四工具 MCP 协议执行：`open → input.next → generation.start → submit_candidate`。同一 handoff 顺序处理一个发布批次内的任务，继续使用既有文本分块、连接状态机、传输预算和候选提交；执行器只能提交候选。Engine 校验确切转写版本、完整段 ID 集合与非空译文，通过既有阶段原子 writer 共同保存候选和任务完成状态。

已接纳候选保存在 `.build/video-translation/accepted/`，计划保存在同目录 `plan.json`。恢复读取相同英文输入，只重新执行缺失任务；已接纳候选不能改写。凑齐一批后调用 `publishVideoEnrichmentBatch`，依赖文件为 `video-enrichments/zh-NNN/transcript_translations.json`。正式 `publish_book` 组装累积快照，来源身份、英文 LID 与历史来源保持。

每批处理包含与下一段之间的静音空隙，第一批从视频开始、末批到视频结束。译文覆盖完成表示整讲段落已处理；它不声称新增了逐词对齐。

## 操作入口

在仓库环境下运行：

```powershell
. .\.worktree-local\environment.ps1
node --import tsx skills/build/video-translation.ts run <构建工作区> <Codex可执行文件> <publish_book可执行文件> <独立服务根>
```

再次运行相同命令恢复缺失任务。省略最后两个参数时只生成并接纳批次，随后可沿既有发布器交付。发布器回执丢失时，驱动读取工作区已有发布链接并直接比较批次清单和状态快照，避免重复复制同一原片。

原片复现入口：`node --import tsx evals/video/vi10-run.ts <Codex可执行文件>`。输入复制自 VI3 工作区，产物及独立书库写入 `evals/video/generated/vi10/`。

## 阅读界面与失败状态

播放器下方显示当前句段中英对照；英文正文每段显示中文或待翻译、翻译失败、正在重试、等待发布。摘要显示已接入和缺失段数，可回看首个待翻译片段。翻译插入继续使用 VI9 的英文段落锚点和原播放器。

`video_translation_progress.json` 保存随发布交付的构建状态快照。已接纳候选在正式批次发布前显示等待发布，不能冒充可用译文；累积发布内已有的译文优先于旧生产者的失败状态。失败由构建端恢复，读者无需发起模型构建。来源预览继续读取回答保存的确切发布、英文与原片。

首次中文等待 947,250 ms，整讲总墙钟时间 2,745,432 ms，均包含中断恢复与本轮调试。最终任务上限由初始 12 段 / 1,800 字符增至 32 段 / 3,200 字符：初始候选只有约 348–592 个估算 token，增加批量后最大 1,172，仍低于既有 2,048 限额。本次保留先前接纳任务，共 33 个任务；新建计划按最终参数划分。

每次发布物化 225,917,024 字节原片；正常六批加英文首发共 1,581,419,168 字节。本轮含失败状态和调参快照实际发布 12 次，复制 2,711,004,288 字节，单次发布 1,583–4,858 ms。CLI 使用默认模型、low reasoning；完成轮次的实际 token 回执保存在凭据中，强制中断轮次无最终用量，模型名称与费用未返回。

原片验证发现并修正两处影响阅读的问题：视频与普通阅读器之间的错误提示破坏了条件分支，导致两个阅读器同时显示；播放器下方内容高度变化时，锚点恢复误把容器位置变化计入正文滚动。现在阅读器互斥显示，锚点按各滚动容器的相对位置保存与恢复。

在完整中文发布上运行原片来源流程，回答保存的来源返回同一出版身份、英文段落、对应中文及 491,966.6875 ms 的真实帧。预览、显式跳回原片及刷新历史均通过，预览期间主播放器保持 507 秒和 1.5 倍速。[来源凭据](../evals/video/results/vi10-20261010/source-verification.json)；[预览截图](../evals/video/results/vi10-20261010/answer-source-preview.png)。

## 已知限制

- 读者看到的是所接入发布的状态快照；未发布的后台变化不实时推送。
- 机器转写疑词在译文保留疑点，英文校正沿 VI16–VI17；本阶段不修改英文。
- 本入口为源代码 Codex Harness；安装态、DSH、Linux 与读时真模型沿既有后续验收。
- 来源回看验收使用本地 HTTP 记录器驱动工具调用；它验证原来源交付，不证明读时模型语义回答质量。
