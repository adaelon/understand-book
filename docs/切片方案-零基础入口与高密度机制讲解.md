## S2 在普通问答的主讲提示中试一条讲法

> 从已经讲清的原理转到读者的新场景时，承接前文，用场景中的具体条件演示一次需要作出的判断或行动。条件改变了做法，就解释原因。读者要求走完整个过程时，给出每个必要步骤。

这条实验指引曾加入 `tutor::control_instructions` 的 `observing` 分支，适用于普通书籍文字问答中从原理转向应用的段落。S2 的装配回归检查了首稿与收束请求里的 `agent.tutor` 是否仍然有效，以及两份系统输入中指引是否各出现一次。候选源码、该回归以及相对于基线的唯一生产差异保存在 [S3 构建快照](evidence/explanation-density-20261126-s3-01/build/README.md)。

装配断言针对上述普通文字回合。音乐走专用提示，Tutor 未激活时跳过 Tutor 写作模块。本机 ACP Agent 由桌面宿主另行组装阅读提示。后续若扩展到 ACP，要核对该入口实际发出的请求与回答。[Resident 提示选择](../crates/runtime/src/agent_prompt.rs) · [ACP 请求组装](../crates/reader-service/src/local_agent_turn.rs)

以练阅读判断为例。若 Agent 已标出摘要漏掉的限定词，读者这一次练到的是回原文核对标注。想练挑错时，可以让 Agent 先给摘要，读者先圈出可能改变原意的地方，再回原文核对。这个做法由题设推出，在线、离线都可以解释。若进一步主张长期使用 Agent 会导致某种能力退化，就要为长期效果取得相应证据。书中转述研究时交代转述者，原论文的结论及条件以读到的论文为据。[证据与归属规则](adr/0193-accessible-entry-and-high-density-mechanism-explanation.md) · [已有情境迁移评阅约定](../evals/semantic/QUALITY_EVAL.md)

## S3 在真实回答上判断是否采用

### 按读者原问验收

| 问题与材料 | 决定是否通过的表现 |
| --- | --- |
| 专栏原题，随后在同一聊天问“只讲一步，如果 Agent 已经先指出错处，我这次还练到了什么？” | 首轮分别答到一万小时定律、刻意练习和 Agent 场景。迁移段给出能执行的动作并说明理由。续问能区分核对一个已标出的错处与自己发现错处，并聚焦这一处。接受其他有依据的讲法。 |
| 吴冠中《审美力》“这本书作者主要在讨论讲述什么” | 从实际读到的材料说清作者的中心问题和一处能说明主线的例子。既有回答和对照记录位于 `tmp/unified-release-20261115/` 的 `quality-after.md` 与 `quality-comparison.json`。 |
| 从零开始完整推导，再只问分母。用下方两袋摸球题复验既有概率错例 | 首轮交付从两条抽取路径到条件概率的完整推导。续问解释为什么另一袋也计入分母。术语有具体所指，联合概率和归一化计算都正确。 |
| 《深入理解 AI Infra》§1.3.2，问“容量与带宽各管什么？两张卡都能装下同一组权重，只加容量或只加带宽，哪个能降低读取时间下界？”随后问“为什么只加容量时下界不变？” | 首轮把能否装下和读取耗时落实到同一次选卡判断。次轮只需讲清读取量与带宽固定时，两者相除所得的下界相同。 |

摸球题是据既有错误新设的复算样本。等可能选甲袋或乙袋，甲有两红一白，乙有一红两白，各球等可能抽到。读者问“摸到红球，选中甲袋的概率是多少？请从头推一遍”，随后追问“为什么分母还要算乙袋？”。“选甲且摸红”和“选乙且摸红”的联合概率分别为 1/3 和 1/6。两条互斥路径涵盖全部红球结果，分母为 1/2，后验概率为 (1/3) ÷ (1/2) = 2/3。若写成乘法，归一化乘数为 2。既有样本曾否认联合概率本身是概率，也曾误把分母当作归一化乘数。依实际答句核对这两处。陌生术语的起步出现退化时，可复用同一记录中的递归队伍报数样本定位。[零基础实测与错例](实施记录-零基础教学默认.md#限制) · [AI Infra 材料与适用条件](examples/inquiry-course/ai-infra-time-bounds.md)

### 事实和解释各自取证

- **核对事实与来源。** 对冻结的普通文字交付，用 `project_text` 与 `text_review_instructions` 将正文、原文和实际读到的网页交给事实审核。按具体主张核对依据和适用条件。普通回答按需显示芯片，读者明确索要书内来源以及画板实质主张按各自合同核对。跨书用 `library.read` 返回的 `published_book_ref` 为参考书绑定来源，网页给原页面链接。回答编译器另行检查标记是否合法、是否泄漏内部 LID。[来源呈现规则](../crates/runtime/src/agent_prompt.rs) · [纯文字事实审核](../crates/runtime/src/tutor_text_review_rules.md)
- **核对讲解。** 将同一交付经 `project_explanation` 投影，只把本问、读者已有帮助和实际交付等可见信息交给独立解释审核。在 `prepare_delivery_review` 显式选择 `explanation_only = true`，分别保存事实与解释的结论和所据答句。`review_delivery` 的便捷入口固定传入 `false`，单次调用覆盖的是事实或综合分支。两份投影可复用现有 `export_independent_explanation_review_probe` 的做法。[投影实现](../crates/runtime/src/tutor_review_input.rs) · [审核分支选择](../crates/runtime/src/tutor.rs) · [独立审核样本导出](../crates/runtime/src/teaching_design_loop_tests.rs)

用两段短稿检验审核边界。一稿根据“Agent 已标出错处”解释读者这一次做了什么，须允许这项有前提的推演。另一稿说“蒙眼遮住了出手后的落点，所以投手脑中没有纠错标准”。遮住落点只限制了这次能看见的反馈，根据这个条件无法断定投手已有的判断能力，事实审核应指出这一步。即使书外说法单列、没有数字，也要核对因果。另测误引情形。若稿件把“长期使用 Agent 会使能力退化”归给作者，所挂选段只谈练习反馈，事实审核应指出该选段支持到哪里。

### 盲读与实施记录

把同题的两次 Reader 交付配成一对，按 `comparisonJobs` 的输入把候选和旧版分别映射为产品路与对照路，生成 A/B、B/A 两种顺序。版本映射随运行资料单独保存。每份交给独立评阅者或独立评阅会话，只给原题、必要上文、材料和匿名答案，要求指出支持判断的具体段落。读者偏好由实际读者盲读后给出。事实出错或漏答的部分单独记录。允许两版相当、都存在缺陷或证据不足。超时、截断和单方交付留在总记录中。[配对与匿名评阅入口](../evals/answer-quality/README.md#评阅)

原题三问答全、迁移段在具体做法和理由上有可指出的改善、局部追问能收窄且推导与关键事实正确时，采用候选。两版同样有效时沿用基线。替代材料的结论只覆盖实测题目。若要判断初学者能否独立运用，请首次接触的读者在相近的新例里尝试一次，记录原话与已得到的帮助。仅有模型交付和盲读时，学习效果记为待评价。

实施后把执行结果、语义判断、失败答句、用量、证据目录及真实读者观察写回[零基础教学实施记录](实施记录-零基础教学默认.md)。如审核误判，依据发生误判的稿件单独修正相应分支。若主讲持续把审稿用语写进正文，再单独试验将评审员专用段落移入对应审核提示。主讲用相同输入重新生成，审核用同一批冻结答稿复核判定。
