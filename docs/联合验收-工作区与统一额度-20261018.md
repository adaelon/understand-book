日期：2026-10-18。对应[统一切片](切片方案-目标工作区与统一Agent额度.md)的 E1，覆盖 W1–W6、Q1–Q5、S1–S2、B1–B2 和 V1 的接点。**E1已完成并通过联合验收；E2尚未开始。本轮未提交、未部署。** 证据见[汇总](https://github.com/adaelon/understand-book/blob/625b4405af3b011e87d4eb256f819c8075f88613/docs/performance/workspace-e1-20261018/README.md)。

## 本轮改动

个人资料入口改为独立上传区域，支持点击、键盘选择和拖放。页面显示支持格式、文件名、大小、实际上传百分比和保存结果；手机使用整行按钮与自动换行。空文件、不支持的格式和一次拖入多个文件有明确反馈。上传完成后沿现有准备方案、百分比确认、暂停和继续流程执行，任务仍绑定发起工作区。

联合场景发现纯画面来源能够引用，却无法保存为跨资料私人理解：旧目标验证要求文字行号。现在 `cross_book::learning` 从本轮已绑定的来源生成 `TeachingMediaBinding`，保存确切发布、画面位置或原声范围；纯媒体记录不补造文字位置。`TeachingTarget.media_bindings` 为可选的运行时派生字段，旧文字记录继续按原格式读取。模型通过已有 `library.learning` 的来源引用使用它；普通 Tutor 目标输入仍遵循原文字来源合同。

控制库 schema18、学习库 schema3 保持不变。新计划仍默认关闭 Pass2 和额外 Tutor 材料。

## A–D 联合场景

| 场景 | 实际链路与判断 | 状态 |
|---|---|---|
| A：同用户两个工作区 | 共享资料、实际工具循环、运行冻结的旧目标、新目标、私人理解修订、后台整理、重启后原聊天接续；费用与后台来源保持原归属 | 通过，[原始结果](performance/workspace-e1-20261018/scenario-a.json) |
| B：两用户共享实例 | 同一混合书/视频发布分别接受目标；实际取帧与私人理解；一人加入私人资料并选择新版，另一人保留原版；旧来源继续解析旧发布，公共成本只记一次 | 通过，[原始结果](performance/workspace-e1-20261018/scenario-b.json) |
| C：回答、后台与构建费用 | 实际回答和后台整理，加上构建失败收费、重试、发送前取消、未知回执、重启和迟到回执；核对预占、待核算、上限、平台差额和 120.7% | 通过，[原始结果](performance/workspace-e1-20261018/scenario-c.json) |
| D：升级与旧学习记录 | 真实临时数据库从 v15 控制边界升级，保留原额度账、聊天文件和理解证据；只带入用户选定记录，重复带入不产生事实，重开后仍可回读 | 通过，[原始结果](performance/workspace-e1-20261018/scenario-d.json) |

测试代码位于 `crates/server/src/tests/e1_workspace_integration_tests.rs`。A/C/D 的回答经过真实本机 Provider HTTP 与普通运行入口；响应语义和用量由受控供应商给出。B 使用实际媒体解码和 `NetworkRunPort`，把已捕获来源交给实际私人理解存储入口。C 的外部失败、取消和迟到回执由验收输入控制，服务端准入、费率、账本及恢复为真实实现。

C 的测试费率计算为：期初 73%，回答及后台整理扣减 20 micro-CNY，个人准备累计扣减封顶 22,980 micro-CNY，总扣减 23,000 micro-CNY，即 2.3%；补充 50% 后为 `73% - 2.3% + 50% = 120.7%`。全部供应商费用记录合计 23,270 micro-CNY，其中 270 micro-CNY 由平台承担；迟到回执补齐前保留 200 micro-CNY 待核算，补齐后归零，重复补交不重复扣减。B 的公共构建测试成本 12 micro-CNY 始终只有一份，两人使用与选择更新没有新增模型请求。

## 后台与浏览器

后台验收复用 `packages/dsh-plugin/test/personal-http.acceptance.ts`，通过 E1 临时服务执行现有编译 Engine、原生 DSH、分块上传、预算拒绝、暂停、宿主重建、成果导入和工作区接续。受控供应商只替代语义模型；原计划、候选接纳、恢复、费用准入和回执沿实际代码执行。视频使用真实 MP4、本地 FFmpeg 和 Whisper，再导入原工作区。

浏览器验收入口为 `packages/web/playwright/workspace-e1.spec.ts`。同一服务上使用两个账号，串联共享使用、81,016 字节文件上传、额度确认、暂停、切换、接续、历史带入、百分比使用记录、视频播放和范围选择、共享版本更新与刷新恢复。中间语义准备进度由受控宿主提交，实际构建由上述后台场景覆盖。

实际后台通过：49 次模型请求逐笔记账，测试费率合计 637 micro-CNY，待核算为 0；低预算拒绝前没有调用，暂停和宿主重建复用已接纳 Pass1，修改目标及引用已有成果没有新增构建调用。真实 8 秒 MP4 经本地 Whisper 产生 2 段转写，个人视频没有付费 CLI 请求或模型额度扣减。见[HTTP结果](https://github.com/adaelon/understand-book/blob/625b4405af3b011e87d4eb256f819c8075f88613/docs/performance/workspace-e1-20261018/http-result.json)。

浏览器通过：11.6 秒完成完整用例，3 块上传，键盘选择与拖放正常；1.25% 上限确认、暂停、跨工作区返回及继续学习保持确切成果身份；两账号版本独立，私人资料和旧记录保留。实际视频可播放并保存 1–4 秒范围；390px 无横向溢出，页面错误为 0。上传过程截图采样于实际 40% 字节进度。见[浏览器结果](performance/workspace-e1-20261018/browser.json)、[桌面上传](performance/workspace-e1-20261018/upload-desktop.png)、[手机上传](performance/workspace-e1-20261018/upload-mobile.png)及[完成状态](performance/workspace-e1-20261018/preparation-complete-mobile.png)。

28 项去重定向测试通过：Server 6、Memory 21（含 6 项类型导出）、Runtime 1；Web 类型检查及多人生产构建通过。Memory 的媒体来源、旧记录与修订测试覆盖了本次数据合同变化，Server 的原跨书和混合视频用例保留通过。浏览器首次脚本误把资料排序位置当作身份，并把导入前的版本当作新成果；已改为使用实际目录身份与导入结果。后端与本轮 HTTP、浏览器服务均已关闭。

## 复跑入口

先运行 Rust 定向测试，再启动浏览器宿主；Windows 上运行中的宿主会占用 Server 测试二进制。

```powershell
cargo test -p memory --lib -- teaching:: learning_evidence::tests:: learning_records::tests::
cargo test -p runtime --lib -- tutor::t15_tests::
cargo test -p server --lib -- e1_workspace_integration_tests::e1_ tests::cross_book_tests:: tests::video_workspace_tests::video_workspace_mixed
cargo test -p server --lib e1_browser_host -- --ignored --nocapture
```

在另一个终端执行后台场景，然后执行浏览器场景：

```powershell
$env:UNDERSTAND_BOOK_ACCEPTANCE_OUTPUT='target/workspace-e1-20261018'
node --import tsx packages/dsh-plugin/test/personal-http.acceptance.ts
$env:VITE_MULTI_USER='1'
pnpm --filter @understand-book/web exec playwright test playwright/workspace-e1.spec.ts --workers=1
```

宿主使用 4190/4191，页面使用 4174。后台场景沿 [B2/V1 复跑配置](个人资料准备与跨资料媒体-20261018.md)找到编译 Engine、发布器与本地 Whisper；视频输入可由 `UNDERSTAND_BOOK_VIDEO_ACCEPTANCE_SOURCE` 指定。完成后调用本机控制服务的 `/stop` 并关闭本轮页面服务。

## 已知限制

本轮费用依据是测试费率和受控供应商用量，不是供应商实扣账单。真实模型的大目标遵循、教学质量、真实成本对照及发布准备仍属于 E2。

个人视频当前提供本地转写与原文学习，完整语义预构建沿已有平台路径提供。原始 PDF 仍需工作台来源对齐，部分外部 CLI 的未确认费用仍保留待核算。生产需要连接 DSH 宿主、有效费率、共享成果目录和本地媒体工具。
