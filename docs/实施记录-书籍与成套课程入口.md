## 当前代码链路

- `learning-collections.ts` 定义书籍／课程集合与可刷新的详情地址；`SharedWorkspaceCatalog.vue` 使用真实按书分页、私人发布快照和原课记录组织目录。点击目录动作只滚动与聚焦；点击具体课才进入原创建或复用流程。
- `workspace_publication.rs` 在可见发布 SQL 上按实际 lesson 来源书籍筛选，先筛选再计数、分页；公开读取只投影概要，不装入完整课件。
- `learning_task.rs` 从任务原发布版本投影书籍或课程、单元及课序；`LearningHomeTask.vue` 展示归属并分开处理看目录与继续任务。
- `NetworkApp.vue` 协调集合地址、精确材料与私人范围。`App.vue` 读取原版本集合，显式原文入口先保存课程／闭卷状态；`InquiryCoursePlayer.vue` 按单元显示、保留跨书路线，并在成功暂停后返回所属集合。
- `WorkspaceDestinations.vue` 与 `ProductHome.vue` 统一“学习”入口，资料入口明确使用 `view=materials`。

### 本地回归

```powershell
New-Item -ItemType Directory -Force .tmp/course-reuse/os-temp | Out-Null
$env:TEMP = (Resolve-Path .tmp/course-reuse/os-temp).Path
$env:TMP = $env:TEMP
pnpm verify:course:local
```

该命令依次运行 reader-service 与 server 的 `closed_book`、memory 的 `closed_book` 和 reader-service 的 `inquiry_course_expression` 回归，覆盖公共闭卷交付与追问续答、云端结果回课与帮助归属、普通课内理解记录的实际帮助。公共行为在 2026-11-17 双发行拆分后由 reader-service 持有，云端模型与浏览器宿主仍由 server 持有。任一步失败即停止；ignored 的模型试验不会被本地回归执行。

### 一次真实模型回课试验

使用当前 `.env` 中的模型配置和本机正式 AI Infra 书库；读取原书，私人记录写入隔离目录。记录代理会改变服务地址，因此官方 DeepSeek 的旧 Flash 别名按现有 runtime 规则映射为 `deepseek-flash`，保持 Messages 接口能力识别；配置名、实际名和请求路径均写入证据。先从 Cargo 的构建回执取得本次测试程序，再启动试验：

```powershell
$courseBuild = cargo test -p server --lib --no-run --message-format=json
$courseTest = $courseBuild | ForEach-Object { $_ | ConvertFrom-Json } |
  Where-Object { $_.reason -eq 'compiler-artifact' -and $_.target.name -eq 'server' -and $_.profile.test -and $_.executable } |
  Select-Object -Last 1 -ExpandProperty executable
pnpm verify:course:model --test-bin $courseTest --out docs/evidence/course-reuse-YYYYMMDD/attempt-1
```

输出目录每次取新名称。上限为一次样本、7 个学习者回合、24 次转发给模型的请求；已记录用量达到 1,200,000 token 后不再转发新请求，进行中的请求可能超过该 token 阈值。每个教学回合最长 180 秒。预算截停在 `run.json` 中标记为 `stopped_at_trial_budget`，不能当作教学或课程失败。

若出现 `Waiting for learner answer`，读取同目录的 `follow-up-N.json`，按教师实际展示的问题，将学习者回答以 UTF-8 写入它指定的 `learner-answer-N.txt`。Agent 或操作者负责这一步，不额外调用模拟学习者模型；最多三次追加回答，每次等待 180 秒。题面、历史原话和真实回答都保留。额外追问是待作答状态；受助、目标未满足、超限或未收到回答均不能记为通过。

`run.json` 记录执行结果、配置与用量，`turn-N.json` 保留每轮原话和教学交付，`original-course-coach.json`、`feedback-read.json`、`next-course-step.json`、`resumed-course.json` 分别记录回课判断、反馈交付、推进及存储恢复。各文件在实际执行到对应步骤后生成；失败时保留已产生的证据，未执行的步骤不能记为通过。`private-state-location.json` 指向保留的隔离库。脚本退出时停止本次代理，保留证据和隔离库。

执行成功仍需阅读题面、帮助、评价和原材料，判断依据、数值、方向与独立性；当前脚本将其标为 `execution_passed_semantic_review_pending`。首次使用者的理解和使用体验通过实际试学另行取得。
