## 验证判据

- 同一本书的课程属于同一书籍入口；跨书课程有完整集合目录，版本来源准确。
- 浏览书籍/课程目录没有私人创建或模型调用；开始选中的具体课才接受目标并复用原提交。
- 首页任务、详情、课内与返回总目录使用同一原学习范围；暂停失败不误跳，刷新不丢归属。
- 当前发布与私人旧版本并存时不串课程、进度或材料；没有课程的书仍能阅读并从材料学习。
- 真实前后端覆盖单书开课、暂停与原任务恢复；跨书准确导航及失败重试使用针对性回归。页面直接核对 1440、390、320 宽度及英文长文案。

## 当前代码链路

- `learning-collections.ts` 定义书籍／课程集合与可刷新的详情地址；`SharedWorkspaceCatalog.vue` 使用真实按书分页、私人发布快照和原课记录组织目录。点击目录动作只滚动与聚焦；点击具体课才进入原创建或复用流程。
- `workspace_publication.rs` 在可见发布 SQL 上按实际 lesson 来源书籍筛选，先筛选再计数、分页；公开读取只投影概要，不装入完整课件。
- `learning_task.rs` 从任务原发布版本投影书籍或课程、单元及课序；`LearningHomeTask.vue` 展示归属并分开处理看目录与继续任务。
- `NetworkApp.vue` 协调集合地址、精确材料与私人范围。`App.vue` 读取原版本集合，显式原文入口先保存课程／闭卷状态；`InquiryCoursePlayer.vue` 按单元显示、保留跨书路线，并在成功暂停后返回所属集合。
- `WorkspaceDestinations.vue` 与 `ProductHome.vue` 统一“学习”入口，资料入口明确使用 `view=materials`。

## 验证结果与边界

统一 `vue-tsc` 与多用户构建通过；最终纯展示调整后的 Vite 构建通过。真实 Rust 服务使用正式 AI Infra 双课单元，验证新用户只浏览时不创建实例、任意选第二课、打开失败重试、回书选第一课、暂停刷新与手机恢复、明确阅读原文。最终只有一个私人实例与一次 `/use`，原 run/chat 和预测草稿保留，导航模型请求为零。

中文／英文 1440、390、320 宽度均完成实际截图查看。手机首屏新增明确课程动作，长标题使用整行，课时详细依据按需展开。跨书总目录使用代表性双书双单元概要验证布局；跨书实际导航合同由组件、父级与接口回归覆盖。本轮没有运行真实跨书完整学习端到端，也没有新增真实模型教学质量或首次使用者试学证据。本机旧 run 未保存完整集合快照时，继续显示已知书籍和原课，不补造历史课序。
