# 深入 Understand Book 写作工作区

本书面向希望理解项目全貌、深入实现并准备技术面试的读者。正文围绕阅读任务展开：原文怎样被整理，Agent 怎样获得信息和执行动作，系统怎样保留证据、阅读现场与长期状态，以及这些机制怎样在多人服务中运行。

书名暂定为《深入 Understand Book：从知识构建到阅读 Agent 的架构与实现》。写作参照《深入理解 AI Agent》的概念递进和《深入理解 AI Infra》的约束分析、算例与实验叙述。读者定位暂按具有基本编程经验、重点准备 AI Agent 与后端架构面试处理。

当前完成全书导读、24/24章正文和6/6份附录。2026-10-08完成附录及全书导航、引用与重点术语校订；各章保留原有实现读取日期和实际验证范围。

## 行文约定

章节从具体场景进入，先说明直接做法，再逐步加入真实约束，解释当前机制和设计代价。正文以连贯段落为主；图表达组件、状态或时序，表格用于比较，代码只摘录决定行为的部分。

教学推导可以使用明确标注的简化模型；项目演进按真实记录叙述。算例写出假设和计量口径，实验结果保留版本、任务范围和条件。技术边界集中在适合的段落或章节，避免把结构性保证扩大为语义正确或学习效果保证。

核心章末提供源码选读、思考题与面试表达。短答来自本章论证；追问题改变一个条件，要求重新判断设计。附录提供回查路线，结果表述保留原始任务与验证条件。

## 使用项目成书 skill

个人 skill `project-to-book` 支持新建项目书、承接已有正文续写，以及依据代码变化修订。当前书稿已经确定读者、目录和参考风格，后续调用直接承接这些文件。

例如：“用 $project-to-book 核对本次会话恢复相关修改，更新受影响章节与来源索引，沿用现有正文风格。”统一校订时，可按来源索引逐章明确要核对的基线与范围。

首版 skill 已用于第9章校订，并承接第1—8、10—24章续写。正文包含职责关系图、构建成本算例、历史实验、双窗口状态案例，以及原文到语义候选、章节选择、输入切片、成果匹配、发布恢复、工具边界、上下文投影、流式交付、持续教学、阅读现场、私人记忆、会话日志、演示修订、宿主并发、多人调度、发行组合、迁入恢复与观测评测的实际局部验证。第22章串联架构选择与修订条件，第23章解释失败、回归和撤回，第24章将这些依据组织成项目介绍与深入追问。
