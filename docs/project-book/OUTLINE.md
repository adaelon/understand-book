# 深入 Understand Book 详细目录

全书沿着一项阅读任务展开，再逐步加入资料规模、持续交互、恢复、多用户与效果评估。第一篇建立坐标；第二篇解释阅读之前的准备；第三篇进入读时 Agent；第四篇追踪长期状态和阅读体验；第五篇分析工程运行；第六篇把设计、实测和表达连接起来。

## 第一篇 从阅读任务建立系统全貌

### 第 1 章 一本书怎样成为可以交互的阅读环境

中心问题：读者要求解释、查证、定位和保存时，系统分别需要完成什么工作？

1.1 从一段选区和一个追问开始。1.2 问答、查证、导航与持续阅读的关系。1.3 完成一次任务需要哪些真实结果。1.4 一个最小阅读 Agent 的组成。1.5 随材料和任务增长出现的要求。

承接：任务已经展开，下一章确定各部分工作放在哪里。

### 第 2 章 构建与阅读如何分工

中心问题：哪些工作能够提前完成，哪些工作必须等待具体问题？

2.1 全文输入与提前整理的比较。2.2 准备成本和多次阅读的分摊。2.3 TypeScript 构建侧与 Rust 阅读侧。2.4 Web、桌面外壳、模型服务和 MCP 的连接。2.5 材料改版与成果发布的位置。

承接：跨阶段交付需要共同的数据约定，也需要明确状态由谁持有。

### 第 3 章 数据身份与状态归属

中心问题：一本材料、一个读者、一个窗口和一次运行怎样在系统中相互关联？

3.1 材料身份与不可变发布。3.2 原文、语义结构和用户记录。3.3 服务、用户、阅读现场与 Run。3.4 Rust 数据定义与 TypeScript 类型投影。3.5 从一项状态找回它的写入口和生命周期。

承接：先看最基础的一项共同约定，原文位置怎样形成。

## 第二篇 从原文构建知识底座

### 第 4 章 原文定位与 LID

中心问题：构建、检索、引用、导航和批注怎样指向同一段内容？

4.1 Markdown、EPUB 和 PDF 的输入路径。4.2 忠实块映射与确定性切分。4.3 层级、顺序、叶子和原文区间。4.4 位置身份与模型输入窗口的分工。4.5 公式、图片、表格及 PDF 选区的对应关系。

承接：确定位置之后，才能把模型提取的语义连接到原文。

### 第 5 章 语义抽取与来源锚定

中心问题：模型读出的概念、断言和关系怎样成为有来源的构建成果？

5.1 从一个窗口看局部抽取。5.2 Pass1 归并与全局目录。5.3 可选 Pass2 和跨章节关系。5.4 篇章、公式与内容规则包。5.5 结构校验能证明什么，语义质量怎样另行判断。

承接：局部语义需要进一步组织成读者能够使用的全书结构。

### 第 6 章 全书结构与语义候选召回

中心问题：系统怎样从分散的原文和语义成果中组织章节重点与跨章主题？

6.1 章节地图和概念图的用途。6.2 候选发现与原文依据。6.3 构建期检索和 Embedding Provider。6.4 选择、主题、关系与结构整理。6.5 局部成果如何组装为全书结果。

承接：把这些语义工作真正做完，还需要可执行的任务划分。

### 第 7 章 模型工作单元与执行调度

中心问题：一本长书怎样拆成模型能够完成、调度器能够追踪的工作？

7.1 原文身份和执行粒度。7.2 单次模型输入的预算。7.3 任务、租约与执行器交接。7.4 Codex 和 DeepSeek Harness 的适配。7.5 实际待办、候选提交与错误反馈。

承接：执行会中断，结果会复用；下一章考察如何从局部进展到正式成果。

### 第 8 章 构建恢复与成果发布

中心问题：系统凭什么判断哪些工作已经完成，哪些成果可以被阅读侧消费？

8.1 构建工作区与有效成果。8.2 输入、策略和工作单元变化。8.3 中断恢复、失败纠正和可复用结果。8.4 阶段发布、提交回执与收口。8.5 工作区搬迁、材料改版和不可变发布。

承接：读时系统开始使用这些成果，后续以一次真实请求展开。

## 第三篇 阅读 Agent 的决策与交付

### 第 9 章 一次有证据的回答

中心问题：一句读者提问怎样变成有来源、可保存并可继续追问的结果？

9.1 提问现场与任务要求。9.2 RunScope 和本轮状态。9.3 定位线索、原文与证据账本。9.4 引文匹配和来源编译。9.5 工具执行与运行进展。9.6 终态、目标与历史提交。9.7 从执行轨迹分析时间和成本。

承接：完整链路已经建立，再分别深入能力面、上下文和交付机制。

### 第 10 章 工具与模型调用边界

中心问题：Agent 怎样知道自己能做什么，并把决定交给正确的执行入口？

10.1 Book 工具与 Reader 动作。10.2 工具契约和注册表。10.3 暴露、发现与权限。10.4 MCP 调用方与内置 Resident。10.5 Native、ReAct 和 Provider 适配边界。

承接：工具和模型之间的每次往返都会改变上下文。

### 第 11 章 上下文组织与持续执行

中心问题：随着任务变长，Agent 怎样继续获得足够且正确的信息？

11.1 一次请求的输入组成。11.2 固定前缀、动态片段和当前工具结果。11.3 历史回执与按需回读。11.4 活动上下文预算、压缩和检查点。11.5 缓存复用、累计用量与进展停止。

承接：模型生成的内容需要通过实际交付路径到达用户。

### 第 12 章 来源与流式交付

中心问题：怎样在缩短等待的同时，让最终回答和来源保持一致？

12.1 模型流、运行活动与回答草稿。12.2 已观察证据到来源绑定。12.3 公开内容编译与修复。12.4 SSE、快照和重连。12.5 接受回答、持久终态和未保存结果。

承接：一次 Run 结束后，读者的任务可能还需要继续。

### 第 13 章 持续目标与教学过程

中心问题：系统怎样跨运行保持任务方向，并把解释与学习过程连接起来？

13.1 Run、聊天 Goal 与 Tutor 的生命周期。13.2 用户要求、工作计划和实际成果。13.3 主动带读与教学地图。13.4 教学活动、评估和学习证据。13.5 完成判断、未完成状态与继续入口。

承接：这些能力最终体现在读者日常使用的阅读环境中。

## 第四篇 阅读体验与长期状态

### 第 14 章 阅读现场与原文交互

中心问题：读者看到的位置、选中的文字和 Agent 使用的材料怎样对应？

14.1 Reader 命令和界面投影。14.2 连续正文、视口和滚动锚点。14.3 PDF 选区解析与原文对应。14.4 来源跳转、批注和阅读连续性。14.5 桌面和移动界面的现场管理。

承接：即时操作中哪些结果应该成为读者长期拥有的数据？

### 第 15 章 笔记 记忆与学习事实

中心问题：哪些信息需要跨聊天保留，怎样保持其来源和归属？

15.1 笔记、阅读记录、画像和教学事实。15.2 私人数据的写入口。15.3 从事实生成派生投影。15.4 更新、纠正、撤销与过期信息。15.5 跨书使用与当前阅读现场。

承接：聊天本身也需要保存，但它与这些领域事实有各自的结构。

### 第 16 章 会话日志与恢复

中心问题：怎样保存持续增长的聊天，并在中断后解释已经发生的事？

16.1 整份快照与增量保存的工作量。16.2 按聊天追加 JSONL。16.3 事件序号、冻结历史位置与纯投影。16.4 消息、目标、来源与成果关联。16.5 持久化失败、重启和阅读回顾。

承接：聊天产生的结果还可以包含可交互的页面和图形。

### 第 17 章 可探索解释与演示版本

中心问题：Agent 生成的解释页面怎样被预览、交付、继续操作和修订？

17.1 从解释任务到呈现方式。17.2 候选、预览与已交付版本。17.3 图表、二维交互和动画资源。17.4 页面现场、追问和同对象修订。17.5 指导上下文、源码回读与制作成本。

承接：这些工作共用宿主资源，需要回到运行组织和并发关系。

## 第五篇 宿主运行与质量证据

### 第 18 章 Rust 宿主与并发边界

中心问题：怎样让长时间模型调用与读者操作同时推进？

18.1 HTTP 宿主与运行协调。18.2 固定输入与短时状态访问。18.3 权威写入口和取消传播。18.4 运行活动、传输与后台工作。18.5 用关键路径和实际等待分析瓶颈。

承接：增加第二个用户时，首先要改变状态归属和资源安排。

### 第 19 章 多用户阅读与调度

中心问题：共享材料和模型资源时，怎样保持私人数据与阅读现场独立？

19.1 服务、用户、现场与 Run 的分层。19.2 身份、对象授权与材料发布。19.3 SQLite 接单和运行准入。19.4 用户公平调度与模型并发。19.5 现场回收、恢复和未来扩展条件。

承接：运行结构确定之后，需要把组件组合成可安装、可维护的产品。

### 第 20 章 桌面 插件与 Linux 发布

中心问题：不同使用形态怎样使用相互匹配的构建和阅读能力？

20.1 Web 与 Tauri 外壳。20.2 插件、执行器和配置。20.3 Linux 阅读服务的组成。20.4 材料发布、数据迁入、备份与恢复。20.5 版本组合和部署验证。

承接：可运行之后，需要判断真实任务的收益、代价和失败。

### 第 21 章 可观测性 成本与效果评测

中心问题：怎样知道系统把时间和调用花在哪里，以及是否完成了任务？

21.1 执行树、终态和用量口径。21.2 元数据观测与持久队列。21.3 证据召回、引用支持、任务成功和实际动作。21.4 产品对照、同环消融与归因。21.5 从失败轨迹确定下一项改进。

承接：回到全局，理解当前设计为何形成，以及哪些条件会推动它变化。

## 第六篇 架构判断与面试表达

### 第 22 章 关键决策及其演进

中心问题：在当时的需求和证据下，为什么选择当前结构？

22.1 构建与读时的语言和边界。22.2 原文身份、语义图和检索方式。22.3 轮数限制、活动上下文和任务进展。22.4 会话保存与多用户状态。22.5 决策何时值得重新讨论。

### 第 23 章 真实失败与工程改进

23.1 召回命中与完整交付之间的缺口。23.2 来源修复、阅读动作和恢复准备。23.3 构建交接、候选失败与持续进展。23.4 演示制作、上下文和实际结果。23.5 从单题修复到条件明确的回归。
