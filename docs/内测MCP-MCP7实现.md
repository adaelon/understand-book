## 账号与购买入口

`GET /api/account/mcp` 保留 `credentials`，增加 `mcp_url` 和 `usage`。`usage` 与远程 MCP 使用相同投影，包含免费／已购余额、各包期限、`charged_units: 0`、`charged_from: null` 及购买入口。身份取当前 Cookie 会话，仍在私人 Reader 装载前完成；创建、撤销继续沿 MCP1 的 Cookie／CSRF 接口。

`AccountMcp.vue` 从书架、阅读区与附属窗口的账号菜单进入。无需打开材料，凭证完整值只留在创建结果中；关闭、撤销或切换账号即清除。创建结果未知时提示刷新列表核对并撤销无法取回的条目。免费恢复与各批次开通／到期采用香港时间显示，已过期的未用次数与当前可用次数分别呈现。

`remote_mcp::usage_value` 为目录、内容、额度查询及额度耗尽响应统一返回 `top_up_url = 站点 Origin + /?account=mcp`。打开该链接会进入接入／购买窗口，未登录则先登录。页面给出账号、单价、次数、期限和联系内测管理员付款的步骤；收款与开通继续使用已有人工流程。

## 来源打开

```text
source_url → NetworkApp 保存六个来源参数 → 必要时登录
  → POST /workspaces 或 book/open（确切 PublishedBookRef，现有授权检查）
  → App 读取该发布 manifest → resolveMcpSource 校验 LID 与绝对 UTF-16 范围
  → 找到实际起始叶段 → reader/goto → 临时来源标记 → 滚动到标记
  → 成功后移除 URL 来源参数；失败保留原链接并提示重试／材料授权
```

`mcp-source.ts` 将范围与 manifest 的叶段相交，再转换为每段 UTF-16 偏移。续页仍可携带原请求 LID，实际导航点取页内坐标所在的叶段；跨段与非 BMP 字符不会按字节或字符数错误换算。Markdown 标题的显示前缀偏移在渲染时扣除；继续滚动加载正文时保留范围标记。

来源引用定位到规范原文；对于 PDF 材料，本次打开切到规范文本表面，不改写保存的阅读表面偏好。只保存既有 Reader 导航位置，来源标记不创建永久高亮、笔记或聊天。无权或不可用版本不会替换为默认版本；错误保留确切引用。
