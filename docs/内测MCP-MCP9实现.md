## 验证路径

`mcp_acceptance_tests.rs` 复用真实多用户宿主、临时 SQLite 与不可变发布；两个账号分别成功读取自己的材料。免费检索耗尽后经真实管理员 HTTP 购包恢复，两页原文分别消费付费次数；后续消费后找回和重放原回执，当前余额不重发。撤权后的缓存续页拒绝，账本按账号及扣除来源核对。

服务端导出的 `source-evidence.json` 由 Web 的生产 `readMcpSource/resolveMcpSource` 解析并重建原文，覆盖服务端 UTF-16 来源到 Reader 的接口。并发用例记录 1／4／8 个同步客户端的耗时、响应字节与实际消费数。

外部客户端使用显式启动的临时宿主；alice 获赠 12 次，bob 模拟耗尽。材料为本次编写的雨水实验文本，客户端工作目录无项目源码、历史或指令，仅提供接入说明和问题。临时凭证仅在隔离目录配置，退出后随临时库失效并移除配置。
