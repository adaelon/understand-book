# 视觉检索与问题驱动精读（VI12）

## 工具与数据流

`video.search(query, within?, analysis_id?, limit?, offset?)` 已接入 Resident 的工具发现和单/多用户运行端口，读取 Run 固定发布内的 `video_enrichments.json` 与 VI11 `visual_units.json`。查询支持画面文字、代码、描述、变化线索和确切 `vu_id`。`within` 是带媒体身份的毫秒区间；默认整片。默认每页八项，最多二十项，`next_offset` 延续同一发布、查询和范围。

`问题 → tool.search → video.search → 候选位置/read_hint → video.read_frames → 成功主模型请求 → 本轮观察 → source.present`。

响应包含确切发布和材料版本、命中 VU/分析 ID、独立出现位置、范围内代表帧、画面文字/描述/变化摘录、转写段 ID、匹配词和覆盖缺口。`read_hint` 是可直接传给 VI5 的有界取帧请求；范围落在两次采样之间时，提示从该范围起点取帧。检索不返回图片，也不登记文字或媒体观察。

## 检索与覆盖

英文按完整标识符分词，保留 `==`、`!=`、`<=`、`>=`、`->`、`@`；中文使用相邻双字词。按匹配词在当前候选中的稀有程度排序，完整画面文字短语和确切 VU ID 优先。命中摘录优先展示包含查询词的行。相同代码的多次出现分别参与排序和分页。

覆盖从可读取且绑定当前材料、实际帧依赖齐全的视觉贡献计算，再按查询范围裁切。旧 VI9 索引占位文件不会凭清单中的覆盖声明变成可检索 VU。缺视觉贡献返回空命中与完整缺口；缺依赖或材料不符返回错误。当前帧提问可直接使用 VI5，不依赖索引完成。

## §1 分析版本选择

**决策**：每个位置采用最新已接纳分析。

**否决**：
- 只用全局最新分析：局部重分析会隐藏其他位置仍有效的旧成果。
- 混排重叠的新旧事件：同一位置重复召回，掩盖修订后的组织。

**命门**：以 VI11 `created_at` 排序，重叠处使用新事件，旧事件保留未被覆盖的区间；显式 `analysis_id` 可读取该发布内指定分析。旧发布和媒体来源引用保持原值。
**展开**：[ADR-0145](adr/0145-video-media-locations-and-revisable-visual-units.md)。

## 验收与复现

确定性测试覆盖标识符和操作符、中文自然语言描述、VU ID、重复位置、分页、范围内无代表帧、局部重分析、显式旧分析、空索引、缺帧和错误发布。Runtime 测试验证工具可发现、检索后仍无观察、后续成功读图才获得来源资格；注册和工具曝光回归保持通过。

`evals/video/vi12-verify.mjs` 使用 VI0a 固定问题，从问题提取可见词/描述查询，并保留 V04 原始自然语言问题直接查询。十四个场景覆盖 dtype/断言差异、四步渐进高亮、两处 einsum 停留、求和维度、GPU 序列号负例、未索引当前帧及 A→B→A 夹具。所需原片候选均在默认八项内；V01-bfloat16 排第七，其余原片目标排第一或第二。

十三次实际回读经 VI5 把原分辨率 PNG 送入本地 HTTP 请求记录器，核对请求图片、实际 PTS、确切发布及观察回执。原片仍为 VI11 正式发布 `01a12543-5248-76d0-9d6c-71a133a14357`；新旧发布分别检索，英文首发没有视觉索引。补充夹具采用独立可读副本，保留 VI11 的合成上下文及媒体身份。

查询不调用模型。十一项原片查询合计 653 ms，三项补充查询合计 23 ms；这是本机本次测量，包含索引读取。原片覆盖仍为 550–655 秒与 1180–1225 秒，共 150 秒。本轮没有新增发布或复制整讲媒体。
