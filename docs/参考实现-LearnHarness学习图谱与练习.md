## 2. 参照了什么

| 编号 | 外部位置 | 事实 | 本项目判断 |
| --- | --- | --- | --- |
| L1 | `docs/teaching-methodology.md` | 一份简短的教学理论作为权威，系统提示词视为其压缩；核心为“从已持有出发，一次一个推理步，逐步检查” | 采用“理论文档先于提示词”的做法；本项目的理论依据另行整理，不搬运其表述 |
| L2 | `docs/architecture.md` §6（:353、:359、:363、:367） | 抽取器只读教师正文（不读学习者消息、测验与工具过程），产出命题与“前提共同推出结论”的推理链；审核器只见命题、只判身份（链接已有节点或新建），**取向是等价合并**：改写、复述、压缩都视为同一命题；确定性合并器追加记录，并删除可由其他链推出的冗余链；类型边 `supports` 已退役；不存任何学习者理解状态 | 采用“抽取—身份判断—确定性合并”的分工与“图中不存理解状态”。**身份取向相反**：本项目保守合并，且不按名称或裸 LID 合并（ADR-0169），因为误合会让召回与跨书选材把不相干的关系当作同一关系。冗余链删除列为 M1 可选 |
| L3 | `docs/vision.md` §1 笔记导入 | 笔记与会话走同一抽取管线，笔记内容被抽为命题 | **不采用**：本项目笔记允许粗略、疑问甚至错误，只做“笔记触及哪些关系”的关联，不从笔记中抽取真命题 |
| L4 | `src/agent/prompts/practice/10-doctrine.md` §II–§VII | 练习目标在出题时须处于非激活状态（题面不点名）；回忆 / 辨析 / 组合三种方式与先后顺序；默认交错；目标优先级为最弱、被依赖最多、最久未激活（§IV）；难度调整为顺利则升、需提示则保持、失误则降，同一目标连续两次失误换目标（§V）；出题前自行解题并排查捷径（§V）；提示阶梯 R0–R5，“澄清题意免费，解题信息计量”（§VI）；失误分为没想到、选错候选、执行失误、粗心、所据命题本身有误（§VII）；重试换新情境 | 采用这些学习科学原理，并按本项目的证据模型改写（ADR-0178 §4–§6）。阶梯的中间层（重述情境、缩小候选范围而不点名）对应本项目的“情境结构”提示。交互形式不同：本项目提示是指向（题目、情境结构、自己的笔记、原文、关键一步），并按种类记录协助 |
| L5 | `src/agent/prompts/practice/00-base.md`（:23、:25、:27、:29） | 练习会话：`problem` 出题并提交私有解答，`conclude` 结束；同时只有一道进行中的题；结束后进入停顿，只有学习者明确“下一题”才出新题；放弃一道题视为完全放弃，必要时日后换新情境重试 | 采用“一次一题、停顿由学习者结束”；不采用独立练习会话的形态 |
| L6 | `docs/architecture.md` §7（:383–:395） | 题集：从图中选节点 → 划分 → 每题一个生成器 → 每份作答一个评分器；每题只能作答一次，提交即展示解答；0–10 分只作反馈，**“是强化而不是评估”，不写回任何地方**；三个参数：难度阶梯（含示例题、补全题）、线索距离（课内 / 邻近 / 远）、理论或应用呈现 | 不采用题集页面与分数。采用“线索距离”的概念作为 P2 的情境距离（近迁移 / 远迁移是通用学习科学概念，档位与命名自定）；示例题与补全题留作零基础学习者的后续选项。**记录取向不同**：本项目把练习结果写入既有学习证据并区分独立与协助，供选材与教学接续使用；为免记录被当作掌握分数，坚持不生成等级（ADR-0178 §5） |
| L7 | `docs/vision.md` 聚类；`docs/architecture.md` §6（:373）与已替代决策表（:572） | `vision.md` 设想用 Louvain 社区检测分区；当前实现按命题首次出现的会话分组，文档明言 “no Louvain anywhere”；已替代决策表记录 Louvain 已被替换 | 不采用聚类；本项目的分组沿用既有工作区、材料与画板 |
| L8 | `docs/architecture.md` 已替代决策表（:570） | 为会话提供历史学习内容时，“热点 + 一跳图邻域”已被“按语义相似取前 K 条（受 token 预算限制）”替代；文档未给出两者的对比数据 | 这不是效果证明，但说明结构邻域并非显然更优；加上本项目 LA9 的结论，结构召回只作为待验证假设，须先通过 M0 |

这些原理本身来自公开的学习科学研究（检索练习、交错练习、合意困难、近迁移与远迁移、逐级提示等），不是任何一方的专有设计。

## 3. 有意的差异

| 方面 | LearnHarness | 本项目 |
| --- | --- | --- |
| 练习入口 | 独立练习会话与题集页面 | 旧想法回访、“练一练”与回到工作区时的热身、阅读边注（默认关闭）、考试冲刺每日练习 |
| 提示 | 教师按内部阶梯（R0–R5）在对话中逐级给出 | 提示本身就是指向：题内条件、情境结构、自己的笔记、原文段落、关键一步；按种类记录协助，界面只显示剩余条数 |
| 作答形式 | 文字作答 | 文字作答；后续可在画板上组装论证、在教具上提交控件状态 |
| 学习者记录 | 只作反馈，不写回（“强化而不是评估”） | 写入既有 `LearningEvidence`，区分独立与协助支持，不形成等级 |
| 出题质量 | 出题前自行解题并排查捷径 | 同样要求作者自查，另有宿主确定性检查与交付后核查；出题前没有同步模型审阅（ADR-0176） |
| 合并取向 | 等价合并：改写即视为同一命题 | 保守合并，不按名称或裸 LID 合并（ADR-0169） |
| 图谱呈现 | 图谱首页与推理链表格 | 不设图谱首页；以“这条想法所依据的…”、有理由的建议联系、生成画板呈现 |
| 笔记 | 被抽取为命题 | 只关联关系；联系经用户确认后才成为 `NoteLink` |
| 来源 | 会话出处 | 带来源与版本的 LID 原文定位 |
