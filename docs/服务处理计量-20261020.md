# 服务处理计量

日期：2026-10-20。对应[云端学习实施计划 C4](实施计划-云端学习与考试冲刺.md#c4-非模型处理纳入统一服务额度)。

## 计量行为

视频准备的每段 Whisper 音频处理、学习对话中的 `video.review_audio` 原声复核都纳入统一账号额度。用量为 Whisper 回执里的实际音频毫秒数，包含转写重叠段；按 `ceil(quantity_ms × 每秒费率 / 1000)` 计算整数内部额度。模型 Token 与音频时长保持独立记录。

准备任务沿原用户确认的父任务预算准入，模型与处理共享剩余额度和总扣减上限。短音频复核沿原 Run、学习工作区及账号归属，使用同一账号余额，不创建构建任务预算。公共构建归平台，无学生扣减。

`service_usage` 保存独立处理事实；`billable_usage` 是模型和处理的只读汇总视图。余额、费用列表、父任务汇总及成本报表都从统一事实读取。准入事务计入未完成预占及待确认金额，所以另一个工作区或模型请求不能使用已经预留的额度。

## 费率配置

配置文件位于服务数据根目录 `service-rates.json`，与 `model-rates.json` 同级。格式为 `{"rates":[...]}`；每条费率包含：

| 字段 | 约束与用途 |
| --- | --- |
| `version` | 非空版本，同一文件内唯一 |
| `service_kind` | 当前为 `video_transcription` |
| `starts_at` / `expires_at` | UTC Unix 秒，有效区间为左闭右开；同种处理费率区间不能重叠 |
| `debit_micro_cny_per_second` | 正整数服务额度费率；正式数值待定 |
| `estimated_cost_micro_cny_per_second` | 平台处理成本估计，可为空；不代表供应商账单 |

个人视频启动及原声复核需要有效费率；缺失、无有效时段或配置无效均返回 `SERVICE_RATE_UNAVAILABLE`，不启动收费处理。费率在每次处理准入时冻结，修改配置不改写在途或历史记录。平台构建允许未配置时记录真实时长与未知成本，仍不扣学生额度。

服务额度、平台实际成本和平台估计成本分别表达。当前本地 Whisper 只有处理用量，实际供应商成本没有可用凭据时保持未知；配置过估计单价的回执标为 `estimated`。报表单独显示估计，不能将其并入已确认供应商成本。价格和正式费率未在本轮设置。

## 执行、恢复与核对

`skills/build/video-operator-build.ts` 把 `ExternalBuildCostLedger.transcriptMeter()` 接到 `buildVideoTranscript()`；生成音频后，先向服务端预占，再启动 Whisper。每段完成回执先写本地，再提交服务端；回执响应丢失时重传同一用量标识，保存的原始输出继续使用。已经完成的段不重新转写或收费。

进程中断且未留下完整回执时保持 `pending` 和原预占；自动重连与宿主恢复不会重新处理同一逻辑段。用户明确“继续”产生新的 `processing_confirmation` 后，未完成段可用新尝试标识执行，原待确认占用继续计入账号余额和父任务上限。服务端比较任务当前确认与上次准入确认，不能只靠更换宿主或用量标识重复启动。已经完成的段始终复用。

运营者可在费用详情根据执行日志确认实际时长，或确认尚未启动以释放原预占。核对使用 `/api/admin/service-usage/:usage_id/reconcile`，与原运营操作回执同事务保存；重复提交或查询同一操作得到原结果。没有证据时保持未知。

网络原声复核在 `NetworkRunPort::review_video_audio` → `video_audio::review_audio_metered` 的真实 Whisper 启动点计量。启动失败释放预占，启动后结果不明则保留待确认；完成后使用解码音频实际时长。维护环境的本地直接调用继续独立运行。

回执结算使用准入时绑定的原额度期，即使收到时账号已经到下一期。历史费用、费率和原期百分比不随续费改变。

## 验证

- `crates/server/src/tests/c4_service_usage_tests.rs`：缺费率拒绝、模型与处理共享预算、跨父任务共享账户余额、费率快照、回执幂等、未知预占、跨期归属、公共构建、原声复核 Run 归属、运营核对回执。
- `packages/core/test/service-usage.test.ts`：准入失败不执行、实际时长缺失保留未知、中断不自动重试、回执丢失恢复、真实 FFmpeg 与转写发布链不重复识别。
- 原 `video-transcript`、`video-operator-build` 测试继续覆盖既有本地恢复和公共构建执行。

编译与测试结果由本轮联合验证统一记录；完成结果以实施计划的 C4 状态为准。
