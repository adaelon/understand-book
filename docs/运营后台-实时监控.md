# 运营后台实时监控

2026-10-28：本地实现与验证完成，尚未发布线上。入口为后台侧栏“实时监控”与 `/admin/monitor`。

## 页面与统计口径

| 指标 | 数据与含义 |
| --- | --- |
| 服务器内存 | Linux `/proc/meminfo`，已用为 `MemTotal - MemAvailable`，可回收缓存计入可用 |
| 服务数据磁盘 | 服务数据根目录所在文件系统的 `statvfs`；总量为 `f_blocks × f_frsize`，已用扣除 `f_bfree`，可用使用普通服务账号可用的 `f_bavail` |
| 实时带宽 | 默认 IPv4 / IPv6 路由网卡去重后读取 `/proc/net/dev`，按单调时钟的实际采样间隔计算收发字节差；页面换算为 bps / Kbps / Mbps / Gbps |
| 在线人数 | 最近 90 秒收到可见页面心跳、且登录会话仍有效的去重账号数，包含管理员；同账号多个页面或登录会话只算一人 |
| 正在进行的 AI 对话 | `run_admissions` 中 `claimed` 且非 `unsaved` 的对话轮次，包含该轮运行与保存过程 |
| 排队 | `preparing` / `queued` 且非 `unsaved` 的轮次 |
| 今日对话轮次 | 香港自然日内已有 `question` 事实的提问或继续；一轮只记一次，多次模型调用不重复记数 |
| 今日完成交付 | 香港自然日内已有 `completed` 事实的轮次，沿用成功保存及交付判定；可以包含前一日发起的对话 |

资源定义参照 [Linux 内核 /proc 文档](https://docs.kernel.org/filesystems/proc.html) 与 [statvfs 手册](https://man7.org/linux/man-pages/man3/statvfs.3.html)。磁盘预留空间使“已用 + 可用”可能小于总量。

## 数据链路

`NetworkApp → useAccountPresence` 与 `App → useAdminPresence` 在已登录、页面可见时每 30 秒发送 `POST /api/account/presence {}`。Reader 初次身份恢复及注册、重置密码页面不发送心跳；离线失败等待下一次尝试，身份切换或组件卸载清理计时器并取消在途请求。

心跳沿用当前 Cookie、Origin 和 CSRF 检查，只更新 `ServerMonitor` 的内存状态。会话键复用既有认证身份；采样时通过 `auth_sessions / users` 的当前会话有效性、账号状态与认证版本过滤，再按账号去重。关闭或隐藏所有页面后，最长 90 秒移出在线统计。

`GET /api/admin/monitor → ReaderAdmin → ServerMonitor::snapshot` 返回 `current`、`history`、采样周期、在线窗口及时区。所有管理员共享 5 秒采样缓存，系统读取在控制库锁外，业务统计在同一只读事务完成；当日事件与运行状态沿用现有索引。接口不装载私人 Reader 现场、不读取聊天正文、不遍历磁盘目录。

趋势至多保存 120 个样本、10 分钟。只有请求监控接口时才采样，无后台常驻采集线程、数据库写入或新增依赖，控制库 schema 保持 21。首次网络样本、超过 15 秒的采样中断、网卡变更或计数器重置均重新建立基线，不显示虚假的零流量或峰值。

页面每 5 秒刷新，支持暂停、恢复、立即刷新及图表采样时间选择；页面隐藏时停止轮询。失败保留上次结果并显示连接中断，资源读取失败分别显示不可用；超过 15 秒未收到更新标记数据过期。刷新年龄按客户端接收时间计算，显示时间统一使用香港时间。

## 验证

后端 6 项专项测试、Admin 73 项全量测试、Reader 14 项相关测试通过。Admin 与 Reader 多人版均完成生产构建。真实浏览器覆盖桌面、手机、深色模式、自动/手动刷新、暂停/恢复、连接错误与部分指标不可用；Linux 临时探针使用同一份资源采集函数读取真实系统数据。命令、截图和原始结果见 [验收记录](performance/server-monitor-20261028/README.md)。

## 已知限制

- 尚未发布正式服务；Reader、Admin 和后端需要同版发布，旧 Reader 页面没有心跳，刷新新版页面后才纳入在线统计。
- 系统资源采集适用于现有 Linux 部署；Windows 本地运行保留业务统计，资源显示不可用。
- 带宽显示默认路由网卡的实际吞吐，包含同机其他进程流量，不表示云服务商购买的带宽上限。
- 在线指仍有可见页面的账号，不等于实际持续操作的人数；纯 MCP 客户端不发送页面心跳。
- 趋势仅保留内存中的近期采样，关闭全部监控页面期间不补采，服务重启后重新积累。
