# 音乐伴听回答中的可试听谱例

2026-11-04 · 已完成本机接入与贝九第 17–21 小节真实 Agent、桌面和手机试听验证。决策依据见 [ADR-0180](adr/0180-agent-authored-playable-music-examples.md)，实际结果见[验收记录](performance/answer-piano-20261104/README.md)。

## 读者看到什么

第 18 小节的 **A4** 和第 20 小节的 **A5** 各自可以点。先点前一个，再点后一个，同一块键盘会在相隔一个八度的两个位置亮起。读者不需要先懂数字 4 和 5 的含义。

一串音在正文里只占一行，例如「**▶ A5 → G5 → E5 → A5**」。点播放键听整串，点其中的 E5 就单听这个音。和弦显示成「**▶ C♯4 + E4 + A4 + E5**」，点播放键时四个键一起亮。再次提到同一组音，Agent 可以把同一标记放在新的位置。音阶、单音、旋律和同时发声的和弦都用这套交互。

首次点击时，在当前对话的可见区域展开一块小键盘，旁边写明「谱面合成 · 第一小提琴 · 第 20 小节」或「教学示例」。键盘在一段试听期间保持同一音域，显示音名和八度，黑键可以点。换谱例就切换同一个键盘。手机把键盘放在对话底部，收起后回到原阅读位置。键盘可用触屏和键盘焦点操作，停止和重听都在手边。

## 怎样找对声部

1. **从提问现场找候选。** 使用本轮冻结的 `MusicQuestionContext`，其中有发布、谱位、演奏出现、关注的乐器和谱线。Agent 用 `music.read` 的 `overview` 查看乐器名称与 `part_id`，再用 `score` 按乐器、谱线和相关小节读取实际音符。播放位置帮助找小节，已选乐器帮助缩小范围。
2. **用谱上的动作区分候选。** 这次回答明确说“第一小提琴，只看它”，对应 `P48`，第二小提琴是 `P49`。第 19 小节，`P48 / 1:1` 和 `P48 / 1:2` 都有延长的 D4，只有 `1:1` 继续走 F5 → E5 → D5。这足以选出回答正在讲的谱线。主题、旋律、低音是音乐作用，同一作用在不同小节可能换乐器。
3. **只登记已经分清的对象。** 当两条线都符合描述，Agent 先读相关谱位。若仍无法区分且区别影响解答，可以问“你想听持续的低 D，还是随后跳高的那条线？”其余已确定的部分照常交付。缺少依据的裸 A 保留为文字。给作品补一个猜测的八度，即使听上去通顺，也无法用作该处的作品谱例。

现有读取已经给出 `part_id`、`voice`、`source_id`、`beat`、`duration_beats`、`midi_pitch`、`rest` 和 `tie`。小节、乐器和谱线用于限定范围，稳定的谱对象 ID 用于指认那个音。例如 `s-p16-m20-n1` 所属的乐器要读对象里的 `part_id`，实际值是 `P48`。[音乐合同](../crates/base-schema/src/music.rs) · [音乐来源读取](../crates/read-tools/src/music.rs)

## Agent 填什么，程序算什么

音乐场景通过 `music.example` 登记回答中的试听内容。凡是回答请读者辨听、又能明确指认的单音或音组，都用试听标记承载。一个连续音组只需一个标记，其中的音可以单点。一次调用可以登记本轮多个谱例，返回每项的可读预览和可插入回答的标记。调用本身没有声音。作品片段沿同一乐器的同一条谱线，允许在原谱顺序中跨小节。第 17–21 小节的完整动机可以一次连奏，各小节仍可分别登记供拆开比较。

以下是用真实谱对象登记三个试听位置的输入。

```json
{
  "items": [
    {
      "key": "a18",
      "kind": "score",
      "part_id": "P48",
      "voice": "1:1",
      "from_id": "s-p16-m18-n2"
    },
    {
      "key": "line20",
      "kind": "score",
      "part_id": "P48",
      "voice": "1:1",
      "from_id": "s-p16-m20-n1",
      "through_id": "s-p16-m20-n4"
    },
    {
      "key": "chord21",
      "kind": "score",
      "part_id": "P48",
      "voice": "1:1",
      "from_id": "s-p16-m21-n3",
      "through_id": "s-p16-m21-n6"
    }
  ]
}
```

**作品谱例。** `key` 只用来对应批量返回项。宿主从本轮已读的 score 对象绑定确切发布和谱本修订，核对端点所属乐器、谱线和原谱先后顺序。只有 `from_id` 时取一个音。带 `through_id` 时，程序从同一发布的谱面展开两个拍位之间的完整片段，包含两端拍位上的同时音、相连延音和休止。跨小节时按完整乐器各谱线的音符及休止范围确定小节跨度，选中谱线的空白保持静默，跨小节相连延音只起音一次。这样 Agent 只给乐句或弦乐和弦的首末位置，程序就能取齐整段。读谱分页时以原谱补全区间，不能把缺少的页当作静默。仅列在调号或拍号出处里的 ID 不等于本轮已经读到那个音符。

上面三个预览分别是 A4、A5 → G5 → E5 → A5，以及同时响的 C♯4、E4、A4、E5。每项预览附乐器名、谱线和小节，Agent 据此核对自己要讲的对象。合法的 `P49` 音符也可能是作者选错了第二小提琴，工具只能证明指定谱位确实这样写。错声部、逆序端点、跨发布或未读端点则返回对应项的具体原因。

标记由宿主分配。假设第二项返回 `[[listen:ex2]]`，Agent 就写「听这串音 `[[listen:ex2]]`，最后一下跳回了开头。」读者在同一个位置看到可点的「▶ A5 → G5 → E5 → A5」。表格再次讲到这串音时可以复用 `[[listen:ex2]]`。这样即使一句话里有几个 A，每个可听位置也由写回答的 Agent 指定。

**教学示例。** 讲解一个自行构造的音阶时，填 `kind: "illustration"` 和按顺序排列的 `steps`。每一步填写带八度的音名列表 `pitches` 和以四分音符为单位的正时值 `beats`。例如 `{"pitches":["D4","F#4","A4"],"beats":1}` 表示三音同响一拍，空列表表示休止。多步和弦组成一次连续播放的和弦接续，每一步内部同时发声，各步按时值相接。示范一条 C 大调上行音阶，可以选定 C4 为起点，逐步写到 C5。工具拒绝缺少八度的音名。「教学示例」只用于回答里明确提出的练习或对照。暂时找不到出处的作品音名保留为文字。

**声音时序。** 保存每个音的实音音高、相对起拍、时值以及整段长度。相连的同音延音只起音一次，独立重复音重新起音。同拍和弦共享起点，每个音保留自己的结束位置，末尾休止计入段长。初版采用固定、可见的示范速度 ♩ = 66。键盘和声音共用试听时钟，录音中的秒数只用作原声定位。回答中的钢琴采用 Salamander Grand Piano V3 的 Yamaha C5 第 8 力度层，直接使用原始 48 kHz、24 bit、双声道 FLAC，30 个录音按原作者的小三度映射覆盖 88 键；浏览器按需加载整段所需采样后，用原生音频时钟安排播放。加载中可以停止，失败显示重听入口，成功解码后在当前页面复用。原件核对、逐键校准和署名许可见[无损验收](performance/salamander-lossless-20261104/README.md)。已有谱面合成器继续作为拍值实现参照。[既有合成器](../packages/core/src/music-demonstrations.ts)

## 回答如何交付

Agent 在音乐场景能直接使用 `music.example`。本轮登记的谱例在最终回答编译时解析成行内 `music_example` 内容，随 `AgentAnswerView.parts` 保存可读标签、来源身份、选中谱对象及播放事件。教学示例只保存其显式事件和示例身份。沿现有来源绑定保存作品出处，保留原发布与谱本修订。一般谱面引用继续提供查看出处的入口。

程序按标记的位置嵌入控件，正文、加粗、列表和 Markdown 表格都适用。流式草稿可显示可读文字，最终交付后才启用按钮。编译时遇到本轮未登记的标记，走现有回答修复路径，最终文本保留可读内容。复制、选区笔记、分享和历史摘要使用同一可读标签，例如“A5 → G5 → E5 → A5”。

一批谱例共用一次取谱，重复试听完全在本机完成。重开会话时使用随回答保存的事件，原发布中的 A4 仍是 A4。点「查看谱面」沿保存的来源打开原谱。开始试听会暂停正在响的原录音或已有示范，保留原位置。用户恢复原声、切换会话或收起试听时停止键盘声音。原声逐音对齐仍是候选的区间，也可以按正确的谱面拍值做钢琴示范。

## 贝九验收样本

采用 Tennstedt 1992《贝多芬第九交响曲》第一乐章，本机发布 `music-beethoven9-tennstedt-m1-release1` / `01a1a0d2-4e74-7f81-8636-4c91fad083d5`。下表来自发布清单中第一小提琴 `P48 / 1:1` 的谱对象，时值以四分音符为 1。这五小节在原录音中从 34.37 秒到 43.64 秒。[材料与重建入口](performance/beethoven9-tennstedt-20261103/README.md)

| 小节 | 程序应该弹出的声音 | 最容易听出的差错 |
| --- | --- | --- |
| 17 | A5 持续 1⅞ 拍，F5 占 ⅛ 拍 | A5 中间再次起音，会把一条长音听成两下。 |
| 18 | D5、A4、F4、A4、F4，时值依次为 ⅞、⅛、¾、⅛、⅛ | 把 A4 弹成 A5，第一步就会从下行变成上行。 |
| 19 | D4 持续 1¼ 拍，然后 F5、E5、D5 各 ¼ 拍 | 若选成 `1:2`，只能听到延长的 D4，整串上跳和回落都会消失。 |
| 20 | A5、G5、E5、A5，各 ½ 拍 | 最后一次上跳回到起点，应点亮开头的同一个键。 |
| 21 | D5 持续 ¾ 拍，休 ¼ 拍，C♯4 + E4 + A4 + E5 同响 ¾ 拍，再休 ¼ 拍 | 分解成四次起音，或把两个 E 合成一个键，都改变了收尾。 |

## 首版边界

作品试听覆盖已发布结构化谱面中有固定音高的单音和单谱线连续乐句。只有扫描谱、无固定音高的打击乐、无法确定时值的装饰音，以及跨谱线的合奏，继续使用已有谱面与原声入口。旧回答只有自然语言时，按保存的文字展示。读者需要补听，可以基于原发布重新生成带谱例的解释。
