# ADR-0193 在同一段阅读问答中讲清原理与应用

2026-11-25 · **已接受。** 2026-11-26 首轮配对试验完成，普通问答沿用改前主讲提示。读者的讲解目标继续作为评阅依据。[实施与验收方案](../切片方案-零基础入口与高密度机制讲解.md) · [首轮采用决定](../实施记录-零基础教学默认.md#s3--七组配对与采用决定)

读者在专栏第 069、070 讲读到刻意练习，又问有了 Agent 该怎样练。按读者复盘，回答先列出练习的四步，随后在 Agent 应用和产品例子中又各列了一遍。读者仍想知道，当工具可以先指出错误时，自己该练哪一步。

**内置 Resident 在普通文字阅读问答中，按读者当前要弄明白或完成的事安排讲解。** 从原理转到应用时，承接已经讲清的部分，用新场景的具体条件走一遍读者需要作出的判断或行动。有条件发生变化，就说明它怎样影响做法。读者要求完整演练时，把必要步骤走完。沿用同一对话入口，读者接着只问其中一步，就回到那一步。[统一问答与练习入口](../实现-统一问答与练习入口.md)

对第一次接触概念的读者，从能辨认的对象和操作起步，术语和公式在有具体所指时引入。一个能直接听懂的判断也可以作开头。概览交代作品主线，完整推导交代前提和中间连接，局部问题讲通当前卡点即可。读者想自己练时，可以先示范，再把下一例的判断留给他。需要突出结论或并排比较时，可用加粗或表格。[零基础教学默认](../实施记录-零基础教学默认.md) · [讲解写作规约](../../crates/runtime/src/tutor_writing_rules.md)

**书中的主张要有原文依据，场景推演要让读者看见前提。** 用已验证的选区或实际读到的原文说明作者说了什么。普通文字问答按需呈现可点击来源，读者明确索要书内出处时给出相应引用，画板中的实质书内主张按画板合同挂接。参考书使用该书的出版身份绑定来源，网页使用实际读过的页面链接。无论是否联网，都可以从已有前提推导或构造条件明确的例子。理论归属、学习效果和外部因果需要相应证据。遇到影响结论的缺口，先读能取得的参考材料或一手来源。确实取不到时，说明哪一问仍待查证。[ADR-0086](0086-runtime-owned-user-visible-source-references.md) · [来源呈现与跨书取证](../../crates/runtime/src/agent_prompt.rs)

首轮固定模型、材料和预算，只比较主讲如何把原理用到新场景。采用与否看专栏三问是否答全、迁移段是否给出可用的判断，以及局部追问和完整推导是否各自讲通。阅读偏好取自读者本人对匿名答案的选择。初学者能否独立运用，另看其在相近新例中的实际表现。
