# ADR-0145 视频媒体定位与可修订视觉事件

状态：已接受设计，2026-09-29；来自 [视频 Grill VQ12](../grill-video.md#vq12-可重新划分的事件与固定来源引用2026-09-29)，用户选择 A。

## §1 媒体来源与视觉事件

**决策**：允许重划分视觉事件，旧引用保持原始片段。

**否决**：
- 首次生成后固定全部 VU 边界：限制渐进索引和补充观察对错误或粗糙划分的修正。
- 用最新 VU 边界重新解释旧引用：改变旧回答、笔记当时所依据的内容。

**命门**：媒体定位表达确定原视频中的时刻或区间；Visual Unit 表达对实际画面状态或变化的语义组织。同一原视频重分析时，VU 可以拆分、合并，已保存来源引用仍固定指向原来的真实片段。引用身份与可修订事件分别承担职责，具体字段合同在后续设计中确定。
