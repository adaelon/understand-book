# ADR-0190 通过代表课确定课程预构建方向

2026-11-19 · **已接受。** [切片方案与实施记录](../切片方案-试课与课程预构建.md)

只给一本书发起制课时，委托人往往能说出为什么喜欢这本书，却还说不准怎样教给别人。把初次交谈中的例子直接扩写成一整门课，会把选错方向的代价推迟到课件已经制成之后。**开放式建课先交付一节可以亲自上的代表课，试过以后再确定课程路线。** 委托人已有明确路线并要求直接制作时，沿已有入口建课。

制课 Agent 读全书结构与候选原文，提出暂定的读者起点，选择一个能用原文检验、能在新情境中独立应用的问题。委托人可以提供背景，也可以先试课。体验中的具体选择、疑问和帮助支持对该活动的判断。Agent 回到相应原文和题目查明困难，再决定是改讲解、换例子，还是向委托人提出不同的课程方向。

试课之后，Agent 用受众、路线总问题、结课任务、拟用章节和随后一两课说明扩大制作的含义。委托人可采用、调整或暂缓该路线。制作端保存选定的设计和范围，私人学习记录保存作答、求助和进度。试课草稿与该书正式课件分别打开，试过的版本能继续回看。正式制作复用仍然适用的课件和来源依据，按照原有预算与发布流程交付。

委托人试课解决的是是否值得这样制课。发布前判断目标读者能否独立应用，仍取证于实际目标读者。单课设计、审题和正式发布的标准沿用 [ADR-0182](0182-book-structure-led-inquiry-courses.md) 与[课程制作规范](../../skills/build/course-methods/authoring-standard.md)。
