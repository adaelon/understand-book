# ADR-0184 以当前任务组织学习入口与教学接续

日期：2026-11-16。状态：**已实施；定向工程验证通过，真实模型与首次使用者尚未完成验收。** 实施范围、顺序和完成依据见[切片方案](../切片方案-学习主线与课程入口.md)，实际证据和剩余问题见[实施记录](../实施记录-学习主线与课程入口.md)。

**决策：以可直接开始、可完成和可接续的当前学习任务组织主体验。** 用户从课程或自己的材料进入，围绕一个明确目标经历讲解或探索、自己表达或应用、针对性反馈与下一步。首页、课内动作和返回入口共同承接这条过程。

2026-11-16 补充：[ADR-0185](0185-book-and-course-collection-learning-hierarchy.md)将一级“课程”入口调整为“学习”，以书籍或成套课程组织单元和单课。当前任务显示所属学习对象，保留本 ADR 的直接继续、明确练习与原现场恢复规则。

## 背景

现有课程已支持问题主线、多轮活动、作答反馈和私人恢复；“练到会”支持显式开启的闭卷对话、补教、独立重试和结束条件。当前入口主要按资料、工作区、会话与记录组织：新用户先创建工作区，共享课程目录默认折叠，主动练习归入学习记录，首页“继续学习”打开工作区第一份可读资料。已有教学能力尚未形成清楚的首次使用与返回路径。

本次调整沿 [ADR-0182](0182-book-structure-led-inquiry-courses.md)、[ADR-0183](0183-closed-book-dialogue-to-independent-performance.md) 复用现有课程和练习；普通对话沿[统一问答与练习入口](../实现-统一问答与练习入口.md)接纳请求。产品继续服务用户自己的问题、兴趣和选择，课堂活动按材料与目标安排。

## 决策

### 1. 首页呈现可开始的课程和可继续的任务

登录后的学习首页优先展示当前未完成任务；没有任务时，展示实际可用课程及“用自己的资料学习”。主导航提供稳定的“课程”入口。课程卡说明本课要解决的问题、建议基础和已有预计时长，主动作直接进入第一项学习活动。宣传首页的课程体验链接进入同一真实路径。

共享课程在开始位置展示公共目标，用户点击“按这个目标开始”即接受该目标；修改目标和考试设置就近展开。该动作沿 [ADR-0170](0170-goal-scoped-learning-workspaces-and-shared-releases.md) 建立或接续原私人实例。工作区仍承担资料、目标与私人记录的归属，浏览和选择课程使用学习者能理解的名称。

目录只把具备可运行课件的内容列为可开始的课。当前资料没有课程时，可从所选内容发起“带我学这一部分”；材料准备状态、课程可用状态和自由问答分别按真实能力展示。

### 2. 用可观察的小目标呈现当前学习段

一课保留原主问题和多轮结构，每段围绕可独立说明、判断或应用的目标组织。界面持续呈现当前目标、正在进行的任务和主要动作；原文、实验和历史为当前任务提供支持。20–30 分钟完整课可按已有轮次暂停，具体长短服从内容与声明起点。

过程按教学需要采用“讲解或探索 → 自己表达或应用 → 反馈 → 下一段”；先预测再观察的课程保留原揭示顺序。用户能够直接求助、插问、暂停和改变方向，返回时接回原任务。

### 3. 在讲解与任务现场提供主动练习

“我来解释一下”“给我一道应用题”和“练到会”属于当前学习动作，放在相关讲解或任务附近。入口采用已交付内容、当前目标和确切材料范围，目标明确时直接进入；只有缺少会改变任务的对象时才澄清。

普通提问与练习继续使用统一问答和原题绑定。持续闭卷追问沿 ADR-0183 默认关闭；进入持续练习的动作在点击前说明“收起资料、根据回答追问或补讲、可随时暂停”，用户选择后建立约定。“给我一道应用题”沿普通练习合同，进一步选择“练到会”才建立持续约定。需要原文或实验的活动在原课程现场完成。

### 4. 反馈决定下一步，已有表现回到原任务

反馈回应本次原话，说明已经成立的理解、仍需补充的关系和适用的下一步。依据充分就结束当前目标；需要帮助时先补具体缺口，再按实际帮助安排独立尝试。结束卡分别表达学习进度与本次表现，并给出继续下一段或暂停的明确动作。

课程中的练习归属原 CourseRun。闭卷完成后的原话、题目和帮助作为原课程任务的判断输入：满足该任务既定要求时由原规则接纳；尚缺观察、推理或迁移时说明具体待完成内容并返回对应位置。课程规则负责推进，界面依据接纳结果显示下一步，已经被接纳的同一要求不再索要重复作答。

### 5. “继续学习”恢复任务现场

首页的继续入口定位用户最近明确开始或继续的未完成任务，展示具体目标和下一动作。课程内处于闭卷或补学时，恢复该子过程及原课程返回点；普通讲解的续学定位原聊天与已交付内容。已暂停的任务使用明确的继续动作恢复，加载页面只读取状态。

当前任务是原课程、练习和对话事实的读取投影。课程进度由 CourseRun 持有，闭卷约定沿 ClosedBookPractice 及其原绑定持有，聊天与帮助沿原事实存储。首页选择和导航只需保存接续引用；后台记录整理不改变用户最近选择的任务。没有未完成任务时可继续阅读或开始课程。

## 与既有决策的衔接

- ADR-0170 的目标接受与私人所有权继续有效；现成课程的接受动作收进开课入口，用户仍可修改目标。
- ADR-0182 继续决定课程组织、揭示顺序和推进；本 ADR 决定其发现、当前任务呈现与接续入口。
- ADR-0183 继续决定闭卷显示范围、帮助事实、独立重试与结束条件；入口文案按具体动作表达。
- 2026-11-15 的统一问答继续作为普通请求执行路径；学习入口直接提交明确请求，历史教学开关保持原有处理。

## 取舍与实施边界

仅移动菜单能够改善发现，但首页继续动作和练习结束后的返回仍会中断学习，因此首批交付贯通“开课—学习—练习反馈—回课—下次继续”。现有课程的课内轮次已能承担分段学习，优先复用；当前任务投影直接利用既有记录，页面加载、浏览和恢复已交付内容由宿主完成。

入口、接续引用与结果回课已按本决策实现；工程交互、模型教学质量和真实学习者的使用结果分别记录于[实施记录](../实施记录-学习主线与课程入口.md)。已有质量问题与验证范围集中维护在[方案的已知问题与证据边界](../切片方案-学习主线与课程入口.md#7-已知问题与证据边界)。
