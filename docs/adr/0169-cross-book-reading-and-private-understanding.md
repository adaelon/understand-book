# ADR-0169 跨书补讲与私人理解接续

日期：2026-10-16。状态：已接受并实现。实施与验收：[切片方案](../切片方案-跨书补讲与理解接续.md)。

## §1 内部书库访问

**决策**：阅读器复用内部授权书库与原文读取。

**否决**：
- 绕远程 MCP 调自己：多出凭证、传输和调用包计费，仍缺少私人学习上下文。
- 为补讲切换当前书：破坏原提问现场和聊天归属。

**命门**：目标材料使用确切 PublishedBookRef；身份来自当前运行，沿既有材料授权。
**展开**：[方案 §2](../切片方案-跨书补讲与理解接续.md#2-内部调用与来源)。

## §2 理解归属

**决策**：跨书理解存入同一用户的 LearningMemory。

**否决**：
- 只把补讲放进当前聊天：回到参考书后不能取得学习积累。
- 把讲解完成记为掌握：没有学习者表现依据。
- 把跨书概念名称当正式对象身份：同名不能证明同一对象。

**命门**：保存原提问与真实用户表达，理解假设关联参考书的确切来源；正式能力证据沿既有评估合同。
**展开**：[方案 §3](../切片方案-跨书补讲与理解接续.md#3-学习记录)。

## §3 引用与接续

**决策**：引用携带材料版本，追问保留原任务。

**否决**：
- 仅按 LID 合并证据：不同书会有相同位置编号。
- 把参考书来源当当前书的导航目标：会跳错原文。

**命门**：正文、历史、引用预览、来源打开和追问使用同一来源身份；读取参考书不改变当前阅读位置。
**展开**：[方案 §4](../切片方案-跨书补讲与理解接续.md#4-引用和追问)。
