# Whole-source prebuild gate for formal learning

Status: Accepted, 2026-09-07. Design decision; implementation pending.

**决策**: 整份材料的教学基座就绪后开放正式学习。

**否决**:
- 来源可读即开放正式学习：阅读就绪不能证明正式教学资产已就绪。
- 某一段或章节就绪即启动正式学习：首版需要整份材料的结构与关系，支撑模糊目标下的起点选择和前置知识处理。

**命门**: 可信原文达到既有门槛后允许先进入阅读器；正式 TutorLoop 以整本书或整篇论文所需公共教学基座就绪为前提，正式对象身份与学习证据边界保持成立。个性化路径、具体问题和提示由读时 Agent 选择或合成，不作为必须预先穷举的产物。
**何时回头**: 产品明确支持独立章节作为正式学习单元时，重新评估就绪单位。
