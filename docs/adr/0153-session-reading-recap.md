# ADR-0153 本次阅读回顾

状态：已接受，2026-10-01；JL8–JL9 已实现并验证，2026-10-02；整体发布验收归 JL10。阅读回顾将当前聊天中的阅读活动组织为可回到原处的记录，数据来自 [ADR-0152](0152-resident-linear-jsonl-session-log.md) 定义的会话历史。

## §1 范围与用途

**决策**：阅读回顾覆盖当前聊天的明确范围。

**否决**：
- 以自然日或 idle 自动切分“本次阅读”：会与用户控制的聊天边界冲突。
- 将跨聊天 TutorSession 的学习进度当成本次回顾：两者的生命周期与用途不同。

**命门**：首版覆盖当前聊天起点至指定已提交序号，显示范围及更新时间；新增记录后由用户刷新。回顾包含讨论过的问题、引用的原文、留下的成果和待继续事项，条目可回到具体回合、原文或成果。
**展开**：[范围、入口与数据合同](../切片方案-会话JSONL与阅读回顾.md)、[读时会话边界](../../CONTEXT.md)。

## §2 事实与理解程度

**决策**：回顾陈列阅读事实，不判定掌握。

**否决**：
- 将回答完成等同于问题已懂：读者理解程度需要独立证据。
- 从普通聊天自动生成成绩或学习画像：会绕过现有教学审核与证据合同。

**命门**：已交付、已保留、已撤销、待处理及中断据实际记录呈现；处置已开始但没有结果时显示待核对。“待继续”只来自明确未完成的聊天任务和运行，不能由回答语气推断。教学引用可以跳转，学习结论仍由原领域持有。
**展开**：[教学证据合同](0143-teaching-trace-assessment-and-learning-evidence.md)。

## §3 生成与保存

**决策**：首版回顾按已保存事实确定性派生。

**否决**：
- 首版另加一次模型总结：引用与状态可直接从已保存事实组织，不需要新推断。
- 将回顾持久化为第二份事实来源：会增加与原会话同步和纠错的负担。

**命门**：用户打开时生成只读投影，条目携带证据位置；刷新不新增聊天回合、不调用工具、不改变目标或学习状态。来源仍按现有权限解析，原对象删除或不可访问时保留历史事实并显示当前不可用。
**何时回头**：用户确实需要跨聊天专题回顾或可编辑、可保存的总结时，再为其定义独立合同。
**展开**：[实施切片](../切片方案-会话JSONL与阅读回顾.md)。
