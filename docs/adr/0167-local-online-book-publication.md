# ADR-0167 本机命令行在线发布书籍

状态：2026-10-15 用户确认先支持命令行不停服发布。

## 决策

保留服务根的进程级独占写锁。新增服务账户可访问的 Unix socket，让现有 `publish_book` 命令将完整输入目录和明确授权名单提交给运行中的服务。后台页面与上传链路沿现状。

发布线程使用独立 `ControlStore` 连接准备和校验完整包，不占用读者书库互斥锁。登记发布、更新默认版本、指定账号授权与操作回执在同一 SQLite 事务提交。发布仍遵守 ADR-0147 的不可变内容及确切引用合同。

SSH 断线是受支持操作方式中的实际失败路径。使用调用者提供的操作编号和原始请求字段比较来恢复已提交结果，不增加内容摘要。重试已提交操作不重新授予后来被撤销的权限。

## 取舍

本机入口沿用服务账户和私人数据目录的操作系统权限，没有增加互联网管理接口。单个发布线程顺序处理导入，现有 HTTP 请求和回答线程继续服务。首次安装程序需要一次重启，后续书籍发布不需要。

schema 14 的 `publication_operations` 保存已提交操作的请求和发布引用，解决完成后回包丢失导致重复导入的问题。首次部署沿项目既有备份和升级流程执行。

操作方式与验证范围见 [书籍不停服发布](../书籍不停服发布.md)。
