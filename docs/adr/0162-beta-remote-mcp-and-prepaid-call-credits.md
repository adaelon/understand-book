# ADR-0162 内测远程 MCP 与预付调用次数

状态：设计已接受，2026-10-11；MCP1 凭证、MCP2 材料读取、MCP3 免费次数、MCP4 付费包、MCP5 远程协议与 MCP6 Agent 使用信息已实现，MCP7 读者接入与来源打开、MCP8 后台次数管理已实现，MCP9 集成及新 Agent 验收已完成，MCP10 发布待实施。

内测读者通过自己的 Agent 使用已构建资料，服务端提供可定位、可引用的检索与读取。调用次数独立于托管模型成本计量，采用月度免费额度与预付调用包。实施入口：[切片方案](../切片方案-内测MCP与调用额度.md)；产品入口：[产品约定](../内测MCP-产品约定.md)。

## §1 使用资格

**决策**：远程 MCP 仅向启用的内测账号开放。

**否决**：
- 匿名使用或免内测码注册：扩大了已确认的内测范围。
- 购买次数即开放全部资料：混淆使用次数与材料授权。

**命门**：沿用账号准入、停用及 PublishedBookRef 材料授权；每次调用绑定账号与明确的材料版本。
**展开**：[身份与接入合同](../切片方案-内测MCP与调用额度.md#3-身份与远程接入)、[ADR-0159](0159-email-accounts-and-single-use-beta-invites.md)。

## §2 内容能力

**决策**：首版提供纯检索读取，由外部 Agent 推理。

**否决**：
- 直接发布完整本机 MCP 工具集：其中含托管模型命令和单书绑定假设。
- 通过 Reader 当前现场选书：使远程调用依赖私人阅读状态。

**命门**：远程工具从获准的已发布材料读取；原文每页最多 8,000 字符，分页保留准确来源位置。
**展开**：[工具与来源合同](../切片方案-内测MCP与调用额度.md#4-工具与来源合同)。

## §3 免费次数

**决策**：每账号每自然月免费 1,000 次内容调用。

**否决**：
- 每客户端分别发放：同一账号的用量无法合并。
- 再叠加每日次数额度：妨碍内测读者集中使用。

**命门**：每月 1 日香港时间 00:00 重置，未用免费次数不累计；首次开通获完整当月额度。
**何时回头**：内测运行两周后，根据真实使用与服务负载调整后续额度。
**展开**：[次数与扣除合同](../切片方案-内测MCP与调用额度.md#5-次数与扣除合同)。

## §4 付费调用包

**决策**：10 元购买 1,000 次，有效期 12 个月。

**否决**：
- 超额后累计欠费：用户难以预先控制 Agent 的使用支出。
- 付费次数随免费额度月度清零：不符合预付调用包权益。

**命门**：先扣免费次数，再扣最早到期的有效调用包；全部耗尽后停止内容调用。每笔购包保存开通时的价格、次数与期限。
**何时回头**：根据实际重复购买、任务成本和运营量调整后续销售方案；已购包按原约定执行。
**展开**：[收款与次数持久化](../切片方案-内测MCP与调用额度.md#6-收款与次数持久化)。

## §5 成功记次与财务归属

**决策**：成功内容调用原子扣次并留下消费记录。

**否决**：
- 在模型费用余额中存调用次数：两种单位和权益不同。
- 发出内容后再异步扣次：并发与重启会导致用量失真。

**命门**：正常空检索计一次；接入、工具发现、目录和额度查询不计次，失败不计次。内容响应交付前完成短事务扣次；人工收款与购包发放同事务完成。
**展开**：[扣次过程](../切片方案-内测MCP与调用额度.md#5-次数与扣除合同)、[收款接入](../切片方案-内测MCP与调用额度.md#6-收款与次数持久化)、[ADR-0156](0156-reader-admin-and-account-allowance.md)。

## §6 Agent 使用入口

**决策**：接入后由 Agent 自主发现工具并完成阅读。

**否决**：
- 要求人类逐项学习参数再教给 Agent：增加目标用户的接入负担。
- 只返回笼统失败文本：Agent 无法判断等待、重新授权或补充次数。

**命门**：提供接入说明、工具用途、结构化来源、剩余额度与明确下一步；购买由用户完成。
**展开**：[Agent 与界面合同](../切片方案-内测MCP与调用额度.md#7-agent-与界面合同)。

## §7 远程接入方式

**决策**：首版采用 Streamable HTTP 与专用接入凭证。

**否决**：
- 复用网页 Cookie 作为 Agent 凭证：绑定了网页登录与写请求流程。
- 首版自建完整 OAuth 服务：当前内测可先由支持请求头配置的客户端接入。

**命门**：凭证由已登录内测账号管理，只授权 MCP 读取；远程入口复用已发布材料和 SQLite，工具协议不复用住户运行现场。
**何时回头**：明确需要接入仅支持 OAuth 的目标客户端时，再补充对应接入方案。
**展开**：[身份与远程接入](../切片方案-内测MCP与调用额度.md#3-身份与远程接入)。
