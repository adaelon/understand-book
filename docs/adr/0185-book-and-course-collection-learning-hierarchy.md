# ADR-0185 以书籍和成套课程组织学习

2026-11-16。状态：**已接受，已实现并完成本轮验证，未部署。** 用户确认以一本书或一套课程作为完整学习对象，再进入单元、单课与当前任务。实施与验证记录见[实施记录](../实施记录-书籍与成套课程入口.md)。

**决策：学习入口按书籍与成套课程组织。** 一级导航使用“学习”；书籍学习首页和专题课程总目录承接发现、整体路线、已提供内容与进度。单课中的预测、实验、表达和练习属于教学步骤。首页的当前任务作为原学习对象的快捷入口，持续显示归属和具体下一步。

## 组织与行为

- **书籍**：一个书籍入口收拢该书已有课程与路线，显示“阅读原文”和“跟着课程学”，课程按原单元组织。同一 `book_id` 的不同发布属于书籍版本；阅读、课程和历史仍保留精确 `publication_id`，不会互换。
- **成套课程**：围绕同一目标组织完整单元目录、各课与关联材料，可以跨书。进入参考书或下一课后保留原课程集合与私人学习范围，能够返回原总目录。
- **当前任务**：显示所属书或课程、原单元与单课，再显示活动、问题和继续动作。继续仍沿 ADR-0184 恢复原 run、chat、材料及草稿；查看整体目录不替换最近学习选择。
- **内容范围**：目录仅列实际已提供的课程，显示实际课数与完成情况。部分单元有课程不意味着整本书已经配齐课程，完成这些课也不意味着掌握全书。

书籍与课程详情可以直接访问和刷新。浏览详情不创建私人工作区；明确开始某一课时接受页面已展示目标，创建或复用原私人实例并打开该课。已有实例的目录、进度与原任务归属使用其所选发布版本；新版是否接入仍沿原更新合同。

私人实例更新后，从旧任务进入的成套课程仍展示该任务原发布版本，可以恢复已经留下的原课记录。旧版本中尚未开始的课转由当前版本入口学习，避免在已更新的实例里混建旧版记录。书籍首页聚合同书课程与已有版本，具体继续任务仍保留原 run 和精确材料。

课内返回所属学习对象时，先沿原暂停／保存规则保留当前现场；失败留在原课并允许重试。跨书下一课向宿主交付精确材料与课目标，在同一私人工作区打开正确阅读现场。闭卷与应用练习继续归属原课，原课程判断决定推进。

## 数据与既有决策

复用 WorkspaceRelease、CourseOverview 的 units/routes/lessons、LearningWorkspace 和 CourseRun。书籍与成套课程是这些原事实的展示投影；单书课程按 lesson 来源的 `book_id` 收拢，跨书课程以原 release 为集合。新增页面位置和归属摘要保存引用，不新增课程所有权或进度真相。

首页课程任务的集合名称、单元与课序从原 release_id/version 的窄投影读取，书名来自任务原发布。既有本机旧 run 未保存整套课程版本概要时，显示已知书籍和原课归属，不补造历史单元或课序。

本决策细化 [ADR-0182 的书内学习](0182-book-structure-led-inquiry-courses.md)与 [ADR-0184 的当前任务接续](0184-task-led-learning-entry-and-continuity.md)。ADR-0184 的一级“课程”入口调整为“学习”，任务优先、显式闭卷、精确恢复和结果回课规则继续有效。

单课平铺能缩短首次开课路径，但不能稳定表达整体学习对象与前后关系。因此首页以书籍和成套课程为入口，同时保留直接继续当前任务的快捷动作。实际语义质量与学习效果仍按原证据分别验收。
