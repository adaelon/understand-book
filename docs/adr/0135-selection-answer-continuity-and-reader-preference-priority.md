# ADR-0135 选区首轮回答连续性与读者偏好优先级

状态：已接受，2026-09-24。关联 ADR-0075、0091、0130、0133。

### §1 选区证据与回答回合

**决策**：已验证选区沿用完整 Agent 回合。

**否决**：
- 两次取证后转独立回答：会丢失画像、历史与演示能力。
- 为选区设置固定取证次数：多问句可能尚未读到所需正文。

**命门**：选区仍是已验证证据；后续读取、来源与 Reader 动作遵守原有授权和预算。
**何时回头**：真实回放证明普通回合不能及时收束局部选区问答时。

### §2 画像预算内的偏好取舍

**决策**：优先保留用户明确的讲解偏好。

**否决**：
- 仅扩大画像预算：记录继续增加后仍会挤掉核心偏好。
- 让适用范围先于来源权威性：推测可能压过用户原话。

**命门**：仍按书籍与内容画像筛选事实；本次只改变有限预算内的排序。
**何时回头**：画像记录出现语义重复，导致明确偏好之间持续互相挤占时。

### §3 讲解偏好的执行

**决策**：常驻 Agent 按相关偏好选择讲解深度与形式。

**否决**：
- 把偏好只当可引用资料：最终回答仍可能忽略它。
- 把画像当书内事实：偏好不能证明任何书中结论。

**命门**：当前用户请求优先；书内结论继续由已验证证据约束。
**何时回头**：真实回放显示偏好应用与用户当前要求冲突时。
