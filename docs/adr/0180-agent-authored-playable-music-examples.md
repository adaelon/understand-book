# ADR-0180 音乐伴听回答中的可试听谱例

2026-11-04 · 已接受，本机实现与贝九实跑完成，2026-11-05 已上线并完成公网真实 Agent 点听验证。[现网发布](../performance/salamander-lossless-20261104/deployment/README.md)。承接[精选音乐预构建与交互伴听](0175-curated-music-prebuild-and-guided-listening.md)。工具合同和交互见[实施方案](../设计方案-音乐伴听回答中的可试听谱例.md)，实际回答与亮键证据见[验收记录](../performance/answer-piano-20261104/README.md)。

## 决策

**由 Agent 在写回答时标出要听的音，由程序核对并演奏。** 音乐伴听增加回答创作工具 `music.example`。Agent 可以一次登记若干单音、旋律、和弦或跨小节的完整动机，把工具返回的标记放在正文或表格的确切位置。读者点音名听单音，点播放键听整组及连续乐句，共用一块随声音亮键的钢琴。回答完成后才开放试听，由读者发起播放。

**作品谱例引用谱对象，教学示例填写音高。** 讲作品时，Agent 指定已读谱本中的乐器、谱线和音符位置。程序从该发布取实音、拍位、时值、延音与休止。讲一个自行构造的音阶或对照时，Agent 明写带八度的音名、哪些音同时响以及各步时值，界面标为「教学示例」。同一回答可以并用两类谱例，读者能看出哪一段来自作品。

**钢琴使用 Salamander V3 的 Yamaha C5 原始无损录音。** 直接提供 48 kHz、24 bit、双声道 FLAC，保留原文件，不进行有损转码、降采样率或降位深。当前采用中等触键第 8 力度层，按乐句所需音域加载并复用。准备阶段逐键校准到 A4=440 Hz 十二平均律参照；播放前整段所需采样全部就绪，和弦共用同一起音时刻。作者署名、CC BY 3.0 许可及播放处理说明可从钢琴面板的“音色来源”打开。固定力度的回答事件适合单层示范；回答需要表达触键力度时再接入其他力度层。[无损音源与实测](../performance/salamander-lossless-20261104/README.md)

## 为什么在写回答时绑定

《贝九》第一乐章的第一小提琴在第 18 小节奏 A4，第 20 小节奏 A5。两处都可以写成“A”，连“向下走、随后回到 A”这样的描述也不能确定八度。第 19 小节还出现了另一层歧义。第一小提琴的两条谱线都奏低 D，只有其中一条继续走 F5 → E5 → D5。Agent 正在解释哪条线，应在它手里还有读谱依据时明确下来。

若把文字里的每个 A 都配到同一个键，上述两处至少会错一处。让 Agent 再抄一份音符，也可能抄错原谱已经写明的八度、时值或和弦。显式引用增加一次可批量的创作调用，读者可以回看谱面依据，Agent 在列表、表格和后续复述里可以复用同一试听。实际样本见[贝九材料记录](../performance/beethoven9-tennstedt-20261103/README.md)。

## 对交付的影响

谱例随最终回答保存。重开会话后，读者点击试听仍能听到当时登记的音，点出处能沿既有谱本引用回到原位置。纯文字历史回答保持可读。声部或音高仍有歧义时，Agent 可以陈述已经确定的部分，只有区分候选会改变回答时才追问。谱面合成与原录音各有自己的时钟和播放入口。
