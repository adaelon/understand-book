# ADR-0183 闭卷对话练到会

日期：2026-11-15。状态：**已接受，已实施并完成当前题面范围的工程验收。** 用户确认增加一个可主动开启的教学模式：讲过概念或题目后，Agent 持续追问、按需补教，直到用户能够独立说明或完成当前目标；过程中只显示对话或题目。实施合同、切片与验收见[切片方案](../切片方案-闭卷对话练到会.md)及[实施记录](../实施记录-闭卷对话练到会.md)。

2026-11-16 接续：[ADR-0184](0184-task-led-learning-entry-and-continuity.md)把表达和练习动作放在当前讲解与任务附近，并将结果接回原课程判断与首页继续入口。显式开启、帮助条件、闭卷显示和独立完成规则继续沿本 ADR；新增入口与回课已实现，切片状态见[学习主线方案](../切片方案-学习主线与课程入口.md)，工程验证与本轮未通过的真实模型样本见[实施记录](../实施记录-学习主线与课程入口.md)。

## 背景

现有 Tutor 已有引导思考、普通表达邀请、跨轮接续和帮助记录；“练一练”可以出新情境题并反馈。用户需要进一步明确教学的结束条件，并在作答时收起可照读的材料。当前 `DirectExplanation` / `GuidedInquiry` 表达教法，普通练习也要求下一题由用户另行发起，均未建立这项持续约定。

本模式围绕用户已经学过或接受的当前目标组织独立表达。目标可以是说清一个概念，也可以是解释方法并解出一道题；本次表现按任务与实际帮助条件记录。

## 决策

### 1. 将“练到会”保存为当前学习的显式约定

界面名称使用“练到会”，开启说明为：“闭卷对话练习；讲完后会请你自己解释或解题，直到你能独立完成。可随时暂停。”默认关闭，开启后对当前学习范围生效；目标、当前待答问题、帮助与返回位置可跨轮及重启恢复。新目标沿既有目标切换规则处理，不自动继承旧目标的练习进度。

这一约定包含资料可见范围、持续追问和结束条件，独立于默认讲解方式。用户要求直接讲解时，Agent 提供帮助并保留尚待独立验证的目标；用户明确关闭、暂停、跳过或改向时按其选择收束。每个已约定重点独立完成后就结束该轮；继续当前范围的下一重点仍等待用户继续，不因授权追问而无限扩展学习范围。

### 2. 练习现场只保留本轮对话、题目和作答

进入闭卷现场后，原文、笔记、课件、演示、知识地图、参考答案及历史讲解不显示，也不提供在该现场直接展开的入口。题干必需的数据和配图属于题目，可以显示；能代替用户完成判断的解析、推导提示和实验结果属于帮助。

每次独立尝试建立清楚的对话显示起点：保留本次题目、用户本次作答和必要交流；进入前的聊天、上一尝试的提示与解答继续保存，在本次作答期间不可回翻。新尝试不能仅通过收起旧提示就把原题的受助回答改记为独立。

用户通过对话求助时可以获得文字提示或补讲；该尝试保留帮助条件。需要查看资料、演示或其他学习现场时，先离开闭卷状态，保留待验证目标与返回位置。Agent 仍可读取可信来源、历史教学和用户原话，以保证问题与反馈正确；其生成上下文明确区分教师可读内容与用户当前可见内容。

### 3. 根据具体缺口追问，以独立表现收口

Agent 一次提出一个有意义的问题，等待真实回答，再决定认可、追问或补教。已说清的部分直接采用，追问服务于尚未完成的关系或步骤；卡住时缩小问题、换例子或重新讲解。用户已经完成当前目标时停止追问，等价表述和合理解法均可成立。

概念目标观察用户能否自行组织关键含义，并按该概念需要解释例子、区别或条件；解题目标观察其能否选择方法、完成关键推理并说明理由。要求在出题前确定，不能随着用户答对不断提高。需要再验证时，提供一个尚未被前文代答的例子、条件变化或同目标变式；补教缺失前提时仍回到原目标。

“懂了”、点击继续、复述刚给出的解法、在逐步提示下答对，都不单独满足独立完成条件。收到足够依据后记录“本次可独立解释”或“本次可独立完成该类任务”，并保留确切原话、任务、实际帮助和判断依据。刚讲完的表达按当堂表现解释，后续检索与迁移仍沿其原有证据要求。

### 4. 沿原会话和课程保存事实

普通教学由当前 `TutorSession` 持有该约定，课程入口由当前 `CourseRun` 持有约定和返回位置。实施沿统一问答的现有 `teaching_trace`、真实聊天、prepared delivery 及理解记录接续，保存目标、待答问题、实际原话与帮助；不为同一次课程另建竞争性的通用教学会话。模式投影集中在 `ClosedBookPractice`，不另建消息存储或评估执行循环。

模式状态与本轮独立表现分别保存。暂停、离开、求助和跳过均保留实际含义。宿主负责可见范围、持久状态、归属及完成依据的引用完整性；Agent 负责有原话依据的语义判断。课程的推进和结课继续由课程原规则接纳，本模式提供的表现证据不能由聊天直接替代课程判定。

### 5. 明确现有规则的适用范围

- [ADR-0178](0178-in-context-retrieval-practice-and-learning-map.md) 的就地情境练习仍保留非激活关系、普通反馈后停顿等约定。主动开启本模式，授权 Agent 在当前目标内继续追问、补教和提供独立重试；该分支允许在对话中给出已请求的帮助。每次仍只交付一道待答题或一个待答问题。讲后概念表达按教学活动保存；符合情境练习条件的题目继续使用其原合同。
- [ADR-0182](0182-book-structure-led-inquiry-courses.md) 的课程、原文、实验和历史回看布局用于普通课程现场。进入本模式期间，学习者视图使用本 ADR 的闭卷边界；离开后恢复原现场。依赖实时实验操作的活动先在课程中完成，再用题目所需的固定条件进入闭卷验证。
- 普通教学的直接求助、暂停与改向权继续有效；开启本模式要求 Agent 持续承接目标，用户始终可以结束当前练习。

## 取舍

仅在提示词中要求“多追问”无法固定可回翻的答案范围，也无法可靠接续待验证目标，因此采用持久会话约定与专门的闭卷视图。逐个术语强制考试会不断扩大当前任务，因此以用户接受的有限目标和真实缺口决定追问范围。题目、评估与学习记录复用现有链路，新增内容集中于模式策略、尝试接续和显示边界。

## 已知限制

闭卷边界覆盖本应用的练习现场；用户在外部自行查阅的情况无法仅凭界面获知。独立表现判断以可观察的作答与帮助事实为依据，单次通过不能替代后续保持、检索或迁移证据。工程验收与真实学习效果分别记录。
