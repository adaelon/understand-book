# ADR-0164 Tutor 使命与认知积木

状态：已接受，2026-10-12；同日按 TO 原则修订职责、上下文与验收设计。TB0–TB5 完成；[TB2](../performance/tutor-building-blocks-tb2/README.md)、[TB3](../performance/tutor-building-blocks-tb3/README.md)与 [TB4](../performance/tutor-building-blocks-tb4/README.md)通过工程与 GPT-6.1-Sol 教学内容验收，TO3 已集成。TB4 新增 2 次授权实验，交付可操作教具并沿实际保存现场接续；原始输出与状态恢复、来源配色、解释引用的局部修正分别保留。[TB5](../performance/tutor-building-blocks-tb5/README.md)完成教法与理解视图，实际记录经浏览器纠正并重开，新增模型调用 0。TB6 待实施；模型自主循环、DeepSeek 专项未复验和真人缺席见各片限制。实施与验收见[切片方案](../切片方案-Tutor使命与认知积木.md)。

Tutor 的核心使命是：**从学习者当前的理解出发，提供他能够理解、操作和组合的认知积木，引导他用这些积木建立新的理解，并逐步能够独立运用。** 知识关系、直观模型、方法、例子和交互教具都可以承担这一作用；判断其价值，要看学习者能够借它完成什么。

本决策细化 [ADR-0119](0119-agent-native-learning-environment-and-teaching-agency.md) 的 Agent 教学选择权，沿用 [ADR-0143](0143-teaching-trace-assessment-and-learning-evidence.md) 的事实与学习证据、[ADR-0158](0158-book-structure-ready-tutor-and-optional-teaching-assets.md) 的来源教学及 [ADR-0163](0163-tutor-continuation-and-contextual-reading-entry.md) 的交互意图和接续边界。工具、指导与验证采用 [TO 方案](../切片方案-工具契约与Agent可用性优化.md) 的契约单源、调用者选择权、实际交付证据和固定对照原则。

## §1 Tutor 的核心责任

**决策**：以学习者能够独立运用的理解组织教学。

**否决**：
- 以解释或演示交付完毕代表学会：交付事实不能证明学习者会使用。
- 以固定问答步骤代表引导：不同内容和起点需要不同支撑。

**命门**：Tutor 的教学选择围绕当前具体能力展开；当前请求、教学开关和会话意图继续决定行为范围。ResidentGoal 的任务交付与学习者的理解进展分别成立。
**展开**：[目标与行为合同](../切片方案-Tutor使命与认知积木.md#2-目标与行为合同)。

## §2 认知积木的归属

**决策**：认知积木由现有教学动作和呈现承载。

**否决**：
- 新建积木注册库和独立用户能力档案：重复现有内容、交付与私人证据的所有权。
- 将积木限定为预制知识卡或交互组件：限制 Agent 按当前理解组织内容。

**命门**：原文提供主张依据，TeachingMap 提供可选结构与素材。Agent 面向当前学习者选取、组合或现场构造支撑，用户相关设计和使用事实保持私人归属。积木的教学适用性与正式学习对象的公共身份分别表达。
**展开**：[现有承载与接点](../切片方案-Tutor使命与认知积木.md#3-现有承载与接点)。

## §3 能力目标与学习者活动

**决策**：同时明确提供的支撑与学习者完成的活动。

**否决**：
- 只把内容讲得更浅或拆得更碎：缺少连接关系与实际运用。
- 将所有未知知识留给用户猜：学习者缺少开始行动所需的材料。
- 固定执行诊断、讲解、练习、评分流程：提前替 Agent 和学习者决定有意义的下一步。

**命门**：当前目标表达用户能够借什么完成什么；工具提供可组合的读取、呈现和记录能力，Agent 选择支撑与教法，学习者承担适当的新判断、解释、构造或运用。一次选择只承担一个有界教学动作，后续由实际回应决定。
**展开**：[认知积木设计样例](../切片方案-Tutor使命与认知积木.md#4-认知积木设计样例)。

## §4 引导与帮助调整

**决策**：依据真实回应调整支撑并逐步减少代做。

**否决**：
- 将引导等同连续提问：示范、反例、局部解释和操作同样能提供支撑。
- 按固定答错次数升级提示：帮助需求不由计数决定。

**命门**：用户难以开始时补足必要连接，能完成时给出更多独立选择和组合空间；明确要求直接讲解时完整回应。需要用户行动的地方停止并等待，不预写其回答或替其完成后续步骤。
**展开**：[目标与行为合同](../切片方案-Tutor使命与认知积木.md#2-目标与行为合同)。

## §5 学习记忆

**决策**：记住用户在何种帮助下能完成什么。

**否决**：
- 将点击、观看、自评或助手解释等同能力：缺少对应的学习者表现。
- 把一次使用概括为整体认知等级：超出观察范围。

**命门**：沿用实际交付、用户原话、来源、帮助条件和尝试记录；近期摘要只表示已返回的范围，必要时沿现有入口回读。普通表达形成可修正的理解假设，正式表现沿原评估合同解释。后续教学据此调整支撑，未知保持未知。
**展开**：[反馈与接续](../切片方案-Tutor使命与认知积木.md#5-反馈与接续)。

## §6 教学指导与工具契约

**决策**：教学指导按需装配，工具语义由原契约维护。

**否决**：
- 在教学提示中复制参数规则和调用示例：形成第二份工具语义，增加输入与漂移。
- 把完整教法、案例和用户历史常驻注入：当前选择被无关内容挤占。

**命门**：TB 负责能力目标、支撑选择和回应适配；TO 负责工具合同、状态示例与共同结果投影。任务数据保留事实身份，示例只说明用法；最终请求中的状态、指导与工具权限一致。
**何时回头**：真实教学缺少必要字段或可回读事实时，由对应所有者扩展原合同，再接入消费方。
**展开**：[指导装配](../切片方案-Tutor使命与认知积木.md#按-to-原则组织教学能力)、[并行边界](../切片方案-Tutor使命与认知积木.md#to-与-tb-的并行边界)。

## §7 实施与验收

**决策**：先验证真实文字教学，再扩展教具与接续。

**否决**：
- 只修改使命文案即宣布完成：无法证明它改变了教学选择。
- 以点击率、回合数或模型自评分代表学习收益：无法还原学习者实际完成的事情。

**命门**：同组 TB 对照固定工具版本、材料、模型与采样预算，从最终请求和真实交付分别核对工具调用、教学内容及学习者表现。保留失败样本；指导文字出现、参数合法或成本下降都不能单独证明教学改善。
**何时回头**：固定样本未改善教学选择时，收敛无收益指导，按真实失败重新定位障碍。
**展开**：[实施切片](../切片方案-Tutor使命与认知积木.md#6-实施切片)、[验证与后续接手](../切片方案-Tutor使命与认知积木.md#7-验证与后续接手)、[已知限制](../切片方案-Tutor使命与认知积木.md#8-已知限制)。
