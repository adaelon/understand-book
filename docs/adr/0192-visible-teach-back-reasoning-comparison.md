# ADR-0192 讲解后同时呈现书中推理、本次表达与关系对照

2026-11-23 · **已接受。** 普通阅读、课内解释与本机 Agent 的实施范围分别见[切片方案与验收样例](../切片方案-讲后三图对照.md)。

一个知道答案的听者，很容易替学生补上没有讲出的理由，再告诉学生“你讲明白了”。**读者选「我来解释一下」，先自己讲；提交后，在同一条反馈下同时看到「书中推理」「本次表达」「关系对照」。** 书中推理与读者表达各画成一张局部有向图。共享的命题只画一次，每处要核对的关系有一个焦点编号。选择焦点时，两张图一起高亮对应部分，下方显示这处判断、成立条件和双方原句。宽容器并排展示两张图，窄容器上下排列。[切片 4 的合同与布局](../切片方案-讲后三图对照.md#4--升级双侧显式局部论述图锚点防截断取证与节点联动对照)

**书中的图是围绕本次问题的有据解读。** 主对照只放直接回答当前问题的核心关系（通常 2–4 条），同节的旁路思路单列折叠提示，不冒充本题必答缺口。BookStructure 定位主线与重点，Pass1 找概念、主张和有向关联，Discourse 找段落间的解释、支持、反驳或问答；三者在同一书源版本按原文位置（LID）接合，实际读到的原句决定一条推理的方向、含义和成立条件。沿用 [ADR-0158](0158-book-structure-ready-tutor-and-optional-teaching-assets.md) 的普通文本书基线且支持软降级：无需 Pass2、认知材料或整本标准推理图；缺少 BookStructure 或 Discourse 时，退回原回答已验证出处与局部原文继续工作。

**学生的图只画这次说出来的关系，由公共 Reader 统一编排两阶段。** 内置 Resident 与本机 ACP 共用同一编排：先在无原讲解正文、无书工具和无参考判据的隔离上下文中，仅凭原问题、极简主题锚点与本轮原话还原学生表达（单纯求助或新提问则直接分流回普通问答）；再与书侧按理由、条件与结论对照，允许一句话跨过几步与等价讲法。没讲不等于不会，书里没找到也不等于学生错。无分歧即收口，有分歧默认只追问最关键一处，不锁死主对话。显式区分「你把我听反了」与「改一下我的想法」：前者仅据首次原话重核解读，不计看图帮助；后者记为新的看图后表达。初次原话、当时解读与后续澄清分别可回看。

**三图是这次交谈的私人反馈，不是评分或课程通关。** 本决策相应调整 [ADR-0184](0184-task-led-learning-entry-and-continuity.md) §3 的入口分工：普通阅读拆分为「我来解释一下」「练到会」「给我一道应用题」三个动作；课内讲解阶段把既有自述解释反馈升级为三图（不再并存两套“解释”入口），同时保留显式「练到会」与「给我一道应用题」。书侧引用公共来源；学生表达、两侧对应及修订归原聊天和学习工作区。首次提交固定先前已展示讲解作为前置支持；三图实际显示后才记为后续澄清的帮助，并透传给后续同目标闭卷练习以要求独立变式验证，绝不倒记到先前提交的原话。「练到会」仍按 [ADR-0183](0183-closed-book-dialogue-to-independent-performance.md) 隐藏资料和解答；课程是否推进仍由原课程规则接纳。
