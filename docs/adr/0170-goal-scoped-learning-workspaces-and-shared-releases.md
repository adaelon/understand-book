# ADR-0170 目标工作区与共享预构建发布

日期：2026-10-18。状态：已接受设计；W1–W6、S1公共编排发布与S2私人实例、选择更新已接入。具体实施及验收状态见[切片方案](../切片方案-目标工作区与统一Agent额度.md)，产品合同见[设计方案](../设计方案-目标工作区与统一Agent额度.md)。

## §1 学习范围

**决策**：工作区组织资料、聊天和私人理解。
**否决**：只扩大单书 Agent 的可读书库；它不能表达同资料在不同学习任务中的理解归属。
**命门**：学习工作区有独立身份，现有 ReaderWorkspace 继续表示阅读现场；工具读取、理解查询和修订使用一致的工作区范围，私人记忆仍归用户。

## §2 大目标

**决策**：创建必填大目标，用户控制方向变更。
**否决**：让 Agent 从资料或聊天自行确立长期目标；推测无法代表用户接受的方向。
**命门**：一句话目标即可开始；Agent 在其内调整阶段焦点，临时插问不改目标。运行保留原目标版本，用户改向后旧规划停止自主推进。

2026-11-16 接续：[ADR-0184](0184-task-led-learning-entry-and-continuity.md)将现成课程的目标接受收进开课入口：页面展示公共目标，用户点击按此目标开始即可接受，也可就地修改。私人工作区与目标历史继续沿本 ADR；新增入口已实现，切片状态见[学习主线方案](../切片方案-学习主线与课程入口.md)，证据见[实施记录](../实施记录-学习主线与课程入口.md)。

目标栏与对话中的明确改向共用目标版本历史；当轮工具接受的新目标另存回合回执，原运行快照不改写。阶段绑定目标版本并保留自身材料范围，目标修订后旧阶段暂停；阶段焦点可随学习调整，最终方向的改变仍来自用户。

2026-10-23：阶段选择按“学习工作区、资料来源”保存，独立书库使用各书自己的选择。同书在不同工作区及书库内分别恢复；工作区大目标继续由工作区持有。多资料阶段按其明确的材料范围共享，后来开始单书阶段只替换该书的选择。未设目标的资料显示空态，不继承另一资料的阶段。

阶段选择从既有 Start/Resume 事件回放，旧历史无需重新设定目标；暂停、结束和全局教学开关原样保留，导航只恢复，不生成教学请求。工作区总目标改版清除旧阶段选择，历史仍可查看。界面、教学准备与交互使用相同的来源选择。实现与验证见[目标恢复与历史演示修复](https://github.com/adaelon/understand-book/blob/625b4405af3b011e87d4eb256f819c8075f88613/docs/performance/goal-presentation-recovery-20261023/README.md)。

## §3 共享发布

**决策**：共享公共编排，使用时建立私人实例。
**否决**：把公共资料复用与多人共享理解状态合并；它们具有不同的所有者与生命周期。
**命门**：发布包含目标、确切资料版本和公共路线；个人实例另存目标与学习状态，复用成果不重建。更新由用户接入，历史出处保持原版本。

S1采用运营者明确提交的公开目标、适用范围、建议基础、确切资料版本、必要能力、主题联系和路线；清单不读取私人BuildIntent、聊天或理解存储。`release_id + version`标识不可变内容，基于最新版本修订会追加新版，原操作重试返回原回执。可见用户按发布版本保存，资料访问仍逐份检查原授权。发布时就绪快照与读取时可用状态分别保存和计算，缺资料、必要能力或访问授权时返回未完整就绪；公开导出仅包含版本身份与选入的公共清单。

S2要求用户接受或修改目标后开始使用，服务端检查选定版本对该用户可见、资料及必要能力实际可用、原材料授权齐全。使用事务新建私人学习工作区、初始目标、资料引用和共享版本关联；公共成果不复制到私人理解，开始使用不触发构建或费用。操作身份按账号去重，重复请求继续同一个实例。

选择更新先展示确切资料、公共目标、能力与编排差异，用户确认后再接入更高版本；个人目标及其历史保持原样。显式添加材料另存私人归属，即使它后来也进入公共清单，再被新版移出时仍保留；用户主动移除则清除该保留意图。版本选择追加历史，旧聊天、笔记和理解证据继续指向原资料发布，已接受运行保留原范围，新运行使用当前成员。共享归档单独保存生命周期状态，不修改公共版本：归档停止新的使用，已有实例继续按材料权限访问。

## §4 历史承接

**决策**：已有学习记录经用户选择关联工作区。
**命门**：旧记录保留原归属和事实；同书不自动归为同一学习目标。用户确认目标并选择记录后，通过原事实引用带入，理解与掌握在新上下文中重新判断。

选择以原聊天的已提交前缀为单位，保存原工作区、聊天、回合和提交位置；重复带入合并引用，后续新增回合需再次选择。读取可追溯必要的因果、评估和修订链，原聊天及学习事实保持原身份，新的解释写入当前工作区。界面和Agent分别从历史入口、`workspace.records.read`回读带入记录；当前掌握统计仍只依据当前工作区证据。来源按原出版解析，不可用时保留当时片段；带入不自动添加资料成员。

本 ADR 调整 ADR-0118/0141 的阶段归属、ADR-0161 的新工作区创建入口与 ADR-0169 的默认理解范围；保留原个人数据所有权、来源引用和用户控制。具体替换范围见设计方案 §9.1。
