# ADR-0179 笔记思考路径与当前理解

日期：2026-11-01。状态：已接受，UP1–UP4 本地实现完成。承接 [ADR-0177](0177-personal-notes-evolution-and-teaching-recall.md)；实施和验证以[切片方案](../切片方案-想法笔记与理解路径.md)为准。

## 决策

**笔记呈现思考路径，系统解释当前理解。** 笔记的原话、修订和明确相关讨论组成可回读的历史；理解说明由真实表达、评分和帮助条件形成，自动更新并允许纠正。正文只在用户保存或采纳时追加版本。保存或打开笔记不调用理解模型。

理解按实际学习范围、材料版本、知识关系和能力归组。正式对象使用对象版本；无正式对象的关系由宿主保存私人关系身份，模型只能引用提供的候选或提出有来源的新关系。笔记可关联多个关系，关系也可关联多条笔记；相似文本和同一聊天不足以建立关联。

当前理解分别说明已观察到的能力、具体困难和待确认之处，每项可回到证据及当时的帮助。新表现按实际发生时间更新可比的判断；原判断、用户纠正及存疑活动留在历史。一次正确或保存正确文字不构成普遍掌握，不使用无依据的掌握百分比。

开放题以逐项评分与目标的明确对应派生证据；旧的无对应记录保留整题结果，不能把同一失败复制到多个知识点。理解假设和活动表现保留各自身份，假设不进入原表现计数。

笔记“思考过程”与“我的理解”读取同一学习存储的当前解释。由确切笔记版本、原始表达和实际采用关系连接历史；跨工作区和材料版本分别展示。现有回合后教练负责补充结构化解释，不新增笔记教师或另一套正文权威。

## 取舍

自动改写正文会混淆用户思考与系统判断；累计成功次数或线性等级不能解释具体卡点；单凭标题、笔记身份或原文位置归组会误合并关系。因此选择可纠正的证据解释及独立的关系身份，付出明确归属和读取投影的实现成本。

## 边界

完整路径指实际记录且有明确关联的过程。无材料的独立笔记先呈现修订和讨论，缺少原判定合同所需材料时显示尚待确认。旧资料只按现存引用接续，不全库重新调用模型。真实模型样例验证具体判断场景；长期学习效果仍由后续真实使用检验。
