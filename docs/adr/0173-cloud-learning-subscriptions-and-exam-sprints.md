# ADR-0173 云端学习、统一账号与考试冲刺套餐

日期：2026-10-20。状态：已接受并实施通用能力，联合验收与生产发布分别记录。完整行为见[产品方案](../产品方案-云端学习与考试冲刺.md)，代码接点与实际验收状态见[实施计划](../实施计划-云端学习与考试冲刺.md)。

**决策**：正式产品采用统一账号的云端学习服务。

Windows 与网站复用账号、资料授权、私人工作区和服务额度。核心 Agent、教学策略与深度资料构建在服务器执行；Windows 默认导入并保存本机文件，可直接阅读，不要求云端存储套餐。用户明确请求多端同步时才上传云端副本并检查云端空间和套餐。三档按使用规模区分，提供月付与 1/3/7 天冲刺时长；首场景为大学生期末复习，公共课程提前准备，个人实例记录各自的目标和学习。

**否决**：仅加登录或模型代理而继续交付完整本地核心，不能达到核心实现收缩目标；只限制上传大小，不能覆盖持续模型与转写处理成本；将日包和月付建立为重叠活跃余额，会破坏现有唯一额度期与费用归属。

**命门**：本机文件、云端空间、云端处理额度是三种独立资源。2026-10-21 明确云端套餐空间只约束书籍、视频、课件等原始材料上传；演示页、交互状态与笔记等学习成果属于学习记录，保存不受存储套餐与上传空间限制。本地导入不调用云端上传接口，不以移除套餐判断后继续上传来模拟本地；登录不自动上传。收款、服务额度和平台成本分账；同账号单一有效权益期，固定百分比基准不随档位改义。公共准备归平台且不重复扣学生费用。

**既有决策接续**：ADR-0068/0070/0089 的本地 Reader、用户 Provider 和 Setup 插件形态仍描述现有本地工具；其正式商业 Windows 默认交付由本决策在 C7/C8 实施后取代。ADR-0147 的多人服务、ADR-0170 的工作区/公共发布与 ADR-0171 的费用基础继续复用；非模型处理计量扩展原服务额度，远程 Book MCP 次数保持独立。

**何时回头**：受支持的正式使用确需完整离线核心执行，或实际服务成本使当前套餐边界不可持续时，重新评估交付与权益边界。具体价格、配额和课程资料尚未确定。
