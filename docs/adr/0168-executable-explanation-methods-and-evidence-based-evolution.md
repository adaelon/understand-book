# ADR-0168 以可执行解释能力和外部证据支持自进化

日期：2026-10-15，更新于 2026-10-16。状态：SE0–SE7 已完成；当前转入首批模板库，SE8 收益实验暂缓。首批登记依据见 §8，SE10 由真实漏检触发。SE1–SE7 的原证据保留在 [解释能力实验目录](../performance/explanation-evolution/)。  
完整合同：[解释能力库与 Agent 自进化](../切片方案-解释能力库与Agent自进化.md)。承接 ADR-0139、0154、0155、0157；本次记录方法资产、反馈归属和跨任务采用边界。

## §1 能力积累单位

**决策**：以语法卡和最小作品积累解释能力。

**否决**：
- 持续扩写共同指导：难以按当前障碍选用，无法直接复用已验证实现。
- 按主题复制整页模板：关系、条件和原文依据变化后容易错用。

**命门**：每个版本同时固定适用条件、配方、可运行代码和预期观察；实际迁移支持其采用范围。
**展开**：[方案 §2](../切片方案-解释能力库与Agent自进化.md#2-解释能力单元)。

## §2 正式使用路径

**决策**：将能力读取与使用版本接入正式运行。

**否决**：
- 只保存 Markdown 和示例文件：无法证明 Agent 发现并读到了代码。
- 将全部示例注入每次回答：增加无关成本，妨碍按内容选择。

**命门**：目录暴露、实际读取、声明使用分别留痕；首版沿编译资产路径，采用后经构建发布才对新运行生效。
**展开**：[方案 §3](../切片方案-解释能力库与Agent自进化.md#3-agent-如何实际使用)。

## §3 用户反馈归属

**决策**：反馈归确切演示版本，保持可改可撤。

**否决**：
- 点赞直接成为学习掌握或方法奖励：喜好不证明内容正确或迁移有效。
- 页面总评分配给每个方法：缺少局部归因依据。
- 必填问卷后才保存：增加普通使用的反馈负担。

**命门**：选择独立保存，原因和现场可选；私人原始反馈沿原用户所有权，方法库使用经整理的通用经验。
**展开**：[方案 §4](../切片方案-解释能力库与Agent自进化.md#4-用户喜欢与不喜欢)。

## §4 跨任务采用

本节规定跨任务收益结论所需的证据；首批制作资产登记适用 §8。

**决策**：用同条件迁移验证决定能力采用。

**否决**：
- 一次修好即全局推广：单题修复没有跨任务证据。
- 增加尝试次数后宣称能力提高：无法区分方法收益与额外预算。

**命门**：相同模型、工具和预算，新旧配对、独立新任务及相关回归；采用后核对下一次实际使用，回退保留旧交付身份。
**展开**：[方案 §5–6](../切片方案-解释能力库与Agent自进化.md#5-从案例到采用)。

## §5 验证方法改进

**决策**：由真实漏检驱动独立验证修订。

**否决**：
- 候选同时改写自身通过标准：丢失可比较的外部依据。
- 只验证能拦下坏例：可能把正确行为一并拒绝。

**命门**：新检查同时验证已确认坏例与好例；合同变化后用同一新合同重比新旧方法。
**展开**：[方案 §6.4](../切片方案-解释能力库与Agent自进化.md#64-验证方法本身的改进)。

## §6 首阶段执行边界

本节保留原闭环路线；2026-10-16 的当前交付优先级见 §8。

**决策**：先贯通一个有界的资产改进闭环。

**否决**：
- 先建设通用自进化平台：尚无重复维护负担支持新的编排和基础设施。
- 线上点踩直接改写运行资产：反馈尚未诊断和验证，编译资产也未因此生效。

**命门**：SE1–SE9 覆盖制作、读取、反馈、候选、验证与采用；SE10 由漏检触发，构建发布沿既有流程。
**何时回头**：多轮真实使用证明固定资产发布或手动案例选择成为主要瓶颈时，再调整自动化程度。
**展开**：[方案 §8–10](../切片方案-解释能力库与Agent自进化.md#8-可实施切片)。

## §7 引用继承与读取依据

**决策**：确切引用随版本保存，整页重写显式声明。

**否决**：
- 按方法名绑定：无法区分不同资产版本。
- 全量 write 默认继承：会把已移除的方法继续算作使用。
- 将工具原始返回全文算作已读：预算投影可能只向模型提供部分正文。

**命门**：patch 省略继承、提供即完整替换；新引用须有当前登记及成功采样的正文依据，旧引用沿确切基版继承；无历史记录保持未知。
**展开**：[SE3 合同与证据](../performance/explanation-evolution/se3/README.md)。

## §8 首批模板库登记

**决策**：先建可用模板库，收益对照后置。

**否决**：
- 仅有一张卡就继续完整收益实验：不能补足常见解释关系。
- 只保存卡片文字：缺少可读取、运行和改写的实现。

**命门**：每单元以作品计算、图形、交互恢复及正式读取完成本批登记；收益与学习效果沿 §4 单独建立证据。
**何时回头**：真实使用出现方法错选、具体回归或有价值的收益问题时，再启动对应验证。
**展开**：[首批模板库](../../skills/presentation/methods/README.md)、[制作与验证记录](../performance/presentation-method-library-v1/README.md)。
