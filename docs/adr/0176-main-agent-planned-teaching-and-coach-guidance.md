# ADR-0176 主 Agent 计划执行与教练指导

日期：2026-10-29。状态：**决策已实施，2026-10-29 已上线；次日公网验收完成。** 主 Agent 复用既有 Goal 执行计划、工具、调整和交付循环；两类教练与正式学生评分保留，默认教师成稿审核已移出交付路径。验证及真实对照见[实施报告](../performance/main-agent-planned-20261029/README.md)。实施入口：[切片方案](../切片方案-主Agent计划执行与教练指导.md)。

## 背景与依据

当前主 Agent 已负责取材、制作与修订，但 `tutor.step select` 还强制进入独立交付审核：纯文字先事实审、通过后再讲解审；带视觉材料的交付走相应综合审核，退回后重新提交。2026-10-29《失败的逻辑》同首稿实验中，最后一组相对本轮基线由 181.053 秒变为 225.061 秒，正文修改由 1 次变为 2 次；调用由 10 次降至 9 次，总输入减少 23.02%，但没有改善等待与返工。最终样本约 181.3 秒用于三次事实审核，主 Agent 约 24.8 秒。原稿已有的条件错误到第二次审核才指出。依据：[实验报告](../performance/teaching-shared-rules-20261029/README.md)、[原始计量](../performance/teaching-shared-rules-20261029/comparison.json)。

这份基线已经包含下午较早的修复，不是全天改动前的版本；单个同首稿样本也不能推导新架构的质量或提速幅度。完整反馈、来源读取、局部修订和上下文去重仍有价值。这里调整的是每份交付都依赖独立模型审批的默认架构。

## 决策

**主 Agent 持有计划并完成交付，教练持续指导。**

正常 Reader 任务沿现有 Resident 循环执行：读取当前请求与可用教练指导 → 按需记录短工作计划 → 取证、计算、制作和实际观察 → 根据结果推进或调整 → 宿主程序校验 → 保存并交付。独立事实、讲解及视觉成稿审阅退出默认交付关键路径；质量标准继续用于主 Agent 工作和开发阶段的独立评测。

### 1. 复用既有计划，保持目标与工作判断分离

沿用 ADR-0155 的 `ResidentGoal.working` 和 `goal.update(operation="working")`。复杂任务使用少量结果导向的工作项；简短确认、局部追问不强制增加规划往返。工作项可重排、拆分、合并、重开；依据已有工具结果保留关键结论和未决工作。计划完成不证明事实正确、操作发生或实际交付，不能修改用户要求或直接完成 Goal。

正常 Reader 问答入场已经建立本轮 ResidentGoal，复用不新增持续任务。无 Goal 的底层入口继续沿其既有合同，不为本次决策扩建 Todo 服务。TeachingDesign 保持教学关系与呈现设计职责，不承载检索、计算等执行待办。

### 2. 保留两种教练及其不同位置

- **教学教练**：由宿主逐轮自动安排，在实际交付后后台复盘真实用户表达、帮助与交付，为下一轮提供指导。只注入已就绪且适用的指导；未就绪时前台继续处理当前请求。当前用户输入优先，教练不审批当前稿件。
- **表达教练**：现有图板／演示制作前的同步指导继续保留，帮助选择表达方法和组织关系；按现有每运行、每制作形式的缓存复用，不因几何、字体等局部修订重新调用。指导不可用时沿现有路径继续。它不是后台教学教练，也不是成稿验收者。

### 3. 程序接纳与内容责任分开

`select/finish` 继续确认确切正文、来源、活动与呈现版本，执行已有程序校验，保留实际交付事实与后台教练触发。主 Agent 对事实、条件、解释深度和视觉效果负责；宿主校验实际读取、引用、保存、预览、操作回执和交付状态，不把这些结构事实包装成语义正确的证明。

图表、图板与页面仍需主 Agent 实际观察适用的结果和关键状态。名称含 `review` 的预览类型或制作阶段不等于独立模型审稿，不能按名称删除。正式 `tutor.step assess` 继续依据冻结合同独立评价学生作答，与教师正文审稿分开。

### 4. 保留真实记录，不制造审核通过

新默认路径不生成 `AgentWorkReviewed`、`accepted_by_review` 或伪造的已解决意见。旧审核历史按原身份保留查询。当前计划与未决工作由 GoalWorkingState 承担，实际正文、来源、工具与帮助沿既有日志和事件保存；本轮不另建作者知识工具或第二套记忆。

教练通过既有“原回合成功读取记录 → verified_read_ranges → 原版本正文”通路取证，媒体沿实际 source bindings；旧审核事件提供的阅读范围只作为历史补充。停止同步审稿也会停止其自动生成的本轮知识摘要，后续上下文不得继续依赖或冒充这份摘要。

实际考虑后未采用：继续以强制审核提示词微调作为主方向；增加规划者或协调者；用空 accept 复用旧审核事件；为新旧流程增加长期双轨或功能开关。现有数据支持改变成本结构，但不证明任何替代流程天然保持质量。

## 既有决策接续

- 部分替代 ADR-0150、ADR-0164、ADR-0174 中默认交付须经同步内容审阅的要求，以及 ADR-0175 中依赖该交付审阅的接线；取证、实际呈现、停止和费用归属继续有效。
- 延续 ADR-0155 的 Goal 工作计划；延续 ADR-0130、ADR-0157 的实际视觉观察和确切版本交付；延续 ADR-0143、ADR-0172 的用户作答评分、真实帮助与理解证据隔离。
- ADR-0174 的“下轮等待教练”文字已落后于现有 `teaching_coach::prepare_execution`；本决策明确采用当前不等待行为。表达教练的制作前同步调用不在此句范围内。
- 实施前现状仍是同步交付审阅。各切片完成和验证后再更新架构的运行现状，不能以 ADR 接受代替代码完成。

## 验收与回看条件

比较新旧冻结版本从同一用户问题开始的完整运行；原首稿保留为纠错和离线审核样例，不再把跳过旧审核后的耗时当成可比的端到端收益。独立内容评测不向运行中的作者反馈，记录事实、解释深度、视觉结果、总时间、调用、重写及原生用量，失败样本同样保留。教练后台成本与前台等待分别计量。

若事实或深度不达标，修正主 Agent 的取证、计划与表达，不能靠降低标准或删除失败样本宣告完成；若达到同等质量仍无可辨别的等待收益，应重新判断本决策。当前尚无新架构质量、耗时或费用结论；发布另沿项目既有流程完成。
