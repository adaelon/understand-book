# ADR-0144 演示页与原对话共享工作区

状态：已接受，2026-09-29；T1 普通演示工作区已实现，T6/T8 正式教学关联、确切现场及宿主行为已实现。扩展 [ADR-0130](0130-agent-rich-presentation-and-read-time-authoring.md)，继承 [ADR-0131](0131-mobile-reading-workspace-and-viewport-projection.md) 的宿主连续性与窄屏原则。

## §1 同处操作与对话

**决策**：演示工作区直接呈现原对话与当前内容。

**否决**：
- 追问后退出演示页查看回答：切断正在观察的内容。
- 演示页另开一套聊天：上下文、历史和教学进度分叉。

**命门**：桌面采用可调整的演示与对话两区，窄屏按需展开讨论；使用同一消息、运行、输入状态与内容实例。展开后合并为一条紧凑工具栏，内容可在 50%–150% 缩放，说明按需显示，附属窗口使用剩余空间；缩放保持同一 iframe。打开时定位相关回合，完整历史可访问，其他演示以引用卡呈现；全局 Tutor 控制在工作区保持可见。
**何时回头**：真实屏幕尺寸无法同时保留必要现场与输入时，调整布局投影。
**展开**：[工作区交互](../切片方案-Tutor全局模式与教学闭环.md#4-演示工作区的完整交互)。

## §2 提问现场与内容更新

**决策**：提问绑定发送现场，恢复和换版由用户决定。

**否决**：
- 回答时读取最新滑块状态：会解释用户提问后改变的现场。
- 新版本自动替换当前画布：破坏正在进行的实验和比较。

**命门**：复用不可变 PresentationFollowUp；发送冻结版本与现场，后续操作不改变已发消息。“定位”只突出相关对象，“回到提问时”才恢复；修改结果以新版本卡交付，旧消息继续引用旧版。来源可原地预览，进入原文保留返回点。
**何时回头**：真实协作编辑需要多人同时选择版本时，重新定义工作区版本选择权。
**展开**：[发送、恢复与版本](../切片方案-Tutor全局模式与教学闭环.md#4-演示工作区的完整交互)。

## §3 自由视觉与正式教学行为

**决策**：页面承载教学表达，宿主持有行为与证据。

**否决**：
- 页面自行授予正确或掌握：绕过冻结合同与私人证据链。
- 为 Tutor 重建另一套演示引擎：重复现有内容、现场、制作和恢复能力。

**命门**：AgentPresentation 保有自由视觉与局部计算；宿主将提交、改答、提示、揭示及跳过关联到实际活动、确切版本和现场。同页可承载多个 TeachingMove，TeachingMove 也可跨正文与演示；跨聊天教学沿明确引用读取旧内容，保留原内容归属与历史回执。
**何时回头**：真实教学需要新类型的用户行为时，扩展宿主合同和实际记录。
**展开**：[正式交互合同](../切片方案-Tutor全局模式与教学闭环.md#8-教学交付判题与私人证据)。
