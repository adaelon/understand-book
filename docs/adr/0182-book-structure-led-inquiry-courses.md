## 背景

2026-11-19 接续：[ADR-0190](0190-representative-lesson-before-course-design.md) 规定了开放式建课委托如何通过代表课形成路线，沿用本决策的单课编排和正式发布标准。

现有系统具备带读、教学设计、可交互演示、作答评估和私人理解记录，但用户仍需通过对话组织相当一部分学习过程。课程承担起点、主线、活动与结束点的组织，使用户能直接开始思考和尝试。

BookStructure 已有章节问题及推进方式、跨章主题问题、阶段发展、关键内容和有依据的依赖。课程复用这些已完成的语义工作，为其制作学习活动。路线总问题可以贯穿全书，每课的主问题承担其中一次具体的理解推进。

## 决策

### 1. 按问题脉络组织课程

**课程同时保留章节路线与主题路线。章节路线默认一章对应一个课程单元，一节对应一课及一个主问题。** 章的问题串联各课；每节的主问题根据已有章问题、该节重点及原文编排。主题路线以一条跨章主线或其中一段知识演进为范围，设置路线总问题，再依据阶段发展组织各课的主问题。

路线总问题组织较长的学习过程，课的主问题对应一次可独立收束的理解目标，关内活动承载预测、阅读、实验、解释和作答。主线数、单元数与课数分别表达；一条贯穿全书的主线可以包含多课。

**每课默认按 20–30 分钟的完整探究过程编排（2026-11-10 调整）。** 同一个主问题下安排多轮递进的预测、实验、解释及综合应用，每轮形成可暂停、可回看的学习段。 时长包含必要阅读、思考、预测、操作、解释、结尾作答与反馈，按声明起点的目标读者估算并通过试学校准。额外追问、深入探索与离开暂停分别记录；正常流程的系统等待同时观察，不以强制计时结束学习。

章／节映射作为明确起点，课程作者结合上述时长目标按内容拆合：一节包含互相独立、不能在同一主问题下推进的理解目标时拆课，保留原节问题串联各课；相邻节共同完成同一问题、单独不能形成有用解释时可合课。同一目标可在课内分活动推进，需要较长推理时按有意义的中间目标分课，并保留必要前提与关键论证。主题路线使用相同尺度；较短但完整的课无需为凑时长增加活动。

主题成员关系、发展顺序与学习前提分别保留；同属一个主题不自动成为先学后学的要求。

### 2. 从已有结构成果制作可运行课程

**课程构建读取完整、已接纳的 BookStructure 成果及所需原文，补齐教学编排和活动资产。** 完整主题成果中的问题、区别、阶段发展和依赖理由供课程构建使用；最终 `throughlines` 的精简投影继续承担原有浏览职责。

构建时将课程实际使用的结构内容与原身份、确切来源版本一起保存为有界的版本快照。学习端读取发布后的课程，不读取私有构建工作目录。结构缺口在构建输入中明确表达，只补本课程实际需要的材料。

制作采用 UbD 的逆向设计：先确定理解与应用目标、最终任务及判断依据，再安排学习过程；适合预测和观察的阶段采用 POE。产物包含路线总问题、各课主问题、阶段路线、必要原文、核心讲解、可运行实验、提示、结尾任务和私有解答，形成用户点击即可开始的课程。

每课先形成带来源的教学蓝本，说明目标关系、适用条件、最终任务及解法、必要支持，以及各活动要让读者作出的判断和看到的证据。题目与演示依据同一蓝本制作：实验由需要区分的判断倒推操作、对照与观察量，页面按目标关系选择现有解释方法并改写；题目保留所用场景、条件、判断依据及揭示时机。书中已有例题、案例和实验可沿用或改编，新构造的教学例子明确其设定。论证或案例比较可使用文本、静态图和证据操作。

数学课程复用已有数学结构索引及原文中的定义、假设、定理、证明和习题，按本课目标安排概念辨认、计算应用或证明。数值与图形探索可用于形成猜想和发现反例；一般命题的成立须有适用的论证依据。题目与解释保留对象范围、成立条件及所需推理，证明要求与声明的读者基础、学习目标一致。

课程制作方法按实际理解任务积累，沿项目已有构建指导保存适用条件、活动安排、完整样课、改写说明及具体失败案例。构建按本课目标和材料选择方法，结合必要的领域要求；同一课可组合多种活动。先核对单课蓝本中的目标、最终任务和必要支持，再制作页面与其他资产。新方法先以真实材料试制，已有方法通过新材料上的制作记录说明适用范围。

### 3. 共享课程，私人教学与表现分别保存

**公共课程沿 WorkspaceRelease 发布，私人实例沿 LearningWorkspace、TutorSession 和既有学习记录接续。** 课程版本固定材料与教学资产；原文、关键点和演示继续使用各自原身份。学生接受预置目标即可开始，也可修改目标。

课程为 TeachingDesign 提供初始主线和可复用内容。Resident 根据用户实际表达选择支撑、补讲、提问和返回位置；当前直接解释、跳过、暂停和改向请求优先。用户自己的预测、操作、作答、帮助与反馈沿既有事实链保存。发布更新沿 ADR-0170 由用户选择接入，历史仍指向原版本。

### 3.1 课程在书内学习（2026-11-09）

2026-11-16 补充：[ADR-0185](0185-book-and-course-collection-learning-hierarchy.md)明确书籍学习首页与跨书课程总目录为上一级入口，单课与当前任务持续显示其归属。课程步骤、原文、实验与私人教学仍沿本节执行。

**工作区提供课程选择入口，正式学习进入对应书籍的 Reader。桌面左侧在课程、原文与实验之间切换，右侧沿用该书在当前私人工作区中的 Agent 对话。** 手机上的学习与问答承接同一状态。课程阶段、草稿和实验控件不因视图切换重新创建；返回原文保留阅读位置，阅读活动的明确定位按钮可以重新定位对应小节。

原文回读是课件中的具体活动。作者提供实验前要寻找的概念或条件，以及实验后要用观察核对的关系。活动内的“查看本课来源”就地打开既有来源预览，定位对应原文并展示当前查证任务；关闭后接着原活动，保留草稿与实验现场。首次加载和失败重试在来源预览内呈现。需要通读时，学生可以明确选择“在阅读器中打开”，接到预览当前小节，再选择原句继续提问、返回原任务。必要回读计入 20–30 分钟的核心时长估算，自由追问按额外探索记录。

提交问题时，服务端从当前私人课程记录冻结已展示的阶段、来源、原话和帮助，并附上页面当前实验参数；客户端不提交完整课件或参考答案。实时参数说明正在观察什么，不能作为理解证据。Agent 接住当前问题，课程仍由用户推进。两侧已交付的帮助沿原事实链进入后续理解分析；反馈在对话区被实际打开后记录为已展示，用户的文字继续进入原“我的理解”。选项按实际文字解释，内部编号仅标识选项。

### 3.2 多轮探究与分段接续（2026-11-10）

一课围绕同一主问题逐轮提高要求：先比较现象，再找边界与条件，再处理情境变化，最后用未展示解法的新数据综合应用。每轮各自保存预测、实验参数和解释，完成当前解释后进入下一轮；先前记录可回看，当前轮不能覆盖旧轮。阶段接口只交付当前轮已揭示内容及已完成轮次，后续实验与答案继续按阶段揭示。反馈保留轮次及当时的帮助条件。

来源在课程开头直接显示。本样课以 §1.3.1、§1.3.2 为共同依据，不将完成这道资源决策问题等同于学完两节的全部内容；批内复用与吞吐仍可形成后续独立问题。27 分钟是活动编排估算，学习收益与真实用时仍由目标用户试学确认。

### 3.3 决策题中的连续教学（2026-11-10）

资源升级综合题增加可选的 `decision_teaching` 编排：作者预先提供本题要观察的理解目标、具体判断依据、必要补讲、实验观察位置，以及数据和升级方向均有变化的新情境。完整课程仍保留前三轮探究；本轮先落实最后一道决策题。

学生提交后，当前工作区就地展示针对其原话的回应。Coach 从当前阶段实际表达中判断哪些目标已有依据、哪里需要帮助、哪里尚未确认，再选择一个当前焦点进行补讲、实验对照或追问。提问和要求直接讲解也是合法的教学动作；先解答疑惑，不能把求助记成答对。提问每次围绕一个有价值的区别，不要求学生复述固定答案或达到字数门槛。

每次续答明确回应最近一轮教学，保留原话、实验参数、已获得帮助和理解变化。反馈实际可见时才记录交付；界面自动展开当前位置的反馈，右侧 Agent 仍可就原文、课程和实验答疑。暂停保留当前题目与进度，旧交流可回看。

进度由服务端检查当前阶段的最新判断和实际交付状态。每个已体现的目标须引用该阶段学习者的确切表达；选择正确、写过文字、点过继续、看过讲解或上一轮通过均不足以完成当前阶段。原题形成完整依据后进入新情境，新情境必须有自己的应用理由才开放结课。该状态只表示本次课程任务有了可核对的依据，不是长期掌握认证；语义判断仍沿现有理解记录保留其来源和帮助条件。

旧版本课程和已经开始的记录继续使用冻结的课件；新教学合同随新版本发布。具体样课见 `docs/examples/inquiry-course/ai-infra-resource-bounds.decision.course.json`。

### 3.4 预测与解释的反馈在课程中接续（2026-11-10）

预测与实验解释的当前回应在左侧活动中直接展示，提交后定位到回应卡；等待、失败重试、补讲和追问留在同一处。仅当回应卡可见且未被来源预览覆盖时记录反馈交付。右侧保留 Agent 自由问答，课程内集中回看旧反馈。

续答区分补充回答、提出疑问、请求讲解，冻结被回应的原话、已展示反馈、本轮内容及实验条件。请求讲解不能替代自己的解释，补讲和提问均不推进阶段。解释已提交时，界面先展示这次回应再开放下一轮；最终决策题继续沿 §3.3 的理解证据门槛。

普通活动回应已交付且没有 `follow_up` 时，界面明确收束本次问答，收起回答框，把当前阶段的下一步放在回应旁；有疑惑时再主动展开提问。不要求学习者对已经确认的答案反复复述。没有追问只表示本次无需继续作答，不产生掌握结论或直接完成整课：预测后去图上验证，实际观察完成后进入解释，解释后的继续仍使用原课程推进条件。补讲期间也保留返回实验或当前活动的入口，避免把可选交流呈现为无限作答任务。

已经进入下一轮而最后一条回应尚未读到时，在课程里直接接上该回应，标明所属轮次，展示当时保存的实验。回看旧轮次的追问继续使用旧轮次条件，当前轮的进度、预测草稿与实验现场保持；当前活动和旧轮次交流可以来回切换。

### 3.5 知识对象参与讲解、实验和答疑（2026-11-10）

课程蓝本同时说明要认识的对象、对象间的关系，以及操作之后应观察到什么。资源模型以权重数据、读取通路、计算阵列、请求与输出为可选择的三维对象；选择对象后展示其含义、对应公式和当前数值，允许带着这个对象向右侧 Agent 提问。引入阶段先认识对象，实验阶段再显示本轮计算结果。解释和决策时模型继续与当前回应同屏。

对象场景、二维决策图、三维下界曲面共用当前实验参数和计算。旋转、拆层、暂停和定位进度用于观察，不改变物理参数，也不作为理解证据。动画表达当前课程声明的充分重叠资源预算，明确区分理想下界与真实执行；对象布局为结构示意。页面使用已有本地三维依赖，隐藏或离开视图时停止播放。

批内复用课用可选的请求数扩展同一资源实验：`work_gflops` 始终为整批总计算量，`read_gb` 为该批共享读取量。改变请求数时按当前每请求计算量更新总量，权重读取保持不变。整批下界、每输出分摊量和吞吐上界分别展示，单请求等待不能用分摊量替代。容量满足是该教学模型的前提，未由动画推断。

本次实现为同一单元的资源升级与批内复用两课，各自保留最终判断及新情境；完成一课后可直接进入下一课。新内容独立发布，原学习记录继续关联原版本。资源对象场景是已验证的具体课程方法，其他领域的知识对象和三维表示须根据其学习目标另行制作。

### 4. 学习活动与理解证据保持各自含义

**预测用于显露初始想法，最终任务用于观察应用，完成进度用于接续。** 初次猜错不直接判为课程失败；当堂观察与检查按其真实帮助条件记录。检索练习继续遵守 ADR-0178 的非激活关系、提示与证据规则。

课程明确区分完成、跳过与尚未作答；点击继续、看过讲解和播放实验本身不生成理解或掌握结论。结尾任务在交付前冻结题面、判断依据和揭示方式，开放任务保留合理的多种答案；得到提示后的表现保留协助条件。

### 5. 质量按证据与实际结果判断

**构建期核验来源、独立解题、教学衔接和实际交互；学习效果由目标用户试学检验。** 关键结论及成立条件回到原文；审题先独立求解再与作者解答对照；可计算实验使用独立计算核对结果，并在真实页面操作和查看。最终任务所需关系必须来自声明的起点或课程实际支持。

审阅只依据具体错误、遗漏或行为失败要求修正，修后复验受影响部分。已知内容错误、错误判题和阻断学习的流程问题解决后，课程才进入正式发布。首批样课经内容核对与目标读者试学建立制作参照；自动检查、模型审阅、工程可用和学习效果分别报告。

每课按其具体结论、任务和交互取得接纳依据，检查范围由实际内容决定；模型独立审阅、计算及真实页面运行承担各自可验证的部分。熟悉内容的人与目标用户试学重点覆盖首次采用或发生实质变化的方法，并按方法与材料选取代表课程抽查；发现共同问题时扩展到相关课件。共用方法和页面机制的已有效验证沿既有记录复用，修改后只重验受影响内容，未解决问题随候选保留。

### 6. 先贯通样课，再接入自动预构建

**先用真实 BookStructure 和现有交互模板完成一条学习闭环，再将可复用制作方法接入现有构建执行器。** 复用已有任务、恢复、预算、费用及发布机制。课程只准备选定范围，使用时直接加载已有内容；个性化补讲与反馈按需执行，局部控件操作由页面计算。

模型配置、生成成本、阶段时长和首批课程规模依据样课实测调整。具体题材与资料版本在首个切片中从真实可用材料确定，梯度下降模板是可优先评估的制作素材。

## 取舍与既有决策接续

- 章节路线保留“一章一单元、一节一课”的默认尺度，主题路线保留跨章问题与演进；用各课的理解目标修正具体拆合，避免单一导航方式决定全部课程组织。
- 不以每个学生入场时重建整门课作为主路径：公共编排和核心实验可共享，现场教学承担个人适配。

- 将 [ADR-0178](0178-in-context-retrieval-practice-and-learning-map.md) 对连续“下一题”流的限制限定于原就地情境练习。课程提供有明确结束点的连续活动，预测和当堂检查不自动归为检索练习。
- 共享版本与个人归属沿 [ADR-0170](0170-goal-scoped-learning-workspaces-and-shared-releases.md)；套餐和成本沿 ADR-0171、0173；知识树和理解果实沿 ADR-0181。

### 课程带学的生命周期（2026-11-12）

**决策**：CourseRun 持有本课全程带学。

开始课程即按已准备的课程主线带学，`active / paused / completed / skipped` 仍由原课程动作维护；目录浏览不创建课程，原文和实验切换不创建新阶段。返回目录或自由阅读先确认暂停保存，失败时保留现场并允许重试。

右侧对话的教学 binding 归属本次 run；接纳时冻结课程位置、已展示内容、实验、原话和帮助，运行中的暂停在下一次采样生效。课程问答提供 trace、understanding 与 hypothesis 操作，课程自己的作答与反馈链路负责判断，答疑不另起教案或推进进度。

课内作答继续调用已有 Coach；右侧回合后继续写入理解观察，后续课内作答按同一 run 回收实际答疑帮助。页面切换、开始、暂停与恢复不新增模型调用。课程就绪以已验证的课程和原文为基础，不依赖正式知识对象。

全程带学按活动调节：预测允许猜测，阅读与实验按需帮助，解释针对实际表达，遇到障碍局部补充并返回原任务，应用与迁移沿用原证据要求。没有强制每轮追问，也没有新增每步掌握门槛。

实现及验证见 课程带学记录。

2026-11-13：本机阅读器可加载当前书目录中的 `inquiry_course.json`，校验实际来源版本与 LID 范围后，复用 InquiryCourse 播放器、私人 CourseRun 与后台 Coach。手工样课和自动构建成果使用相同课件协议；本地加载不冒充自动审题报告，线上 operator 的导入要求保持独立。数学探究可附带弦高、梯度迭代、半平面可行方向三种实验；参数与当轮作答一同保存，独立题按真实原话给分项依据。方法见[数学制课](../../skills/build/course-methods/mathematics.md)，实际范围和验证见三课记录。
