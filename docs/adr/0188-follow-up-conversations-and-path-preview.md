# ADR-0188 从回答原句另开追问对话

2026-11-18 · **已接受，已在阅读器实现。** [切片、设计参照与实施结果](../切片方案-追问对话与路径预览.md)

读者问“多出来的 8 分，是软件带来的吗？”，同一段回答里出现了“对照组”和“随机分组”。读者想先弄懂其中一个，也可能看一眼已有解释就回去读书。**从回答原句另开聊天，用出处连接聊天。** 读者只在想单独讨论时开支线，路径由此成树，每条聊天内部继续顺序记录。

## 聊天与来源

树上每个已开启的节点对应一段可以连续交谈的聊天。普通发送追加在当前聊天，独立新建的聊天自成根。读者选中已交付回答中的文字，写下首问，点击「开始这条追问」后才建立子聊天。子聊天的创建事件持有唯一的父聊天、父回合和可核对的回答片段。首轮使用读者的问题、原问题及所引解释，需要材料依据时沿原回合已验证的来源取证。父、子和同级聊天各自保存后续消息、运行和交付。

把每个问答回合都画成节点，会让“能举个例子吗”也占据探索路径。把支线塞进回答下方的折叠区，读者谈上几轮后仍得穿过嵌套内容才能接回原话。独立聊天让读者沿用原来的输入与阅读方式，代价是系统要保留准确的出处、各自的草稿和回去的位置。旧聊天按原格式读作独立根，历史回放和压缩沿用 [ADR-0152](0152-resident-linear-jsonl-session-log.md)。

## 预览、进入与返回

选中树节点只预览。已有聊天显示真实问答摘录，待追问显示来源、可修改的首问和已有的追问意图。预览是只读操作，模型调用从用户发送问题开始。「进入这条对话」切换活动聊天。「回到原回答」定位直接父回合的原句，「阅读」恢复书里的位置。读者可以收起预览，接着写留在原聊天的半句话。

分栏阅读时，入口在问答输入框上沿，展开仅占问答栏下部，所引原句在上方可读。宽屏全屏问答把同一棵树放进已有的左侧「会话」区。手机问答使用底部面板。主题用既有铜色点明出处，实点和「当前」标记正在交谈的位置，浅底标记正在预览的节点。布局沿用[阅读工作区的设备投影](0131-mobile-reading-workspace-and-viewport-projection.md)。

书的知识图谱表达材料中的实体和关系，追问路径记录一位读者怎样从一问走到下一问。路径属于读者的私人聊天历史，课程中的实际求助沿当前课程记账。掌握程度仍由既有学习证据支持。若以后确有编辑旧回答并保留多个版本的需求，再评估回合版本树。[学习工作区与独立书库的归属](0170-goal-scoped-learning-workspaces-and-shared-releases.md)
