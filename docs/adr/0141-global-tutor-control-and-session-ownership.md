# ADR-0141 全局 Tutor 控制与教学会话所有权

状态：已接受，2026-09-29；T2 控制、私人存储及会话生命周期已实现，T6/T7 的教学关联与 Resident 运行已实现。细化 [ADR-0118](0118-learning-memory-owned-replayable-tutor-session.md) 与 [ADR-0119](0119-agent-native-learning-environment-and-teaching-agency.md)。

## §1 全局教学控制

**决策**：LearningMemory 持有全局 Tutor 开关。

**否决**：
- 每张演示页单独启停：跨阅读、聊天和演示的学习行为不连续。
- 用会话教法或长期偏好代替：开关、教学方法和稳定画像的生命周期不同。

**命门**：默认关闭，恢复用户上次显式选择；关闭暂停当前教学并保留进展，开启后依据会话与就绪状态继续。材料未就绪时保留开启意图并显示准备状态，昂贵构建仍使用既有 BuildPlan 授权。当前回合直接讲解只覆盖教法。
**何时回头**：产品正式支持多个独立读者或同时教学的工作区时，重新界定控制范围。
**展开**：[控制与生命周期](../切片方案-Tutor全局模式与教学闭环.md#3-全局控制与教学会话)。

## §2 会话范围与连续性

**决策**：单一当前教学会话跨聊天与页面延续。

**否决**：
- 聊天或页面各自持有学习目标：导航和历史管理会暗中改变学习任务。
- 同时自动推进多个教学会话：当前动作与进度归属不明确。

**命门**：会话分别保存用户意图与约束、Agent 当前焦点、参考材料及默认教法；显式切换暂停原会话，历史会话可恢复。结束会话不等于关闭全局模式，换书也不自动更换目标；消息和运行保存确切会话 revision，ResidentGoal 继续拥有聊天交付任务。
**何时回头**：真实用法要求并行课程且能明确区分每次动作的归属时，扩展当前会话规则。
**展开**：[会话合同及运行边界](../切片方案-Tutor全局模式与教学闭环.md#3-全局控制与教学会话)。

## §3 私人持久化

**决策**：稳定画像与动态学习状态分库持有。

**否决**：
- 将持续追加的学习记录塞入 memory.json：关联反查、回放和重算不适合整份文档改写。
- 仅保存模型给出的当前掌握状态：无法追溯判断依据或重算。

**命门**：既有 ProfileFact 保留在 memory.json；全局控制、会话事件、Trace、Assessment、Evidence 与可重建投影存入同一读者私有 learning.db。原始事实与解释性证据分别保留，聊天压缩不拥有它们的生命周期。
**何时回头**：实际同步或查询需求要求改变存储边界时再调整。
**展开**：[三个领域与存储](../切片方案-Tutor全局模式与教学闭环.md#2-三个领域与所有权)、[Grill Q71](../grill.md#grill-q71---learning-traceevidence-与-state-的本地持久化)。
