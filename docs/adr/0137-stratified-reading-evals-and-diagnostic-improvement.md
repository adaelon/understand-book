# ADR-0137 分层阅读评测与诊断驱动改进

状态：已接受，2026-09-25；EV0–EV6 已实施，EV3 人工校准与 EV4 出题人审、首轮当前版本运行及 EV5–EV6 首个诊断完成；EV7 待实施。实施合同见[切片方案](../切片方案-Agent分层评测与诊断闭环.md)。

历史评测同时记录了充分取证后的交付失败、判分故障和简单 RAG 的有效成功。评测需要区分这些原因，并用可复现的干预实验指导改进。沿用既有生产入口、原始运行记录和质量复评能力。

## §1 任务分类

**决策**：阅读理解分四层，交互状态独立标记。
**否决**：
- 按工具数、章节数或回答长度分级：实现路径和篇幅不代表必要理解操作。
- 把重启恢复设为最高理解层：混淆内容理解与状态连续性。
**命门**：L1 定位提取、L2 解释与局部推导、L3 多证据整合、L4 情境诊断与迁移评价；单轮、多轮、跨会话分别标记。层级由任务要求冻结，实测难度由结果观察；保留简单题及既有题型。
**何时回头**：真实任务反复无法按必要理解操作归类时，修订分类版本。
**展开**：[任务合同与层级](../切片方案-Agent分层评测与诊断闭环.md#任务合同与层级)。

## §2 判定单位与事实边界

**决策**：逐项判任务要求，分列交付与评分状态。
**否决**：
- 将判分失败计为内容错误：错误信号会引导修改错误模块。
- 以运行停止或 Agent 完成声明代替结果验证：二者都不证明用户任务已完成。
- 用未交付草稿补产品成功：掩盖真实交付缺口。
**命门**：任务结果保留 pass/fail/unresolved，评分故障保留具体原因；引用和动作由实际结果验证，语义由有原文依据的判定支持。沿用 ADR-0132/0136 的运行、交付和 Goal 边界，完整分母不变。
**展开**：[判分合同](../切片方案-Agent分层评测与诊断闭环.md#判分合同)。

## §3 评委校准

**决策**：绝对合格与配对偏好分别校准和使用。
**否决**：
- 任意偏好分歧阻断全部语义判定：不同用途的可信范围被混为一谈。
- 只以总体一致率批准裁判：大量简单题会掩盖严重错误误放。
**命门**：人工确认原子判例、误放和误杀；校准结论绑定任务范围、评委及协议版本。偏好未校准时不参与版本取舍；自动草拟标签保持候选。四维质量为汇总视图，关键错误不能被平均抵消。
**何时回头**：更换评委、评分规则、核验材料或扩展能力范围时，重新校准受影响范围。
**展开**：[EV3](../切片方案-Agent分层评测与诊断闭环.md#ev3-按用途校准评委)。

## §4 对照与诊断

**决策**：产品比较、定位消融与诊断实验分账。
**否决**：
- 用完整 RAG/Agent 分差归因图谱：提示、上下文和执行合同同时不同。
- 用充分证据或共同回答器成绩替代产品成绩：诊断干预改变了被测条件。
- 为证明 Harness 优势而移除简单题：会漏掉真实基础能力退化。
**命门**：复用 Text/Tree/Graph 同环消融；按失败增加充分证据下的交付测试、实际取证结果的共同回答器测试。必要证据曾出现不等于决策时仍可见；每项干预记录改变了什么。
**展开**：[EV5 与 EV6](../切片方案-Agent分层评测与诊断闭环.md#ev5-充分证据下的交付诊断)。

## §5 持续改进与所有权

**决策**：每次改动绑定假设、配对结果与退化检查。
**否决**：
- 只看总分或只复跑失败题：看不见局部收益、能力倒退与运行波动。
- 改写历史结果或拼接不同程序样本：无法区分产品变化和量尺变化。
**命门**：本地评测持有任务、评分与实验合同；生产持有真实行为和交付事实，LangSmith 沿 ADR-0134 仅作可选投影。按证据链分开发/留出，报告新增及失去成功、未决、失败成本与重复稳定性；读者学习效果属于独立验证。
**何时回头**：重复实验仍不能分辨有实际价值的差异时，调整样本与实验设计。
**展开**：[EV7 与限制](../切片方案-Agent分层评测与诊断闭环.md#ev7-完成首个改进闭环)。

## §6 原文支持与引用定位

**决策**：分判原文支持与引用定位后重建基线。
**否决**：
- 只评高亮或只扩大高亮：无法区分实际依据与定位交付。
- 自由语义文本与英文标签比相等：会将正确释义误判为内容失败。
- 以来源通过率上涨宣称理解提升：混淆量尺修正、交付修复与能力变化。
**命门**：新协议只用实际交付来源判支持，逐论断指明依据；语义要求直接判定，精确值由程序核对。旧答案经新版本校准后统一复评，来源绑定与提示分别验收。
**何时回头**：校准仍无法区分完整依据、缺条件和宽泛定位时，修订判例及合同。
**展开**：[来源交付与评分修正切片方案](../切片方案-来源交付与评分修正.md)。
