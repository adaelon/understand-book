# ADR-0161 对话起步、普通理解观察与多人后台记忆

状态：2026-10-10，用户确认；本地实现，未部署。

## §1 对话起点

**决策**：首问承载学习起点，目标在对话中可见。

**否决**：
- 先进入管理面板填写：聊天可以工作却没有学习会话，状态对用户不可见。
- 打开开关即发送默认问题：替用户确定目标，产生额外模型请求。

**命门**：Tutor 开启且尚无当前会话时，首个已接纳问题建立学习意图；暂停和结束不被普通消息自动解除。目标与调整入口在聊天顶部展示；本书没有匹配会话时提供直接设定目标的入口，调整目标保留上一目标历史。

## §2 理解观察

**决策**：普通理解观察独立于主动教学开关。

**否决**：
- 无 TutorSession 就不分析理解：丢失普通追问、复述和纠正。
- 关闭 Tutor 仍自动教学：违背用户对主动教学的控制。

**命门**：普通回合使用按材料归属的观察范围，复用 InteractionTrace、LearningEvidence 与 LearnerContext，不创建隐藏的活动教学会话。只允许事实回读、理解读取及有原文依据的假设写入；正式动作和判题仍检查有效教学会话。理解假设可以跨观察与教学会话修订，但来源及版本必须一致；表现证据仍绑定原活动。没有依据的回合不强制制造结论。

## §3 多人后台记忆

**决策**：多人宿主负责消费持久画像审核任务。

**否决**：
- 只登记队列：任务会永远停留在 queued。
- 复用不带账号的裸模型调用：脱离授权、额度和费用归属。

**命门**：空闲 60 秒或同会话累计 8 个未审核回合后执行；前台存在未完成回合时让出。短锁领取任务，锁外执行同一个 ReviewExtractor，经 LimitedAdapter、ReaderTask 费用归属及现有证据规则后提交；失败保留重试状态。启动时发现持久未完成任务，运行期间将新任务归属加入恢复队列，按现有用户容量逐个恢复，不依赖用户重新登录；过程沿用同一私人运行态和宿主取消信号。
