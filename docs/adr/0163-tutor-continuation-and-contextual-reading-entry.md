## 背景与决定摘要

用户已经拥有原文、选区、回答或演示现场，却仍需把阅读困难翻译成 prompt。当前 Markdown/PDF 的“问 AI”主要绑定引用并打开空输入框；Tutor 已能读取 LearnerContext、选择教学动作和积累学习证据，但缺少与实际交付绑定、可执行且可纠正的下一步建议。

决定在**同一个 Resident / TutorLoop** 内补上两段连接：

```text
用户对已核验选区点击“帮我弄懂这段”
  → 原 Agent Run → 按当前控制状态进入普通解释或 Tutor

首次普通解释 → 显式开启连续教学 → 点击“继续理解这段”
  → 新 Run 以原回答和来源范围承接首个教学请求

Tutor 实际交付本轮帮助 + 可选的轻量下一步建议
  → 用户接受其中一项、点击“这一步没跟上”，或直接改问
  → 新 Run 冻结真实动作、原回答与原现场
  → 同一 TutorLoop 执行一个实际教学动作
  → 实际反馈分别进入意图、理解假设或表现证据路径

求助命中当前待作答正式活动 → 原活动提示／揭示入口
  → 实际帮助展示仍归属原题，再按原帮助条件作答
```

目标是减少组织操作指令的负担，不是减少理解内容的思考，也不是提高所有工具的调用率。这里借用“提出候选、获得反馈”的交互思路，不实现 token 推测解码、多分支答案预生成或推荐模型训练。

## §1 所有权不变：协商属于 Tutor，不新增推荐系统

**决策**：下一步建议由处理当前任务的 Resident 产生，附属于本轮实际教学交付；建议被接受后仍通过原 Run 执行。

沿用现有分工：

| 既有对象 | 继续负责 | 不承担的新职责 |
|---|---|---|
| TutorControl / TutorSession | 主动教学授权、学习意图、暂停与恢复 | 不为每个按钮新建会话 |
| ResidentGoal | 当前任务的要求、工作进展与实际交付 | 不把全部候选都变成待完成任务 |
| TeachingTarget / TeachingMove | 本轮有来源的焦点和实际教学动作 | 不代替“未来可能做什么”的建议 |
| LearningMemory | 私人事实、假设、表现与可重建视图 | 不新增第二份能力档案 |
| 原 Run / SessionStore / 费用端口 | 接纳、执行、恢复、取消和实际模型成本 | 不新建推荐队列或另一路计费 |

接受建议时，相关且仍 open 的 ResidentGoal 可按现有规则接续；原任务已完成时建立有关联的新任务，不篡改旧完成事实。二者都不自动改变 TutorSession 的总学习意图。“例子已交付”不等于“用户已掌握”。

**否决**：新增推荐 Agent、并行完整讲解分支、第二套用户建模存储、把此功能接到后台画像审核队列。

## §2 先能直接开始：选区是对象，点击是请求

**决策**：原文选区可直接求助，已交付回答可直接接续与纠偏。

已核验的 Markdown/PDF 选区提供“帮我弄懂这段”；普通路径点击即发起一次解释。命中当前待作答正式活动时，按 §6 返回原活动帮助入口。原“围绕这段提问”继续保留。

请求保留动作来源和选区来源；只有文字为空但带合法、已授权的类型化动作时，才能发送。普通空白聊天仍拒绝。发送前原文范围可见，失败、重连或换现场不会悄悄改用当前视口。已有自由输入草稿不得因该动作被清空或自动夹带发送。

首版不从停留时长、滚动、划线或打开材料推断求助。无选区时仍保留自由输入；“当前整段”“图表对象”等入口待其定位合同完整后复用本协议，不在本轮额外扩展。

Tutor 已开启、无当前会话且满足原首问条件时，用“已接纳动作 + 实际来源范围”建立初始意图。按钮文案不是完整目标，也不能自动扩张为整本书课程。存在暂停、结束或其他材料会话时，沿用既有显式管理边界，不擅自替换会话。

已持久交付的回答提供“这一步没跟上”，可附读者明确选中的回答片段。点击表达本次解释仍需帮助，冻结原回答与片段，直接进入原 Run；普通模式同样可用。模型先拆开一步或换一种具体讲法，确实无法定位障碍时才问一个简短、具体的问题。读者无需重述原问题或自行诊断知识缺口。

回答接续是新增输入能力，复用回答选区的定位与摘录，新增服务端对已交付回答的核验。回答片段保留 Agent 内容身份；点击不构成原题作答、稳定偏好或能力诊断。

**依据**：[ADR-0161](0161-conversation-first-learning-and-multi-user-memory.md)；`crates/server/src/teaching.rs:334–367`。

## §3 建议不是教学交付：TeachingMove 增加可选 continuation

**决策**：在 TeachingMove 上增加向后兼容的可选 `continuation`；首版每回合至多一个建议集合，包含一个推荐项，必要时一个备选项。

每项只包含稳定选项标识、用户可见的请求文案、具体用途及受限教学方向。首版继承所属 TeachingMove 的已核验 TeachingTarget，限于当前焦点内的解释、对比或观察；不预先生成未来答案、完整演示、评分合同或任意工具参数。技术形态按内容需要决定，不把“生成动画”作为默认目标。

候选是可执行意图，不是新事实证据。若文案需要新来源支持，先按原规则读取；首版优先利用本轮已读范围，不为了凑选项遍历材料。未知背景不写成诊断性断言。

推荐项不能列入 `MoveSelected` 作为另一个实际动作；更不能把选择伪装成当前活动的 `submit`、`self_report` 或 `skip`。现有正式活动行为合同保持独立。

本轮回答持久交付后，建议随公开教学交付保存。建议进入可见区域才形成建议展示回执。以下三件事严格区分：

```text
交付了建议 ≠ 用户看到了建议
用户看到了建议 ≠ 用户选择了建议
用户选择了建议 ≠ 下一步内容已经交付，更不等于掌握
```

没有必要的下一步时允许不生成。失败、未保存或未实际交付的回答，不产生可执行建议。

**依据**：`crates/runtime/src/tutor.rs:64–77`；`crates/server/src/teaching.rs:639–805,821–909`。

## §4 接受建议是正式输入，不能伪造用户原话

**决策**：接受建议与直接动作使用互斥的类型化输入。

AgentChatMeta 增加 `teaching_choice={delivery_ref, option_id}`；`entry_action` 支持 `explain_selection`、`clarify_answer` 和 `continue_answer`。前者绑定有效原文选区，后两者绑定 `answer_ref={turn_id, excerpt?}`；turn 必须属于当前读者的原聊天并已持久交付，excerpt 按原回答公开文字核验。原文选区与回答片段分别保留来源身份。

服务端读取原交付、核验动作和当前边界，生成不可变的解析结果。聊天分别显示“选择：……”“操作：帮我弄懂这段”“操作：这一步没跟上”或“操作：继续理解这段”，额外输入仍按用户原话保留。模型可使用已公开、被接受的意图，不得把内部扩展指令、推荐理由或系统假设伪装为用户声明。

补充类型化的当前动作意图来源，接通 `intent_origin` 的 schema、服务端校验、历史投影与模型上下文；不通过伪造 `intent_quote` 兼容旧校验。直接解释优先于引导式会话默认，当前用户补充优先于旧建议。

模型本轮可见的工具合同按冻结状态收窄：普通观察仅开放回读与理解假设，历史引用仅开放 trace，未开放的 continuation 不进入采样参数。纯按钮请求中已确定的意图及来源由程序根据解析快照补齐，不再要求模型重复声明；无补充的直接帮助固定为直接解释，接续依次采用会话默认、已确认偏好和中性兜底。真实补充与自然语言偏好仍保留语义解析，存储合同继续记录最终意图及来源。

类型化阅读动作选择完整 TeachingTarget，能力只在目标中声明一次，服务端填入 Move 的对应持久化字段。来源、对象修订和实际教法仍按原目标合同校验。

`teaching_choice` 和回答接续都不自动填入 `teaching_ref`。后者目前会形成原活动的 `chat_response`，且后续交付可被关联为活动帮助，不能当普通的“相关内容”字段复用。命中当前评分活动的求助在接纳 Run 前分流到 §6 的原活动帮助路径。

**依据**：`crates/server/src/teaching.rs:315–330,655–685,848–864`；`packages/web/src/api.ts:1196–1205`。

## §5 单次接纳与可恢复执行，而非“先记点击，再补聊天”

**决策**：进入 Run 的类型化动作与执行请求一起持久保存。

直接解释、回答接续、回答纠偏与建议选择均保存原动作、解析结果和请求身份。客户端重试同一操作保留原请求身份，先核对结果；服务端不同载荷不能复用同一请求身份。返回原活动帮助入口的分支不接纳新 Run，实际提示／揭示复用原活动操作的身份和回执。

多人模式沿原接纳协议：核验与解析 → 保存带原选择的 FrozenTurn → 幂等追加教学事实 → 保存 prepared 回执 → queued。只有准备完整才可领取。崩溃恢复读取原冻结输入，不重新询问模型、不重新生成建议、不把 claimed Run 自动重放。事件补记不构成第二次执行。

本地模式不假定已经具有多人 RunAdmissions 的完整保证。必须在既有本地聊天/回合持久化与运行入口中增加必要的动作身份查重和已接纳输入保存，复用共同解析器；未完成该门槛前，不开放本地新类型化动作入口。

按原 delivery 建议集合接纳一次新选择。跨标签页的不同请求身份也要检查原聊天 head 和已接纳回合，不能仅靠按钮 disabled 防重复。重试原请求先返回原接纳结果，再进行“新选择”资格判断；任务失败后的显式继续沿原 Goal/Run 恢复路径，不重新消费同一建议。

不宣称对外部模型实现 exactly-once：本合同保证相同操作不额外接纳新的执行，未知结果不盲目重放；实际费用和供应商不确定状态继续按原费用合同处理。

**依据**：`crates/server/src/run_admission.rs:367–423,498–648,775–803`；`packages/web/src/network-client.ts:121–187`；本地入口 `crates/server/src/lib.rs:11845–11912`。

## §6 事实、意图与理解证据分流

**决策**：在原 learning.db 的教学事实账本中增加建议展示与选择事件，不新增用户模型。

- `ContinuationDisplayed`：记录确实展示的选项标识、顺序和推荐项。只表示界面接触，不证明阅读或理解。
- `ContinuationChosen`：记录被接纳的真实选择、原建议集合引用及接纳回合。原 Run 保存解析快照，事实事件只由原快照幂等投影。

展示回执失败不应阻断合法选择，也不能反过来补造“整个集合都被看见”。选择依据服务端已交付选项核验；展示、选择和执行结果分别保留。

选择事件进入 LearnerContext 的当前意图/近期交互，不进入作答次数、评分分母或掌握聚合，不自动生成 ProfileFact。纯路线选择不应成为必须处理的“待解释理解事实”，也不能单独支持能力强弱假设。

用户自然表达的卡点、复述与纠正，可继续按原文及事实依据生成 `nature=hypothesis`，通过 `teaching_implication` 影响讲法。正式作答才沿原冻结合同进入 Performance 路径。更新 `teaching_recent`、trace 摘要、回读与投影过滤，使新事件既不遗漏，也不污染已有证据。

TC6 将近期交互与认知待办分开：待办及假设引文取真实用户表达，助手交付不能单独支持假设；展示、选择与纯操作仍可回读。后台画像审核、历史回填和待审核上下文只引用真实补充，动作单列且保留回合序号。实现和验证见 [TC6](../performance/tutor-continuation-tc6.md)。

首版有当前待作答正式活动时，不提供另起路线的 continuation。服务端同时检查原文直接帮助与回答接续：若选区与该活动目标范围相交，或原回答属于该活动及其已关联帮助，则返回原活动的提示／揭示入口，不另起解释 Run。旧对象式活动使用原冻结评分来源范围。判定使用现有会话、焦点、来源版本与活动事实；暂停或关闭 Tutor 不解除原题的帮助归属，历史无关未答题不阻塞普通解释。

打开帮助入口只定位原题。实际提示／揭示继续产生原 HelpDelivered、HelpDisplayed，提交冻结原 assistance_refs 和尝试条件；没有可用帮助时明确提示，并保留原活动与返回阅读入口。新生成的题内帮助留待有完整活动关联与实际展示合同后接入。

**依据**：`crates/memory/src/teaching.rs:69–122`；`crates/memory/src/learning_evidence.rs:17–53,123–138,190–216`；`crates/server/src/teaching.rs:1015–1113`。

## §7 控制边界、失效与界面职责

**决策**：动态建议首版仅在 Tutor 活动会话中提供；直接解释入口在普通模式仍可用。Tutor 关闭不取消 ADR-0161 的普通理解观察，但不自动建会话、选教学动作或出题。

首次普通解释附近复用“开启连续教学”入口，说明开关对所有书籍生效。开启只改变授权，不发起模型调用；Tutor 已开启、材料就绪且尚无当前会话，或已有匹配的活动会话时，读者另点“继续理解这段”，由 `continue_answer` 携带原回答与来源范围进入首问／接续流程。存在暂停、结束或其他材料会话时先走既有显式管理。就绪不足时普通解释与回答纠偏仍可用，界面如实说明动态建议暂不可用。

建议读取与选择必须核验账号、原聊天、材料授权、原来源版本、TutorSession/control revision 和当前聊天 head。新输入被接纳、来源变化、目标修改或控制换代后，旧建议保留为历史，不自动换绑最新材料继续执行。暂停或结束时给出既有显式恢复入口，恢复本身不自动执行旧建议。

回答接续是一次新的明确请求，可指向本聊天中的历史已交付回答；它按点击时聊天 head 接纳，不复用旧建议的消费资格。来源或授权失效时保留原结果并提示，不能换绑新版本。启用连续教学后也不为旧回答后台补造建议。

已接纳请求运行期间发生暂停，沿用现有“普通明确请求可完成、停止自动教学推进”的边界；是否取消本轮仍由原停止操作负责。交付事实可如实保存，但过期建议不能继续执行。

新增轻量 `TutorContinuation` 宿主组件，与 `TutorActivities` 分工：前者承接未来帮助选择，后者承接当前活动作答与帮助。一个建议集合只出现一个主入口；普通回答与演示工作区不重复渲染。演示只通过原宿主桥请求操作，不让生成 HTML 任意调用教学 API。

TC5 已接入按原 turn／演示版本过滤的公开建议投影、可见选项回执和整段／片段纠偏。本地浏览器持久保留原类型化请求，刷新先查询原接纳，再由用户显式重试；多人复用原提交恢复入口。见 [TC5 实施与验证](../performance/tutor-continuation-tc5.md)。

首版不主动出小测、不弹出能力问卷，不新增“学习模式选择器”。自由输入、纠偏、停止、返回原文始终可用。跳过、返回阅读或没有选择都不形成“不懂/已懂”的判断。

**依据**：`crates/server/src/teaching.rs:105–127`；`crates/runtime/src/tutor.rs:82–92`；`packages/web/src/components/TutorActivities.vue:58–88,133–149`。

## §8 范围、代价与回头条件

**首版范围**：可信选区直接解释；绑定已交付回答的接续与低门槛纠偏；首次帮助到活动 Tutor 的显式入口；同一焦点内的少量动态建议；动作的持久接纳与恢复；私人事实接续；Markdown/PDF 和现有普通回答/演示宿主兼容。

**不做**：跨书推荐、整本书自动课表、停留行为触发教学、多路内容预生成、后台推荐模型、长期偏好自动定型、评分算法重写、公共 TeachingMap 私有写入、远程 MCP/调用包改造。ADR-0162 的远程 MCP 方案与本 ADR 不互相阻塞。

建议生成复用本轮模型预算，但仍可能增加 token 和工具成本；不是零成本功能。展示/读取不额外调用模型，选择只产生一个新 Run，Run 内仍沿用原模型—工具循环及费用控制。

新字段对旧记录可缺省，但这只保证新版读取旧记录；旧版 TeachingMove 的 deny_unknown_fields 及新增事件枚举都可能阻止旧二进制读取新数据，必须明确测试。回退不能假定旧二进制能读新格式；优先采用同版本保留读取能力、撤下新入口与指导的降级。涉及旧版本回退时，按验证后的兼容方案和备份运行单执行，不删事件伪装兼容。

验收以“无需学习产品术语就能开始、继续并纠正一次阅读帮助”为主，同时验证不误判理解、不越权、不重复执行。TC2 后验证默认关闭 Tutor 的首次帮助与入口转换，TC3 后用真实材料验证建议是否推进原问题，TC5 验证建议未猜中时能否少量表达完成纠偏；TC7 保留完整工程与读者验收。推荐点击率仅为交互指标，不作为学习收益代理。

**已知限制**：首版从读者能指明的原文或已交付回答起步；无法定位阅读卡点、跨范围补前置知识尚不在覆盖内。普通模式不生成动态建议，需显式进入活动 Tutor。降低表达负担与改善阅读推进的实际效果，以真实模型及真实读者结果确认。

以下情况才扩大设计：真实读者仍无法开始；建议反复不相关；局部范围确实不足以推进任务；已有数据证明需要更多路线或跨书接续。先定位断点，再扩展，不提前引入推荐引擎。

## §9 按需教学指导（TC2A）

**决策**：按任务装配教学指导，常驻简短能力入口。

**否决**：
- active 状态即注入全部教学流程：普通讲解持续承担未触发的任务指导。
- 只凭工具可见性加载发现规则：会重新引入 ADR-0104 的首轮导航循环依赖。
- 同时改变目标提交时序或新增分类模型：无法单独判断指令装配的影响。

**命门**：沿用请求计划、上下文片段与工具发现；冻结数据与采样指导分开，共用证据约束及短入口保留。真实用户表达或理解回读展开更新流程；真实未评估提交展开正式评估，成功后失效；导航按激活能力、演示按阶段加载。显式带读预激活、原文与操作权限不变。见 [ADR-0104 §2](0104-intent-seeded-guided-reading-tool-exposure-and-resident-navigation-policy.md#2-常驻发现入口与按需导航规则)及 [TC2A 实施记录](../performance/tutor-continuation-tc2a.md)。
**何时回头**：受支持的带读、自由表达、理解更新或评估因流程未加载而失败时，修正入口和触发条件；数学错误未改善时独立保留内容问题。
