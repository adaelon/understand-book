承接 [ADR-0136](0136-resident-goal-lifecycle-and-delivery-completion.md) 的用户要求与工作判断分离、[ADR-0154](0154-presentation-global-framework-and-staged-authoring.md) 的复杂解释制作方法，以及[调用成本计划](../计划-调用成本与DeepSeek适配.md)的动态状态追加原则。

## 背景

[EX12.4](../performance/presentation-staged-authoring-ex12-4.md) 已跑通关键局部、反馈、全文展开与 review，但范围遗漏和数值修正仍依赖外部反馈。现有 Goal 只有工作焦点与下一步，没有逐项进度；阶段指导变化改写前部 instructions，当前回合的旧 write HTML 持续参与采样，修订入口无条件加入整篇可读正文。最终补丁原生验收被 DeepSeek 402 阻断，不能据此宣称 EX12.4 完成。

## §1 任务与制作方法

**决策**：Goal 持有任务进度，框架表达解释设计。
**否决**：
- 用全局/局部阶段代替待办：阶段无法表达完整范围与实际剩余工作。
- 把所有计划步骤写成用户要求：Agent 将失去依据观察调整方法的能力。
- 删除全局理解路径：复杂内容仍需要明确的前提、关系与衔接。
**命门**：原要求以用户消息为依据；工作计划可变；先整体后局部保留为适用方法，小修订不强制走完整流程。
**展开**：[概念与边界](../切片方案-EX13-Goal工作计划与演示修订上下文.md#1-已确认的产品边界)。

## §2 工作计划所有权

**决策**：在 Goal 内增加最小工作项列表。
**否决**：
- 新建独立 Todo 服务：重复持久化、恢复与状态投影。
- 用完成勾选替代实际交付：工作判断不能授予页面或 Reader 操作资格。
**命门**：工作项只含身份、描述和状态，复用 working 更新、Goal revision 和会话日志；不自动完成 Goal，不覆盖 requirements。
**展开**：[数据与更新合同](../切片方案-EX13-Goal工作计划与演示修订上下文.md#4-goal-工作计划的最小合同)。

## §3 指导组装与缓存

**决策**：固定共同前缀，按采样追加指导变更。
**否决**：
- 每次切阶段替换请求前部：使已有长历史失去前缀复用机会。
- 为缓存降低状态更新频率：下一次决策会使用过时信息。
- 首次加载全部技术细节：增加无关输入，干扰表示选择。
**命门**：固定资源指导与任务设计数据保持权限层次；最新选择生效，旧选择失效，压缩后当前指导可恢复。
**展开**：[目标请求结构](../切片方案-EX13-Goal工作计划与演示修订上下文.md#3-目标请求结构)。

## §4 历史裁剪与版本修订

**决策**：围绕确切版本和当前缺陷组织修订。
**否决**：
- 每轮发送全部历史源码和失败过程：重复输入掩盖当前工作。
- 删除没有可靠落点的材料：会破坏恢复和内容修订。
- 自动使用最新版本：可能修改用户未选中的内容。
**命门**：先有成功保存和可重读定位，再裁剪模型投影；原记录、来源和调用配对保留。receipt 修订不能因漏 based_on 默默另建对象，明确新建仍可表达。
**展开**：[确切版本合同](../切片方案-EX13-Goal工作计划与演示修订上下文.md#5-按确切版本组织修订)。

## §5 摘要与效果验证

**决策**：先减输入重复，再优化摘要请求复用。
**否决**：
- 继续扩大摘要输出上限作为主要修法：没有消除重复与修复成本。
- 放宽来源覆盖规则换取成功：摘要可能遗失用户要求和必要证据。
- 用离线前缀相同宣称真实费用下降：缓存与计费仍需提供方记录。
**命门**：保留十节摘要、逐来源覆盖和一次修复；先离线验证，真实接续需有明确范围和费用边界，当前不自动启动新付费实验。
**展开**：[实施切片](../切片方案-EX13-Goal工作计划与演示修订上下文.md#6-实施切片与依赖)。

## 对既有决策的修订

ADR-0136 的工作判断扩展为可修订工作项，所有权、用户依据及实际交付语义不变。ADR-0154 §4/§5 的按阶段按需加载保留，但指导不再通过改写共同 instructions 实现；阶段也不承担整项任务进度。框架继续为运行内设计数据，持久 PresentationBrief 保留原条件性边界。

## 已知限制

本 ADR 的 EX13.0–EX13.6 已完成，EX12.4 最终原生验收通过。真实接续保留原 Goal 要求、来源和同对象版本；缓存与费用仅报告已发生样本，不推断一般收益。EX12.5 部署与 Reader 连续使用待完成，状态以 [checkpoint](../../checkpoint_ex.md) 为准。
