# ADR-0158 BookStructure 就绪即可使用 Tutor，教学预构建按需接入

状态：已接受，2026-10-09；T15 就绪合同、T16 来源教学、T17 使用观察与反馈适配、T18 连续使用与界面已实现，T19 待实施。

实施合同：[Tutor 预构建不阻塞教学切片方案](../切片方案-Tutor预构建不阻塞教学.md)。

现有 Tutor 把整份 TeachingMap 发布作为开始教学的条件，用户在原文与 BookStructure 已就绪后仍需等待正式对象、认知素材和教学发布。新决策保留全局结构作为起步基础，使 Tutor 能立即围绕用户当前目标、原文与真实反馈开展教学，已具备的预构建资料继续使用。用户建模贯穿普通阅读、对话与演示使用：记录双方的实际过程，形成可修正的理解判断，并用于后续教学。

本决策替代 [ADR-0120](0120-whole-source-prebuild-gate-for-formal-learning.md) 的 Tutor 启动门槛，以及 [ADR-0142 §3](0142-grounded-teaching-map-and-whole-source-readiness.md#3-正式学习就绪)、[ADR-0143 §3](0143-teaching-trace-assessment-and-learning-evidence.md#3-教学循环与反馈) 中将教学资产完整就绪作为 TutorLoop 准入条件的部分。正式对象身份、公共资产质量与版本发布、实际交付和帮助条件、评分合同先冻结等规则继续有效；教学目标与证据关联按本决策扩展。

## §1 Tutor 可用就绪

**决策**：BookStructure 及必要前置就绪即可教学。

**否决**：
- 等全部教学预构建完成：首次教学被与当前问题无关的素材工作阻塞。
- 只取消前端等待：后续动作与记录仍强制依赖对象和地图，首轮无法完成。
- 缺少构建回执即拒绝旧书：已有基础成品可以直接使用，无需为新门槛重建或重新导入。

**命门**：读时直接使用当前来源已有的 Pass1 基座、discourse 与 BookStructure；只检查成品可读及来源归属，不要求构建接纳回执。Pass2 维持可选，正式对象、认知素材与教学发布不参与 Tutor 可用就绪判断。
**展开**：[准入与运行合同](../切片方案-Tutor预构建不阻塞教学.md#2-准入与运行合同)。

## §2 预构建资料的使用

**决策**：有适用资料就使用，缺少时依据原文教学。

**否决**：
- 关闭现有对象教学：丢失已经具备的语义整理与学习连续性。
- 为每个缺失对象启动整本构建：把同一等待重新带入当前回答。

**命门**：同一个 Resident TutorLoop 按当前问题读取来源、选择材料和交付动作。仅使用已接纳、对当前读者可见且与来源相符的资料；其缺失、准备中或失败不阻止来源教学。当前回合及已交付活动保留所用版本，后续回合可接入新可用资料；构建范围与预算沿用 ADR-0093。
**展开**：[运行与资料接入](../切片方案-Tutor预构建不阻塞教学.md#2-准入与运行合同)、[连续使用与界面](../切片方案-Tutor预构建不阻塞教学.md#t18-连续使用与界面)。

## §3 教学目标与私人证据

**决策**：以学习目标和原文承载教学及反馈记录。

**否决**：
- 没有正式对象就停用理解检查：实际题目、回应与帮助已经提供可用事实。
- 用临时编号冒充正式对象：污染对象身份和长期理解判断。
- 材料补齐后自动迁移掌握结论：名称相同不足以建立证据对应。

**命门**：TeachingMove、实际交付、Assessment 与 Evidence 绑定当时学习焦点、来源版本及实际活动或对话事实；存在正式对象时附加确切对象引用。未关联正式对象的记录参与持续教学，正式对象状态只消费有明确关联且满足能力证据条件的解释；后续关联保留原记录与帮助条件，不直接产生掌握结论。
**展开**：[教学动作与记录合同](../切片方案-Tutor预构建不阻塞教学.md#3-教学动作与记录合同)。

## §4 用户的理解起点

**决策**：每轮从已知背景与实际表现组织理解。

**否决**：
- 用阅读位置或展示记录代替理解证据：页面出现过不代表已经学会。
- 为新用户先索取完整画像：增加开始学习的等待。

**命门**：LearnerContext 在无教学预构建时仍包含用户意图、明确背景、当前焦点与相关反馈；未知保持未知。首次带读先建立理解目标所需的对象、关系与因果过程，明确基础和实际回应可调整深度；演示沿用既有制作能力，并围绕本轮理解障碍设计。
**展开**：[学习起点与演示](../切片方案-Tutor预构建不阻塞教学.md#4-学习起点与演示)。

## §5 持续观察与理解分析

**决策**：从日常使用中持续修订用户理解判断。

**否决**：
- 只有做题才更新认识：追问、复述、纠正和解释反馈同样影响教学。
- 收集日志却不用于教学：后续讲法无法接住用户的理解变化。
- 把阅读轨迹直接算成掌握：接触内容没有表达用户如何理解。

**命门**：使用记录覆盖用户的相关阅读、提问、回应和演示现场，以及系统实际讲过的内容和提供的帮助；复用现有私人记录与事实引用。当前 Resident 从新增相关事实形成或修订理解假设，区分用户原话、暂定推断与能力证据；每轮按相关性加载，并使起点、深度、例子或下一步选择受到实际影响。分析无需等待正式题目、完整画像或预构建对象。
**展开**：[持续观察与理解分析](../切片方案-Tutor预构建不阻塞教学.md#4a-持续观察与理解分析)。

## §6 学习记忆与修订

**决策**：事实可回读，解释可修订，教学可接续。

**否决**：
- 仅在当前聊天保存理解摘要：新聊天或上下文压缩后无法持续带读。
- 独立维护无依据的用户能力档案：判断与真实使用过程脱离。

**命门**：LearningMemory 持有事实及带依据的解释，用户理解空间提供当前视图，LearnerContext 组合本轮所需内容。理解假设保留适用范围、事实引用与修订关系；用户纠正和后续表现更新当前判断，原事实保持原样。现有读取与对话记录沿原生命周期保存，Tutor 开关继续只决定主动教学；模型分析纳入读者回合，不为每次滚动或参数变化单独发起调用。
**展开**：[记录与分析节奏](../切片方案-Tutor预构建不阻塞教学.md#4a-持续观察与理解分析)、[T17 使用观察与反馈适配](../切片方案-Tutor预构建不阻塞教学.md#t17-使用观察理解分析与反馈适配)。
