# ADR-0136 Resident Goal 生命周期与交付完成判断

状态：已接受，2026-09-25；G0–G5 已完成工程实现，G6 章节自然请求已交付，其余自然场景与发布验收未完成。实施见 [Goal 切片方案](../切片方案-Resident-Goal目标维持与交付闭环.md)，验证见 [G0–G3 记录](../performance/resident-goal-g0-g3-20260925.md)与 [G4–G6 记录](../performance/resident-goal-g4-g6-20260925.md)。2026-10-02 接受的工作计划扩展见 [ADR-0155](0155-goal-work-plan-and-version-centered-presentation-context.md)，尚未实施。

Resident 已有证据账本、预算提示和富呈现交付合同，但一次真实的章节演示请求在发现制作能力后，连续检索与修引用耗尽十二轮，未调用制作工具便退回文字。Goal 将用户任务与一次 Run 分离，使目标、实际结果和剩余缺口共同参与决策与结束判断。TutorSession、TutorLoop 等教学会话设计尚未实现，不构成本方案的运行依赖。

## §1 所有权与生命周期

**决策**：Resident 会话持有跨运行的任务目标。
**否决**：
- 等待 TutorSession 实现：普通问答和制作任务已需要目标连续性。
- 把 Goal 只放在 Run 或压缩摘要：运行结束或摘要改写会丢失任务权威状态。
- 将任务写成长期画像目标：临时交付要求会污染长期读者上下文。
**命门**：首版 Goal 归当前书的 AgentChatSession 持有，同聊天跨轮、压缩和重启可恢复；Run 停止不等于 Goal 完成。未来 TutorSession 若接入，另定关联，不预置依赖或转移其教学会话所有权。
**何时回头**：明确需要跨聊天继续同一个任务时，再定义任务移动及归属。
**展开**：[所有权与状态](../切片方案-Resident-Goal目标维持与交付闭环.md#1-所有权与生命周期)。

## §2 用户要求与工作判断

**决策**：保留用户要求，允许 Agent 调整执行方法。
**否决**：
- 只反复注入用户原话：缺少当前成果及尚未完成的交付。
- 将计划中的每一步锁成硬要求：限制基于新观察改变方法。
**命门**：目标解释及要求保留用户消息依据；范围缩减、取消或替换来自用户。Agent 可细化工作焦点、缺口与表达方法，不能把自己的方案升级为用户要求，也不能自行把明确的网页交付降为文字。
**何时回头**：现有语义解释在真实请求上持续误解用户要求时，调整建立与澄清方式。
**展开**：[数据与入口](../切片方案-Resident-Goal目标维持与交付闭环.md#2-数据合同与建立入口)。

## §3 决策上下文与执行事实

**决策**：每次决策投影目标、实际成果与剩余缺口。
**否决**：
- 以工具调用次数或证据数量表示任务进展：局部活动可能不推进交付。
- 复制整套证据与页面存储：制造第二份事实源。
- 每轮另调监督模型重写计划：增加成本，仍不能证明实际完成。
**命门**：Agent 提交可修订工作判断；Harness 从现有工具、预览、交付和历史提交结果取得事实。Goal 投影与压缩检查点分工明确，摘要中的 active_goal 不是新 Goal 的权威副本。
**何时回头**：精简投影仍不能改善真实任务的行动选择时，再调整反馈方式。
**展开**：[循环与恢复](../切片方案-Resident-Goal目标维持与交付闭环.md#3-决策循环与恢复)。

## §4 任务完成与运行终态

**决策**：用实际交付核对任务完成声明。
**否决**：
- 有最终文字即标完成：文字不能替代明确要求的页面或操作。
- 页面通过预览即证明用户理解：工程交付与学习效果是不同事实。
- 未完成就无限续跑：绕过预算和用户停止意图。
**命门**：客观交付条件复用已有合同；内容是否回应目标由 Agent 结合观察判断，用户掌握保持未知。完成候选通过检查且回答与产物引用持久提交后才能标完成；超限、取消运行、Provider 错误或提交失败保存缺口，不伪造完成。
**何时回头**：新增真实交付类型时，扩展对应完成证据，而非引入通用自评分。
**展开**：[结束语义](../切片方案-Resident-Goal目标维持与交付闭环.md#4-完成检查与预算)。

## §5 与既有决策的关系

**决策**：Goal 补充任务语义并沿用现有执行边界。
**否决**：
- 用 Goal 替代工具权限与来源校验：任务意图不能授予额外权限。
- 把 Goal 当作 PresentationBrief：任务目标与具体页面的设计假设生命周期不同。
**命门**：细化 ADR-0132 的预算收敛提示，在已有证据之外考虑剩余交付；保留原十二轮上限、取消和交付失败语义。沿用 ADR-0130/0131 的页面交付条件及 ADR-0119 的 Agent 自主选择原则；ADR-0118 与 ADR-0133 的未实施部分仍保持原状态。
**展开**：[接入位置与切片](../切片方案-Resident-Goal目标维持与交付闭环.md#5-实施切片)。
