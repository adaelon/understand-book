# ADR-0143 实际教学交付、判题与学习证据

状态：已接受，2026-09-29；T6–T12 的交付事实、教学循环、显式行为、判题、Evidence 和学习投影已实现；验证与限制见 [T9–T12 记录](../performance/tutor-t9-t12-20260929.md)。收敛 Grill Q78、Q81–Q88，继承 [ADR-0119](0119-agent-native-learning-environment-and-teaching-agency.md) 的 Agent 教学选择权与系统状态所有权。

2026-10-09 更新：[ADR-0158](0158-book-structure-ready-tutor-and-optional-teaching-assets.md) 替代 §3 中“正式资产共同决定是否进入 TutorLoop”的准入要求，并扩展 §1–2 的目标关联：学习目标与确切原文可独立承载实际交付、评分和证据，正式对象引用按可用性补充。下述对象教学合同继续适用于已有正式对象的路径，实际事实、帮助条件和评分冻结规则继续有效。

## §1 事实与判断

**决策**：实际呈现与行为经证据解释形成学习状态。

**否决**：
- 模型直接更新“已掌握”：失去呈现、帮助和表现依据。
- 读取聊天摘要代替交互记录：不能还原确切题面、版本与帮助条件。
- 把浏览器结果或停留时间当能力证据：观察到内容不证明理解。

**命门**：追加式 InteractionTrace 连接真实交付、帮助暴露、用户行为与会话；LearningEvidence 保存对象、能力轴、帮助、尝试及精确 Trace 引用。状态是带解释器版本和证据水位的投影，未显示候选不记交付，同一活动已揭示的帮助不会因回退或切换模式而消失。
**何时回头**：真实教学事实无法从现有语义事件重建时，定向扩展事件合同。
**展开**：[交互事实与证据链](../切片方案-Tutor全局模式与教学闭环.md#8-教学交付判题与私人证据)。

## §2 评分合同

**决策**：评分合同先冻结，题目判定与掌握分离。

**否决**：
- 看见答案后调整评分标准：无法解释同一题的判定依据。
- 统一交给自由模型打分：可确定的答案失去客观锚点。
- 将技术失败或依据不足计为答错：系统失败会污染用户状态。

**命门**：可判题活动交付前冻结题面、对象能力、答案键或原子 rubric、来源规则、揭示策略和版本；封闭题确定性判定，开放题按有来源的原子标准逐项解释并接受合同校验。uncertain 与 unassessed 分开，自评保留主观身份，ResponseAssessment 不直接写掌握状态。
**何时回头**：某类真实任务不能由既定评分合同可靠评价时，将其保留为未评分互动并单独改进判定方式。
**展开**：[评分与重建](../切片方案-Tutor全局模式与教学闭环.md#8-教学交付判题与私人证据)。

## §3 教学循环与反馈

**决策**：现有 Resident 每次选择一个有界教学动作。

**否决**：
- 新建固定流程教学编排器：限制 Agent 根据目标、来源和反馈作选择。
- 每个滑块或动画帧调用模型：局部操作不需要一次教学决策。
- 一次正确推出统一掌握：帮助、能力和任务条件不同。

**命门**：全局开启、有效会话与正式资产共同决定是否进入 TutorLoop；每轮冻结有界 LearnerContext，细节按需读取，实际结果回到 Trace/Evidence 后再影响后续动作。本回合直接讲解优先，未知保持未知，来源缺口仅暂停依赖它的判断。
**何时回头**：真实回合显示某类认知动作需要专门策略时，在现有循环内补充。
**展开**：[运行流程](../切片方案-Tutor全局模式与教学闭环.md#9-resident-中的-tutorloop)。
