# ADR-0178 情境练习与学习脉络

日期：2026-10-30。状态：**已接受方向；P1 已在本地实现（分支 `feat/practice-p1`，未提交、未部署），P1b 部分在本地，真实模型验收待定。** 用户已确认：先做练习、后做学习脉络；笔记只关联不抽取；练习结果进入既有学习证据；学习脉络以隐性方式呈现；交互形式与外部参照明确区分。2026-10-30 复核后另确认：不恢复出题前的同步模型审阅，改为交付后核查；增加“情境结构”提示；阅读边注默认关闭；答对后展示完整解答。实施合同、切片与完成判据见[切片方案](../切片方案-情境练习与学习脉络.md)；外部参照与差异见 [LearnHarness 参考索引](../参考实现-LearnHarness学习图谱与练习.md)。

## 背景与目标

现有教学已经能从用户问题出发、组织支持、承接真实表达；个人笔记（ADR-0177）已能稳定保存、修订、跨材料召回并影响教学。但系统缺少一类关键学习活动：**让已经讲过的关系在没有被点名的新情境中被想起并用出来。**

当前情况：

- 教学邀请多是在刚讲完的关系上请用户表达，该关系仍处于激活状态；它说明“当场能跟上”，不说明“以后遇到时能想到”。
- `LearnerProjection` 的 `KnowledgeRow` 已区分 `independent_support` 与 `assisted_support`，但现有活动产生的多为协助条件下的证据，独立证据来源稀少。
- 练习只出现在考试冲刺的“直接做题或短诊断”中；`learner_starting_point.md` 明确同法练习不应成为默认对话起点。没有专为检索与迁移设计的活动。
- 书籍图谱属于单本书的公共基座；用户跨书学到了什么、这些关系如何互相依据，没有私人、可重建的结构。PN3 召回只依赖关键词与语义相似。
- ADR-0176（MA3）已将同步内容审核移出默认 select：“接纳”只表示宿主已校验并保存，不表示模型审核通过。本决策不恢复同步审核。

目标：建立**情境练习**，使已讲关系在真实阅读、自己的旧想法、画板与教具中被重新调用，并诚实记录独立与协助；随后建立**学习脉络**，把跨书的已讲关系连接起来，服务笔记召回、建议联系与练习选材。

## 决策

### 1. 练习是独立的学习活动，嵌入现场而非独立页面

**决策：练习与教学分别承担职责；练习默认出现在用户已经所在的位置。**

练习的定义条件：**目标关系在出题时处于非激活状态**——题面不点名所练关系，只有情境特征能让它被想起。刚讲完后的确认属于教学，不计为练习。

| 入口 | 形式 | 主要训练 | 切片 |
| --- | --- | --- | --- |
| 旧想法回访 | 展示用户某条笔记的确切版本原话，配一个新情境：“这里还成立吗？” | 辨析与应用 | P1 |
| 热身 | 用学过的内容做小题；P1 为“练一练”目的入口，回到工作区时自动提议属 P3 | 间隔与交错 | P1 / P3 |
| 阅读边注 | 阅读时出现一个需要调用此前所学关系的小问题；**默认关闭**，用户开启后低频出现 | 真实材料中的回忆与迁移 | P3 |
| 画板组装 | 给出前提卡片与少量干扰卡片，请用户组装论证 | 组合 | P4 |
| 教具目标 | 在已有交互教具上给出目标，以用户提交的控件状态作答 | 组合与运用 | P4 |
| 考试冲刺每日练习 | 按考试日期、范围与课程编排题安排的每日剂量 | 全部方式 | P5 |

不建立独立的题集页面或连续“下一题”流。每道题都可一键跳过；同一次交付至多一道题。

### 2. 练习沿用正式活动，不新建存储

**决策：练习题是带 `practice` 的正式教学活动，沿用既有教学事实链、冻结评分合同、提示与证据，不新建题目对象或存储。**

- `move.kind=question`，带冻结评分合同 `assessment` 与私有完整解答 `explanation`；结束前二者都不公开。
- `move.practice` 记录入口、方式、逐级提示与（旧想法回访时）确切笔记版本。
- 公开视图只含入口、方式与提示条数；提示正文按请求逐条释放，释放与展示分别记为 `HelpDelivered` 与 `HelpDisplayed`。

### 3. 出题质量：作者自查、宿主检查、交付后核查

**决策：不在出题前增加同步模型审阅（与 ADR-0176 一致）。** 练习题由三层保障：

1. **作者自查**：练习指导要求出题前自行解题，排查不用所练关系也能解出的捷径，确认本轮已读材料足够；解答有误等于用错误标准评判学习者。
2. **宿主确定性检查**：合同完整（`kind=question`、冻结评分、私有解答、允许提交 / 提示 / 查看解答 / 跳过）；提示顺序与指向完整；所引 LID 本轮已读；所引笔记版本存在；公开文字不含所练关系的标签；旧想法回访逐字引用原话；同一交付至多一题。
3. **交付后核查**：题目展示后，宿主按 ADR-0176 教练相同的后台方式运行一次独立核查（持久任务，前台不等待），只读题面、私有解答、评分合同、提示与选择时冻结的评分来源。结论为“存疑”（解答或评分有误、存在捷径、超出材料、题面泄露、提示一次透露多步）时：活动显示“这道题的解答可能有误，本题结果不计入学习记录”；投影重算时排除该题产生的证据；之后的回应回合不再依据原评分断言对错。核查未完成或失败时证据照常计入（与当前无门槛的状态一致），得出“存疑”后再排除。核查调用计入既有额度与成本记账（ADR-0171）。

点击回答或本课的「给我一道应用题」时，出题者须从公开题干中逐字标出新情境。条件必须有变化，学习者仍须作出一个先前讲解没有替他完成的判断。宿主在交付前拒绝缺失的情境和从评分原文、前一回答或本课讲解照抄的情境，要求重新选题。既有交付后核查同时读取该入口冻结的讲解，用来判断抄写、排序、复述能否绕过所练关系。选区上的「练一练」仍支持原文阅读题。

这一入口遇到重复读同一段、或模型连续拼不出题卡时，会沿用已读原文和教学设计继续出题。读者仅点击按钮、且设计采用文字材料时，恢复步骤可以提交一题单选。模型提供情境、问句、选项、私有答案、解答和提示，宿主填入已有设计、评分来源和作答操作，再执行正常的选题校验。题面和选项公开，解答仍由活动按时释放。无法交付可作答题卡时，Reader 提示重试。

`tutor_review_rules.md` 的 R7 只用于离线评测审阅；交付后核查采用相同的判断标准。

### 4. 提示指回来源，协助程度诚实记录

**决策：提示以“指向”为主，每次请求只前进一步。**

提示顺序（由少到多，每类至多一条，共 1–5 条）：

1. **题内指向**：提示重读题中某个条件或现象；
2. **情境结构**：不点名关系，重新描述这是一个什么样的情形，为用户保留一次自己想起的机会；
3. **自己的笔记**：打开与所需关系相关的那条笔记（确切版本）；
4. **原文**：打开承载该关系的书籍段落（LID）；
5. **关键一步**：示范决定性的一步，而非全部解答。

澄清题意在对话中回答，不是提示，不作记录。只用到题内指向计为独立；其余四类计为协助，并按种类保留，供 P2 判断难度。用到笔记时首版一律从严计为协助，是否按笔记已含所需关系区分，留待真实使用后再定。界面只显示剩余提示条数，不显示编号等级。

### 5. 练习结果写入既有学习证据，不形成等级

**决策：沿用 `derive_assessed_evidence` 与 `LearnerProjection`，不另建记录。**

- 每次已评估的作答（提交或改答）各产生一条表现证据；`assistance_refs` 为作答时已展示且计协助的提示。跳过、查看解答本身不产生证据；查看解答之后的改答按协助计。
- **答对或查看解答即结束本题。** 答对时宿主随评估结果释放完整解答并记为已交付帮助；跳过不强制展示解答。
- 用户作答以普通对话回合进入回应流程，可用现有“留为我的想法”保存为笔记（ADR-0177），不另建入口。
- 无正式对象的练习证据目前不进入 `LearnerProjection`（投影只按正式对象聚合）；P2 选材另行读取这类证据（见 §6）。
- 失误性质（没想到 / 选错相近关系 / 执行失误 / 粗心 / 所据关系冲突）首版不记录：封闭题评估只给出对、部分对、错。P2 再定是否以可修正的理解假设补记；所据关系冲突时的教学修复建议同属 P2。
- 不生成能力等级、分数或掌握结论。

### 6. 选材与节奏

**决策：选材依据现有证据与材料结构，默认交错；规则参照 LearnHarness 练习准则并按本项目证据模型改写（参考索引 L4）。**

- 目标优先级：独立支持较少者、被更多后续关系依赖者、最久未被调用者。
- 证据来源：有正式对象的读投影；无正式对象的练习证据按同一来源版本的 LID 范围相交读取。不新建掌握状态库。
- 方式顺序：同一目标先回忆，再辨析，再组合；后层失败时回到前层检验。
- 难度旋钮：方式之外增加记录在 `practice` 中的**情境距离**（贴近原讲解 / 同一领域的新情境 / 远迁移），使“调高一档”可检验。
- 难度调整：未用提示或只用题内指向答对 → 调高；用到情境结构后答对 → 保持；用到笔记、原文或关键一步，或答错 → 调低；同一目标连续两次未答对后换目标。
- 只有已评分的提交或改答参与上述难度判断。练习历史分别保留跳过、显示解答和此前已评的结果，教练依据本次对话里的实际作答解释困难。
- 重试使用新的情境，不在反馈后立即复问同一题。
- 节奏来自用户返回、阅读进度与考试日期，不由连续出题按钮驱动。

### 7. 学习脉络：私人、派生、可重建

**决策：在书籍图谱与个人笔记之间建立私人学习脉络层，并遵守 ADR-0169 的跨书身份规则。**

| 层 | 内容 | 归属 | 状态 |
| --- | --- | --- | --- |
| 书籍图谱 | 带 LID 的断言与概念 | 公共，预构建 | 已有 |
| 学习脉络 | 该用户被讲授过的关系与推理链，跨书 | 私人，派生、可删除重建 | 新增 |
| 个人笔记 | `PersonalNote` 修订与 `NoteLink` | 用户所有 | 已有 |

- **抽取来源**：只读已交付的教学正文及其来源引用，不读取用户消息、思考或工具过程。ADR-0176 之后交付未经模型审核，因此只收录有原文出处、且与所引段落相符的关系。
- **来源身份**：一律带 `(source_id, source_revision, LID)`；不同书的相同 LID 不能互相认同（ADR-0169 §3）。
- **跨书合并**：只由模型依据陈述与原文证据判断是否同一关系，不按名称或 LID 合并（ADR-0169 §2）。取向保守：宁可重复，不可误合——误合会让召回和跨书选材把不相干的关系当作同一关系。这与 LearnHarness 当前“改写即合并”的取向相反。
- **不承载状态**：合并只产生脉络节点，不是正式对象身份，不转移任何理解证据；理解证据仍按原来源读取。脉络只追加、可整体删除重建。

### 8. 笔记只关联、不抽取

**决策：笔记修订可以“触及”脉络中的关系，但笔记内容不作为真命题进入脉络。**

- 关联属于系统解释，展示时如此标明，可被用户移除；关联不代表理解。
- **结构召回是待验证假设**：在 PN3 的 BM25 与 MiniLM 之外增加第三路——从当前教学焦点沿推理链找到前提，再取触及这些前提的笔记，以 RRF 融合。本项目 LA9 未显示图谱路径优于其他检索，外部参照也改用了语义检索（参考索引 L8），因此须先通过 M0 才进入 M2。
- **建议联系**：两条笔记分别触及同一推理链的两端时，可提出带理由的联系建议；只有用户接受后才成为 `NoteLink`。
- 笔记修订改变其触及的关系时，思考过程视图可显示“这次修改涉及的关系”，不称为进步。

### 9. 学习脉络以隐性方式呈现

**决策：不设图谱首页或推理链表格。** 脉络出现在：笔记旁“这条想法所依据的…”（含其他书的原文段落）；建议联系；“把这条推理链做成画板”；练习选材。

### 10. 与外部参照保持区分

**决策：采用公开的学习科学原理，交互、命名、文案与实现均为本项目自有。** 不复制 AGPL 项目的源码、提示词正文或界面形态；参照、采用与差异记录在参考索引中。内部枚举使用通用学习科学术语，界面文案使用本项目命名。

## 实际取舍与影响

- 没有同步审阅，一道有误的题可能在核查完成前已经展示。缓解：作者自查与宿主检查在前，核查存疑后提示用户并追溯排除证据。
- 每道练习题多一次后台模型调用（交付后核查），计入额度。
- 阅读边注默认关闭，减少对阅读的打扰；是否改为默认开启，取决于开启用户的使用数据。
- 学习脉络的价值不由问答检索证明（LA9），须由笔记召回评测（M0）证明；未通过则不做后续呈现。
- 学习脉络默认关闭、由用户按学习工作区开启：每次已交付的讲解多一至两次后台模型调用（抽取，有候选时再加身份判断），计入额度；关闭即删除派生脉络，重新开启则从全部已交付讲解重建。结构召回在评测通过前只在显式请求（M0 评测）时运行。

## 既有决策接续

- ADR-0164 / 0172 / 0174 / 0176：教学使命、交互教学状态、教练与主 Agent 教学继续负责讲解；练习不代替教学，结构性失误转交教学修复。
- ADR-0176（MA3）：默认 select 不做同步内容审核；本决策的交付后核查沿用其后台任务方式。
- ADR-0172 与“页面计算只是观察，不是评估”：教具题以用户提交的控件状态作为作答，按冻结合同评估；页面自身的计算结果仍只是观察。
- ADR-0169：跨书来源身份与“不按名称、不按裸 LID 认同”的规则约束学习脉络。
- ADR-0171：交付后核查计入统一额度与成本记账。
- ADR-0173：考试冲刺的日期、范围与课程编排作为练习入口之一，不另建掌握状态库。
- ADR-0177：笔记身份、修订、召回与联系所有权不变；本决策只新增关联与第三路召回候选。
- `learner_starting_point.md`：零基础默认与“不要求先测试再帮助”不变；练习永远可跳过，不是获得帮助的前置条件。

## 验收与回看条件

- **练习机制**（可用模型模拟学习者验证）：题面不点名目标；提示逐级释放且协助记录与实际展示一致；跳过不产生证据；答对后展示解答；回应回合不泄露提示与解答；核查存疑的题不计入投影；教具与画板题以用户提交的状态判断。
- **学习效果**：模型模拟的学习者不能证明保持或迁移。只能在真实使用中、经用户同意，比较间隔之后同一目标在新情境下的独立表现；取得这类数据之前，不对外宣称练习提升了学习效果。
- **阅读边注**：开启比例、忽略率与对阅读完成度的影响，决定是否调整默认值。
- **学习脉络**：M0 评测集上，结构召回须找回 BM25 与 MiniLM 都漏掉的相关笔记，否则不进入 M2/M3。
