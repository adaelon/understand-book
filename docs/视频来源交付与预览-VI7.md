# 视频来源交付与预览（VI7）

## 入口与合同

视频阅读页支持发送绑定当前画面的问题。回答中的来源按钮打开独立预览，可查看实际读取帧、区域、相关英文与已有中文，播放原片上下文或原音频。点击“进入原视频位置”才跳转主播放器，倍速保持。

`source.present` 接受二选一输入：既有 `quote`，或 VI1 的 `target: EvidenceTarget`。视觉目标必须逐帧、逐区域匹配本轮成功模型请求的观察；音频目标必须匹配本轮工具观察的位置与复核结果引用。联合目标的每个成员分别验证，并保存支持角色。文字仍由本轮已读 UTF-16 范围约束。

`video.read_frames` 返回的英文句段进入文本账本；图片仅在成功主模型请求后成为画面观察。裁剪不授予整帧观察，离散帧不授予连续区间。媒体身份、转写版本、发布与范围在来源快照入口校验。

## 数据流与持久化

`本轮文本/媒体观察 → source.present → 原发布材料校验 → MediaSource 快照 → SourceBinding → 回答编译器 → sources.bound / 回合终态 → 历史来源解析`。

`SourceBinding` 的文本分支保存原有范围与摘要，媒体分支保存目标、确切发布、相关句段、译文及观察回执；纯视觉没有文本 LID。媒体快照沿既有会话与演示保存，不另外建立历史存储。带小数 PTS 的媒体从 JSON Value 解码，避免 serde 内部标签缓冲与 arbitrary_precision 数字表示冲突。

视频材料中的普通 `quote` 自动取得句段时间映射；其目标保留实际引用的字符范围。相关英文作为上下文保存，界面标明机器转写与句段精度。已有译文从发布内 `transcript_translations.json` 读取，格式为 `TranscriptTranslation[]`，只消费匹配转写版本及段 ID 的项目。VI10 接续该文件的生产与覆盖。

网络来源解析按保存的 PublishedBookRef 重新授权并加载原发布；本地按发布目录的同书版本布局定位并核对 publication.json。媒体播放沿原发布授权或本地原来源接口提供 Range/HEAD。预览图片从保存的实际 PTS/区域读取，核对解码帧相同；VU 文件不参与定位。

缺发布、撤权或缺媒体时返回原标签、媒体目标、英文及译文快照，标明不可用，关闭播放与进入操作。预览关闭时停止自身播放器。新窗口当前发布不用于替代旧来源。

## 验证入口

- Runtime：`video_source_tests.rs` 验证文本、视觉、音频合同夹具、联合成员、未观察拒绝、错误发布、裁剪边界、回答编译与 JSON 回读。
- Server：`tests/video_source_tests.rs` 验证真实 FFmpeg 帧回看、译文、联合快照、VU 重划分无关性、原发布历史与授权失效。
- Web：`MediaSourcePreview.test.ts`、既有 `SourceExcerpt` / `RightRail` / 播放器及启动测试验证预览和主播放器状态。
- 原片浏览器：先构建最新 Server，再运行 `node evals/video/vi7-browser.mjs`。脚本在 8794/5176 启动独立进程，使用 VI3 原发布及本地 HTTP 记录器，保存请求、引用、历史和预览截图。

## 已知限制

- 音频分支使用协议回执夹具，真实音频复核由 VI15 接入。中文的生产与分批覆盖由 VI10 接续。
- 原片 HTTP 记录器不做模型语义推理。读时真模型、DSH、Linux、安装态及逐字听核沿既有待办继续。
