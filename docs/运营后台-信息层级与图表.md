# 运营后台信息层级与图表

日期：2026-10-23。已部署至 [正式运营后台](https://understandbook.top/admin/)，发布与线上验收见[发布记录](performance/admin-usability-release-20261023/README.md)。

## 展示方式

运营后台按「概览 → 构成与状态 → 核对明细」组织信息。已确认金额、可用额度、待处理事项优先呈现；原始回执、费率、额度期与历史操作按需展开。

| 页面 | 主要改动 |
| --- | --- |
| 全站用量、账号用量 | 费用概览、使用与收款、任务账单三个视图；今天、近 7 天、近 30 天快捷查询；服务成本条形图、活跃账号构成、任务费用对比 |
| 账号管理与详情 | 账号与邮箱合并展示，额度比例可视化；详情拆为账号概览、额度与套餐、MCP 调用包、材料授权、费用与账单、用量分析六个分区 |
| AI 额度、套餐与 MCP | 可用数量优先，额度和免费调用次数用分配条展示；已购批次、购买条款、旧额度期折叠；套餐价格与权益分层 |
| 服务费用与核算 | 明确的状态标记、成本与扣减指标、折叠回执；核算与更正沿用原操作流程 |
| 构建任务 | 当前页状态分布与筛选；剩余预算、预算分配条、未确认费用提示；实际阶段进度保留 |
| 共享工作区 | 当前页发布状态分布与筛选；详情首先显示缺失能力和未齐全授权；历史就绪情况折叠 |
| 内测码及移动端 | 码与状态突出，筛选工具栏统一；小屏表格转换为带字段名称的纵向记录 |

概览金额保留两位小数，小于一分的非零金额显示 `< 0.01`；精确金额保留在可展开明细与金额提示中。未知、估计与已确认成本分别呈现。费用构成图以已确认成本为依据，费用未知不会计为零元的完整成本。

概览比例最多保留两位小数，精确比例仍可核对。线上旧额度期尚未配置百分比基准时，直接显示已有实际金额与金额分配条，并保留配置入口；不会自动猜测或写入基准。手机弹窗使用可收缩的单列布局，长回执只在原始数据区域内滚动。

额度分配条按本期实际授予额绘制，标签沿用原固定基准；授予 150%、剩余 130% 时保留该语义。构建预算使用既有接口的已确认、估计、待核算、预留和剩余值。页面接口提供期间汇总，因此使用构成与比较图展示数据。

## 代码入口

- `apps/admin/src/components/analytics.tsx`：概览金额、关键指标、分配条、状态、分区切换与展开明细。
- `apps/admin/src/pages/cost-summary.tsx`、`usage.tsx`：费用构成、分组查询、期间切换和调用明细。
- `apps/admin/src/pages/users.tsx`：六个账号管理分区，按当前分区挂载对应内容。
- `apps/admin/src/components/data.tsx`、`styles/index.css`：通用表格的移动端字段标签和布局。
- 其余后台页面复用相同展示组件，原 API 参数、金额写入和操作回执流程沿用。
