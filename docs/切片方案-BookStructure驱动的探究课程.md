# 切片方案：BookStructure 驱动的探究课程

日期：2026-11-08；2026-11-12 补充核心体验。状态：**已有单课、多轮探究、两课接续与私人恢复；自动课程制作已完成本地工程验证，完整跨章路线与目标用户试学待续。第 1.2 节为已接受、尚待实施的新增体验。** 决策见 [ADR-0182](adr/0182-book-structure-led-inquiry-courses.md)。以下完成定义保留整体目标，实际进度见第 5 节；首课记录见验收证据，最新构建与部署状态见2026-11-12 自动课程记录。

## 1. 目标与完成定义

用户可以从一章、跨章主线或某段知识演进进入课程，接受已经写明的目标，直接开始一段有内容、有行动和结束点的学习。默认过程为问题导入、必要知识、预测、实验或对照、解释修正及最终作答；教师按实际需要提供支持，用户可以提问、跳过、暂停和改向。离开后能恢复到原阶段、活动与实验现场。

完成首批交付须同时看到：

- 基于真实材料的章节路线与跨章主题路线使用同一课件合同，由现有构建执行器制作并通过正式版本交付；章节路线体现章／节默认尺度，主题路线体现跨章发展关系。
- 预置内容可直接开始，预测发生在结果揭示前，实验可以操作，最终题有确切判断依据，反馈能回到所用原文。
- 原生课程入口与单课页面接通私人工作区、教学与学习证据；无自由输入也能完成默认路径，主动提问后能回到原任务。
- 答错、求助、得到帮助后改答、跳过及中断恢复均保留真实含义；课程进度与理解记录分别展示。
- 发布前技术与内容核验完成，首批目标用户试学完成并修正已确认问题；真人学习表现与工程结果分别留证。

### 1.1 提问、兴趣与自主选择

课程遵循[产品价值观](产品方案-云端学习与考试冲刺.md#14-提问兴趣与自主选择)，将用户自己的问题、尝试与选择接入学习过程。本节为 2026-11-08 新增设计要求，纳入 IC2、IC3 和 IC6 的后续工作；本次未逐项核对其运行时实现与验收，既有首课完成记录不自动覆盖这些新增要求。

- **让自己的问题进入课程**：在适合当前内容的观察、解释或收束节点，允许用户提出疑问、猜想和反例，并据此调整帮助或继续探索。需要支撑时可示范“哪个条件让你不确定”“换一个条件会怎样”等问法；问题原话与 AI 提供的示例分别保存。回应解释这个问题涉及什么关系、怎样查证或尝试；不要求每课必须提问，直接解释与默认路径继续可用。
- **让兴趣有一次具体尝试**：主问题说明值得探索的现象或个人用途，适合延展的内容提供一个可选的小实验、观察或创作方向。用户可以自由改变条件、按自己的想法尝试，也可以收束当前学习；课外探索和作品不成为本课完成的附加条件。示例选择允许服务好奇和乐趣。
- **让下一步由用户参与决定**：收束时结合实际表达提供适用的继续方向，并允许用户选择自己的问题或暂停。选择改变目标时沿原工作区目标修订处理；临时插问保留原活动返回点。探索的选择与取舍保持原义，不据此推断能力、人格或长期志向。

这些要求复用现有问题、对话、教学设计、个人想法与目标修订记录。是否形成长期兴趣或更强的自主性，需要实际使用与后续回访；课程功能验收只说明对应行为可用。

### 1.2 核心体验与短补学支路

2026-11-12，用户确认以先猜后验、理解状态可视化、帮助人学会提问作为核心卖点，并加入课程卡点补学。本节是新增体验的行为合同，实施接入 IC2、IC3、IC6；既有课程验收不表示本节已完成。产品定位见[产品方案 §1.5](产品方案-云端学习与考试冲刺.md#15-核心卖点与课程卡点补学)。

**学习主线**：当前问题与自己的猜想 → 观察、取证或推理 → 对照原判断并解释 → 应用与理解状态更新 → 继续追究自己的问题。

**卡点支路**：指出当前困难 → 必要时确认所缺的一步 → 短补学 → 回到原问题重新应用。支路可以从预测、探究、解释或应用阶段进入，始终保留进入时的原任务。

#### 1.2.1 同一课中的三个卖点

| 体验 | 用户实际做的事 | 界面与反馈承担的工作 |
|---|---|---|
| 先猜后验 | 留下初始判断与理由，比较实际依据，说明保留或修正了什么 | 就地对照原话、观察或原文、当前解释和仍未解决的问题；猜对、猜错或保留判断均按实际理由接续 |
| 理解状态可视化 | 查看某个关系上能解释、能应用、能迁移到什么程度，选择下一步 | 按具体能力展示已表现、当前困难与待确认，注明独立或协助条件；从状态回到原话、活动或适合的检验任务 |
| 帮助人学会提问 | 从自己的困惑提出问题，按需要澄清或改写，选择怎样追究 | 保留用户原话与 AI 建议的不同来源，反馈问题分清了什么、需要什么证据；随着实际表现减少支撑，保留未解决问题的接续入口 |

提问活动沿第 1.1 节的自主选择执行。用户可以要求直接解释、只走默认课程或停止追究。初始判断与修订之间的联系须以真实表达为依据；用户可纠正系统对变化原因的解释。信心表达仅作为可选自述，在确实用于前后对照时呈现。

#### 1.2.2 进入与完成短补学

**定位卡点。** 入口承接用户明确指出的题目、原句、计算步骤或实验对象，以及当前已有的表达。教师先判断本次需要澄清题意、复核计算，还是补一个必要关系；确有两种合理解释且会改变帮助时，才用一个简短问题确认。首次预测错误仍沿先猜后验继续，不自动认定前置知识不足。

**选择必要支持。** 使用本课蓝本、已有带来源的前置关系与当前表达，说明这一关系怎样帮助原任务。辅助背景按用户需要展开。没有依据确认前置缺口时，围绕原题提供解释并保留判断未知。

**一次补清一处。** 短补学围绕一个当前必需的关系，以一个具体例子、原文片段、对照或可操作观察接通原题；随后邀请一次有用途的表达或尝试。已有表达足以说明该关系时直接承接。需要更早的前提时重新选择当前补学焦点，仍保留同一个原任务返回点；用户可选择直接讲解、返回或暂停。短表示范围可收束，时长按实际内容观察。

**返回原题。** 进入支路时保存课程版本、课、轮次、阶段、题面身份、草稿、实验配置及返回位置。页面持续显示正在补什么、为什么与原题有关，并提供“回到原问题”。返回恢复原现场，邀请用户把刚才的关系用到原来的判断或步骤；原回答保留，修订追加。支路暂停、刷新、来源查阅与再次进入沿同一私人课程实例恢复。

**理解随证据更新。** 补讲、原文和关键提示按实际展示进入既有帮助记录，回到原题后的表现保留适用帮助条件。支路结束与原题返回本身只改变活动位置；原题和新情境各自依据已有规则判断。后续无相关提示的新情境表现另作证据，未解决的卡点仍可查看和接续。

#### 1.2.3 样课与实施接点

首个切片在一门现有课程中同时贯通提问、变化对照、补学返回与理解状态。可用平均速率场景说明完整行为：用户把两段速度直接平均，确认后发现他未区分路程占比和耗时占比；短补学用同一路程的两段用时作对照；返回原题，由用户重新解释自己的计算。若原列式正确而只有除法出错，则只复核计算，保留原本成立的理解。

沿 `CourseRun` 保存支路归属、当前焦点和返回现场，沿现有教学设计及活动交付补学，表达、修订和帮助进入既有学习事实链。知识树和“我的理解”读取同一证据，按能力展示状态并保留来源。实现时以当前课程、活动内答疑、题内讨论和理解卡片为接点，复用其恢复与引用身份。

样课先取得工程与内容证据，再请符合课程起点的目标用户实际学习。需要观察用户能否指出自己弄清了什么、哪条依据改变了判断、仍有什么问题，以及理解视图能否帮助他选择下一步。后续接入既有练习和返回学习入口，观察离开本次帮助后独立应用与自主提问的表现；有效方法再扩展到更多课程和首页已有动手体验。

**本节完成依据**：同一原题上的概念困难与计算失误得到不同且适用的帮助；进入支路后刷新、查源和返回仍保留题面、草稿与实验现场；返回后的真实应用更新理解并保留帮助条件；用户自己的问题实际影响了取证或教学行动。桌面和手机均能看清当前支路及返回入口。工程行为、模型回应与真人学习表现分别记录，问题修正后只复验受影响的流程。

## 3. 课程合同与所有权

### 3.1 主问题、阶段与活动

课程区分路线总问题与课的主问题。路线总问题说明整个学习过程追究什么，课的主问题说明这一次要建立什么理解；单课短课中两者可以相同。路线声明目标读者起点、预期理解和最终应用任务，各课再明确自己的收束任务。

| 组织方式 | 默认映射 | 课的主问题来自哪里 |
|---|---|---|
| 章节路线 | 一章对应一个课程单元，一节对应一课 | 章的问题及推进方向，结合该节已有重点和必要原文形成具体问题 |
| 主题路线 | 一条跨章主线或一段演进对应一条路线，发展阶段形成分课候选 | 阶段实际增加的认识、解决的困难或修正的条件 |

每课默认设计为 20–30 分钟（2026-11-10 调整），围绕主问题组织多轮可暂停的探究，包含必要阅读、思考、预测、操作、解释、结尾作答和反馈。作者按声明起点估算各活动用时及合计，试学后校准；额外追问、深入探索和离开暂停分别记录，正常流程的系统等待另行观察。预计时长用于安排内容与展示学习预期，用户可以按自己的速度继续、求助或暂停。

章节路线先按章／节形成完整编排，再结合时长目标调整具体边界：一节包含多个可独立收束的理解目标时拆成短课，原节问题继续串联这些课；相邻节共同回答一个问题、拆开后各自不能形成有用解释时可合课。多个知识点、例子和实验若共同支撑一个可在目标时长内完成的理解目标，则留在同一课内分活动推进。较长推理按有意义的中间目标分课，必要前提与关键论证保留在必经学习内容中。每次拆合指出对应目标与来源，较短但完整的课不额外填充活动。

主题路线使用相同的单课尺度：一条很长的主线形成多课，某个发展阶段也可按理解目标拆合。路线数、单元数和课数分别展示。章节与主题可以复用问题、目标及活动均适用的课件；仅来源相同不自动合并课程或转移完成状态。

现有章问题和主题发展供作者直接复用；每节的主问题要结合该节真实内容编排，不能仅把小节标题加上问号当作课程设计。单课编排应能说明：读者开始时已有什么基础、要建立哪条关系、最后怎样独立使用它。

章节成员和主题成员继续指向已有来源；发展顺序作为编排依据，已明确的前置关系另行提供。补充前提要说明为什么当前任务需要它。用户明确已有基础时可换入口，系统保留其选择及已有表现。

每课至少表达当前问题、目标关系、必要支持、活动与收束任务。适用时采用“先预测及理由 → 操作或观察 → 对照预测解释 → 新情境应用”。必要知识可在预测前提供，也可在观察后引入；直接解释请求沿原教学选择执行。预测属于初始表达，正式评分任务另有冻结合同。

### 3.2 公共课件

课程版本沿 `WorkspaceRelease` 的不可变版本归属交付。当前合同位于 `crates/memory/src/course.rs`，公开类型由 ts-rs 生成到 `packages/web/src/generated/Course*.ts`；首课使用资源下界实验和单选计算／解释任务。下表同时保留后续完整结构与通用活动合同的目标。

| 内容 | 使用方与用途 |
|---|---|
| 课程身份、来源发布、所选结构引用和内容语言 | 目录、授权、来源导航、历史版本及生成上下文 |
| 路线总问题、单元组织、各课主问题、适用起点、阶段关系和最终任务 | 课程入口、分层导航、作者及 Resident 教学设计 |
| 单课预计学习时长、各活动用时及估算或试学依据 | 作者控制单课范围，入口展示学习预期，试学后修正过长或缺少支持的编排 |
| 被选结构内容的版本快照 | 保留问题、阶段发展、成员、依赖解释及确切来源，支持离开构建工作区后的读取 |
| 各课核心文字、原文定位、活动目标与题面、所用场景和演示版本 | 学习首屏与课堂直接加载，使任务、实验条件及实际所见对应，支持按需读源和实验操作 |
| 提示、完整解答、任务判断依据及揭示方式 | 宿主按活动进度释放帮助，原评分链实例化任务；初始公开视图不提前揭示答案 |
| 课程所需素材与验收结果引用 | 发布就绪和定点修复，记录适用范围、实际运行及尚未解决的问题 |

课程只引用本次实际使用的公共结构和来源。完整主题结果由构建侧读取或沿已接纳记录恢复，写入课程所需的有界快照；读时不依赖 `.build`、作者操作历史或构建模型。快照是该课程版本的依据，不成为可独立修改的另一份 BookStructure。

已有书若仅剩精简投影，构建准备先报告所缺的发展成果；能够从既有接纳记录恢复时直接恢复，否则将所选范围的补齐纳入构建方案和预算。不能将摘要改写冒充已经存在的阶段分析。普通带读仍沿现有就绪条件使用。

共享演示保存可复用的内容版本与原始状态，个人操作另存现场。复用现有呈现合同，补齐公共资产到私人场景的实例化；课程不能引用某位作者的私人会话页面作为公共必需资源。

### 3.3 私人接续与证据

个人实例保留课程发布版本、当前课及活动、实际完成与跳过记录，以及对应教学会话和实验现场引用。课程推进事件存入原学习存储，投影供恢复和界面使用；学生原话、实际交付、帮助、评分和理解仍由原事实对象持有。

开始按钮接受页面已展示的课程目标，并沿原共享使用／学习启动流程进入；需要启用教学时在操作文案中明确。原目录浏览和来源跳转只负责导航。阶段开始、暂停、跳过、收束由真实操作或被接纳的教学行动记录，后台观察和刷新不会自动推进。

课程进度区分未开始、进行中、已完成和已跳过；最终题另保留未作答、实际评估及帮助条件。课的正常收束发生在计划活动和最终反馈实际交付之后；主动略过保留跳过事实，不能由浏览或点击下一步写成“已通过”。帮助后完成可以收束课程，其理解证据仍为协助条件。课程总进度分别显示完成与跳过数量。

预置讲解、例题、实验结果和提示也按实际展示写入原交付／帮助记录，再与随后用户表达关联；直接加载成品不能漏记已给帮助。课程保存的来源引用用于定位依据，新生成解释的读源仍遵守当轮真实读取合同。

任务实例化时冻结确切课程版本、题面、来源、判断依据和揭示策略；运行时补充任务按原合同另行冻结。开放回答接受合理替代解释，系统执行失败不计为答错。初次预测与刚讲后的确认不因进入课程就标成 ADR-0178 的检索练习。

插问带着当前活动、所用来源和实际页面状态进入 Resident，处理后提供返回原任务的入口。目标明确改变时沿原目标修订暂停不适用的课程推进。更新课程版本使用原差异预览与用户选择，新运行使用所选版本，旧作答和已开始的活动保留原合同。

## 4. 课程制作与质量判断

### 4.1 构建过程

```mermaid
flowchart LR
    A[选定目标与 BookStructure 问题脉络] --> B[读取完整结构和必要原文]
    B --> C[确定最终任务与阶段设计]
    C --> M[选择适用制作方法与样课]
    M --> P[单课蓝本 目标关系 活动与观察依据]
    P --> Q[核对最终任务及必要支持]
    Q --> D[按同一蓝本制作讲解 实验 题目与提示]
    D --> E[读源核对 独立解题 实际运行]
    E --> F[修正具体问题并复验]
    F --> G[课程版本与私人学习接续]
```

作者先明确主问题与预期应用任务，独立解出任务，再倒推所需知识与支持。阶段活动使用 UbD 和 POE 作为设计方法，按关系选择已验证的演示模板。适合比较的任务控制实际变量；离散更新、因果解释、案例对照和论证重组各使用能表达该关系的形式。

作者规范与首批样课进入项目既有构建指导和素材目录，记录正确作品及真实失败的修法。语义制作沿现有执行器和工作单元接入，按课程与阶段有界读取；暂停、预算耗尽和失败恢复复用已接纳产物。核心课件共享使用，个性化补讲和反馈按实际需要调用模型。

#### 4.1.1 从原文到单课蓝本

BookStructure 提供本课在章或主线中的位置、已有问题、关键内容及发展关系。作者按这些引用读取所需原文，取出要建立的关系、成立条件、可用例子和必要前提；材料中已有的练习、图解、案例与实验优先按本课目标评估采用。新构造的情境、参数和对照注明为教学设定，引用说明支持哪条关系，不把它们归为书中原例或实测数据。

单课蓝本属于原课程构建产物，记录以下与制作直接有关的内容；由此生成公共课件，并为私人 TeachingDesign 提供初始编排。

| 蓝本内容 | 后续据此制作什么 |
|---|---|
| 主问题、目标读者基础、目标关系与来源条件 | 明确本课范围，确定必要阅读和核心解释 |
| 最终应用任务、允许使用的前提、解法与判断依据 | 检查本课要建立的理解，反推需要提供的支持 |
| 各活动的目的、学生动作、所用条件、可观察结果及返回主问题的解释 | 制作预测、实验、解释和应用活动，安排提示与揭示顺序 |
| 选用的解释方法、需要改写的模型或案例、场景与任务的对应 | 向原 Author 提供具体页面制作依据，绑定题目与确切实验条件 |

蓝本中的备选判断用于设计能区分它们的活动，不能据此认定具体学生持有某种误解。制作顺序先确定目标与最终任务；学生经历的顺序按学习需要安排，适用时先预测再揭示结果。

#### 4.1.2 题目如何得出

每个问题服务于本课的一次具体判断；题目数量随关系和支持需要决定。正式任务的参考解答及判断依据在交付前确定，并沿现有评估合同冻结。

| 问题用途 | 从哪里推导 | 产出要求 |
|---|---|---|
| 预测与理由 | 从本课要区分的判断构造结果尚未展示的具体情境 | 给出足够的已知条件，询问结果或趋势及理由；已有支持按事实记录 |
| 观察与解释 | 从实验的实际变化或案例差异提出问题 | 指向具体可见证据，要求连接操作、结果与目标关系 |
| 最终应用 | 从本课目标关系构造一个尚未展示解法的新情境 | 保持前提在声明起点和课程支持内，改变需要重新判断的情境或条件 |
| 提示与补充问题 | 从解法中缺失的步骤、条件或证据反推 | 帮助定位下一步，记录实际给出的支持及其对后续作答的影响 |

选择题选项表达可区分的推理或结果，开放题允许成立的替代解释。每道题保留目标关系、题面、条件、来源、参考解法或可接受判断、预置支持与揭示安排。涉及演示的题目绑定具体场景或题面给定条件；学生自由改参后，解释引用其实际现场，原题的判断依据仍对应原条件。

#### 4.1.3 实验与演示页如何得出

先确定学生需要借助观察分辨什么，再设计能产生这项证据的操作。实验蓝本明确模型或案例依据、可操作因素、保持不变的条件、观察量、预期差异与适用边界。制作前用独立计算或来源支持的实例确认所选条件确实能呈现差异；无法产生有效观察时调整条件或表达方式。

页面按目标关系选择现有方法：更新规则使用离散更新，对照输入使用单因素比较，规则变化使用规则比较，论证使用证据链，内部空间使用剖切或拆解。依据方法卡读取确切版本、完整作品、元数据及适配说明，改写模型、图形、文案和控件，沿既有 Author 预览与交付流程完成。需要推理、阅读和案例比较的内容可以使用文本、静态图或证据操作；一个页面可以支持多个活动，各活动仍有自己的任务和现场。

预测阶段保留足够作答的已知条件，按本题所问控制未来轨迹、下一步读数及结论文字的显示；观察阶段再揭示结果。既有模板中的说明和预设同样按实际问题调整。已经看到结果的回答按已获支持记录。页面图形和可读数值来自同一模型；验收使用独立依据，同时核对实际页面及题目所指的条件。

课程构建负责蓝本与题目，原 Author 负责按蓝本制作演示，原评估链负责接纳冻结任务后的作答判断。这些职责沿现有执行器和发布路径接入；课件加载时可直接使用预构建活动，Resident 按学习中的实际表达补讲、调整或另发任务。

#### 4.1.4 数学课程的活动与论证

数学课沿用章／节与主题路线的粒度。作者结合已有数学结构索引定位定义、定理、假设、证明、习题及其引用，读取所需原文，在单课蓝本中写清对象与定义域、前提及量词、目标结论、允许使用的结果，以及本课要求达到的理解或推理程度。索引提供定位和引用依据，具体陈述及证明按原文使用。

| 本课主要目标 | 可以组织的活动 | 收束任务的依据 |
|---|---|---|
| 理解定义与概念 | 比较例子与非例、改变条件、在公式和图形间对应 | 能按定义辨认对象、说明理由，并构造合适例子 |
| 理解定理及条件 | 先预测、计算或作图，形成猜想；检查条件，结合证明解释成立原因 | 能准确使用条件、辨明结论，并完成目标要求的应用或论证 |
| 学习计算或解题方法 | 比较可用方法，观察关键变形；提供示范，再由读者完成关键步骤及独立题 | 方法适用，推导保持必要条件，结果及解集正确 |
| 学习证明方法 | 根据结论寻找所需中间命题，解释关键一步，补全论证、辨错或构造反例 | 前提足够，步骤成立，覆盖所声称的全部情况；接受其他有效证明 |

这些目标可以在一课内协同，不按表格机械增加课数。数学探索包括拖动几何对象、枚举具体对象、变换条件、构造反例和组织推理。根据当前关系选择图形、公式、文本或交互；既有演示的模型与控件按数学对象和条件改写。

适合探究的定理课可按“预测 → 试例或观察 → 明确猜想 → 证明或反例 → 应用”推进。有限次观察不能建立未覆盖对象上的一般命题；经精确核实的反例可以否定相应全称命题。证明可按本课目标提供全文讲解、关键步骤支撑或独立任务，依赖的定义和引理须在声明起点或实际支持中提供。

阅读证明、在支撑下补全和独立完成证明分别记录。任务要求独立构造论证时须取得读者实际推理；选择给定步骤体现相应识别或补全表现。课程完成与理解证据继续按第 3.3 节分别表达。

任务判定结合答案与所要求的推理。等价表达在相同定义域下接受，除法、平方、开方等变形核对是否改变条件或解集；近似值按题目所需精度解释。计算和图形可用精确算例、独立推导或适用的符号工具核对；一般命题的证明另核对前提、推理与结论覆盖范围。页面呈现已发生的观察与结论各自的依据，数值采样成功本身不记成证明完成。

#### 4.1.5 制作方法与样课的复用

课程方法沿项目既有构建指导与素材目录维护，与演示方法库分工：课程方法组织学生怎样形成理解，演示方法实现其中需要观察和操作的部分。按真实制作需求逐步积累概念辨认、机制解释、条件与论证、方法练习等做法；它们可跨学科采用或在同一课内组合，适用性由本课目标、读者起点与材料判断。

每种已采用做法保留适用条件、必要的教学关系、可调整的活动顺序、完整样课、改写说明、核验依据，以及真实失败及其修法。完整样课包含原文依据、蓝本、题目与解答、实际课件和制作／试学记录；试学尚未完成时保留其实际状态。构建只读取本次选中的方法和所需示例，原题内容及解答按当前材料重新建立。

方法选择与领域要求分别判断。例如用反例辨认一个数学条件，需要概念辨认的活动安排，也需要数学定义域和推理要求；涉及计算与交互时继续核对对应计算和现场。检查范围取自本课实际主张、任务和资产，课程标签不代替对内容的判断。

生成页面前先检查蓝本：最终任务能够解答，其解法所需关系来自声明起点或计划支持，活动确实推进主问题，包含思考与作答的默认过程预计可在 20–30 分钟完成。此时修正目标过大、方法不适用或支持缺失等问题；需要拆课时先确定各课能够收束的目标，再进入页面制作。成品核验关注实际交付是否实现蓝本；未改变的任务与来源沿用有效核验记录。

首次采用一种做法时先完成可运行样课；准备用于批量制作时，选取未参与该方法修订的新材料试制，观察是否仍能正确选取内容、安排活动并完成核验。发现失败时明确修正方法或收窄适用范围。没有合适方法的课程先作为单独试制候选完成，不以现有方法名称宣称已经获得相同制作依据。

### 4.2 检查必须改变下一步

| 要发现的具体失败 | 使用的证据与方法 | 失败后处理 |
|---|---|---|
| 结论漏条件、引文不能支持解释、原文身份错误 | 关键关系及核心题解逐项回读必要原文，宿主核对来源归属 | 修正结论、来源或课程承诺；不以格式有效代替语义成立 |
| 题目无解、多解被当单解、答案错误 | 独立上下文先读题目与允许前提求解，再与作者解答对照；计算题另行复算 | 修题面、解答或判断依据；冻结新版本后才交付 |
| 最后任务依赖前面从未建立的关系 | 从任务解法回查声明起点及实际提供的支持 | 补前提、调整阶段，或缩小任务 |
| 数学变形改变定义域或解集、证明漏用条件、有限样例被当作一般证明 | 对照原文陈述、题面范围及逐步推理，计算部分用独立依据核对 | 修正条件、推理或任务要求；数值结果与一般命题分别判定 |
| 实验运行正常却无法区分当前两种判断 | 实际使用所选初值、对照条件和观察量走通预测与解释 | 改对照、观察任务或实验形式 |
| 题目所用条件与演示现场不同，按另一组参数判答 | 对照题面条件、绑定场景和实际操作记录走完作答 | 修正场景或题目绑定；现场变更产生的新任务按原合同另行冻结 |
| 图像与计算不符、参数未应用、提示／答案提前出现、恢复位置丢失 | 独立计算或已知实例，加真实浏览器操作和视觉查看 | 修正对应计算、状态、揭示或恢复路径，再复验受影响场景 |
| 用户只能照着答案完成，换情境后仍不能应用 | 目标用户实际试学，保留原预测、帮助、解释及新的应用任务；适用时延迟回访 | 修改真正失效的讲解或活动，保留修前修后表现 |

来源与解题审阅输出具体问题、依据和需要修改的内容；不因风格偏好或另一种同样合理的编排退回课程。一次集中审阅后定点修复，有新改动或新事实时再检查受影响部分。已知实质错误未解决的课程保持未发布，预算和未完成工作沿原构建记录保留。

构建期审阅是可复用课件的制作成本，沿现有预算计量；学习回合继续遵守 ADR-0176 的交付机制。真实用户试学用于判断实际理解困难，模拟学生只用于帮助发现流程和提示暴露问题。

### 4.3 逐课接纳与批量制作

每课接纳同时使用公共要求和实际内容所需的判断：来源与成立条件、目标与最终任务的对应、所需支持、正确解答，以及实际存在的页面交互。计算、证明、案例解释和可操作实验分别采用相应依据；允许合理的活动组合与表达方式，不要求所有课程具有相同页面数量或教学步骤。

构建接纳沿既有候选、修订和发布记录保存具体结论、所针对的产物版本、必要证据引用及未解决问题。内容错误、错误判题和阻断学习的行为须先修正；不同但同样成立的编排可以接纳。独立审题先取得题面与允许前提求解，再看作者解答；来源审阅回读所需原文，页面核验运行实际课件。审阅分歧回到原文、推理或运行结果裁定，无法确认的关键结论保留待核对，并交由熟悉该内容的人处理。

批量制作复用课程方法、页面机制与对应的有效验证，每课仍核对其新增内容、条件、任务和实验结果。共用页面实现未变时复用适用的交互覆盖；新模型、数据、文案、揭示顺序和布局变化按其影响核验。修复以活动或课件为单位，只重做和复验受影响产物；费用耗尽或关键问题未解决时按原构建机制保留候选、结果与后续工作。

人工核对与真实试学重点覆盖首批采用的方法、新方法、实质修订及无法可靠裁定的内容，并从持续制作结果中按方法与材料抽取代表课程。每课的内容和工程接纳继续执行；学习效果的结论只覆盖实际试学的人群、材料和条件。试学关注默认过程的完成用时、需要了什么帮助、哪一步无法继续、解释如何变化、能否完成新的应用任务，并区分正常等待、额外探索与离开暂停。超出时长目标时按实际困难调整支持或拆课。系统性困难回到制作方法修正，单课问题修对应内容；发现同类错误时扩展核对使用相同做法的课件。

### IC2：单课教学与真实证据闭环

接入预测与理由、结果揭示、提示、解释邀请、最终任务、评分和课程收束。课程活动绑定原 TeachingDesign／TeachingMove；正式作答进入原冻结评估，实际使用的帮助随记录保存。暂停、离开、重开恢复到原活动及原演示现场。

新增接续要求（第 1.1 节；书内插问已接通，自动调整主线待续）：将自主提问接入同一教学回合，承接一句尚不完整的问题或对结论的质疑，按实际内容调整解释、取证或实验；用户要求直接讲解时交付帮助。用真实模型回应核对用户的问题是否实际影响下一步、问题来源是否准确，以及未提问的用户是否仍能完成默认路径。

完成判据：正常完成一课；预测前页面未展示本题所问结果，首次猜错可以继续探究；题面、实验条件与判断依据一致，自由探索后仍能返回原任务；预置支持与实时帮助都进入实际展示记录，请求帮助后改答保留协助条件；跳过不记成通过；未知或执行失败不计答错。真实模型处理一次具体错误和一次有效解释，核对最终交付与原记录；学习记录可从原入口读回。

2026-11-09 的 IC1/IC2 接续已实现：共享工作区保留选课入口，课程进入对应书籍 Reader；左侧课程／原文／实验保留草稿、图形视角和原文位置，右侧沿用 Agent。提交时冻结服务端当前课件投影与帮助、附带实时实验参数；原文中的选段沿原引用提问流程。书内反馈通过显式打开记录交付，课程与对话的文字沿同一理解事实链保存。手机从学习视图直达反馈与提问，再回到当前任务。验收见书内课程记录。后续 IC3 继续处理多课主题路线，IC4/IC5 负责自动制作与接纳。

### IC3：跨章路线与连续使用

把真实主题的各发展阶段接成多课路线，保留“这一课怎样推进总问题”；章节路线提供章单元和节课程的连续入口。两种路线可以使用同一适用课件、来源与实验资产，课程选择和私人表现分别保存。接入下一课、返回来源、插问后回到任务、主动跳过、继续学习和用户选择新版课程。

适用的课后延展沿现有对话、实验和想法记录承接，用户可继续自己的问题、选择一次小尝试或暂停。验收一次自主选择延展后返回主线，以及一次明确修改目标后旧路线停止推进；选择延展或停止均不改写既有作答与理解事实。

完成判据：用户既可按章／节完成连续课程，也可沿跨章主线走过多个阶段并完成最终应用；两种路线均能辨认当前课的主问题与上层问题；临时插问不丢原活动；重开仍恢复确切课程版本和位置；接受新版后旧答案仍回到原题与来源。明确改向暂停旧主线，普通阅读及原情境练习继续按各自入口运行。

### IC6：首批样课与正式交付

试学同时观察第 1.1 节的实际体验：用户表达含混疑问、质疑解释或选择自由尝试时，系统是否接住并作出相应改变；用户能否按自己的理由选择继续或停止。保留实际发生的表达与后续行为，区分自发提问和提示后的提问。无人提问本身不能判定失败；若表达入口难找、质疑被忽略或停止后仍被催促，则修正对应设计。长期兴趣与自主性未获得回访证据时保持未验证。

完成判据：首批课程内容与工程核验通过，试学中确认的阻断问题已修正；按项目原发布流程交付，并检查正式环境下的课程入口、材料、实验与接续。记录课程版本、适用起点、真实试学范围与尚未证明的学习收益；需要扩大试用后才能判断的事项明确保留。
