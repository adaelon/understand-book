# 云端课程运营样例

本目录提供预置课程的通用准备与发布结构。材料是项目内原创的短篇验收材料，用来验证套餐、课程实例和来源定位；正式首发课程及其教材、视频仍待选定。

## 材料与能力

| 材料 | 本目录内容 | 验收时产生的能力 |
| --- | --- | --- |
| 原创短篇讲义 | `lesson.txt` | 中英原文、资料结构与概念入口、确切文字来源 |
| 原创人工字幕 | `video-transcript.txt` | 两秒测试视频的文字与时间映射 |
| 短视频 | 测试运行时用 FFmpeg 本地生成的动态图案 | 原视频播放、真实帧读取、字幕时段回跳 |
| 私人补充 | 测试用户单独添加的既有资料 | 仅加入该用户实例，公共版本更新后继续保留 |

视频是无音轨的来源定位样例。人工字幕描述测试图案，不代表经过语音转写，也不代表已经完成学科教学内容制作。讲义提供中文说明及简短英文对应内容，结构入口和概念标记均指向实际原文，便于学生以中文提出问题后查找资料。原始短文本不需要调用商业模型；测试准备状态沿用项目既有受控资料构建夹具。

2026-10-20 真实问答验收后修订讲义：补充“证据支持成立”与“来源定位精确”的区别，说明较宽窗口包含必要证据时仍可能支持结论，过宽主要增加定位成本，理解所需的上下文应保留。该修订改变验收输入材料，复验记录须对应修订后的资料版本，首轮材料与回答仍作为原始证据保留。

## 正式课程准备记录

复制 `preparation-record.example.json` 作为某次课程制作的运营记录，填写课程适用范围、版本、来源与使用授权。公共准备由平台承担。实际处理沿运营后台的资料准备流程执行，完成后取得每份资料确切的 `book_id`、`publication_id`，再填入 `release.template.json`。

`release.template.json` 是 `/api/admin/workspace-releases` 的请求格式。模板中的引用必须替换为真实发布编号；课程发布允许保存未就绪状态，只有资料存在、所需能力就绪且当前账号具备访问资格时才能开始使用。每次发布使用新的 `operation_id`，`expected_version` 填当前版本；相同操作编号只用于重试原请求。

首批三档使用相同课程范围时，填写 `allowed_tiers: ["basic", "plus", "pro"]`，`visible_to_users` 留空。逐人名单仍可用于原有明确授权。套餐课程不要为了方便写入永久的个人资料授权，否则会改变到期后的访问范围。

课程说明由运营填写名称、适用范围、先修条件、公共目标和材料编排。文字资料在实际具备教学资产前只声明 `text`；视频在实际导入并建立字幕时间映射后声明 `text`、`video`、`transcript`。视觉检索、翻译、配音和教学能力分别依据实际产物声明。

外部课程链接填入发布请求 `manifest.external_resources`，每项包含 `title`、`url` 和可选 `description`。课程详情和个人实例将其单独显示为“外部链接导览”，支持打开 HTTP/HTTPS 网页；链接随课程版本保存和更新。模板中的 `example.invalid` 仅为示例，正式发布时替换或删除。

发布合同中的 `materials` 仍必须引用已经准备的资料，不能用 B 站网址代替发布编号，也不能把外链声明为可检索字幕或可读取视频帧。外链没有原文位置、视频时间轴或准备状态，也不参与资料就绪判断和私人空间占用。要提供检索或时间段来源，须先完成相应授权与资料准备，再添加实际发布引用。

## 学生使用与更新

核款后账号获得套餐与独立额度期。学生选择课程，确认个人目标及考试日期后，创建自己的工作区实例；教材、视频仍引用同一份公共发布。这个动作不创建公共构建任务，也不再次扣准备费用。

发布新版本后，学生先预览变化，再明确采用。个人目标、考试设置、私人添加材料及已有学习记录保留。旧回答中的来源仍指向原来的资料发布及文字或视频位置，不能改写为新版引用。

## 运行验收

在仓库根目录执行：

```text
cargo test -p server cloud_course
```

需要已有 Rust 构建环境和 FFmpeg；可通过 `FFMPEG` 指定其路径。测试使用临时数据库、临时账号、测试商品和本地生成视频，不连接支付服务，不调用商业模型，不发布正式课程。

这组测试覆盖从未开通账号、人工核款、套餐课程访问到两名学生建立个人实例的请求链，并读取真实视频帧、保存来源、采用新版后解析旧来源。课程能力与资料就绪检查沿生产实现执行。

正式课程上线前，运营记录需要补齐真实课程与授权材料、正式商品配置、真实教学效果及代表性成本记录。测试通过提供通用流程证据，正式课程完成状态仍由这些实际产出决定。
