# 切片方案：知识树与理解果实

日期：2026-11-05。状态：本地实现及本轮验证完成，未部署。决策见 [ADR-0181](adr/0181-source-knowledge-tree-and-understanding-fruits.md)，交互方向见[设计方案](设计方案-知识树与理解果实.md)。

## 目标与完成标准

读者在真实树形地图中浏览书籍、音乐、视频的已有知识，看到当前所在位置和自己的理解果实。果实能读到原话、当时帮助与理解变化，并能返回来源、继续推敲。地图直接复用既有知识产物，理解沿原学习存储保存，不增加一次专门的模型归类调用。

视觉沿用已认可的树形预览、产品中性色与焙橙强调色。粗枝表示当前内容范围，细枝表示已有知识，果实表示有依据的理解记录；位置标记独立显示。局部展开、路径返回、键盘和触屏操作均可用，窄屏详情在树下展开。

## KT1 公共知识投影与入口

状态：已完成。

- 从实际 Book 及音乐／视频发布内容构造来源明确的节点，提供有界分枝读取、定位和详情；复用原条目身份与关系。
- 文字以章、节为骨架，直接呈现 Pass1 知识，discourse 补充解释与论证；LID 叶子仅作来源地址，同节重复条目保留一个入口；音乐保留曲式、事件与重复出现；视频保留视觉范围和讲解结构。
- 接入现有阅读工作区的树入口，能在大材料上逐层浏览，跳回准确原文、画面、原声或谱面。
- 验证：同段多个论断分别可见，跨段概念不丢出现位置，重复音乐事件不混淆，视频关系不按时间邻近伪造；缺少语义产物仍可导航。

## KT2 理解引用与现有整理调用

状态：已完成。

- 为理解目标提供精确知识引用和引用对应的用户表达片段，使用现有来源绑定与事实权威。
- 在现有回合后整理输入加入有界真实候选；提交时核对候选与实际表达，保存进现有 LearningEvidence。
- 历史有明确对象／事件对应时展示相应果实；只有来源范围的记录保留范围归属。
- 验证：同段两条论断只挂实际涉及的一条；一个表达可明确涉及两处；错误版本、未提供候选或不属于用户原话的片段不被保存；无新理解不产果实。

## KT3 果实详情与无笔记接续

状态：已完成。

- 树与“我的理解”读取同一批证据，保留原话、帮助、纠正和时间线；后台完成后更新果实。
- 去除继续理解对笔记的强制依赖，保留材料、工作区、原讨论和确切目标；从空枝条也可发起讨论。
- 播放更新位置提示，浏览选择保持稳定；Agent 接续使用实际理解和原问题现场。
- 验证：重开后果实和历史保留，无笔记理解可继续，纠正同步，音乐两处比较与视频联合依据可回到准确来源。

## KT4 端到端与交付

状态：已完成。

- 用真实文字、音乐、视频产物运行读取与挂接场景；运行受影响的服务、前端与交互检查。
- 在桌面和手机检查树形、长标题、空态、加载失败、来源跳转、果实详情与继续问答；直接查看渲染和截图。
- 记录材料规模、读取范围与返回大小，确认展开和刷新不把整部材料或全部历史重复交给模型／浏览器。
- 更新本方案状态、代码链路、实际证据和已知限制；未上线状态明确保留。

## KT5 首屏重点与阅读入口

状态：已完成。

- 标题直接显示当前内容范围，使用已有章节说明或明确标注的开篇线索；将搜索移到次要工具栏。
- 提供一个清楚的开始入口，有理解时承接实际表达；大范围先展示少量导航分枝，进入叶子直接呈现内容与来源。
- 打开时跟随阅读／播放位置，后台刷新固定手动选择；原知识引用、来源和理解归属保持连续。
- 验证：真实 D2L 锚框小节由 37 个直接子项收成少量导航分枝，全部知识可达；首屏开始按钮可见；手机、音乐、果实接续与选中位置仍正确。

## KT6 真实模型贯穿验收

状态：文字材料功能闭环已通过；教学内容与描述质量问题已记录。

- 使用真实 D2L 锚框章节、现有模型配置和独立学习记录，走完提问、表达、后台理解、树上果实、点击接续和新的表达。
- 检查同一份理解在各处的身份、用户原话、帮助条件、知识归属和原讨论引用；界面操作本身不新增理解。
- 实际运行两组四轮对话，修复前问来源丢失、面板内跳转失败、前台与后台抢写、重复提问、后台时限过短、旧误解仍列为当前状态六处问题。
- 最新表达成为当前判断，旧原话留在原枝条和时间线；桌面、手机和服务重开均已核对。完整证据与尚未通过的内容质量项见[真实模型验收](performance/socratic-understanding-live-20261105/README.md)。
