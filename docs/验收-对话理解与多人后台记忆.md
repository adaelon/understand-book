# 对话理解与多人后台记忆：本地验收

## 已验证行为

| 范围 | 验证结果 |
| --- | --- |
| 对话目标 | 聊天起点提示目标或首问；开启 Tutor 不自动发送问题；目标在聊天中可编辑；本书无匹配会话时可直接设定目标。 |
| 普通理解观察 | Tutor 关闭、没有学习会话时，普通追问可通过原文读取和对话事实保存理解假设；不能选择主动教学动作。 |
| 理解接续 | 保存的假设重开后可读；进入正式教学后可修订旧解释；来源版本、实际表现与原活动约束仍保留。 |
| 理解界面 | 聊天完成时刷新；组件卸载后停止监听；用户纠正沿现有保存路径。 |
| 后台画像 | 空闲门槛、退避重试、完成后不重复执行、模型请求期间释放用户锁、按账号归属画像。 |
| 持久恢复 | 通过真实聊天存储生成 8 个未审核回合；用户卸载后从队列恢复；释放整个服务并重开后，由宿主工作线程自动恢复中断任务。 |
| 真实传输与费用 | 本机 HTTP 模型服务先返回不合格抽取结果，再返回合法结果；两次实际模型调用均归属 A 的 memory_review 费用记录，最终任务完成并落盘。 |

## 已知问题与验证边界

- 理解仍由当前对话模型选择有依据的保存操作；没有强制每轮生成理解的独立后台分析器。无依据时保持未知。
- 扩展运行 `cargo test -p server mu --lib` 得到 139 通过、13 失败、5 忽略。与本项相关的 3 处测试问题已修正并定向通过；剩余 10 项未修改：8 项 MU4 在旧 `Fixture::seed_private` 直接重写事件存储历史时触发 `SESSION_EVENT_WRITE_REQUIRED`，2 项 MU10 仍从已经移入会话日志的 `turn.admission_input` 字段读取冻结输入。不能将本轮描述为全套回归全绿。
- 上述 MU4 夹具和 MU10 字段读取方式在本项改动前的基线源码中已存在；本次真实 HTTP 恢复和费用测试使用现有事件存储路径。
- 前端构建保留现有大体积资源包提示；组件测试保留 KaTeX 测试环境提示。未做真实在线模型的教学质量验收。
