# 统一问答与练习入口

决策（2026-11-15）：删除连续教学开关和普通对话的独立教学交付流程。

普通提问、追问、章节导读和接续均直接走正常问答。学习目标、实际用户表达、已交付回答和理解记录继续保存；旧开关及教学会话状态不再决定回答方式。练习由明确的练习入口或原题回应触发，保留题目、作答、提示、评分和历史记录；已配置课程保留自身进度。

实现：

- `crates/server/src/teaching.rs:freeze_prepare` 统一进入观察上下文；普通问答不再创建、恢复或切换自动教学阶段。旧目标只提供学习意图与约束。
- `crates/runtime/src/tutor.rs:requires_practice_delivery` 和 `orchestrator.rs` 将必须选定活动的条件限制在明确的活动请求。普通解释和原题反馈可以直接交付完整回答，不再因缺少 `tutor.step select` 丢弃答案并重试。
- `teaching.rs:prepare_observation`、`memory/src/teaching.rs:latest_chat_teaching_activity` 保留实际表达、回答、理解记录和原题身份；普通问题不会被尚未作答的练习接管。接续按当前对话、原回答和材料版本解析。
- 删除 `TutorControl.vue`，移除 App、RightRail、学习目标面板和手机预览中的开关、默认教学模式选择及自动启用请求。练习、学习记录、目标和接续沿用原入口。
- 旧开关事件继续可读，不再控制新请求；公开接口拒绝修改已移除的开关。无需改写历史学习数据。

回归与发布证据保存在 `tmp/unified-release-20261115/`。前端沿用现有页面布局，在 1440px、390px 与 320px 宽度下验证接续、练习、作答、学习记录和键盘布局；`ui-1440.png`、`ui-390.png` 为实际 App 截图。

后端回归覆盖旧开关开／关均使用正常问答、保留原始学习记录、接续和练习不依赖旧开关，以及完整解释不再触发教学选择重试。历史测试按新的产品行为改写，练习测试使用实际题目、私有答案与评分依据；跨对话原题接续保留原交付身份。

本轮同时处理的测试与故障：

- 部分脚本模型只识别旧教学提示词，导致后台任务持续等待。更新为普通问答的理解记录协议，保留任务完成和数据落盘断言。
- 网络停流测试将整个回合的 1 秒耗时误当作 150 毫秒传输超时。模拟服务现在持续保持响应体，直接验证客户端在服务端结束响应前超时，并验证资源释放及后续请求恢复。
- 32 MiB SSE 事件发布的时限测试在并行调试测试中争抢 CPU。保留原 5 秒发布断言，将该测试单独运行；其余服务器测试仍并行运行。
- Linux 回归补齐仓库已有的历史场景数据，并使用已安装的绘图 Python、语音转写 Python 和 Chrome；纸质文献锁测试改用仓库测试夹具，消除对开发机私有目录的依赖。
- TB5 历史记录测试直接定位同级 TB4 数据目录，修正 Linux 不能穿过不存在的中间目录解析 `../` 的问题；该处仅改变测试夹具路径，生产源代码未在完整回归后修改。
- 修复 `presentation_api.rs:save_state` 的实际错误分类问题：校验新内容时不再恢复旧状态。旧状态目录不可读时，由保存操作返回存储失败，不再误报公开内容非法。
