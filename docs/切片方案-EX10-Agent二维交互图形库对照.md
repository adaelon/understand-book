# EX10：原生 SVG 与 Konva 的 Agent 同题制作对照

日期：2026-09-28。状态：EX10.1–EX10.4 已完成；三批按停止条件提前结束，第三批 B/C 均保存交付页但质量不通过，C 最终回执不完整，保留 SVG、暂不接入 Konva。[最新第三批报告](performance/explorable-explanation-ex10-svg-konva-batch3-20260928.md)与[可操作入口](performance/ex10-svg-konva/index.html)已交付。原始证据见 [EX10 目录](performance/ex10-svg-konva/)。上位合同见[可探索解释方案](切片方案-可探索解释方法库与连续视觉演示.md)，决策见 [ADR-0139 §13](adr/0139-explorable-explanation.md#13-二维交互图形库对照)。

## 1. 目标与完成定义

验证给 Agent 提供 Konva 及最小使用资料后，是否比原生 SVG 更容易交付正确、可操作的二维解释，并减少必要的生成与修订成本。两组都通过实际 Resident 制作页面，最终直接交付可拖动参数、连续播放、暂停与回退的网页。

本刀交付两组全部产物、验证与成本记录，以及采用或保留原生 SVG 的结论。结果为负也可完成本切片；正式采用 Konva 需要通过第 7 节条件。EX9a 视频继续作为讲解编排参考。

术语沿用既有 presentation、页面结果读取与时间现场合同；SVG/Konva 是绘图实现选项，不新增领域对象。变更类型为纯技术实验。范围限二维学习率同题对照，生产方法仍为 ed3.v1；EX2 原批次和 EX7 的状态保持独立。

## 2. 固定任务与交互行为

两组使用下面同一条学习请求，实施时逐字保存到 `docs/performance/ex10-svg-konva/input.json`：

> 学习率大一点，为什么会来回跳，甚至越来越远？我想自己拖动学习率，马上看见每一步会走到哪里，也能播放、暂停和回到前一步。这里的简化材料是 L(w)=(w-2)^2，更新规则 w_{t+1}=w_t-2η(w_t-2)，初值 w_0=0；只在这个一维模型内解释。

这是在 EX0 题目上明确加入交互意图的新输入。请求不包含库名、实现代码或独立答案。技术条件由实验制作说明提供，不将本批冒充为 EX2 原始输入或自主选库实验。

两组收到相同的体验要求：同一线性尺度显示位置、真实更新箭头和端点残影；图形、数值和公式说明联动；覆盖 η=0.2/0.8/1.1，支持 η∈[0,1.2]、k=0…5。布局、强调顺序和讲解措辞由 Agent 制作。

```text
拖动 η -> 停止播放 -> 从 w0 重算 -> k=0、progress=0
       -> 立即显示新的第一步目标、更新箭头和数值
播放 / 拖动时间进度 -> 同一个 renderAt(k, progress, parameters)
暂停 / 回退 / 重开 -> 从保存的参数、k 与 progress 重建
```

改 η 沿用上位方案 §1 的重置约定，拖动中持续更新第一步预览，不等松手才生效。真实迭代和视觉插值分离；保存与追问沿用既有语义提交边界，高频视觉帧不逐帧保存。解释文字、公式和数值用可读取的 HTML 表达，绘图与文字读取同一计算结果。

## 3. 对照组与共同底座

| 项 | B：原生 SVG | C：Konva |
| --- | --- | --- |
| 图形路径 | 原生 SVG + JavaScript | 固定版本 Konva + JavaScript |
| 通用能力 | 相同 HTML 控件、公式表达、计算与现场合同 | 同左 |
| 使用资料 | 简短 SVG 接口说明与通用小例 | 同等任务覆盖的 Konva 接口说明与通用小例 |
| 示例范围 | 一个对象移动、一个参数联动、暂停/定位 | 同左 |
| 库装配 | 无附加图形库 | 测试装配嵌入固定版本库 |

共同底座为同一工作树快照、Resident/Server/Reader、工具 schema、来源校验、三视口、EX6 seek、read_selector 和模型配置；主方法正文保持 ed3.v1，两组追加相同体验合同及各自最小 API 资料。不加载 EX2 v7 候选。

示例使用与学习率无关的点/线运动，不给出本题实现、数值答案或预写讲解；两组资料完成后一起冻结，记录各自字节数和实际输入 tokens。不能只给 C 一套成熟讲解模板，再把差异归为库的收益。

本批处理变量是“图形库及必要使用资料”的完整制作组合。各组使用指定技术路径，验证 Agent 在该条件下制作页面的能力；库发现与自主选择不在本次结论中。资料长度、库加载及候选装配成本照实记录，不声称已分离渲染引擎的独立贡献。

## 4. 最小接入与先行验证

当前 `presentation.author` 要求自包含 HTML，Server preview 拒绝外部/未装配依赖，CSP 禁止联网；候选连同资产受现有 1 MiB 限制。Reader 虽能内联版本内脚本，现有 author 的 `asset_refs` 主要用于已生成 SVG，不能把安装 npm 包等同于模型已能使用它。

因此先实现 EX10 专用测试装配：模型输出固定的 Konva 库标记及自己的场景代码；宿主在 test-only Author Write 内部、候选校验和保存之前，把已选定版本的库原样内联进 HTML，最终候选保存实际库源码。B 走相同实验入口，无库标记替换。记录模型原始 HTML、装配后 HTML、库版本/来源/许可证与总字节数；模型不重抄库源码，重开不读取网络最新版本。

装配只识别本实验固定资源，不接受任意依赖路径。沿用现有校验和大小限制，不为本次对照放宽生产 CSP 或构建通用依赖管理器。若固定库加最小页面无法通过现有候选合同，记录具体缺口，停止后续模型采样并拆出必要的接入工作。

先行验证只用无题目答案的小场景：一个可拖动点与关联线段。检测库未加载、脚本顺序错误、三视口尺寸/触控失效，以及保存/重开后对象不重建；这些失败先在装配或示例内修复，再冻结正式批次。先行场景属于工程诊断，不计入 B/C 成功样本。

现有 preview 有 click/key/seek，尚无通用 drag 动作。本刀的真实鼠标/触屏拖动由已有浏览器测试入口执行，模型仍可用 HTML 控件的 key/click 和 seek 观察参数与中间场景；不把增设生产拖拽工具作为对照的前置工程。

## 6. 运行、验收与停止条件

每组 3 次独立会话，固定顺序 B1/C1/B2/C2/B3/C3。模型沿用 EX0 的 deepseek-v4-flash、temperature=0 及现有输出/运行时停止机制；实施时核对并写入实际配置。历史 B、EX1 和 EX9a 不充作本批样本。用户已取消的旧 tokens/墙钟拒绝上限不恢复；本批成本为实录比较项。

**正确性与图文一致性。** 用 EX0 独立闭式核对 η=0.2/0.8/1.1、k=0…5 的 w/e/L、`Δw=−2ηe`、步长 `2η|e|`；追加支持域内 η=0/0.5/1/1.2 的静止、一步到达、等幅振荡与发散检查。画面端点、箭头方向/长度和定量距离比例须与数值相符，模型最终解释也在核对范围内。SVG 测量真实图元，Konva 测量实际对象经变换后的几何并结合截图；只检查模型自己写出的数值对象不算图形通过。若模型保留更大可操作范围，一并检查其边界和末步。

**操作与播放。** 真实拖动 η 后，首步目标和公式随参数更新；播放、暂停、中间位置定位、回退再前进、改参清除旧轨迹均可复现。沿用 960×720 mouse、320×420 touch、640×240 touch，触控目标至少 44 CSS px。使用 EX5a 的五秒观察口径检查可见帧间隔和本地观察开销；发生停顿则区分绘图与宿主观察原因。三视口截图不能替代实际拖动和播放。

**状态与结果读取。** 暂停中间位置后保存、同版重开、追问应绑定相同参数与语义步骤；read_selector 返回的 HTML 读数与当前画面对应。Canvas 绘制不应令解释文字或来源脱离既有公开内容校验。

**停止。** 先行装配不通过就不启动采样；正式运行中，已交付的 C 出现正确性/必要交互失败、C 未交付或任一组 Provider/宿主异常时，完成该次失败记录后停止本批，不修改提示后补抽。模型在同一次会话内依据 preview 修订属于正常成本。B 的内容失败保留并完成对应 C；若 C 继续通过则按顺序运行。修复后建立新批次，旧样本保留原义。

**每次记录。** 首次 write 是否通过（质量按完整验收回看首稿）、首次可交互时间、模型请求次数、Provider tokens、总墙钟、write/preview/修订次数、Agent 场景代码量及最终交付。库本体字节数单列，完整候选大小也报告。全部必要预览/修订计入成本；没有返回的用量记未知。工程安装/资料准备/装配成本与模型生成成本分列。

## 7. 采用依据与交付

不设加权总分，按实际结果判断：

- **建议进入有限接入切片**：C 的 3 次均通过正确性、必要交互和状态合同；相对本批 B，在首次交付、修订负担、可操作表达或总成本中有重复出现的具体改善，并明确其余指标的代价。若仅一项更好而成本明显增加，报告权衡，不自动采用。
- **保持原生 SVG**：C 没有明确改善，或收益不足以抵消资源装配、回读/状态接入与维护成本。较少代码本身不能抵消数学或交互错误。
- **继续补证**：批次停止、样本不足或结论只来自单个成功页面；给出具体缺口和下一独立切片，不宣称稳定性已证明。

交付 B/C 全部已运行页面与可操作对照入口、原始证据、独立验证、成本报告和明确建议。若原始生成未交付而需手工修复供观看，另存并标明身份，不改写模型成功率。报告用户实际操作反馈；尚未取得时如实标记。读者学习收益另行评价。

## 8. 边界与资料

本刀不把 Konva 设成全部学科的统一绘图方式，不引入三维库、通用动画 DSL 或模板市场。生产默认能力及跨题推广由后续证据决定；EX2、EX7 的独立 Gate 继续有效。
