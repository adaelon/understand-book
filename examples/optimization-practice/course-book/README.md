# 最优化方法 I：复习讲义与历年考试题

当前交付采用“19 章讲解与精选课后习题 → 5 套完整试题 → 按年份参考解答”的结构。章末共精选 30 道练习，直接写出题干、条件和要求，保留学年、原题号及小问。第 1、10—12 章没有直接对应的试题，不安排空练习节。

## 当前稿件

- `chapters/`：19 章正文与 30 道课后习题全文，按“习题 章号.序号”编号。
- `preface.md`、`exam-guide.md`：使用说明、考纲与做题指引。
- `past-exams.md`：经扫描件逐页校对的 5 套试题，共 32 道大题，包含 2018—2019 学年的完整三页内容。
- `past-exam-answers.md`：32 道大题的参考解答。解答为整理推导，非官方评分答案；原题条件缺漏或笔误在相应题下说明。
- `exam-exercises.json`：试题元数据、原扫描 PDF 页码和 30 道章末精选习题的对应关系。整卷题目正文以 `past-exams.md` 为准；章末正文以 `chapters/` 为准。
- `questions.json`：构建时输出的考试题索引，含题目、解答、年份及章节对应。
- `sources.json`：正文来源及教材节号记录。
- `notes.md`：公式及适用条件说明。
- `build.py`、`typeset.tex`：合并 Markdown 与 PDF 排版。

旧的 `answers/`、`review-questions.md`、`review-answers.md`、`answer-preface.md` 和编程题材料保留为历史稿件，不参与当前输出。正文中用于讲解的例题保留。

## 生成文件

生成合并 Markdown 与题目索引：

```text
python examples/optimization-practice/course-book/build.py
```

同时生成合并 PDF（需要 Pandoc、XeLaTeX 和 Windows 中文字体）：

```text
python examples/optimization-practice/course-book/build.py --pdf
```

当前交付路径：

- `output/markdown/最优化方法I-复习讲义与习题解答.md`
- `output/pdf/最优化方法I-复习讲义与习题解答.pdf`

本次原 PDF 正被其他程序占用，最新的 112 页版本另存为 `output/pdf/最优化方法I-复习讲义与习题解答（完整课后习题版）.pdf`。

沿用合并文件名，正文标题为“复习讲义与历年考试题”。Markdown 使用普通标题和标题链接，不生成 HTML 锚点。构建会检查试题是否有对应解答、所选习题引用是否有效、链接是否有效、标题是否重复，以及是否残留旧练习表述。完整试卷中的题目不必全部选入章末。
