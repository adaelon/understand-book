## 选题约定

参考书的例题和练习题以课件原题为主，每讲的作业题完整收入并单列。可适量选用教材已有题目，并注明教材小节、题号或页码；不自行编题，不改动原题数值、条件和所求内容，不将原题自行改成选择题。

讲解可以补全原题已有解答省略的推导。提示和评分依据针对原题所求，不附加新的作答要求。若原材料有错误或条件不全，应明确说明，不能静默修改题目。

## 讲解写法

使用课件和教材的数学术语，用短句解释其含义。每一步先说明固定什么、计算什么，再写公式；公式后说明为什么能够得到下一步。字母首次出现时说明用途，减少不必要的缩写记号。保持直接的数学解释，不借助比喻或另拟题目。

基础讲解与教材补充分开呈现，条件放在实际使用结论的位置。通俗化不省略可行性、乘子范围、最优性或可微性条件。广告费例题先按课件的 KKT 条件求候选解，再利用预算等式配方核对最优性。
